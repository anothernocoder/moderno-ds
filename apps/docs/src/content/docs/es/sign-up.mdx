## Referencia de API

### Props

Los callbacks son props `on…` en React y Solid, en minúsculas (`onsubmit`) en Svelte y eventos (`submit`, `navigate`) en Vue.

| Prop          | Tipo                     | Por defecto     | Descripción                                                                             |
| ------------- | ------------------------ | --------------- | --------------------------------------------------------------------------------------- |
| `error`       | `string`                 | —               | No se pudo crear la cuenta: muestra la alerta del formulario.                           |
| `errors`      | `Record<string, string>` | —               | Mensajes por campo con clave `fullName`, `email` o `password`.                          |
| `loading`     | `boolean`                | `false`         | Envío en curso: todos los controles inertes, el botón ocupado.                          |
| `disabled`    | `boolean`                | `false`         | No se puede crear cuenta (beta cerrada, espacio solo por invitación).                   |
| `highlights`  | `SignUpHighlight[]`      | tres de ejemplo | Razones junto al formulario, como `{ id, title, description? }`. `[]` oculta el aparte. |
| `onSubmit`    | `(event) => void`        | —               | Envío nativo del formulario.                                                            |
| `onNavigate`  | `(to, event) => void`    | —               | Se pulsó un enlace de la pantalla: `home`, `signIn`, `privacy` o `terms`.               |
| `signInHref`  | `string`                 | `"#"`           | Destino de «Sign in», en la cabecera y en el pie de la tarjeta.                         |
| `homeHref`    | `string`                 | `"#"`           | Destino del logotipo.                                                                   |
| `privacyHref` | `string`                 | `"#"`           | Destino de los enlaces de privacidad.                                                   |
| `termsHref`   | `string`                 | `"#"`           | Destino de los enlaces de términos.                                                     |

### Estados

| Estado           | Props             | Qué se renderiza                                     |
| ---------------- | ----------------- | ---------------------------------------------------- |
| Por defecto      | —                 | La tarjeta con las razones al lado o debajo.         |
| Error            | `error`           | Una alerta de formulario; ningún campo marcado.      |
| Errores de campo | `errors`          | Cada campo nombrado inválido, con su propio mensaje. |
| Cargando         | `loading`         | Controles inertes, envío con `aria-busy`.            |
| Deshabilitado    | `disabled`        | El formulario se ve pero no se puede usar.           |
| Vacío            | `highlights={[]}` | Sin aparte; la tarjeta queda centrada y sola.        |

### Campos del formulario

| Nombre     | Control    | Se envía                                    |
| ---------- | ---------- | ------------------------------------------- |
| `fullName` | Texto      | Siempre.                                    |
| `email`    | Correo     | Siempre.                                    |
| `password` | Contraseña | Siempre, con `autocomplete="new-password"`. |
| `terms`    | Casilla    | Obligatoria; se envía al marcarla.          |

### Tamaño

| Paso del contenedor      | Cambio                                     |
| ------------------------ | ------------------------------------------ |
| `@sm` (`--container-sm`) | La cabecera pasa a una sola fila.          |
| `@md` (`--container-md`) | El pie pasa a una sola fila.               |
| `@lg` (`--container-lg`) | Las razones se colocan junto a la tarjeta. |

### Composición

| Parte                        | Papel                                                                   |
| ---------------------------- | ----------------------------------------------------------------------- |
| [LoginForm](/es/login-form/) | La tarjeta de credenciales, en modo `sign-up`, con `titleLevel={1}`.    |
| Aparte de razones            | Lo dibuja la propia pantalla, bajo el título «What you get on day one». |

## Notas

- Presentacional: sin petición, sin router, sin lógica de cuentas. Los pone la página que la monta.
- Los enlaces de inicio de sesión, términos y privacidad son `href` normales, así que el texto legal abre antes de hidratar.
- A diferencia del inicio de sesión, un registro puede nombrar con `errors` el campo que rechazó.
- `onNavigate` entrega el evento del clic: ignora los clics con `metaKey`/`ctrlKey` y luego `preventDefault()` para enrutar.
- La raíz es un `<div>`, no un `<main>`. Conviértela en tu `<main>` si la ruta no tiene uno.
- La pantalla importa su bloque desde `@/components/blocks/…`; cambia esa línea si tu alias es otro.
