## Referencia de la API

### Props

| Prop       | Tipo                                                       | Por defecto          | Descripción                                                                              |
| ---------- | ---------------------------------------------------------- | -------------------- | ---------------------------------------------------------------------------------------- |
| `website`  | `string`                                                   | `"acme.shop"`        | La dirección de la tienda tras el prefijo `https://`.                                    |
| `price`    | `string`                                                   | `"49.00"`            | El importe entre el prefijo `$` y el sufijo `USD`.                                       |
| `apiKey`   | `string`                                                   | una clave de muestra | La clave de solo lectura junto a Copy. `""` muestra `No key yet` y deshabilita Copy.     |
| `query`    | `string`                                                   | `""`                 | El texto de búsqueda junto al botón Search.                                              |
| `errors`   | `Partial<Record<"website" \| "price" \| "query", string>>` | —                    | Un mensaje por campo no válido, bajo el campo.                                           |
| `loading`  | `boolean`                                                  | `false`              | Hay una búsqueda en curso: todo control queda deshabilitado y Search muestra un spinner. |
| `disabled` | `boolean`                                                  | `false`              | Todos los campos y botones quedan deshabilitados.                                        |
| `onCopy`   | `(apiKey: string) => void`                                 | —                    | Se pulsó Copy. Svelte: `oncopy`. Vue: `@copy`.                                           |
| `onSearch` | `(query: string) => void`                                  | —                    | Se envió la búsqueda. Svelte: `onsearch`. Vue: `@search`.                                |

### Grupos

| Grupo          | Adjuntos                  | Nombre del campo |
| -------------- | ------------------------- | ---------------- |
| Store address  | `https://` delante        | `website`        |
| Price          | `$` delante, `USD` detrás | `price`          |
| API key        | un botón Copy detrás      | `apiKey`         |
| Find a product | un botón Search detrás    | `query`          |

### Estados

| Estado        | Prop                       | Qué se muestra                                                       |
| ------------- | -------------------------- | -------------------------------------------------------------------- |
| Por defecto   | —                          | Los cuatro grupos con valores de muestra.                            |
| Vacío         | `website=""`, `apiKey=""`… | Textos de ejemplo en cada campo, y Copy deshabilitado.               |
| Cargando      | `loading`                  | Todo control deshabilitado; Search muestra un spinner y `Searching`. |
| Error         | `errors`                   | Campos y adjuntos en rojo, cada uno con su mensaje debajo.           |
| Deshabilitado | `disabled`                 | Todos los campos y botones deshabilitados.                           |

El hover y el foco de teclado vienen de las primitivas Field y Button.

### Tamaño

| Paso del contenedor      | Qué cambia                                                         |
| ------------------------ | ------------------------------------------------------------------ |
| bajo `@sm`               | Una columna: cada grupo bajo el anterior.                          |
| `@sm` (`--container-sm`) | Más espacio entre el título y los grupos, y entre los grupos.      |
| `@md` (`--container-md`) | El título sube un tamaño, y los grupos van de dos en dos por fila. |
| `@lg` (`--container-lg`) | El título va en una columna junto a los grupos, de un tercio.      |
