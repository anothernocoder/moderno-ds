## Uso

<ForFramework fw="react">

```tsx

const points = [
  { x: 0, y: 12 },
  { x: 1, y: 18 },
  { x: 2, y: 15 },
];
```

```tsx
<SparkChart points={points} aria-label="Ingresos, últimas 3 semanas" />
```

El gráfico ocupa el ancho de su contenedor. `width` y `height` solo fijan su proporción.

## Referencia de API

### SparkChart

<PropsTable component="SparkChart" />

### Valores por defecto

| Prop            | Por defecto                                         |
| --------------- | --------------------------------------------------- |
| `width`         | `120`                                               |
| `height`        | `32`                                                |
| `yDomain`       | Del valor y más bajo al más alto (sin forzar el 0). |
| `curve`         | Segmentos rectos                                    |
| `area`          | `false`                                             |
| `showLastPoint` | `false`                                             |

### Atributos de datos

| Atributo      | En              | Valores                                              |
| ------------- | --------------- | ---------------------------------------------------- |
| `data-chart`  | `svg` raíz      | `spark`                                              |
| `data-part`   | Cada elemento   | `root`, `series`, `area`, `line`, `point`            |
| `data-series` | `g` de la serie | Siempre `0`, así cada forma se pinta con `--chart-1` |

## Notas

- No hay ejes, cuadrícula ni etiquetas. Da a cada gráfico un `aria-label`.
- No hay prop de color: la línea, el relleno y el marcador se pintan con `--chart-1`.
- Para comparar varios minigráficos, pásales el mismo `yDomain`.
