## Referencia de la API

### Props

| Prop             | Tipo             | Por defecto               | Descripción                                                                              |
| ---------------- | ---------------- | ------------------------- | ---------------------------------------------------------------------------------------- |
| `kicker`         | `string`         | `"Blog"`                  | Una línea corta sobre el título; `""` la oculta.                                         |
| `title`          | `string`         | `"Notes from the ledger"` | El `h1` de la página. Va en la fuente con serifa.                                        |
| `description`    | `string`         | una frase                 | Una frase bajo el título; `""` la oculta.                                                |
| `categories`     | `BlogCategory[]` | seis categorías           | Un chip por categoría, en orden. `[]` muestra el mensaje de vacío.                       |
| `activeCategory` | `string`         | `"all"`                   | El `id` de la categoría actual. Su chip va relleno.                                      |
| `error`          | `string`         | —                         | Falló la carga de las categorías; un Alert de error con reintento las reemplaza.         |
| `loading`        | `boolean`        | `false`                   | Chips de marcador en una región ocupada reemplazan las categorías.                       |
| `disabled`       | `boolean`        | `false`                   | Los chips se quedan; cada enlace de categoría queda inerte y el reintento deshabilitado. |
| `onRetry`        | `() => void`     | —                         | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                              |

### BlogCategory

| Campo   | Tipo     | Descripción                                       |
| ------- | -------- | ------------------------------------------------- |
| `id`    | `string` | Una clave estable, la que busca `activeCategory`. |
| `label` | `string` | El texto del chip, como `"Product"`.              |
| `href`  | `string` | La página de la categoría.                        |

### Estados

| Estado        | Prop              | Qué se muestra                                                               |
| ------------- | ----------------- | ---------------------------------------------------------------------------- |
| Por defecto   | —                 | Antetítulo, título, descripción y un chip por categoría.                     |
| Vacío         | `categories={[]}` | Antetítulo, título, descripción y "No categories yet."                       |
| Cargando      | `loading`         | Antetítulo, título, descripción y cinco chips de marcador.                   |
| Error         | `error`           | Antetítulo, título, descripción y después un Alert de error con "Try again". |
| Deshabilitado | `disabled`        | Los mismos chips con cada enlace de categoría inerte.                        |

### Tamaño

| Paso del contenedor      | Qué cambia                                            |
| ------------------------ | ----------------------------------------------------- |
| bajo `@sm`               | El título y la descripción más pequeños.              |
| `@sm` (`--container-sm`) | La descripción sube un tamaño.                        |
| `@md` (`--container-md`) | El título sube un tamaño, y los chips se separan más. |
| `@lg` (`--container-lg`) | Más espacio arriba y abajo, y entre las partes.       |

## Notas

- Deja el antetítulo en una o dos palabras, como el nombre del blog.
- Pon "All posts" primero, para que el lector siempre pueda volver a todas las entradas.
