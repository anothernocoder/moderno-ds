## Uso

Tags Input es un campo de texto que convierte lo que escribe el usuario en etiquetas. Úsalo para una lista corta de valores libres, como palabras clave o temas. Enter o una coma añade una etiqueta; la × de una etiqueta la quita.

<ForFramework fw="react">

```tsx
import { TagsInput } from "@moderno-ui/react";
```

```tsx
<TagsInput.Root value={tags} onValueChange={(details) => setTags(details.value)}>
  <TagsInput.Label>Frameworks</TagsInput.Label>
  <TagsInput.Control>
    <TagsInput.Context>
      {(tagsInput) =>
        tagsInput.value.map((value, index) => (
          <TagsInput.Item key={index} index={index} value={value}>
            <TagsInput.ItemPreview>
              <TagsInput.ItemText>{value}</TagsInput.ItemText>
              <TagsInput.ItemDeleteTrigger>×</TagsInput.ItemDeleteTrigger>
            </TagsInput.ItemPreview>
            <TagsInput.ItemInput />
          </TagsInput.Item>
        ))
      }
    </TagsInput.Context>
    <TagsInput.Input placeholder="Añade un framework" />
  </TagsInput.Control>
</TagsInput.Root>
```

</ForFramework>

El valor es una lista de textos, como `["React", "Vue"]`. `TagsInput.Context` te la pasa para que dibujes un item por etiqueta.

## Referencia de la API

### TagsInput.Root

`size` es el añadido de Moderno; todas las partes lo siguen. El resto de props vienen del TagsInput de Ark.

<PropsTable component="TagsInput" />

| Prop              | Tipo                                                             | Por defecto | Descripción                                                           |
| ----------------- | ---------------------------------------------------------------- | ----------- | --------------------------------------------------------------------- |
| `value`           | `string[]`                                                       | —           | Etiquetas controladas.                                                |
| `defaultValue`    | `string[]`                                                       | `[]`        | Etiquetas al principio, sin control.                                  |
| `onValueChange`   | `(details: { value: string[] }) => void`                         | —           | Se llama al añadir, editar o quitar una etiqueta.                     |
| `inputValue`      | `string`                                                         | —           | Texto controlado del input.                                           |
| `max`             | `number`                                                         | `Infinity`  | El máximo de etiquetas. Pasado ese número, rechaza una nueva.         |
| `allowOverflow`   | `boolean`                                                        | `false`     | Acepta etiquetas por encima de `max` y marca el campo como erróneo.   |
| `delimiter`       | `string \| RegExp`                                               | `","`       | La tecla que añade una etiqueta, y lo que separa el texto pegado.     |
| `addOnPaste`      | `boolean`                                                        | `false`     | Convierte el texto pegado en etiquetas, separadas por el delimitador. |
| `blurBehavior`    | `"add" \| "clear"`                                               | —           | Qué pasa con el texto escrito cuando el input pierde el foco.         |
| `editable`        | `boolean`                                                        | `true`      | Deja editar una etiqueta con doble clic o Enter.                      |
| `allowDuplicates` | `boolean`                                                        | `false`     | Acepta una etiqueta que ya está en la lista.                          |
| `validate`        | `(details: { inputValue: string; value: string[] }) => boolean`  | —           | Devuelve `false` para rechazar una etiqueta.                          |
| `onValueInvalid`  | `(details: { reason: "rangeOverflow" \| "invalidTag" }) => void` | —           | Se llama cuando `validate` rechaza una etiqueta, o se pasa de `max`.  |
| `maxLength`       | `number`                                                         | —           | El máximo de caracteres de una etiqueta.                              |
| `disabled`        | `boolean`                                                        | `false`     | Atenúa el campo e ignora la entrada.                                  |
| `readOnly`        | `boolean`                                                        | `false`     | Muestra las etiquetas pero ignora la entrada.                         |
| `invalid`         | `boolean`                                                        | —           | Marca las etiquetas como erróneas.                                    |
| `required`        | `boolean`                                                        | `false`     | Marca el campo como obligatorio en un formulario.                     |
| `name`            | `string`                                                         | —           | El nombre de campo del input oculto.                                  |

En Vue, enlaza el valor con `:model-value` o `v-model`, y escucha con `@value-change`.

### Partes

| Parte                         | Elemento   | Descripción                                                               |
| ----------------------------- | ---------- | ------------------------------------------------------------------------- |
| `TagsInput.Root`              | `<div>`    | Lleva `data-size`.                                                        |
| `TagsInput.Label`             | `<label>`  | Opcional. Nombra el campo. Al pulsarla, enfoca el input.                  |
| `TagsInput.Control`           | `<div>`    | La caja con borde. Contiene las etiquetas y el input.                     |
| `TagsInput.Item`              | `<div>`    | Una etiqueta. Recibe `index` y `value`.                                   |
| `TagsInput.ItemPreview`       | `<div>`    | El chip de la etiqueta. Con doble clic se edita.                          |
| `TagsInput.ItemText`          | `<span>`   | El texto de la etiqueta.                                                  |
| `TagsInput.ItemDeleteTrigger` | `<button>` | Quita la etiqueta. Ark le pone nombre para los lectores de pantalla.      |
| `TagsInput.ItemInput`         | `<input>`  | Sustituye al chip mientras se edita la etiqueta.                          |
| `TagsInput.Input`             | `<input>`  | El campo de texto. Enter o el delimitador convierte el texto en etiqueta. |
| `TagsInput.ClearTrigger`      | `<button>` | Opcional. Quita todas las etiquetas. Se oculta si no hay ninguna.         |
| `TagsInput.HiddenInput`       | `<input>`  | Opcional. Envía las etiquetas con un formulario.                          |
| `TagsInput.Context`           | —          | Te pasa las etiquetas como `value`, para dibujar un item por cada una.    |

### Atributos data

| Atributo           | Valores                                                               |
| ------------------ | --------------------------------------------------------------------- |
| `data-focus`       | Mientras el campo tiene el foco, en la raíz y la caja                 |
| `data-invalid`     | Cuando las etiquetas son erróneas, en la raíz, etiqueta, caja e input |
| `data-disabled`    | Con `disabled`, en todas las partes                                   |
| `data-readonly`    | Con `readOnly`, en la raíz, la etiqueta, la caja y el input           |
| `data-empty`       | Mientras no hay etiquetas, en la raíz y el input                      |
| `data-highlighted` | En la etiqueta elegida con las flechas                                |
| `data-size`        | En la raíz: `"sm"`, `"md"` o `"lg"`                                   |

## Notas

- `TagsInput.Root` está envuelto para añadir `size`; el resto de partes son las de Ark sin cambios.
- El teclado: las flechas izquierda y derecha se mueven entre etiquetas, Retroceso o Suprimir quita la resaltada, Enter la edita y Escape cancela la edición.
- Los botones de quitar no entran en el orden de tabulación; Retroceso hace lo mismo desde el input.
