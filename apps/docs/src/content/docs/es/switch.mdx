## Uso

Un switch activa o desactiva un ajuste, y el cambio se aplica al instante. Úsalo para preferencias, no para respuestas que se envían con un formulario.

<ForFramework fw="react">

```tsx
import { Switch } from "@moderno-ui/react";
```

```tsx
<Switch.Root>
  <Switch.Control>
    <Switch.Thumb />
  </Switch.Control>
  <Switch.Label>Notificaciones por correo</Switch.Label>
  <Switch.HiddenInput />
</Switch.Root>
```

</ForFramework>

## Referencia de API

### Switch.Root

`size` es el añadido de Moderno y vale `md` por defecto; el resto de props vienen del Switch de Ark.

<PropsTable component="Switch" />

| Prop              | Tipo                             | Por defecto | Descripción                                                |
| ----------------- | -------------------------------- | ----------- | ---------------------------------------------------------- |
| `checked`         | `boolean`                        | —           | Estado controlado. Úsalo con `onCheckedChange`.            |
| `defaultChecked`  | `boolean`                        | `false`     | Estado inicial cuando no está controlado.                  |
| `onCheckedChange` | `(details: { checked }) => void` | —           | Se llama cuando el switch se activa o se desactiva.        |
| `disabled`        | `boolean`                        | `false`     | Deshabilita el input oculto y atenúa todas las partes.     |
| `invalid`         | `boolean`                        | `false`     | Pone `aria-invalid` y rodea el riel con `--destructive`.   |
| `readOnly`        | `boolean`                        | `false`     | Muestra el estado pero ignora los clics.                   |
| `required`        | `boolean`                        | `false`     | Marca el input como obligatorio.                           |
| `name`            | `string`                         | —           | Nombre del campo en el formulario.                         |
| `value`           | `string`                         | `"on"`      | Valor que se envía con el formulario cuando está activado. |

### Partes

| Parte                | Elemento                  | Descripción                                                                                    |
| -------------------- | ------------------------- | ---------------------------------------------------------------------------------------------- |
| `Switch.Root`        | `<label>`                 | Lleva `data-size`; un clic en cualquier punto alterna el switch.                               |
| `Switch.Control`     | `<span>`                  | El riel.                                                                                       |
| `Switch.Thumb`       | `<span>`                  | La perilla dentro del riel; se desliza al otro extremo cuando está activado.                   |
| `Switch.Label`       | `<span>`                  | El texto junto al riel.                                                                        |
| `Switch.HiddenInput` | `<input type="checkbox">` | Input nativo oculto con `role="switch"`; lleva el foco, `name` y `value`. Renderízalo siempre. |

### Atributos data

| Atributo        | Valores                                          |
| --------------- | ------------------------------------------------ |
| `data-state`    | `"checked"` o `"unchecked"`, en todas las partes |
| `data-disabled` | Presente con `disabled`                          |
| `data-invalid`  | Presente con `invalid`                           |
| `data-readonly` | Presente con `readOnly`                          |
| `data-size`     | En la raíz: `"sm"`, `"md"` o `"lg"`              |

## Notas

- `Switch.Root` está envuelto para añadir `size`, y `Switch.HiddenInput` para añadir `role="switch"`; el resto de partes son las de Ark sin cambios.
- Estiliza el estado desde `data-state` y los atributos `data-*`; `size` es la única prop visual.
- La perilla se desliza con `margin-inline-start`, así que se mueve al revés en páginas de derecha a izquierda.
- Switch reemplaza al Toggle del predecesor.
