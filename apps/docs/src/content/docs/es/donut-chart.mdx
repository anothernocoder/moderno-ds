## Referencia de la API

### DonutChart

<PropsTable component="DonutChart" />

### Data

Cada entrada de `data` es una porción.

| Campo   | Tipo     | Descripción                                                  |
| ------- | -------- | ------------------------------------------------------------ |
| `name`  | `string` | Etiqueta opcional de la porción.                             |
| `value` | `number` | Su parte del total. Un valor de 0 o menos no dibuja porción. |

### Valores por defecto

| Prop          | Por defecto                           |
| ------------- | ------------------------------------- |
| `innerRadius` | `0.6` (el hueco es el 60% del anillo) |
| `padAngle`    | `0` (las porciones se tocan)          |

### Atributos de datos

| Atributo      | En              | Valores                                                                  |
| ------------- | --------------- | ------------------------------------------------------------------------ |
| `data-chart`  | `svg` raíz      | `donut`                                                                  |
| `data-part`   | Cada elemento   | `root`, `series`, `slice`                                                |
| `data-series` | `g` de la serie | El índice de la porción en `data`, asignado de `--chart-1` a `--chart-5` |

## Notas

- Las porciones empiezan a las 12 en punto y siguen el sentido del reloj, en el orden de `data`.
- No hay prop de color: las porciones se pintan de `--chart-1` a `--chart-5` por índice. La sexta porción y las siguientes vuelven a `--chart-1`.
- El gráfico ocupa el ancho de su contenedor. Dale tamaño con CSS en un contenedor o con una `class`.
- Dale un `aria-label`: para un lector de pantalla el gráfico es una sola imagen.
- La geometría viene de `@moderno-ui/charts-core`, matemática pura sin DOM, así se renderiza en el servidor.
