## Referencia de API

### Menu.Root

<PropsTable component="Menu" />

El resto de props vienen del Menu de Ark. Las que más usarás:

| Prop            | Tipo                                   | Por defecto | Descripción                                                         |
| --------------- | -------------------------------------- | ----------- | ------------------------------------------------------------------- |
| `onSelect`      | `(details: { value: string }) => void` | —           | Se llama cuando el usuario elige una opción, con su `value`.        |
| `open`          | `boolean`                              | —           | Estado abierto controlado. Actualízalo desde `onOpenChange`.        |
| `defaultOpen`   | `boolean`                              | `false`     | Abierto al inicio, sin control.                                     |
| `onOpenChange`  | `(details: { open: boolean }) => void` | —           | Se llama cuando el menú se abre o se cierra.                        |
| `closeOnSelect` | `boolean`                              | `true`      | Cerrar el menú cuando el usuario elige una opción.                  |
| `positioning`   | `PositioningOptions`                   | —           | Dónde se abre el menú, por ejemplo `{ placement: "bottom-start" }`. |

En Vue, escucha con `@select` y `@open-change`, y enlaza con `v-model:open`.

### Partes

| Parte                 | Elemento   | Descripción                                                                   |
| --------------------- | ---------- | ----------------------------------------------------------------------------- |
| `Menu.Root`           | —          | Guarda el estado. Recibe `size` y las props de Ark. No pinta ningún elemento. |
| `Menu.Trigger`        | `<button>` | Abre y cierra el menú. Lleva `data-size`.                                     |
| `Menu.Indicator`      | `<div>`    | Opcional. Una flecha en el botón que gira mientras está abierto.              |
| `Menu.ContextTrigger` | `<button>` | Opcional. Una zona que abre el menú con clic derecho o pulsación larga.       |
| `Menu.Positioner`     | `<div>`    | Coloca el menú. Envuélvelo en `Portal`.                                       |
| `Menu.Content`        | `<div>`    | La superficie del menú. Lleva `data-size`.                                    |
| `Menu.Item`           | `<div>`    | Una acción. Recibe un `value` único, y `disabled`.                            |
| `Menu.ItemGroup`      | `<div>`    | Agrupa opciones bajo una etiqueta.                                            |
| `Menu.ItemGroupLabel` | `<div>`    | El nombre del grupo.                                                          |
| `Menu.Separator`      | `<hr>`     | Una línea entre grupos.                                                       |
| `Menu.CheckboxItem`   | `<div>`    | Una opción que se activa y desactiva. Recibe `checked`.                       |
| `Menu.RadioItemGroup` | `<div>`    | Agrupa opciones de radio. Recibe `value`.                                     |
| `Menu.RadioItem`      | `<div>`    | Una elección de un grupo de radio.                                            |
| `Menu.ItemText`       | `<div>`    | La etiqueta de una opción marcable.                                           |
| `Menu.ItemIndicator`  | `<div>`    | Se ve mientras una opción marcable está marcada.                              |
| `Menu.TriggerItem`    | `<div>`    | Una opción que abre un submenú.                                               |
| `Menu.Arrow`          | `<div>`    | Opcional. Apunta al botón. Contiene `Menu.ArrowTip`.                          |

### Atributos data

| Atributo           | En                         | Valores                                   |
| ------------------ | -------------------------- | ----------------------------------------- |
| `data-size`        | Trigger, Content           | `sm`, `md` (por defecto), `lg`            |
| `data-state`       | Trigger, Content           | `open`, `closed`                          |
| `data-state`       | Opción de checkbox o radio | `checked`, `unchecked`                    |
| `data-highlighted` | Item                       | Presente en la opción resaltada           |
| `data-disabled`    | Item                       | Presente cuando la opción está `disabled` |

## Notas

- En una pantalla de menos de 40rem, el menú abierto es una hoja inferior: baja al pie de la pantalla sobre la página atenuada. Un toque en la página atenuada lo cierra.
- `Menu.Root`, `Menu.Trigger` y `Menu.Content` están envueltos para añadir `size`. El resto de partes son las de Ark.
- Un submenú toma el tamaño de su menú padre, salvo que le des uno propio.
- Las flechas mueven el resaltado, escribir salta a una opción y Escape cierra el menú.
