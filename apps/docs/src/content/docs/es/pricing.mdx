Cada plan es un objeto simple:

```ts
const plans = [
  {
    id: "pro",
    name: "Pro",
    price: "29 $",
    period: "/mes",
    description: "Para equipos pequeños que facturan cada semana.",
    features: ["Conexiones bancarias ilimitadas", "Control de horas", "Soporte por correo"],
    action: "Empezar la prueba gratis",
    highlighted: true,
    badge: "El más elegido",
  },
];
```

## Referencia de la API

### Props

| Prop          | Tipo                   | Por defecto                     | Descripción                                                                                |
| ------------- | ---------------------- | ------------------------------- | ------------------------------------------------------------------------------------------ |
| `title`       | `string`               | `"Pricing that grows with you"` | El título de la sección, con la tipografía con serifa.                                     |
| `description` | `string`               | una frase                       | Una o dos frases bajo el título; `""` la oculta.                                           |
| `plans`       | `PricingPlan[]`        | tres planes de ejemplo          | Los planes que se comparan, en orden. `[]` muestra el mensaje de vacío.                    |
| `error`       | `string`               | —                               | Falló la carga de los planes; un Alert de error con reintento los sustituye.               |
| `loading`     | `boolean`              | `false`                         | Tarjetas de esqueleto en una región ocupada sustituyen a los planes.                       |
| `disabled`    | `boolean`              | `false`                         | Los planes se quedan y todos los botones se deshabilitan.                                  |
| `onSelect`    | `(id: string) => void` | —                               | Se pulsó el botón de un plan, con el `id` de ese plan. Svelte: `onselect`. Vue: `@select`. |
| `onRetry`     | `() => void`           | —                               | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                                |

### PricingPlan

| Campo         | Tipo       | Descripción                                                     |
| ------------- | ---------- | --------------------------------------------------------------- |
| `id`          | `string`   | Lo que recibe `onSelect`.                                       |
| `name`        | `string`   | El nombre del plan, el título de la tarjeta.                    |
| `price`       | `string`   | El importe tal como quieres mostrarlo, con la moneda: `"29 $"`. |
| `period`      | `string?`  | Se muestra tras el precio en texto atenuado: `"/mes"`.          |
| `description` | `string?`  | Una línea bajo el nombre.                                       |
| `features`    | `string[]` | Lo que incluye el plan, con una marca de verificación cada uno. |
| `action`      | `string`   | La etiqueta del botón.                                          |
| `highlighted` | `boolean?` | El plan recomendado: un borde --primary y el botón principal.   |
| `badge`       | `string?`  | Una etiqueta corta junto al nombre, como `"El más elegido"`.    |

### Estados

| Estado        | Prop       | Qué se muestra                                                          |
| ------------- | ---------- | ----------------------------------------------------------------------- |
| Por defecto   | —          | Título, descripción y una tarjeta por plan, con la destacada remarcada. |
| Vacío         | `plans=[]` | Título, descripción y un mensaje "No plans to show yet".                |
| Cargando      | `loading`  | Título, descripción y tres tarjetas de marcador.                        |
| Error         | `error`    | Título, descripción y un Alert de error con "Try again".                |
| Deshabilitado | `disabled` | Los mismos planes con todos los botones deshabilitados.                 |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------- |
| bajo `@sm`               | Los planes se apilan, una función por línea.                                        |
| `@sm` (`--container-sm`) | Los planes siguen apilados; cada uno reparte sus funciones en dos columnas.         |
| `@md` (`--container-md`) | Los planes van uno junto a otro, una función por línea, y el título sube un tamaño. |
| `@lg` (`--container-lg`) | Más espacio arriba y abajo del bloque y entre los planes.                           |

## Notas

- Destaca un plan como mucho. Dos planes destacados se anulan entre sí.
- Mantén cada lista de funciones corta y en el mismo orden en todos los planes, para que se puedan comparar línea a línea.
