<Install pkg="@moderno-ui/react" />

## Uso

Usa un color picker cuando el usuario elige un color, como el color de una marca. El botón muestra el color y su hex. Abre un panel con un área, deslizadores y una caja para el hex.

<ForFramework fw="react">

```tsx
import { ColorPicker } from "@moderno-ui/react";
```

```tsx
<ColorPicker defaultValue="#1E90FF" onValueChange={(details) => save(details.value)} />
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { ColorPicker } from "@moderno-ui/vue";
```

```vue
<ColorPicker v-model="color" />
```

</ForFramework>

<ForFramework fw="svelte">

```ts
import { ColorPicker } from "@moderno-ui/svelte";
```

```svelte
<ColorPicker bind:value={color} />
```

</ForFramework>

<ForFramework fw="solid">

```tsx
import { ColorPicker } from "@moderno-ui/solid";
```

```tsx
<ColorPicker defaultValue="#1E90FF" onValueChange={(details) => save(details.value)} />
```

</ForFramework>

El valor es un hex: `#RRGGBB`, o `#RRGGBBAA` cuando el color es transparente.

## Referencia de API

### ColorPicker

<PropsTable component="ColorPicker" />

También acepta estas props del ColorPicker de Ark:

| Prop            | Tipo                          | Por defecto | Descripción                                                                |
| --------------- | ----------------------------- | ----------- | -------------------------------------------------------------------------- |
| `open`          | `boolean`                     | —           | Estado abierto controlado. Úsalo con `onOpenChange`.                       |
| `defaultOpen`   | `boolean`                     | `false`     | Estado abierto inicial cuando no está controlado.                          |
| `onOpenChange`  | `(details: { open }) => void` | —           | Se llama cuando el panel se abre o se cierra.                              |
| `closeOnSelect` | `boolean`                     | `false`     | Cierra el panel al elegir una muestra.                                     |
| `disabled`      | `boolean`                     | `false`     | Desactiva el selector.                                                     |
| `readOnly`      | `boolean`                     | `false`     | Muestra el color, pero el usuario no puede cambiarlo.                      |
| `invalid`       | `boolean`                     | `false`     | Marca el valor como incorrecto: el borde del botón pasa a `--destructive`. |
| `positioning`   | `PositioningOptions`          | —           | Dónde va el panel: `placement` (`"bottom-start"`), `gutter`, `flip`, …     |

En Vue, enlaza el valor con `v-model` y escucha con `@value-change`. En Svelte, usa `bind:value`.

### Partes

| Parte                  | Elemento   | Descripción                                                           |
| ---------------------- | ---------- | --------------------------------------------------------------------- |
| `root`                 | `<div>`    | Contiene el botón y el panel. Lleva `data-size`.                      |
| `trigger`              | `<button>` | Abre el panel. Muestra la muestra de color y el hex.                  |
| `swatch`               | `<div>`    | Una muestra de color, sobre un tablero de ajedrez si es transparente. |
| `value-text`           | `<span>`   | El hex, dentro del botón.                                             |
| `content`              | `<div>`    | El panel, `role="dialog"`.                                            |
| `area`                 | `<div>`    | Saturación (a lo ancho) y brillo (a lo alto).                         |
| `area-thumb`           | `<div>`    | El control 2D del área, llamado "Saturation and brightness".          |
| `channel-slider`       | `<div>`    | Un deslizador. `data-channel="hue"`, o `"alpha"` con `alpha`.         |
| `channel-slider-thumb` | `<div>`    | El control del deslizador, llamado "Hue" o "Alpha".                   |
| `hex-input`            | `<input>`  | La caja del hex.                                                      |
| `eye-dropper-trigger`  | `<button>` | Toma un color de la pantalla. Solo donde el navegador puede.          |
| `swatch-group`         | `<div>`    | Las muestras predefinidas.                                            |
| `swatch-trigger`       | `<button>` | Una muestra. `data-state="checked"` cuando es el valor.               |

### Teclado

| Tecla                   | Acción                                                                |
| ----------------------- | --------------------------------------------------------------------- |
| `Enter` / `Space`       | En el botón, abre el panel.                                           |
| `Arrow keys`            | En el área, cambian saturación y brillo. En un deslizador, lo mueven. |
| `Page Up` / `Page Down` | Mueven con un paso más grande.                                        |
| `Home` / `End`          | En un deslizador, van al inicio o al final.                           |
| `Enter`                 | En la caja del hex, toma el hex escrito.                              |
| `Esc`                   | Cierra el panel y lleva el foco al botón.                             |

## Notas

- La caja del hex acepta `#RGB`, `#RRGGBB` o `#RRGGBBAA`, con o sin `#`. Un hex no válido se descarta cuando la caja pierde el foco.
- El cuentagotas solo aparece en navegadores con la API EyeDropper.
- Traduce los nombres de las partes para un lector de pantalla con `translations`, por ejemplo `{ hue: "Tono" }`.
