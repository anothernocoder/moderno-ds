## Referencia de API

### Checkbox.Root

`size` es el añadido de Moderno y vale `md` por defecto; el resto de props vienen del Checkbox de Ark.

<PropsTable component="Checkbox" />

| Prop              | Tipo                             | Por defecto | Descripción                                                     |
| ----------------- | -------------------------------- | ----------- | --------------------------------------------------------------- |
| `checked`         | `boolean \| "indeterminate"`     | —           | Estado controlado. Úsalo con `onCheckedChange`.                 |
| `defaultChecked`  | `boolean \| "indeterminate"`     | `false`     | Estado inicial cuando no está controlado.                       |
| `onCheckedChange` | `(details: { checked }) => void` | —           | Se llama cuando cambia el estado.                               |
| `disabled`        | `boolean`                        | `false`     | Deshabilita el input oculto y atenúa todas las partes.          |
| `invalid`         | `boolean`                        | `false`     | Pone `aria-invalid` y recolorea el borde desde `--destructive`. |
| `required`        | `boolean`                        | `false`     | Marca el input como obligatorio.                                |
| `name`            | `string`                         | —           | Nombre del campo en el formulario.                              |
| `value`           | `string`                         | `"on"`      | Valor que se envía con el formulario cuando está marcada.       |

### Checkbox.Indicator

| Prop            | Tipo      | Por defecto | Descripción                                                     |
| --------------- | --------- | ----------- | --------------------------------------------------------------- |
| `indeterminate` | `boolean` | `false`     | Muestra este indicador en el estado mixto en lugar del marcado. |

### Partes

| Parte                  | Elemento                  | Descripción                                                                   |
| ---------------------- | ------------------------- | ----------------------------------------------------------------------------- |
| `Checkbox.Root`        | `<label>`                 | Lleva `data-size`; un clic en cualquier punto alterna la casilla.             |
| `Checkbox.Control`     | `<div>`                   | La caja visible.                                                              |
| `Checkbox.Indicator`   | `<div>`                   | El glifo; solo se muestra en su estado.                                       |
| `Checkbox.Label`       | `<span>`                  | El texto junto a la caja.                                                     |
| `Checkbox.HiddenInput` | `<input type="checkbox">` | Input nativo oculto que lleva el foco, `name` y `value`. Renderízalo siempre. |

### Atributos data

| Atributo        | Valores                                                             |
| --------------- | ------------------------------------------------------------------- |
| `data-state`    | `"checked"`, `"unchecked"` o `"indeterminate"`, en todas las partes |
| `data-disabled` | Presente con `disabled`                                             |
| `data-invalid`  | Presente con `invalid`                                              |
| `data-size`     | En la raíz: `"sm"`, `"md"` o `"lg"`                                 |

## Notas

- Solo `Checkbox.Root` está envuelto, para añadir `size`; el resto de partes son las de Ark sin cambios.
- Estiliza el estado desde `data-state` y los flags `data-*`; `size` es la única prop visual.
- La caja rellena usa `--primary` con el glifo en `--primary-foreground`; el borde en reposo es `--input`.
