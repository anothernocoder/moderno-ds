## Uso

Usa Shopping Cart para la página del carrito de una tienda. El cliente ve lo que eligió, cambia cantidades, quita artículos y pasa a pagar.

<ForFramework fw="react">

```tsx
import { ShoppingCart } from "@/components/blocks/shopping-cart";
```

```tsx
<ShoppingCart
  items={items}
  subtotal={subtotal}
  onQuantityChange={setQuantity}
  onRemove={removeItem}
  onCheckout={goToCheckout}
/>
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import ShoppingCart from "@/components/blocks/ShoppingCart.vue";
</script>
```

```vue
<ShoppingCart
  :items="items"
  :subtotal="subtotal"
  @quantity-change="setQuantity"
  @remove="removeItem"
  @checkout="goToCheckout"
/>
```

</ForFramework>
<ForFramework fw="svelte">

```svelte
<script lang="ts">
  import ShoppingCart from "@/components/blocks/ShoppingCart.svelte";

```

```svelte
<ShoppingCart
```

<ForFramework fw="solid">

```tsx
import { ShoppingCart } from "@/components/blocks/shopping-cart";
```

El bloque no hace cuentas. Cuando cambia una cantidad, calcula el precio de la línea y el subtotal, y vuelve a pasarlos.

## Referencia de la API

### Props

| Prop               | Tipo                                     | Por defecto                                   | Descripción                                                                                                                          |
| ------------------ | ---------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `heading`          | `string`                                 | `"Shopping cart"`                             | El título de la sección. Va en la fuente con serifa.                                                                                 |
| `items`            | `CartItem[]`                             | tres de muestra                               | Las líneas del carrito. `[]` muestra el mensaje de vacío.                                                                            |
| `subtotal`         | `string`                                 | `"€134"` con los de muestra                   | El subtotal tal como se lee. Sin él, el resumen no tiene fila de subtotal.                                                           |
| `note`             | `string`                                 | `"Shipping and taxes are added at checkout."` | Una línea bajo el subtotal; `""` la oculta.                                                                                          |
| `error`            | `string`                                 | —                                             | No se pudo cargar el carrito; un Alert de error con reintento sustituye las líneas y el resumen.                                     |
| `loading`          | `boolean`                                | `false`                                       | Líneas de marcador en una región ocupada sustituyen las líneas y el resumen.                                                         |
| `disabled`         | `boolean`                                | `false`                                       | Las líneas se quedan; cada enlace queda inerte y cada caja de cantidad y botón apagado.                                              |
| `onQuantityChange` | `(id: string, quantity: number) => void` | —                                             | Cambió la cantidad de una línea, siempre un número entero de 1 a `maxQuantity`. Svelte: `onquantitychange`. Vue: `@quantity-change`. |
| `onRemove`         | `(id: string) => void`                   | —                                             | Se pulsó "Remove" en una línea. Svelte: `onremove`. Vue: `@remove`.                                                                  |
| `onCheckout`       | `() => void`                             | —                                             | Se pulsó "Checkout". Svelte: `oncheckout`. Vue: `@checkout`.                                                                         |
| `onRetry`          | `() => void`                             | —                                             | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                                                                          |

### CartItem

| Campo         | Tipo            | Descripción                                                          |
| ------------- | --------------- | -------------------------------------------------------------------- |
| `id`          | `string`        | Una clave estable para la línea. Los callbacks la devuelven.         |
| `name`        | `string`        | El nombre del producto.                                              |
| `price`       | `string`        | El precio de la línea por toda su cantidad, como `"€56"`.            |
| `quantity`    | `number`        | Cuántos hay en el carrito. La caja de cantidad empieza en él.        |
| `maxQuantity` | `number`        | Opcional. El máximo que se puede elegir; `99` si no se pasa.         |
| `options`     | `string`        | Opcional. Lo que eligió el cliente, como `"Sage · 350 ml"`.          |
| `href`        | `string`        | Opcional. Convierte el nombre en un enlace a la página del producto. |
| `image`       | `CartItemImage` | Opcional. La foto: `{ src, alt }`. Sin ella, una caja atenuada.      |

### Estados

| Estado        | Prop         | Qué se muestra                                                                |
| ------------- | ------------ | ----------------------------------------------------------------------------- |
| Por defecto   | —            | El título, una línea por artículo y el resumen del pedido.                    |
| Vacío         | `items={[]}` | El título y "Your cart is empty." en una caja discontinua.                    |
| Cargando      | `loading`    | El título y tres líneas de marcador.                                          |
| Error         | `error`      | El título y un Alert de error con "Try again".                                |
| Deshabilitado | `disabled`   | Las mismas líneas con los enlaces inertes y las cajas y los botones apagados. |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| bajo `@sm`               | Una imagen pequeña. La cantidad y "Remove" van en su propia fila, bajo la imagen. El resumen va bajo las líneas. |
| `@sm` (`--container-sm`) | La imagen crece, y la cantidad y "Remove" pasan a su lado, bajo el nombre.                                       |
| `@md` (`--container-md`) | La imagen crece otra vez, y el título sube un tamaño.                                                            |
| `@lg` (`--container-lg`) | El resumen pasa al lado de las líneas.                                                                           |
