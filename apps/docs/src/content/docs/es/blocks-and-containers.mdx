## Breakpoints de contenedor

El mismo bloque `Pricing` en ambas pestañas: se apila por debajo de 36rem de ancho de contenedor y pasa a tres columnas por encima.

| Slot             | Por defecto | Variante | Utilidades de ancho |
| ---------------- | ----------- | -------- | ------------------- |
| `--container-sm` | `24rem`     | `@sm:`   | `max-w-sm`, `w-sm`  |
| `--container-md` | `36rem`     | `@md:`   | `max-w-md`, `w-md`  |
| `--container-lg` | `48rem`     | `@lg:`   | `max-w-lg`, `w-lg`  |

Las variantes vienen del preset de Tailwind. Consulta [Contrato de tokens](/es/token-contract#tailwind-v4) para ver cómo las mapea.

## Construir un bloque responsive

1. Declara `@container` en la raíz del bloque.
2. Maquétalo con `@sm:`, `@md:` y `@lg:`.
3. Píntalo y dimensiónalo solo con slots del contrato.

```tsx
<section className="@container">
  <h2 className="text-lg font-semibold @md:text-xl">Pricing</h2>
  <ul className="mt-6 grid gap-4 @md:grid-cols-3">
    <li className="rounded-lg bg-card p-6 text-card-foreground shadow-sm">…</li>
  </ul>
</section>
```

## Reglas

| Regla                               | Detalle                                                                                                                               |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `@container`, no `@media`           | Las media queries de viewport quedan reservadas para primitivos que cambian de forma en pantallas pequeñas. Esa lista está vacía hoy. |
| Solo tres pasos                     | El preset reemplaza la escala de contenedores de Tailwind: `@xl:` y superiores no existen.                                            |
| Sin colores ni longitudes literales | Un hex o una longitud arbitraria como `w-[320px]` falla en `moderno-lint`, que CI ejecuta sobre cada archivo fuente del registro.     |
| La maquetación intrínseca vale      | Un `grid` con columnas `auto-fit` no necesita breakpoint. Usa una container query cuando la maquetación cambie de forma.              |
