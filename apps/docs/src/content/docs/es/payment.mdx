Úsala en el paso de pago del checkout. El cliente escribe su tarjeta y ve lo que paga; tu página cobra la tarjeta.

`pay` recibe el evento de envío del formulario. Evita que la página se recargue y envía la tarjeta:

```ts
function pay(event) {
  event.preventDefault();
  const card = new FormData(event.currentTarget);
  // Envía card.get("cardNumber"), card.get("expiry"), … a tu proveedor de pagos.
}
```

## Referencia de API

### Props

Los callbacks son props `on…` en React y Solid, en minúsculas (`onsubmit`) en Svelte y eventos (`submit`, `back`, `retry`, `navigate`) en Vue.

| Prop          | Tipo                     | Por defecto             | Descripción                                                                        |
| ------------- | ------------------------ | ----------------------- | ---------------------------------------------------------------------------------- |
| `heading`     | `string`                 | `"Payment"`             | El `h1` de la página, el título del bloque de checkout.                            |
| `description` | `string`                 | la línea del bloque     | La línea bajo el título; `""` la oculta.                                           |
| `items`       | `OrderItem[]`            | los ejemplos del bloque | Los artículos que se pagan. `[]` muestra el mensaje de vacío.                      |
| `totals`      | `OrderTotal[]`           | los ejemplos del bloque | Las filas sobre el total: `{ label, amount }`.                                     |
| `total`       | `string`                 | el ejemplo del bloque   | El importe a pagar tal como se lee, como `"€168"`.                                 |
| `error`       | `string`                 | —                       | Falló el pago: una alerta sobre los campos de la tarjeta.                          |
| `errors`      | `Record<string, string>` | —                       | Un mensaje bajo cada campo erróneo, por su `name`.                                 |
| `submitting`  | `boolean`                | `false`                 | Se está haciendo el pedido: Place order gira y todos los controles quedan inertes. |
| `loading`     | `boolean`                | `false`                 | El pedido está cargando: líneas de marcador reemplazan el resumen.                 |
| `orderError`  | `string`                 | —                       | Falló la carga del pedido: una alerta con reintento reemplaza el resumen.          |
| `disabled`    | `boolean`                | `false`                 | Todo se queda en pantalla; todos los controles quedan inertes.                     |
| `onSubmit`    | `(event) => void`        | —                       | Se pulsó Place order. Llama a `preventDefault()` para quedarte en la página.       |
| `onBack`      | `() => void`             | —                       | Se pulsó Back to shipping.                                                         |
| `onRetry`     | `() => void`             | —                       | «Try again» tras `orderError`.                                                     |
| `onNavigate`  | `(to, event) => void`    | —                       | Se pulsó un enlace de la pantalla: `home`, `cart`, `privacy` o `terms`.            |
| `homeHref`    | `string`                 | `"#"`                   | Destino del logotipo.                                                              |
| `cartHref`    | `string`                 | `"#"`                   | Destino de «Edit cart».                                                            |
| `privacyHref` | `string`                 | `"#"`                   | Destino del enlace de privacidad.                                                  |
| `termsHref`   | `string`                 | `"#"`                   | Destino del enlace de términos.                                                    |

Los campos de la tarjeta se llaman `cardName`, `cardNumber`, `expiry`, `cvc` y `saveCard`.

### Estados

| Estado             | Props        | Qué se renderiza                                                      |
| ------------------ | ------------ | --------------------------------------------------------------------- |
| Por defecto        | —            | El formulario de la tarjeta y el resumen del pedido con su total.     |
| Rechazada          | `error`      | Una alerta sobre los campos de la tarjeta; `errors` marca cada campo. |
| Haciendo el pedido | `submitting` | «Placing order» con un indicador; todos los controles inertes.        |
| Cargando           | `loading`    | El formulario, y líneas de marcador en lugar del resumen.             |
| Error del pedido   | `orderError` | El formulario, y una alerta con «Try again» en lugar del resumen.     |
| Vacío              | `items=[]`   | El formulario, y «Your order is empty.» en lugar del resumen.         |
| Deshabilitado      | `disabled`   | Todo se muestra, todos los controles inertes.                         |

### Tamaño

| Paso del contenedor      | Cambio                                          |
| ------------------------ | ----------------------------------------------- |
| `@sm` (`--container-sm`) | La cabecera pasa a una sola fila.               |
| `@md` (`--container-md`) | El pie pasa a una sola fila.                    |
| `@lg` (`--container-lg`) | El resumen del pedido pasa junto al formulario. |

## Notas

- Presentacional: no se cobra ninguna tarjeta y no hay router. La página que la monta hace las dos cosas.
- `onNavigate` pasa el evento del clic: ignora los clics con `metaKey`/`ctrlKey` y luego llama a `preventDefault()` para enrutar.
- La raíz es un `<div>`, no un `<main>`. Conviértela en tu `<main>` si la ruta no tiene uno.
- La pantalla importa sus dos bloques desde `@/components/blocks/…`; cambia esas líneas si tu alias es otro.
