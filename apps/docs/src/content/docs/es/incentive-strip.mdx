## Referencia de la API

### Props

| Prop          | Tipo                   | Por defecto                 | Descripción                                                                     |
| ------------- | ---------------------- | --------------------------- | ------------------------------------------------------------------------------- |
| `heading`     | `string`               | una frase                   | El título sobre las garantías. Se muestra como `h2`.                            |
| `description` | `string`               | una frase                   | Una línea breve bajo el encabezado. `""` la oculta.                             |
| `incentives`  | `IncentiveStripItem[]` | cuatro garantías de muestra | Las garantías, en orden. `[]` muestra el mensaje de vacío.                      |
| `error`       | `string`               | —                           | Falló la carga de las garantías; un Alert de error con reintento las sustituye. |
| `loading`     | `boolean`              | `false`                     | Marcadores de esqueleto en una región ocupada sustituyen a las garantías.       |
| `disabled`    | `boolean`              | `false`                     | Las garantías se quedan; sus enlaces y el reintento quedan fuera de alcance.    |
| `onRetry`     | `() => void`           | —                           | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                     |

### Garantía

| Campo         | Tipo                                         | Descripción                                          |
| ------------- | -------------------------------------------- | ---------------------------------------------------- |
| `id`          | `string`                                     | Una clave estable para la garantía.                  |
| `icon`        | `"truck" \| "returns" \| "shield" \| "gift"` | El icono del recuadro.                               |
| `title`       | `string`                                     | La promesa, en pocas palabras. Se muestra como `h3`. |
| `description` | `string`                                     | Una frase que la respalda.                           |
| `link`        | `{ label: string; href: string }`            | Opcional. Un enlace a la política que hay detrás.    |

### Estados

| Estado        | Prop              | Qué se muestra                                                        |
| ------------- | ----------------- | --------------------------------------------------------------------- |
| Por defecto   | —                 | El encabezado y cada garantía.                                        |
| Vacío         | `incentives={[]}` | El encabezado y "No incentives to show yet." en un recuadro punteado. |
| Cargando      | `loading`         | El encabezado y cuatro marcadores.                                    |
| Error         | `error`           | El encabezado y un Alert de error con "Try again".                    |
| Deshabilitado | `disabled`        | Las mismas garantías; los enlaces se atenúan y no se pueden abrir.    |

### Tamaño

| Paso del contenedor      | Qué cambia                                                        |
| ------------------------ | ----------------------------------------------------------------- |
| bajo `@sm`               | Una garantía por fila, con el icono junto al texto.               |
| `@sm` (`--container-sm`) | Dos garantías por fila, cada icono sobre su texto.                |
| `@md` (`--container-md`) | El encabezado sube un tamaño.                                     |
| `@lg` (`--container-lg`) | Las cuatro garantías en una fila, con más espacio arriba y abajo. |

## Notas

- Promete solo lo que la tienda cumple. Pon las cifras en la frase: "más de 50 €", "en 30 días".
- Enlaza cada promesa con la página que la explica, para que se pueda leer la letra pequeña.
