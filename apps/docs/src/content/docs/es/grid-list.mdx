## Referencia de API

### Props

| Prop          | Tipo                   | Por defecto            | Descripción                                                                 |
| ------------- | ---------------------- | ---------------------- | --------------------------------------------------------------------------- |
| `items`       | `GridListItem[]`       | un conjunto de muestra | Las tarjetas, en el orden en que se muestran. `[]` muestra el estado vacío. |
| `heading`     | `string`               | `"Projects"`           | El título sobre la cuadrícula.                                              |
| `description` | `string`               | una frase              | La línea bajo el título; `""` la oculta.                                    |
| `error`       | `string`               | —                      | La cuadrícula no cargó; una alerta con reintento la sustituye.              |
| `loading`     | `boolean`              | `false`                | Tarjetas esqueleto en una región ocupada sustituyen la cuadrícula.          |
| `disabled`    | `boolean`              | `false`                | Las tarjetas siguen legibles y todos los botones quedan deshabilitados.     |
| `onOpen`      | `(id: string) => void` | —                      | El botón Open de una tarjeta. Svelte: `onopen`. Vue: `@open`.               |
| `onCreate`    | `() => void`           | —                      | "New project". Svelte: `oncreate`. Vue: `@create`.                          |
| `onRetry`     | `() => void`           | —                      | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                 |

### GridListItem

| Campo           | Tipo                                                       | Descripción                                       |
| --------------- | ---------------------------------------------------------- | ------------------------------------------------- |
| `id`            | `string`                                                   | Identidad estable, la que devuelve `onOpen`.      |
| `title`         | `string`                                                   | El título de la tarjeta.                          |
| `subtitle`      | `string`                                                   | Línea opcional bajo el título, como un equipo.    |
| `initials`      | `string`                                                   | El respaldo del avatar cuando no hay imagen.      |
| `image`         | `string`                                                   | URL opcional de la miniatura del avatar.          |
| `status`        | `string`                                                   | Texto opcional de la insignia.                    |
| `statusVariant` | `"neutral" \| "info" \| "success" \| "warning" \| "error"` | El color de la insignia. Por defecto `"neutral"`. |
| `meta`          | `string`                                                   | Línea tenue opcional, como "Updated 2 hrs ago".   |

### Estados

| Estado        | Prop         | Qué se muestra                                                          |
| ------------- | ------------ | ----------------------------------------------------------------------- |
| Por defecto   | —            | Una tarjeta por elemento.                                               |
| Vacío         | `items={[]}` | Una tarjeta "No projects yet".                                          |
| Cargando      | `loading`    | Tres tarjetas esqueleto en una región `status` ocupada.                 |
| Error         | `error`      | Una alerta de error con un botón "Try again" en lugar de la cuadrícula. |
| Deshabilitado | `disabled`   | La cuadrícula con todos los botones deshabilitados.                     |

### Dimensionado

| Paso del contenedor      | Qué cambia                                |
| ------------------------ | ----------------------------------------- |
| `@sm` (`--container-sm`) | El título y "New project" comparten fila. |
| `@md` (`--container-md`) | Dos columnas; el título sube un tamaño.   |
| `@lg` (`--container-lg`) | Tres columnas.                            |
