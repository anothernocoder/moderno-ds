## Uso

Una toolbar reúne los controles de un editor en una barra: deshacer, rehacer, estilo de texto, zoom. Con el teclado se llega a toda la barra con un solo Tab y se pasa de un elemento a otro con las flechas.

<ForFramework fw="react">

```tsx
import { Toolbar } from "@moderno-ui/react";
```

```tsx
<Toolbar.Root aria-label="Canvas tools">
  <Toolbar.Button label="Undo" shortcut="⌘Z" onClick={undo}>
    <UndoIcon />
  </Toolbar.Button>
  <Toolbar.Separator />
  <Toolbar.Toggle label="Bold" pressed={bold} onPressedChange={setBold}>
    <BoldIcon />
  </Toolbar.Toggle>
</Toolbar.Root>
```

</ForFramework>

## Referencia de API

### Toolbar.Root

<PropsTable component="Toolbar" />

| Prop          | Tipo                         | Por defecto    | Descripción                                                                      |
| ------------- | ---------------------------- | -------------- | -------------------------------------------------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Pone los elementos en fila o en columna, y elige las flechas.                    |
| `size`        | `"sm" \| "md" \| "lg"`       | `"md"`         | Alto de cada elemento: los tamaños de Button.                                    |
| `dir`         | `"ltr" \| "rtl"`             | `"ltr"`        | Dirección del texto. En `rtl` se invierten las flechas izquierda y derecha.      |
| `aria-label`  | `string`                     | —              | Nombra la toolbar para lectores de pantalla, como `"Canvas tools"`. Obligatorio. |

### Toolbar.Button

| Prop       | Tipo      | Por defecto | Descripción                                                                              |
| ---------- | --------- | ----------- | ---------------------------------------------------------------------------------------- |
| `label`    | `string`  | —           | Nombra un botón de solo icono. Es su `aria-label` y el texto de su tooltip.              |
| `shortcut` | `string`  | —           | Un atajo de teclado que el tooltip muestra entre paréntesis tras el label.               |
| `disabled` | `boolean` | `false`     | El botón sigue en el orden de las flechas y se anuncia deshabilitado, pero no hace nada. |

Cualquier otra prop, como `onClick`, llega al `<button>`.

### Toolbar.Toggle

Acepta `label`, `shortcut` y `disabled` como `Toolbar.Button`, y además:

| Prop              | Tipo                         | Por defecto | Descripción                                             |
| ----------------- | ---------------------------- | ----------- | ------------------------------------------------------- |
| `pressed`         | `boolean`                    | —           | Estado pulsado controlado. Úsalo con `onPressedChange`. |
| `defaultPressed`  | `boolean`                    | `false`     | Estado pulsado inicial cuando no está controlado.       |
| `onPressedChange` | `(pressed: boolean) => void` | —           | Se llama con el nuevo estado cuando se pulsa.           |

En Vue, enlázalo con `v-model:pressed` o escucha `@pressed-change`. En Svelte funciona `bind:pressed`.

### Toolbar.Group y Toolbar.Separator

`Toolbar.Group` reúne elementos relacionados. Dale un `aria-label`, como `"Text style"`. `Toolbar.Separator` dibuja una línea entre grupos. Ninguno tiene props propias.

### Partes

| Parte               | Elemento   | Descripción                                                                                    |
| ------------------- | ---------- | ---------------------------------------------------------------------------------------------- |
| `Toolbar.Root`      | `<div>`    | `role="toolbar"` con `aria-orientation`. Lleva `data-size`.                                    |
| `Toolbar.Button`    | `<button>` | Una acción. Con `label`, muestra un tooltip al pasar el ratón y al enfocarlo con el teclado.   |
| `Toolbar.Toggle`    | `<button>` | Un botón que se queda pulsado, con `aria-pressed`.                                             |
| `Toolbar.Group`     | `<div>`    | `role="group"`: elementos relacionados.                                                        |
| `Toolbar.Separator` | `<div>`    | `role="separator"`, a lo ancho de la toolbar: vertical en una fila, horizontal en una columna. |

Cualquier otro elemento dentro de la raíz, como el nivel de zoom, queda en la misma línea que los elementos.

### Teclado

| Tecla                      | Acción                                                                                    |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| `Tab`                      | Entra en la toolbar, en el último elemento usado (el primero al empezar), y sale de ella. |
| `ArrowRight` / `ArrowLeft` | Elemento siguiente / anterior en una fila. Da la vuelta en los extremos.                  |
| `ArrowDown` / `ArrowUp`    | Elemento siguiente / anterior en una columna. Da la vuelta en los extremos.               |
| `Home` / `End`             | Primer / último elemento.                                                                 |
| `Enter`, `Space`           | Activa el elemento enfocado: ejecuta un botón, pulsa un toggle.                           |

### Atributos data

| Atributo           | Valores                                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| `data-size`        | En la raíz: `"sm"`, `"md"` o `"lg"`                                                                        |
| `data-orientation` | `"horizontal"` o `"vertical"`, en la raíz, los elementos y los grupos; el de un separador es su propio eje |
| `data-state`       | En un toggle: `"on"` u `"off"`                                                                             |
| `data-disabled`    | Presente en un elemento deshabilitado                                                                      |
