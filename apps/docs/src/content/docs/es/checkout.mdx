Úsalo para montar una compra completa de una vez: carrito, envío, pago, revisión y confirmación. Recórrelo arriba: pulsa Checkout, rellena cada formulario y haz el pedido.

## Instalación

<Install item="checkout" />

El flujo se instala en `src/components/flows/`, sus cinco pantallas en `screens/` y sus bloques en `blocks/`, cada uno con su propia versión.

## Referencia de API

### Props

Los callbacks son props `on…` en React y Solid, en minúsculas (`onorderplaced`) en Svelte y eventos (`stepChange`, `orderPlaced`, `continueShopping`) en Vue.

| Prop                 | Tipo                       | Por defecto           | Descripción                                                            |
| -------------------- | -------------------------- | --------------------- | ---------------------------------------------------------------------- |
| `initialStep`        | `CheckoutStep`             | `"cart"`              | La pantalla con la que abre el flujo; en una app, lo que diga la ruta. |
| `initialLines`       | `CheckoutLine[]`           | un carrito de ejemplo | Las líneas del carrito al abrir el flujo.                              |
| `deliveryOptions`    | `CheckoutDeliveryOption[]` | estándar, exprés      | Las formas de enviar el pedido, con precios numéricos.                 |
| `formatPrice`        | `(amount) => string`       | `` `€${amount}` ``    | Cómo se lee un importe en pantalla.                                    |
| `hrefFor`            | `(step) => string`         | `` `#${step}` ``      | La URL de cada paso; la usan los enlaces «Edit cart».                  |
| `onStepChange`       | `(step) => void`           | —                     | El flujo se movió; refléjalo en la URL.                                |
| `onOrderPlaced`      | `(order) => void`          | —                     | «Place order» se completó en la revisión.                              |
| `onContinueShopping` | `() => void`               | —                     | Se pulsó «Continue shopping» en la confirmación.                       |
| `homeHref`           | `string`                   | `"#"`                 | Destino del logotipo en todas las pantallas.                           |
| `shopHref`           | `string`                   | `"#"`                 | Destino de «Continue shopping» en la cabecera del carrito.             |
| `helpHref`           | `string`                   | `"#"`                 | Destino de «Need help?» en el envío.                                   |
| `ordersHref`         | `string`                   | `"#"`                 | Destino de «Your orders» en la confirmación.                           |
| `privacyHref`        | `string`                   | `"#"`                 | Destino del enlace de privacidad en todas las pantallas.               |
| `termsHref`          | `string`                   | `"#"`                 | Destino del enlace de términos en todas las pantallas.                 |

### Tipos

| Tipo                     | Campos                                                                           |
| ------------------------ | -------------------------------------------------------------------------------- |
| `CheckoutLine`           | `id`, `name`, `unitPrice`, `quantity` y, opcionales, `options`, `href`, `image`. |
| `CheckoutDeliveryOption` | `id`, `label`, `description`, `price`.                                           |
| `CheckoutOrder`          | `number`, `email`, `lines`, `delivery`, `total`: lo que recibe `onOrderPlaced`.  |

### Pasos

`CheckoutStep` es una de las cinco pantallas, en el orden en que el flujo las recorre.

| Paso                                | Se llega por                                          | Sale hacia                                                 |
| ----------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------- |
| [`cart`](/es/cart/)                 | El primer paso, Back, «Edit cart» o Continue shopping | `shipping`, con Checkout                                   |
| [`shipping`](/es/shipping/)         | Checkout, «Back to shipping» o un Change              | `payment`, con el formulario completo; `cart`, con Back    |
| [`payment`](/es/payment/)           | Una dirección guardada, «Back to payment» o un Change | `review`, con el formulario completo; `shipping`, con Back |
| [`review`](/es/review/)             | Una tarjeta guardada                                  | `confirmation`, con Place order; `payment`, con Back       |
| [`confirmation`](/es/confirmation/) | Un pedido hecho                                       | `cart`, con Continue shopping                              |

### Estado

Lo que guarda el ensamblaje para que las pantallas no tengan que hacerlo.

| Estado            | Guarda                                                             |
| ----------------- | ------------------------------------------------------------------ |
| `step`            | La pantalla que está ahora en la ruta.                             |
| `lines`           | El carrito: aquí llega cada cambio de cantidad y cada eliminación. |
| `shippingDetails` | El contacto y la dirección del formulario de envío.                |
| `deliveryId`      | El método de envío elegido.                                        |
| `cardEnding`      | Los cuatro últimos dígitos de la tarjeta, para la revisión.        |
| `order`           | El pedido hecho que muestra la confirmación.                       |
| `errors`          | Los campos que el último envío dejó vacíos.                        |

## Notas

- El ensamblaje es código de ejemplo, el único archivo que se espera que reescribas. Las pantallas quedan como se publicaron.
- Los precios son números en el ensamblaje y texto en pantalla; `formatPrice` los une.
- Los formularios de envío y pago solo comprueban que no haya campos vacíos. Pon tus peticiones en `saveAddress` y `saveCard`.
- El bloque checkout-form no recibe valores, así que un formulario al que vuelves empieza vacío.
- «Edit cart» es un `href` real: los clics izquierdos simples mueven el flujo, los modificados van al navegador.
- Hacer el pedido vacía el carrito. `#MD-10482` sustituye al número de pedido de tu servidor.
