## Uso

Number Input es un campo de texto para un número, con botones que lo suben y lo bajan. Úsalo para un número exacto con límites, como una cantidad. Las flechas del teclado también lo cambian.

<ForFramework fw="react">

```tsx
import { NumberInput } from "@moderno-ui/react";
```

```tsx
<NumberInput.Root value={quantity} onValueChange={(details) => setQuantity(details.value)}>
  <NumberInput.Label>Cantidad</NumberInput.Label>
  <NumberInput.Control>
    <NumberInput.Input />
    <NumberInput.DecrementTrigger>−</NumberInput.DecrementTrigger>
    <NumberInput.IncrementTrigger>+</NumberInput.IncrementTrigger>
  </NumberInput.Control>
</NumberInput.Root>
```

</ForFramework>

El valor es un texto, como `"3"`. `onValueChange` también da `valueAsNumber`.

## Referencia de la API

### NumberInput.Root

`size` es el añadido de Moderno; todas las partes lo siguen. El resto de props vienen del NumberInput de Ark.

<PropsTable component="NumberInput" />

| Prop               | Tipo                                                          | Por defecto | Descripción                                                     |
| ------------------ | ------------------------------------------------------------- | ----------- | --------------------------------------------------------------- |
| `value`            | `string`                                                      | —           | Valor controlado.                                               |
| `defaultValue`     | `string`                                                      | —           | Valor al principio, sin control.                                |
| `onValueChange`    | `(details: { value: string; valueAsNumber: number }) => void` | —           | Se llama cuando cambia el valor.                                |
| `onValueInvalid`   | `(details: { value: string; reason: string }) => void`        | —           | Se llama cuando el valor baja de `min` o pasa de `max`.         |
| `min`              | `number`                                                      | —           | El valor más bajo.                                              |
| `max`              | `number`                                                      | —           | El valor más alto.                                              |
| `step`             | `number`                                                      | `1`         | Cuánto avanza un paso.                                          |
| `formatOptions`    | `Intl.NumberFormatOptions`                                    | —           | Cómo mostrar el número: moneda, porcentaje, decimales.          |
| `locale`           | `string`                                                      | `"en-US"`   | El idioma con el que se formatea y se lee el número.            |
| `clampValueOnBlur` | `boolean`                                                     | `true`      | Ajusta un valor escrito a `min`–`max` al salir del campo.       |
| `allowOverflow`    | `boolean`                                                     | `false`     | Deja que un paso pase de `min` y `max`.                         |
| `allowMouseWheel`  | `boolean`                                                     | `false`     | Cambia el valor con la rueda del ratón mientras tiene el foco.  |
| `spinOnPress`      | `boolean`                                                     | `true`      | Sigue cambiando el valor mientras se mantiene pulsado un botón. |
| `disabled`         | `boolean`                                                     | `false`     | Atenúa el campo e ignora la entrada.                            |
| `readOnly`         | `boolean`                                                     | `false`     | Muestra el valor pero ignora la entrada.                        |
| `invalid`          | `boolean`                                                     | —           | Marca el valor como erróneo. Sin él, sigue a `min` y `max`.     |
| `required`         | `boolean`                                                     | `false`     | Marca el campo como obligatorio en un formulario.               |
| `name`             | `string`                                                      | —           | El nombre de campo del input.                                   |
| `translations`     | `{ incrementLabel?: string; decrementLabel?: string }`        | —           | Lo que dice un lector de pantalla de cada botón.                |

En Vue, enlaza el valor con `:model-value` o `v-model`, y escucha con `@value-change`.

### Partes

| Parte                          | Elemento   | Descripción                                                     |
| ------------------------------ | ---------- | --------------------------------------------------------------- |
| `NumberInput.Root`             | `<div>`    | Lleva `data-size`.                                              |
| `NumberInput.Label`            | `<label>`  | Opcional. Nombra el campo. Al pulsarla, enfoca el input.        |
| `NumberInput.Control`          | `<div>`    | La caja con borde. Contiene el input y los botones.             |
| `NumberInput.Input`            | `<input>`  | El campo de texto, con `role="spinbutton"`.                     |
| `NumberInput.DecrementTrigger` | `<button>` | Baja el valor un paso. Se apaga en `min`.                       |
| `NumberInput.IncrementTrigger` | `<button>` | Sube el valor un paso. Se apaga en `max`.                       |
| `NumberInput.Scrubber`         | `<div>`    | Opcional. Arrástralo de lado para cambiar el valor.             |
| `NumberInput.ValueText`        | `<span>`   | Opcional. El valor formateado, para mostrarlo fuera de la caja. |

### Atributos data

| Atributo         | Valores                                                            |
| ---------------- | ------------------------------------------------------------------ |
| `data-focus`     | Mientras el input tiene el foco, en la raíz, la etiqueta y la caja |
| `data-invalid`   | Cuando el valor es erróneo, en la raíz, la caja y el input         |
| `data-disabled`  | Con `disabled`, en todas las partes; en un botón en su límite      |
| `data-scrubbing` | Mientras se arrastra el scrubber, en la raíz y sus partes          |
| `data-size`      | En la raíz: `"sm"`, `"md"` o `"lg"`                                |

## Notas

- `NumberInput.Root` está envuelto para añadir `size`; el resto de partes son las de Ark sin cambios.
- Los botones no entran en el orden de tabulación. Las flechas hacen lo mismo desde el input; con Mayús avanzan diez pasos de golpe.
- Para un valor que se elige arrastrando por una pista, usa un Slider.
