## Referencia de la API

### Props

| Prop                | Tipo         | Por defecto                           | Descripción                                                                                  |
| ------------------- | ------------ | ------------------------------------- | -------------------------------------------------------------------------------------------- |
| `kicker`            | `string`     | `"Now in public beta"`                | Una etiqueta corta sobre el título; `""` la oculta.                                          |
| `title`             | `string`     | `"Run your business, not your books"` | Qué hace el producto, en pocas palabras. Va en la fuente con serifa.                         |
| `subtitle`          | `string`     | una frase                             | Una o dos frases bajo el título; `""` lo oculta.                                             |
| `primaryAction`     | `string`     | `"Start free trial"`                  | La etiqueta del botón principal; `""` lo oculta.                                             |
| `secondaryAction`   | `string`     | `"Book a demo"`                       | La etiqueta del botón con contorno; `""` lo oculta.                                          |
| `error`             | `string`     | —                                     | Algo detrás de las acciones falló; un Alert de error con reintento sustituye a las acciones. |
| `loading`           | `boolean`    | `false`                               | Marcadores de esqueleto en una región ocupada sustituyen al contenido.                       |
| `disabled`          | `boolean`    | `false`                               | El contenido se queda y todos los botones se deshabilitan.                                   |
| `onPrimaryAction`   | `() => void` | —                                     | Se pulsó el botón principal. Svelte: `onprimaryaction`. Vue: `@primary-action`.              |
| `onSecondaryAction` | `() => void` | —                                     | Se pulsó el botón con contorno. Svelte: `onsecondaryaction`. Vue: `@secondary-action`.       |
| `onRetry`           | `() => void` | —                                     | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                                  |

### Estados

| Estado        | Prop                     | Qué se muestra                                                                      |
| ------------- | ------------------------ | ----------------------------------------------------------------------------------- |
| Por defecto   | —                        | Antetítulo, título, subtítulo y las dos acciones.                                   |
| Vacío         | todo texto menos `title` | Solo el título, cuando pasas `""` al antetítulo, al subtítulo y a las dos acciones. |
| Cargando      | `loading`                | Marcadores para el antetítulo, el título, el subtítulo y un botón.                  |
| Error         | `error`                  | El título y el subtítulo, y después un Alert de error con "Try again".              |
| Deshabilitado | `disabled`               | El mismo contenido con los dos botones deshabilitados.                              |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                      |
| ------------------------ | ------------------------------------------------------------------------------- |
| bajo `@sm`               | Las acciones se apilan, cada una tan ancha como el bloque, la principal arriba. |
| `@sm` (`--container-sm`) | Las acciones van una junto a otra, centradas, con su propio ancho.              |
| `@md` (`--container-md`) | El título y el subtítulo suben un tamaño.                                       |
| `@lg` (`--container-lg`) | El bloque toma el doble de espacio arriba y abajo.                              |

## Notas

- Usa un solo hero por página, arriba del todo.
- Mantén el título corto. Di qué hace el producto, no cómo se llama.
