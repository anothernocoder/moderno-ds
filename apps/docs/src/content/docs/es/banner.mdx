## Referencia de API

### Props

| Prop          | Tipo         | Por defecto          | Descripción                                                      |
| ------------- | ------------ | -------------------- | ---------------------------------------------------------------- |
| `badge`       | `string`     | `"New"`              | Una etiqueta corta antes del título. `""` la quita.              |
| `title`       | `string`     | texto de muestra     | El aviso, en negrita.                                            |
| `message`     | `string`     | texto de muestra     | Una línea más, tras el título.                                   |
| `actionLabel` | `string`     | `"See how it works"` | El texto del botón de acción. `""` quita el botón.               |
| `dismissible` | `boolean`    | `true`               | Muestra el botón para descartar.                                 |
| `error`       | `string`     | —                    | El aviso no cargó; una alerta con reintento lo sustituye.        |
| `loading`     | `boolean`    | `false`              | Una franja esqueleto en una región ocupada lo sustituye.         |
| `disabled`    | `boolean`    | `false`              | La franja sigue legible y sus dos botones quedan deshabilitados. |
| `onAction`    | `() => void` | —                    | Se pulsó la acción. Svelte: `onaction`. Vue: `@action`.          |
| `onDismiss`   | `() => void` | —                    | Se descartó la franja. Svelte: `ondismiss`. Vue: `@dismiss`.     |
| `onRetry`     | `() => void` | —                    | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.      |

### Estados

| Estado        | Prop                    | Qué se muestra                                                      |
| ------------- | ----------------------- | ------------------------------------------------------------------- |
| Por defecto   | —                       | La franja con su insignia, título, mensaje, acción y descarte.      |
| Descartado    | pulsar descartar        | Nada: la franja se oculta y llama a `onDismiss`.                    |
| Vacío         | `title=""` `message=""` | Nada: el bloque no ocupa espacio.                                   |
| Cargando      | `loading`               | Una franja esqueleto en una región `status` ocupada.                |
| Error         | `error`                 | Una alerta de error con el botón "Try again" en lugar de la franja. |
| Deshabilitado | `disabled`              | La franja con sus dos botones deshabilitados.                       |

### Tamaño

| Paso del contenedor      | Qué cambia                                               |
| ------------------------ | -------------------------------------------------------- |
| bajo `@sm`               | La acción va bajo el mensaje.                            |
| `@sm` (`--container-sm`) | La acción pasa junto al mensaje.                         |
| `@md` (`--container-md`) | La insignia, el título y el mensaje comparten una línea. |
| `@lg` (`--container-lg`) | El mensaje y la acción se centran en la franja.          |

## Notas

- Ponlo una sola vez, sobre la cabecera de la página, para que ocupe todo el ancho.
- Para que siga descartado en la próxima visita, guárdalo en `onDismiss` y deja de mostrar el bloque.
