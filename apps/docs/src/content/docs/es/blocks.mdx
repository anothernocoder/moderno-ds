Un bloque es una sección de página compuesta solo por primitivas. La CLI lo copia a tu proyecto, donde es tuyo, y se dimensiona según su contenedor, no según el viewport.

```sh
npx @moderno-ui/cli add <block>-<framework>
```

## Bloques disponibles

| Bloque                                       | Descripción                                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [Formulario de acceso](/es/login-form/)      | La tarjeta de credenciales para acceso, registro, recuperación, contraseña nueva y verificación. |
| [Formulario por secciones](/es/form-layout/) | Un formulario de ajustes con grupos de campos titulados y una sola fila de acciones.             |
| [Lista de alertas](/es/alert-list/)          | Un centro de notificaciones con alertas de estado descartables.                                  |
| Precios                                      | Una sección de precios con tres planes.                                                          |
| Estado vacío                                 | Un marcador centrado para cuando no hay datos, con una sola llamada a la acción.                 |

Para las reglas de contenedor que siguen todos los bloques, consulta [Bloques y contenedores](/es/blocks-and-containers/).
