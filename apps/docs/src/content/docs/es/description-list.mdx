## Referencia de API

### Props

| Prop          | Tipo                    | Por defecto           | Descripción                                                              |
| ------------- | ----------------------- | --------------------- | ------------------------------------------------------------------------ |
| `items`       | `DescriptionListItem[]` | un cliente de muestra | Las filas, en el orden en que se muestran. `[]` muestra el estado vacío. |
| `heading`     | `string`                | `"Customer details"`  | El título sobre la lista.                                                |
| `description` | `string`                | una frase             | La línea bajo el título; `""` la oculta.                                 |
| `error`       | `string`                | —                     | Los detalles no cargaron; una alerta con reintento los sustituye.        |
| `loading`     | `boolean`               | `false`               | Filas esqueleto en una región ocupada sustituyen la lista.               |
| `disabled`    | `boolean`               | `false`               | Las filas siguen legibles y todas las acciones quedan deshabilitadas.    |
| `onAction`    | `(id: string) => void`  | —                     | El botón de acción de una fila. Svelte: `onaction`. Vue: `@action`.      |
| `onRetry`     | `() => void`            | —                     | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.              |

### DescriptionListItem

| Campo    | Tipo                                                       | Descripción                                                |
| -------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| `id`     | `string`                                                   | Identidad estable, la que devuelve `onAction`.             |
| `term`   | `string`                                                   | La etiqueta, como "Email".                                 |
| `value`  | `string`                                                   | El dato. El texto largo se ajusta.                         |
| `badge`  | `"neutral" \| "info" \| "success" \| "warning" \| "error"` | Opcional. Muestra el valor como una insignia de ese color. |
| `action` | `string`                                                   | Opcional. El texto de un botón en la fila, como "Change".  |

### Estados

| Estado        | Prop         | Qué se muestra                                                      |
| ------------- | ------------ | ------------------------------------------------------------------- |
| Por defecto   | —            | Una fila por elemento.                                              |
| Vacío         | `items={[]}` | Una tarjeta "No details yet".                                       |
| Cargando      | `loading`    | Cuatro filas esqueleto en una región `status` ocupada.              |
| Error         | `error`      | Una alerta de error con el botón "Try again" en lugar de las filas. |
| Deshabilitado | `disabled`   | Las filas con todas las acciones deshabilitadas.                    |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                             |
| ------------------------ | -------------------------------------------------------------------------------------- |
| bajo `@sm`               | Cada término va sobre su valor, y la acción debajo de ambos.                           |
| `@sm` (`--container-sm`) | La acción de una fila pasa junto a su valor.                                           |
| `@md` (`--container-md`) | El término va junto a su valor, en una columna de un tercio; el título sube un tamaño. |
| `@lg` (`--container-lg`) | La columna de términos se estrecha a un cuarto.                                        |

## Notas

- Presentacional: no edita nada. `onAction` indica qué fila quiere cambiar el lector.
- El nombre accesible de cada acción de fila incluye su término.
