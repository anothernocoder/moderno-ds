## Uso

Usa una insignia para marcar el estado de algo que ya está en la página: una factura **Pagada**, una función en **Beta**, **3** mensajes nuevos.

<ForFramework fw="react">

```tsx
import { Badge } from "@moderno-ui/react";
```

```tsx
<Badge variant="success">Pagada</Badge>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Badge } from "@moderno-ui/vue";
```

```vue
<Badge variant="success">Pagada</Badge>
```

</ForFramework>

<ForFramework fw="svelte">

```ts
import { Badge } from "@moderno-ui/svelte";
```

```svelte
<Badge variant="success">Pagada</Badge>
```

</ForFramework>

<ForFramework fw="solid">


</ForFramework>

## Referencia de API

### Badge

Renderiza un `<span>`; sus hijos son el texto. `variant` vale `neutral` por defecto y `size`, `md`.

<PropsTable component="Badge" />

### Partes

| Parte  | Elemento | Descripción                                             |
| ------ | -------- | ------------------------------------------------------- |
| `root` | `<span>` | La etiqueta. Lleva `data-variant` y `data-size`.        |
| `dot`  | `<span>` | Solo con `dot`. Toma el color del texto; `aria-hidden`. |

## Notas

- Badge es solo CSS: un `<span>` con `data-scope="badge"`, sin máquina de Ark.
- Una insignia no es interactiva. Para algo que el usuario puede quitar, usa Chip.
- El punto es decorativo; el texto debe decir el estado.
