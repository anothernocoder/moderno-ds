## Uso

Progress muestra cuánto de una tarea está hecho. Úsalo cuando el usuario espera un trabajo que puedes medir, como una subida de archivos. Dibuja una barra, o un anillo si lo construyes con `Progress.Circle`.

<ForFramework fw="react">

```tsx
import { Progress } from "@moderno-ui/react";
```

```tsx
<Progress.Root value={progress}>
  <Progress.Label>Subiendo fotos</Progress.Label>
  <Progress.ValueText />
  <Progress.Track>
    <Progress.Range />
  </Progress.Track>
</Progress.Root>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Progress } from "@moderno-ui/vue";
```

```vue
<Progress.Root :model-value="progress">
  <Progress.Label>Subiendo fotos</Progress.Label>
  <Progress.ValueText />
  <Progress.Track>
    <Progress.Range />
  </Progress.Track>
</Progress.Root>
```

</ForFramework>

`value` va de 0 a 100 por defecto. Pasa `null` cuando todavía no sabes la cantidad.

## Referencia de la API

### Progress.Root

`size` es el añadido de Moderno; todas las partes lo siguen. El resto de props vienen del Progress de Ark.

<PropsTable component="Progress" />

| Prop            | Tipo                                           | Por defecto            | Descripción                                       |
| --------------- | ---------------------------------------------- | ---------------------- | ------------------------------------------------- |
| `value`         | `number \| null`                               | —                      | Valor controlado. `null` lo vuelve indeterminado. |
| `defaultValue`  | `number \| null`                               | `50`                   | Valor al principio, sin control.                  |
| `onValueChange` | `(details: { value: number \| null }) => void` | —                      | Se llama cuando cambia el valor.                  |
| `min`           | `number`                                       | `0`                    | El valor de una barra vacía.                      |
| `max`           | `number`                                       | `100`                  | El valor de una barra llena.                      |
| `orientation`   | `"horizontal" \| "vertical"`                   | `"horizontal"`         | Tiende la barra o la pone de pie.                 |
| `formatOptions` | `Intl.NumberFormatOptions`                     | `{ style: "percent" }` | Cómo imprime el valor `Progress.ValueText`.       |
| `locale`        | `string`                                       | `"en-US"`              | El idioma con el que se imprime el valor.         |

En Vue, enlaza el valor con `:model-value` o `v-model`, y escucha con `@value-change`.

### Progress.View

| Prop    | Tipo                                         | Por defecto | Descripción                                            |
| ------- | -------------------------------------------- | ----------- | ------------------------------------------------------ |
| `state` | `"loading" \| "complete" \| "indeterminate"` | —           | Obligatorio. Muestra su contenido solo en este estado. |

### Partes

| Parte                  | Elemento   | Descripción                                                       |
| ---------------------- | ---------- | ----------------------------------------------------------------- |
| `Progress.Root`        | `<div>`    | Lleva `data-size`.                                                |
| `Progress.Label`       | `<span>`   | Opcional. Nombra lo que está en curso.                            |
| `Progress.ValueText`   | `<span>`   | Opcional. El porcentaje, o tu propio texto.                       |
| `Progress.Track`       | `<div>`    | La barra, con `role="progressbar"` y `aria-valuenow`.             |
| `Progress.Range`       | `<div>`    | La parte llena de la barra. Ark fija su ancho a partir del valor. |
| `Progress.Circle`      | `<svg>`    | El anillo, con `role="progressbar"` y `aria-valuenow`.            |
| `Progress.CircleTrack` | `<circle>` | El anillo completo, detrás del rango.                             |
| `Progress.CircleRange` | `<circle>` | El arco, dibujado hasta el valor.                                 |
| `Progress.View`        | `<span>`   | Opcional. Muestra su contenido en un solo estado.                 |

### Atributos data

| Atributo           | Valores                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| `data-state`       | `"loading"`, `"complete"` o `"indeterminate"`, en la raíz, el track y el rango, y el círculo y su rango |
| `data-orientation` | `"horizontal"` o `"vertical"`, en la raíz, la etiqueta, el track y el rango                             |
| `data-size`        | En la raíz: `"sm"`, `"md"` o `"lg"`                                                                     |

## Notas

- `Progress.Root` está envuelto para añadir `size`; el resto de partes son las de Ark sin cambios.
- La barra de progreso se nombra con su valor (por ejemplo "60%"). Para nombrarla con la tarea, pasa `aria-label` a `Progress.Track` o a `Progress.Circle`.
- En Solid, empieza un progreso indeterminado con `defaultValue={null}`. El binding de Solid de Ark trata `value={null}` como no controlado.
- Con movimiento reducido el valor deja de deslizarse, y la barra y el anillo indeterminados se mueven más despacio en vez de pararse.
- Para una espera corta sin nada que medir, usa Spinner.
