## Referencia de API

### Dialog.Root

El Dialog de Ark, reexportado sin cambios; no renderiza ningún elemento propio.

| Prop                     | Tipo                                   | Por defecto | Descripción                                                                                                                           |
| ------------------------ | -------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `open`                   | `boolean`                              | —           | Estado abierto controlado. Úsalo con `onOpenChange` (`bind:open` en Svelte, `v-model:open` en Vue).                                   |
| `defaultOpen`            | `boolean`                              | `false`     | Estado abierto inicial cuando no está controlado.                                                                                     |
| `onOpenChange`           | `(details: { open: boolean }) => void` | —           | Se llama en cada apertura o cierre, incluidos Escape y los clics en el fondo.                                                         |
| `role`                   | `"dialog" \| "alertdialog"`            | `"dialog"`  | Usa `alertdialog` para confirmaciones que no se pueden deshacer.                                                                      |
| `modal`                  | `boolean`                              | `true`      | Bloquea la interacción fuera y oculta el contenido de debajo a las tecnologías de asistencia.                                         |
| `trapFocus`              | `boolean`                              | `true`      | Mantiene el foco dentro del diálogo mientras está abierto.                                                                            |
| `preventScroll`          | `boolean`                              | `true`      | Bloquea el scroll de la página mientras está abierto.                                                                                 |
| `restoreFocus`           | `boolean`                              | `true`      | Devuelve el foco al elemento enfocado antes de abrir.                                                                                 |
| `closeOnEscape`          | `boolean`                              | `true`      | Cierra con Escape.                                                                                                                    |
| `closeOnInteractOutside` | `boolean`                              | `true`      | Cierra con un clic fuera; `false` cuando `role="alertdialog"`.                                                                        |
| `initialFocusEl`         | `() => HTMLElement \| null`            | —           | Elemento que recibe el foco al abrir. Por defecto, el primer elemento enfocable, o el primer `Dialog.CloseTrigger` con `alertdialog`. |
| `finalFocusEl`           | `() => HTMLElement \| null`            | —           | Elemento que recibe el foco al cerrar.                                                                                                |
| `lazyMount`              | `boolean`                              | `false`     | Monta el contenido solo en la primera apertura.                                                                                       |
| `unmountOnExit`          | `boolean`                              | `false`     | Quita el contenido del DOM al cerrar.                                                                                                 |

### Portal

Renderiza sus hijos al final de `document.body`, fuera del contexto de apilamiento de la página.

### Partes

Cada parte acepta los atributos de su elemento; `Dialog.Trigger` y `Dialog.CloseTrigger` aceptan además `asChild` para renderizar tu propio `Button`.

| Parte                 | Elemento   | Descripción                                                                     |
| --------------------- | ---------- | ------------------------------------------------------------------------------- |
| `Dialog.Trigger`      | `<button>` | Abre el diálogo.                                                                |
| `Dialog.Backdrop`     | `<div>`    | La capa detrás del contenido: `--overlay` sobre la página desenfocada.          |
| `Dialog.Positioner`   | `<div>`    | Centra el contenido en el viewport.                                             |
| `Dialog.Content`      | `<div>`    | La superficie, pintada desde `--popover` y `--popover-foreground`. Una columna. |
| `Dialog.Title`        | `<h2>`     | El nombre accesible, conectado vía `aria-labelledby`.                           |
| `Dialog.Description`  | `<div>`    | Conectada vía `aria-describedby`.                                               |
| `Dialog.CloseTrigger` | `<button>` | Cierra el diálogo.                                                              |

### Teclado

| Tecla               | Acción                                                                            |
| ------------------- | --------------------------------------------------------------------------------- |
| `Esc`               | Cierra el diálogo.                                                                |
| `Tab` / `Shift+Tab` | Mueve el foco entre los elementos enfocables, dando la vuelta dentro del diálogo. |

## Notas

- Renderiza siempre `Dialog.Title`; es el nombre accesible del diálogo.
- El atrapado de foco, el bloqueo de scroll y la restauración del foco vienen de Ark; no los reimplementes.
- Un render SSR emite solo el trigger; tras la hidratación el contenido sigue en el DOM, oculto con el atributo `hidden`.
- Dialog no tiene variantes; el tono destructivo es de los `Button` que contiene.
