Dialog se compone como `Root > Trigger + Portal(> Backdrop + Positioner >
Content)`. Ark maneja el atrapado y restauración de foco, el bloqueo de
scroll y la conexión `aria-labelledby`/`aria-describedby`. Un render SSR solo
emite el trigger; después de hidratar, el contenido se queda en el DOM entre
aperturas y Ark lo saca del layout con el atributo `hidden`, que
`components.css` respeta para todas las partes. Sin variantes de CVA — la
superficie viene directo de los slots `--popover` / `--popover-foreground` vía
`components.css`.
