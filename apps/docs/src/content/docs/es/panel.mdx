Cada panel es `{ id, title, description, actionLabel }`. Omite `actionLabel` para un panel sin botón.

## Referencia de API

### Propiedades

| Propiedad     | Tipo                   | Por defecto          | Descripción                                                            |
| ------------- | ---------------------- | -------------------- | ---------------------------------------------------------------------- |
| `panels`      | `PanelItem[]`          | un ejemplo           | Los paneles, en orden de lectura. `[]` muestra el estado vacío.        |
| `heading`     | `string`               | `"Account settings"` | El título sobre los paneles.                                           |
| `description` | `string`               | una frase            | La línea bajo el título; `""` la oculta.                               |
| `error`       | `string`               | —                    | Los paneles no cargaron; una alerta con reintento los reemplaza.       |
| `loading`     | `boolean`              | `false`              | Paneles de marcador en una región ocupada reemplazan los paneles.      |
| `disabled`    | `boolean`              | `false`              | Los paneles siguen legibles y todos los botones quedan desactivados.   |
| `onAction`    | `(id: string) => void` | —                    | El botón de un panel, con su `id`. Svelte: `onaction`. Vue: `@action`. |
| `onRetry`     | `() => void`           | —                    | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.            |

### PanelItem

| Campo         | Tipo     | Descripción                                      |
| ------------- | -------- | ------------------------------------------------ |
| `id`          | `string` | Identidad estable, la que devuelve `onAction`.   |
| `title`       | `string` | Lo que agrupa el panel.                          |
| `description` | `string` | Una frase sobre lo que hay dentro.               |
| `actionLabel` | `string` | Texto opcional del botón; nombra el panel en él. |

### Estados

| Estado        | Propiedad     | Qué se muestra                                                        |
| ------------- | ------------- | --------------------------------------------------------------------- |
| Por defecto   | —             | Una tarjeta por panel.                                                |
| Vacío         | `panels={[]}` | Una tarjeta "Nothing to set up yet".                                  |
| Cargando      | `loading`     | Cuatro paneles de marcador en una región `status` ocupada.            |
| Error         | `error`       | Una alerta de error con el botón "Try again" en lugar de los paneles. |
| Deshabilitado | `disabled`    | Los paneles con todos los botones desactivados.                       |

### Dimensionado

| Paso del contenedor      | Qué cambia                                         |
| ------------------------ | -------------------------------------------------- |
| bajo `@sm`               | Un panel por fila; cada botón ocupa todo su panel. |
| `@sm` (`--container-sm`) | Cada botón se ajusta a su texto.                   |
| `@md` (`--container-md`) | Dos paneles por fila y un título más grande.       |
| `@lg` (`--container-lg`) | Más espacio entre los paneles.                     |
