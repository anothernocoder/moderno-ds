## Uso

Usa Product Details en la parte de arriba de la página de un producto. El cliente mira las fotos, elige un color o una talla, decide cuántos quiere y añade el producto al carrito.

<ForFramework fw="react">

```tsx
import { ProductDetails } from "@/components/blocks/product-details";
```

```tsx
<ProductDetails product={product} adding={adding} onAddToCart={addToCart} />
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import ProductDetails from "@/components/blocks/ProductDetails.vue";
</script>
```

```vue
<ProductDetails :product="product" :adding="adding" @add-to-cart="addToCart" />
```

</ForFramework>
<ForFramework fw="svelte">

```svelte
<script lang="ts">
  import ProductDetails from "@/components/blocks/ProductDetails.svelte";
</script>
```

```svelte
<ProductDetails {product} {adding} onaddtocart={addToCart} />
```

</ForFramework>
<ForFramework fw="solid">

```tsx
import { ProductDetails } from "@/components/blocks/product-details";
```

```tsx
<ProductDetails product={product()} adding={adding()} onAddToCart={addToCart} />
```

</ForFramework>

`addToCart` recibe las opciones elegidas y la cantidad, por ejemplo `{ options: { Colour: "sage", Size: "350" }, quantity: 2 }`. Pasa `adding` mientras lo guardas.

## Referencia de la API

### Props

| Prop          | Tipo                                    | Por defecto            | Descripción                                                                                                  |
| ------------- | --------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------ |
| `product`     | `Product \| null`                       | un producto de ejemplo | El producto que se muestra. `null` muestra el mensaje de vacío.                                              |
| `error`       | `string`                                | —                      | No se pudo cargar el producto; una Alert de error con un reintento lo reemplaza.                             |
| `loading`     | `boolean`                               | `false`                | Unos marcadores en una región ocupada reemplazan el producto.                                                |
| `disabled`    | `boolean`                               | `false`                | El producto se sigue leyendo; todas las opciones, la caja de cantidad y los botones se apagan.               |
| `adding`      | `boolean`                               | `false`                | El botón muestra un spinner, dice "Adding" y no se puede pulsar.                                             |
| `onAddToCart` | `(selection: ProductSelection) => void` | —                      | Se pulsó "Add to cart", con las opciones y la cantidad elegidas. Svelte: `onaddtocart`. Vue: `@add-to-cart`. |
| `onRetry`     | `() => void`                            | —                      | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                                                  |

### Product

| Campo            | Tipo               | Descripción                                                          |
| ---------------- | ------------------ | -------------------------------------------------------------------- |
| `name`           | `string`           | El nombre del producto, el encabezado del bloque.                    |
| `price`          | `string`           | El precio tal como se lee, como `"€28"`.                             |
| `compareAtPrice` | `string`           | Opcional. El precio anterior, tachado junto al precio.               |
| `description`    | `string`           | Opcional. Un párrafo corto bajo el precio.                           |
| `images`         | `ProductImage[]`   | Opcional. Las fotos, `{ src, alt }`. Sin ellas, un cuadrado apagado. |
| `options`        | `ProductOption[]`  | Opcional. `{ name, values }`, un RadioGroup por cada una.            |
| `sections`       | `ProductSection[]` | Opcional. `{ title, body }`, una pestaña por cada una.               |
| `maxQuantity`    | `number`           | Opcional. Lo máximo que se puede elegir; `99` si no se indica.       |

### ProductOptionValue

| Campo     | Tipo      | Descripción                                             |
| --------- | --------- | ------------------------------------------------------- |
| `value`   | `string`  | Lo que `onAddToCart` informa para esta elección.        |
| `label`   | `string`  | Lo que lee el cliente, como `"Sage"`.                   |
| `soldOut` | `boolean` | Opcional. Marca la elección como "Sold out" y la apaga. |

### ProductSelection

| Campo      | Tipo                     | Descripción                                      |
| ---------- | ------------------------ | ------------------------------------------------ |
| `options`  | `Record<string, string>` | El `name` de cada opción con el `value` elegido. |
| `quantity` | `number`                 | Cuántos, un número entero de 1 a `maxQuantity`.  |

### Estados

| Estado      | Prop                 | Qué se muestra                                                                     |
| ----------- | -------------------- | ---------------------------------------------------------------------------------- |
| Normal      | —                    | La galería, el nombre, el precio, las opciones, la cantidad y las pestañas.        |
| Añadiendo   | `adding`             | Lo mismo, con un spinner y "Adding" en el botón.                                   |
| Agotado     | todo valor `soldOut` | Lo mismo, con "Sold out" en el botón y la caja de cantidad apagada.                |
| Vacío       | `product={null}`     | "This product is no longer available." en una caja discontinua.                    |
| Cargando    | `loading`            | Marcadores para la galería y los detalles.                                         |
| Error       | `error`              | Una Alert de error con "Try again".                                                |
| Desactivado | `disabled`           | El mismo producto con todas las opciones, la caja de cantidad y el botón apagados. |

### Tamaños

| Paso del contenedor      | Qué cambia                                    |
| ------------------------ | --------------------------------------------- |
| bajo `@sm`               | Una columna. La cantidad va encima del botón. |
| `@sm` (`--container-sm`) | La cantidad y el botón comparten fila.        |
| `@md` (`--container-md`) | El nombre crece.                              |
| `@lg` (`--container-lg`) | La galería pasa junto a los detalles.         |
