## Referencia de la API

### Props

| Prop          | Tipo              | Por defecto              | Descripción                                                                  |
| ------------- | ----------------- | ------------------------ | ---------------------------------------------------------------------------- |
| `heading`     | `string`          | una frase                | El título sobre las cifras. Se muestra como `h2`.                            |
| `description` | `string`          | una frase                | Una línea breve bajo el encabezado. `""` la oculta.                          |
| `actionLabel` | `string`          | una etiqueta             | El botón outline junto al encabezado. `""` lo oculta.                        |
| `stats`       | `StatStripStat[]` | cuatro cifras de muestra | Las cifras, en orden. `[]` muestra el mensaje de vacío.                      |
| `error`       | `string`          | —                        | Falló la carga de las cifras; un Alert de error con reintento las sustituye. |
| `loading`     | `boolean`         | `false`                  | Pares de esqueleto en una región ocupada sustituyen a las cifras.            |
| `disabled`    | `boolean`         | `false`                  | Las cifras se quedan; la acción y el reintento quedan deshabilitados.        |
| `onAction`    | `() => void`      | —                        | Se pulsó la acción. Svelte: `onaction`. Vue: `@action`.                      |
| `onRetry`     | `() => void`      | —                        | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                  |

### Cifra

| Campo   | Tipo     | Descripción                                   |
| ------- | -------- | --------------------------------------------- |
| `id`    | `string` | Una clave estable para la cifra.              |
| `value` | `string` | La cifra, ya con formato, como `$2.4B`.       |
| `label` | `string` | Lo que cuenta la cifra. Se lee bajo el valor. |

### Estados

| Estado        | Prop         | Qué se muestra                                                     |
| ------------- | ------------ | ------------------------------------------------------------------ |
| Por defecto   | —            | El encabezado, la acción y cada cifra.                             |
| Vacío         | `stats={[]}` | El encabezado y "No numbers to show yet." en un recuadro punteado. |
| Cargando      | `loading`    | El encabezado y cuatro pares de marcador.                          |
| Error         | `error`      | El encabezado y un Alert de error con "Try again".                 |
| Deshabilitado | `disabled`   | Las mismas cifras; la acción queda deshabilitada.                  |

### Tamaño

| Paso del contenedor      | Qué cambia                                                     |
| ------------------------ | -------------------------------------------------------------- |
| bajo `@sm`               | Dos cifras por fila; la acción va bajo el encabezado.          |
| `@sm` (`--container-sm`) | La acción pasa junto al encabezado.                            |
| `@md` (`--container-md`) | El encabezado y los valores suben un tamaño.                   |
| `@lg` (`--container-lg`) | Las cuatro cifras en una fila, con más espacio arriba y abajo. |

## Notas

- Mantén los valores cortos. Una cifra de más de unos ocho caracteres aprieta su columna.
- Di de dónde sale cada número, en la descripción o en la página que abre la acción.
