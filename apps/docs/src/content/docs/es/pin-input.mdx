## Uso

<ForFramework fw="react">

```tsx
import { PinInput } from "@moderno-ui/react";

const cells = [0, 1, 2, 3, 4, 5];
```

```tsx
<PinInput.Root count={cells.length} otp>
  <PinInput.Label>Verification code</PinInput.Label>
  <PinInput.Control>
    {cells.map((index) => (
      <PinInput.Input key={index} index={index} />
    ))}
  </PinInput.Control>
  <PinInput.HiddenInput />
</PinInput.Root>
```

</ForFramework>

<ForFramework fw="vue">

```vue
<script setup lang="ts">
import { PinInput } from "@moderno-ui/vue";
```

```vue

    </PinInput.Control>
    <PinInput.HiddenInput />
  </PinInput.Root>
```


</ForFramework>

## Referencia de API

### PinInput.Root

<PropsTable component="PinInput" />

Las props de comportamiento vienen de Ark. Las que usan los ejemplos:

| Prop           | Tipo                                    | Por defecto | Descripción                                                                                      |
| -------------- | --------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------ |
| `count`        | `number`                                | —           | Número de celdas. Pásalo para que las etiquetas aria del servidor coincidan con las del cliente. |
| `type`         | `numeric`, `alphanumeric`, `alphabetic` | `numeric`   | Caracteres aceptados. `numeric` renderiza las celdas como `type="tel"`.                          |
| `mask`         | `boolean`                               | `false`     | Renderiza cada celda como `type="password"`.                                                     |
| `otp`          | `boolean`                               | `false`     | Pone `autocomplete="one-time-code"` en las celdas.                                               |
| `invalid`      | `boolean`                               | `false`     | Pone `aria-invalid` y `data-invalid`.                                                            |
| `defaultValue` | `string[]`                              | —           | Caracteres iniciales, uno por celda.                                                             |

### Partes

| Parte                  | Descripción                                                    |
| ---------------------- | -------------------------------------------------------------- |
| `PinInput.Root`        | Guarda el estado. Recibe `size` y las props de comportamiento. |
| `PinInput.Label`       | La etiqueta visible.                                           |
| `PinInput.Control`     | Envuelve las celdas.                                           |
| `PinInput.Input`       | Una celda. Renderiza una por `index`, de 0 a `count - 1`.      |
| `PinInput.HiddenInput` | El campo de formulario con nombre que lleva el código unido.   |

### Atributos de datos

| Atributo        | En                 | Significado                                         |
| --------------- | ------------------ | --------------------------------------------------- |
| `data-size`     | Root               | `sm`, `md` (por defecto), `lg`                      |
| `data-filled`   | Input              | La celda tiene un carácter.                         |
| `data-complete` | Root, Label, Input | Todas las celdas tienen un carácter.                |
| `data-invalid`  | Root, Label, Input | `invalid` está activo. Gana sobre lleno y completo. |
| `data-disabled` | Root, Label, Input | `disabled` está activo.                             |

## Notas

- El foco avanza al escribir, retrocede con Backspace, y un código pegado llena las celdas.
- Solo `PinInput.Root` está envuelto, para añadir `size`. Todas las demás partes son las de Ark.
- Añade `PinInput.HiddenInput` cuando el código se envía con un formulario.
- Lleno, completo e inválido son atributos de datos de Ark: estilízalos, no los recrees.
