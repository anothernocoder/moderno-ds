Solo `PinInput.Root` está envuelto, para inyectar el `data-size` de la receta
`size`; el resto de las partes son las de Ark tal cual. Ark avanza el foco a
medida que llegan los caracteres, retrocede con backspace, reparte un código
pegado entre las celdas, las cambia a `type="password"` cuando se activa `mask`
y refleja `invalid` en `aria-invalid` más un `data-invalid` en cada parte — así
`components.css` pinta los estados lleno, completo e inválido sin que el binding
lleve la cuenta de ninguno.
