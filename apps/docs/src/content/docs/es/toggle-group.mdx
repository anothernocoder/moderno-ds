## Uso

Un toggle group es una fila de botones para opciones relacionadas. Por defecto se queda pulsado un botón a la vez, como en la alineación del texto; con `multiple` pueden quedarse varios, como negrita y cursiva.

<ForFramework fw="react">

```tsx
import { ToggleGroup } from "@moderno-ui/react";
```

```tsx
<ToggleGroup.Root defaultValue={["left"]} aria-label="Text alignment">
  <ToggleGroup.Item value="left">Left</ToggleGroup.Item>
  <ToggleGroup.Item value="center">Center</ToggleGroup.Item>
  <ToggleGroup.Item value="right">Right</ToggleGroup.Item>
</ToggleGroup.Root>
```

</ForFramework>

## Referencia de la API

### ToggleGroup.Root

`variant` y `size` son los añadidos de Moderno, y todos los elementos los siguen. El resto de props vienen del ToggleGroup de Ark.

<PropsTable component="ToggleGroup" />

| Prop            | Tipo                                     | Por defecto    | Descripción                                                                |
| --------------- | ---------------------------------------- | -------------- | -------------------------------------------------------------------------- |
| `value`         | `string[]`                               | —              | Elementos pulsados, controlado. Úsalo con `onValueChange`.                 |
| `defaultValue`  | `string[]`                               | `[]`           | Elementos pulsados al inicio cuando no está controlado.                    |
| `onValueChange` | `(details: { value: string[] }) => void` | —              | Se llama cuando un elemento se pulsa o se suelta.                          |
| `multiple`      | `boolean`                                | `false`        | Permite que varios elementos se queden pulsados.                           |
| `deselectable`  | `boolean`                                | `true`         | En modo simple, deja soltar el elemento pulsado.                           |
| `orientation`   | `"horizontal" \| "vertical"`             | `"horizontal"` | Coloca los elementos en fila o en columna; define las flechas del teclado. |
| `disabled`      | `boolean`                                | `false`        | Deshabilita todos los elementos.                                           |
| `loopFocus`     | `boolean`                                | `true`         | Las flechas pasan del último elemento al primero.                          |
| `rovingFocus`   | `boolean`                                | `true`         | Tab se detiene una vez en el grupo; las flechas se mueven entre elementos. |

En Vue, escucha con `@value-change` o enlaza el valor con `v-model`.

### ToggleGroup.Item

| Prop       | Tipo      | Por defecto | Descripción                         |
| ---------- | --------- | ----------- | ----------------------------------- |
| `value`    | `string`  | —           | Obligatorio. El valor del elemento. |
| `disabled` | `boolean` | `false`     | Deshabilita solo este elemento.     |

### Partes

| Parte              | Elemento   | Descripción                                                                                                   |
| ------------------ | ---------- | ------------------------------------------------------------------------------------------------------------- |
| `ToggleGroup.Root` | `<div>`    | `role="radiogroup"`, o `role="group"` con `multiple`. Lleva `data-variant`, `data-size` y `data-orientation`. |
| `ToggleGroup.Item` | `<button>` | Una opción. `role="radio"` con `aria-checked`, o `aria-pressed` con `multiple`.                               |

### Atributos data

| Atributo           | Valores                                                                                |
| ------------------ | -------------------------------------------------------------------------------------- |
| `data-state`       | En cada elemento: `"on"` u `"off"`                                                     |
| `data-disabled`    | Presente en un elemento deshabilitado, y en la raíz cuando el grupo está deshabilitado |
| `data-orientation` | `"horizontal"` o `"vertical"`, en la raíz y los elementos                              |
| `data-variant`     | En la raíz: `"ghost"` u `"outline"`                                                    |
| `data-size`        | En la raíz: `"sm"`, `"md"` o `"lg"`                                                    |

## Notas

- `ToggleGroup.Root` está envuelto para añadir `variant` y `size`; el resto de partes son las de Ark sin cambios.
- Estiliza el estado desde `data-state` y los atributos `data-*` de cada elemento; `variant` y `size` son las únicas props visuales.
- Para una elección en un formulario, donde cada opción necesita su propia etiqueta, usa Radio Group.
