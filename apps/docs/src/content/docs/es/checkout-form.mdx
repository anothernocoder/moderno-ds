## Referencia de la API

### Props

| Prop              | Tipo                      | Por defecto       | Descripción                                                            |
| ----------------- | ------------------------- | ----------------- | ---------------------------------------------------------------------- |
| `step`            | `"shipping" \| "payment"` | `"shipping"`      | Qué paso pide el formulario.                                           |
| `heading`         | `string`                  | según el paso     | El encabezado. Va en la fuente con serifa.                             |
| `description`     | `string`                  | según el paso     | Una frase bajo el encabezado; `""` la oculta.                          |
| `headingLevel`    | `1 \| 2`                  | `2`               | `1` hace del encabezado un h1 y del título de cada grupo un h2.        |
| `deliveryOptions` | `DeliveryOption[]`        | estándar y exprés | Los métodos de entrega del paso de envío. `[]` los oculta.             |
| `error`           | `string`                  | —                 | Falló el paso; un Alert de error va arriba del formulario.             |
| `errors`          | `Record<string, string>`  | —                 | Un mensaje por campo, bajo el nombre del campo.                        |
| `loading`         | `boolean`                 | `false`           | Todos los controles deshabilitados y el botón de seguir ocupado.       |
| `disabled`        | `boolean`                 | `false`           | Todos los controles y los dos botones deshabilitados.                  |
| `onSubmit`        | `(event) => void`         | —                 | El evento de envío del formulario. Svelte: `onsubmit`. Vue: `@submit`. |
| `onBack`          | `() => void`              | —                 | Se pulsó el botón de volver. Svelte: `onback`. Vue: `@back`.           |

### Campos

| Paso       | Grupo            | Nombres de campo                                                  |
| ---------- | ---------------- | ----------------------------------------------------------------- |
| `shipping` | Contact          | `email`                                                           |
| `shipping` | Shipping address | `fullName`, `address`, `city`, `region`, `postalCode`, `country`  |
| `shipping` | Delivery method  | `delivery` (el `id` de la opción elegida)                         |
| `payment`  | Card details     | `cardName`, `cardNumber`, `expiry`, `cvc`, `saveCard` (el switch) |

### DeliveryOption

| Campo         | Tipo     | Descripción                                       |
| ------------- | -------- | ------------------------------------------------- |
| `id`          | `string` | El valor que el formulario envía bajo `delivery`. |
| `label`       | `string` | El nombre de la opción, como `"Express"`.         |
| `description` | `string` | Cuánto tarda, como `"2–5 business days"`.         |
| `price`       | `string` | Lo que cuesta, ya con formato, como `"$16.00"`.   |

### Estados

| Estado        | Prop                   | Qué se muestra                                               |
| ------------- | ---------------------- | ------------------------------------------------------------ |
| Por defecto   | —                      | El paso de envío: contacto, dirección y método de entrega.   |
| Pago          | `step="payment"`       | Los datos de la tarjeta y el switch para guardarla.          |
| Vacío         | `deliveryOptions={[]}` | El paso de envío sin método de entrega.                      |
| Cargando      | `loading`              | Todos los controles deshabilitados y un "Saving" ocupado.    |
| Error         | `error`/`errors`       | Un Alert de error arriba del formulario y campos no válidos. |
| Deshabilitado | `disabled`             | Todos los controles y los dos botones deshabilitados.        |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------------- |
| bajo `@sm`               | Cada campo en su propia fila. Los botones se apilan a todo el ancho, seguir arriba.                 |
| `@sm` (`--container-sm`) | Ciudad y estado, código postal y país, vencimiento y CVC van en pareja. Los botones comparten fila. |
| `@md` (`--container-md`) | El encabezado sube un tamaño. Las opciones de entrega van lado a lado.                              |
| `@lg` (`--container-lg`) | El título de cada grupo va junto a sus campos, con más espacio arriba y abajo.                      |

## Notas

- Envía los datos de la tarjeta directamente a tu proveedor de pagos, nunca a tu propio servidor.
- Deja `error` corto y di qué falló. El formulario conserva lo escrito, así el comprador puede corregirlo e intentarlo otra vez.
