## Uso

Usa Store Nav una vez, arriba en cada página de una tienda. Enlaza al inicio y a las categorías, busca en el catálogo y abre el carrito.

<ForFramework fw="react">

```tsx
import { StoreNav } from "@/components/blocks/store-nav";
```

```tsx
<StoreNav
  brand="Northwind"
  categories={categories}
  suggestions={products}
  cartCount={cart.length}
  onSearch={(query) => navigate(`/search?q=${encodeURIComponent(query)}`)}
  onCart={openCart}
/>
```

</ForFramework>

Una categoría es así: `{ id: "bags", label: "Bolsos", href: "/bags" }`, o `{ id: "workspace", label: "Escritorio", links: [...] }` cuando tiene subcategorías. Una sugerencia es así: `{ value: "canvas-tote", label: "Bolso de lona", href: "/products/canvas-tote" }`.

## Referencia de la API

### Props

| Prop          | Tipo                      | Por defecto                             | Descripción                                                                            |
| ------------- | ------------------------- | --------------------------------------- | -------------------------------------------------------------------------------------- |
| `brand`       | `string`                  | `"Northwind"`                           | El nombre de la tienda, en la fuente serif. Enlaza al inicio y titula el Drawer.       |
| `homeHref`    | `string`                  | `"/"`                                   | A dónde enlaza la marca.                                                               |
| `categories`  | `StoreNavCategory[]`      | dos categorías con subcategorías y Bags | Las categorías, en la barra y en el Drawer.                                            |
| `suggestions` | `StoreNavSuggestion[]`    | seis productos de ejemplo               | Lo que sugiere la búsqueda, filtrado por el texto escrito.                             |
| `cartCount`   | `number`                  | `2`                                     | Cuántos artículos tiene el carrito, en un Badge.                                       |
| `error`       | `string`                  | —                                       | Las categorías no cargaron; una Alert de error con un reintento aparece bajo la barra. |
| `loading`     | `boolean`                 | `false`                                 | Marcadores en una región ocupada reemplazan las categorías.                            |
| `onSearch`    | `(query: string) => void` | —                                       | Enter en la búsqueda sin una sugerencia resaltada. Svelte: `onsearch`. Vue: `@search`. |
| `onCart`      | `() => void`              | —                                       | Se pulsó el botón del carrito. Svelte: `oncart`. Vue: `@cart`.                         |
| `onRetry`     | `() => void`              | —                                       | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                            |

### StoreNavCategory

`StoreNavCategory` es un `StoreNavLink` o un `StoreNavMenu`.

Un `StoreNavLink`:

| Campo      | Tipo      | Descripción                                                              |
| ---------- | --------- | ------------------------------------------------------------------------ |
| `id`       | `string`  | Una clave estable para el enlace.                                        |
| `label`    | `string`  | El texto del enlace.                                                     |
| `href`     | `string`  | A dónde lleva el enlace.                                                 |
| `current`  | `boolean` | Opcional. La categoría en la que está el usuario: `aria-current="page"`. |
| `disabled` | `boolean` | Opcional. El enlace se atenúa, no tiene `href` y no recibe el foco.      |

Un `StoreNavMenu`:

| Campo   | Tipo             | Descripción                                                                               |
| ------- | ---------------- | ----------------------------------------------------------------------------------------- |
| `id`    | `string`         | Una clave estable para la categoría.                                                      |
| `label` | `string`         | El texto del disparador del Menu en la barra, y la etiqueta de la categoría en el Drawer. |
| `links` | `StoreNavLink[]` | Las subcategorías: elementos del Menu en la barra, una lista en el Drawer.                |

### StoreNavSuggestion

| Campo   | Tipo     | Descripción                                  |
| ------- | -------- | -------------------------------------------- |
| `value` | `string` | Una clave estable para la sugerencia.        |
| `label` | `string` | El texto que se muestra y el que se compara. |
| `href`  | `string` | A dónde lleva elegir la sugerencia.          |

### Estados

| Estado         | Prop                    | Qué se muestra                                                    |
| -------------- | ----------------------- | ----------------------------------------------------------------- |
| Por defecto    | `categories`            | La marca, las categorías, la búsqueda y el carrito.               |
| Vacío          | `categories={[]}`       | La marca, la búsqueda y el carrito. Sin botón "Menu".             |
| Sin resultados | una búsqueda            | La lista dice "No suggestions. Press Enter to search."            |
| Cargando       | `loading`               | Tres marcadores donde van las categorías.                         |
| Error          | `error`                 | Una Alert de error con "Try again" bajo la barra. Sin categorías. |
| Deshabilitado  | `disabled` en un enlace | Ese enlace atenuado, fuera del orden de tabulación.               |

### Tamaño

| Paso del contenedor      | Qué cambia                                                             |
| ------------------------ | ---------------------------------------------------------------------- |
| bajo `@sm`               | La marca y "Menu". La búsqueda y el carrito comparten una fila debajo. |
| `@sm` (`--container-sm`) | Más espacio en los extremos de la barra.                               |
| `@md` (`--container-md`) | Las categorías van en la barra. El botón "Menu" desaparece.            |
| `@lg` (`--container-lg`) | La búsqueda y el carrito entran en la barra, tras las categorías.      |

## Notas

- Deja pocas sugerencias: un puñado de productos o categorías. Para un catálogo completo, búscalas mientras el usuario escribe y pasa el resultado.
- Deja las etiquetas de las categorías en una palabra, para que la barra quepa en una línea.
