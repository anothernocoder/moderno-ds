## Referencia de API

### Divider

Renderiza un `<div>`; sus hijos se convierten en la etiqueta. `orientation` vale `horizontal` por defecto y `align`, `center`.

<PropsTable component="Divider" />

### Partes

| Parte   | Elemento | Descripción                                                                             |
| ------- | -------- | --------------------------------------------------------------------------------------- |
| `root`  | `<div>`  | La regla. Lleva `data-orientation` y `data-align`; el trazo es su `::before`/`::after`. |
| `label` | `<span>` | Solo se renderiza cuando hay hijos.                                                     |

### Semántica

| Divisor            | `role`      | `aria-orientation` |
| ------------------ | ----------- | ------------------ |
| Simple (sin hijos) | `separator` | El `orientation`   |
| Con etiqueta       | ninguno     | ninguno            |

## Notas

- Un divisor con etiqueta quita `role="separator"`, porque ese rol ocultaría la etiqueta a las tecnologías de asistencia.
- `align` solo mueve la etiqueta; no hace nada en un divisor simple.
- Un divisor vertical se estira a la altura de su fila, con un mínimo de `--spacing-4`.
- El trazo es `--border` y la etiqueta `--muted-foreground`; nunca pases un color.
