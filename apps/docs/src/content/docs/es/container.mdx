Usa `sm` para lectura y formularios cortos, `md` para la mayoría de las páginas y `lg` para vistas densas.

## Referencia de API

### Propiedades

| Propiedad  | Tipo                              | Por defecto         | Descripción                                                        |
| ---------- | --------------------------------- | ------------------- | ------------------------------------------------------------------ |
| `size`     | `"sm" \| "md" \| "lg" \| "full"`  | `"lg"`              | El ancho máximo del contenido; `full` no tiene límite.             |
| `children` | contenido (Vue y Svelte: el slot) | una tarjeta ejemplo | Lo que el contenedor centra. Sin él, se ve una tarjeta de ejemplo. |

### Tamaños

| Tamaño | Ancho máximo                    |
| ------ | ------------------------------- |
| `sm`   | `--container-sm` (24rem)        |
| `md`   | `--container-md` (36rem)        |
| `lg`   | `--container-lg` (48rem)        |
| `full` | ninguno: el ancho de su espacio |

### Estados

El contenedor no tiene estados propios. Cargando, vacío y error son de su contenido.

### Dimensionado

| Paso del contenedor      | Qué cambia                                |
| ------------------------ | ----------------------------------------- |
| bajo `@sm`               | Un margen estrecho a cada lado.           |
| `@sm` (`--container-sm`) | Un margen más ancho.                      |
| `@md` (`--container-md`) | Un margen más ancho todavía.              |
| `@lg` (`--container-lg`) | Más espacio arriba y abajo del contenido. |
