## Referencia de API

### Props

Los callbacks son props `on…` en React y Solid, en minúsculas (`onsubmit`) en Svelte y eventos (`submit`, `navigate`) en Vue.

| Prop               | Tipo                     | Por defecto     | Descripción                                                                |
| ------------------ | ------------------------ | --------------- | -------------------------------------------------------------------------- |
| `token`            | `string`                 | `""`            | El token del enlace del correo, enviado desde un campo oculto.             |
| `requirements`     | `PasswordRequirement[]`  | tres sin marcar | Reglas bajo la contraseña nueva, como `{ id, label, met? }`.               |
| `error`            | `string`                 | —               | Fallo del formulario: el enlace caducó o ya se usó, o no se pudo guardar.  |
| `errors`           | `Record<string, string>` | —               | Mensajes por campo con clave `password` o `confirmPassword`.               |
| `loading`          | `boolean`                | `false`         | Envío en curso: todos los controles inertes, el botón ocupado.             |
| `disabled`         | `boolean`                | `false`         | Aquí no se puede fijar contraseña; combínalo con `error`.                  |
| `notices`          | `AlertListItem[]`        | tres de ejemplo | Notas junto a la tarjeta. `[]` oculta el aparte.                           |
| `noticesError`     | `string`                 | —               | Las notas no cargaron; este mensaje sustituye a la lista.                  |
| `noticesLoading`   | `boolean`                | `false`         | Una región ocupada sustituye a las notas.                                  |
| `onSubmit`         | `(event) => void`        | —               | Envío nativo del formulario.                                               |
| `onNavigate`       | `(to, event) => void`    | —               | Se pulsó un enlace de la pantalla: `home`, `support`, `privacy` o `terms`. |
| `onNoticeAction`   | `(id) => void`           | —               | El botón de acción de una nota, con su id.                                 |
| `onDismissNotice`  | `(id) => void`           | —               | Se descartó una nota.                                                      |
| `onDismissNotices` | `() => void`             | —               | Se descartaron todas las notas.                                            |
| `onRetryNotices`   | `() => void`             | —               | Reintentar tras `noticesError`.                                            |
| `signInHref`       | `string`                 | `"#"`           | Destino de «Sign in» en el pie de la tarjeta.                              |
| `homeHref`         | `string`                 | `"#"`           | Destino del logotipo.                                                      |
| `supportHref`      | `string`                 | `"#"`           | Destino de «Contact support».                                              |
| `privacyHref`      | `string`                 | `"#"`           | Destino del enlace de privacidad.                                          |
| `termsHref`        | `string`                 | `"#"`           | Destino del enlace de términos.                                            |

### Estados

| Estado           | Props                          | Qué se renderiza                                                   |
| ---------------- | ------------------------------ | ------------------------------------------------------------------ |
| Por defecto      | —                              | Contraseña nueva y confirmación, reglas sin marcar, notas al lado. |
| Reglas cumplidas | `requirements` con `met`       | Filas marcadas; cada una se anuncia como «met» por sí sola.        |
| Error            | `error` + `disabled`           | Un enlace gastado o caducado: una alerta, el formulario inerte.    |
| Error de campo   | `errors={{ confirmPassword }}` | Ese campo inválido, con su propio mensaje.                         |
| Cargando         | `loading`                      | Controles inertes, envío con `aria-busy`.                          |
| Notas cargando   | `noticesLoading`               | Una región ocupada en lugar de las notas.                          |
| Error de notas   | `noticesError`                 | Una alerta en lugar de las notas.                                  |
| Vacío            | `notices={[]}`                 | Sin aparte; la tarjeta queda centrada y sola.                      |

### Campos del formulario

| Nombre            | Control      | Se envía                                    |
| ----------------- | ------------ | ------------------------------------------- |
| `password`        | Contraseña   | Siempre, con `autocomplete="new-password"`. |
| `confirmPassword` | Contraseña   | Siempre, con `autocomplete="new-password"`. |
| `token`           | Campo oculto | Cuando hay `token`.                         |

### Tamaño

| Paso del contenedor      | Cambio                                   |
| ------------------------ | ---------------------------------------- |
| `@sm` (`--container-sm`) | La cabecera pasa a una sola fila.        |
| `@md` (`--container-md`) | El pie pasa a una sola fila.             |
| `@lg` (`--container-lg`) | Las notas se colocan junto a la tarjeta. |

| Parte                        | Papel                                                       |

## Notas

- Las reglas son el texto de ayuda del campo, así que están en su `aria-describedby` y se leen al enfocarlo.
- La lista de reglas es una región viva educada; el color nunca es la única señal de que una regla se cumple.
- La pantalla no guarda el valor: recalcula `met` en tu página. Nunca bloquea un envío.
- Tu servidor debe aplicar cada regla de nuevo; la lista del navegador es solo una guía.
- Un enlace caducado o usado es `error` más `disabled`, nunca un error de campo.
- El token viaja en un campo oculto, así que el restablecimiento se envía como formulario normal antes de hidratar.
