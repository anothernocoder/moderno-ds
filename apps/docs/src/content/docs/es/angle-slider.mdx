## Uso

Angle Slider permite elegir un ángulo girando un dial redondo. Úsalo para una dirección o una rotación, como la dirección de un degradado. El campo numérico junto al dial muestra el mismo ángulo, y el usuario también puede escribirlo ahí.

**0° apunta hacia arriba**, y el ángulo crece en el sentido de las agujas del reloj: 90° apunta a la derecha, 180° hacia abajo, 270° a la izquierda.

El valor es un número de grados, de 0 a 359. Al arrastrar más allá de 360° sigue desde 0°, sin saltos.

## Referencia de la API

### AngleSlider.Root

`size`, `marks` y `getAriaValueText` son lo que añade Moderno. Las demás props vienen del Angle Slider de Ark.

<PropsTable component="AngleSlider" />

| Prop               | Tipo                                                          | Por defecto    | Descripción                                                            |
| ------------------ | ------------------------------------------------------------- | -------------- | ---------------------------------------------------------------------- |
| `value`            | `number`                                                      | —              | Ángulo controlado, en grados.                                          |
| `defaultValue`     | `number`                                                      | `0`            | Ángulo inicial cuando no está controlado.                              |
| `onValueChange`    | `(details: { value: number; valueAsDegree: string }) => void` | —              | Se llama mientras cambia el ángulo.                                    |
| `onValueChangeEnd` | `(details: { value: number; valueAsDegree: string }) => void` | —              | Se llama una vez, cuando el usuario suelta o una tecla fija el ángulo. |
| `step`             | `number`                                                      | `1`            | Cuánto gira el dial en cada paso, en grados.                           |
| `marks`            | `number[]`                                                    | —              | Ángulos a los que se ajusta al arrastrar con Shift.                    |
| `size`             | `"sm" \| "md" \| "lg"`                                        | `"md"`         | El tamaño del dial, igual a los tamaños de Field.                      |
| `disabled`         | `boolean`                                                     | `false`        | Atenúa el dial y el campo e ignora la entrada.                         |
| `readOnly`         | `boolean`                                                     | `false`        | Muestra el ángulo pero ignora la entrada.                              |
| `invalid`          | `boolean`                                                     | `false`        | Marca el ángulo como incorrecto.                                       |
| `name`             | `string`                                                      | —              | El nombre del campo oculto en un formulario.                           |
| `getAriaValueText` | `(value: number) => string`                                   | `"45 degrees"` | Lo que dice un lector de pantalla para un ángulo.                      |

En Vue, enlaza el valor con `:model-value` o `v-model`, y escucha con `@value-change`.

### AngleSlider.Marker

| Prop    | Tipo     | Por defecto | Descripción                               |
| ------- | -------- | ----------- | ----------------------------------------- |
| `value` | `number` | —           | Obligatorio. El ángulo donde va la marca. |

### Partes

| Parte                     | Elemento  | Descripción                                              |
| ------------------------- | --------- | -------------------------------------------------------- |
| `AngleSlider.Root`        | `<div>`   | Lleva `data-size` y el ángulo como `--angle`.            |
| `AngleSlider.Label`       | `<label>` | Nombra el dial y el campo. Al hacer clic enfoca el dial. |
| `AngleSlider.Control`     | `<div>`   | El dial redondo donde se hace clic o se arrastra.        |
| `AngleSlider.Thumb`       | `<div>`   | La aguja, con `role="slider"`. Recibe el foco.           |
| `AngleSlider.MarkerGroup` | `<div>`   | Opcional. Contiene las marcas, dentro del control.       |
| `AngleSlider.Marker`      | `<div>`   | Una marca en un ángulo.                                  |
| `AngleSlider.Input`       | `<div>`   | El campo numérico con un `°` detrás. Parte de Moderno.   |
| `AngleSlider.HiddenInput` | `<input>` | Lleva el ángulo a un formulario.                         |
| `AngleSlider.ValueText`   | `<div>`   | Opcional. El ángulo como texto.                          |

### Teclado

| Tecla                     | Acción                                          |
| ------------------------- | ----------------------------------------------- |
| `ArrowRight`, `ArrowDown` | Gira el dial un `step` en el sentido del reloj. |
| `ArrowLeft`, `ArrowUp`    | Gira el dial un `step` hacia atrás.             |
| `PageUp`, `PageDown`      | Gira el dial 15° hacia delante o hacia atrás.   |
| `Home`                    | Va a 0°.                                        |
| `End`                     | Va a 359°.                                      |

### Atributos data

| Atributo        | Valores                                                        |
| --------------- | -------------------------------------------------------------- |
| `data-disabled` | Con `disabled`, en todas las partes                            |
| `data-invalid`  | Con `invalid`, en la raíz, la etiqueta, el control y la aguja  |
| `data-readonly` | Con `readOnly`, en la raíz, la etiqueta, el control y la aguja |
| `data-state`    | En cada marca: `"under-value"`, `"at-value"` o `"over-value"`  |
| `data-size`     | En la raíz: `"sm"`, `"md"` o `"lg"`                            |

## Notas

- `AngleSlider.Root` y `AngleSlider.Thumb` están envueltos, y `AngleSlider.Input` es de Moderno; las demás partes son las de Ark sin cambios.
- Un lector de pantalla dice el ángulo en grados ("45 degrees"). Pasa `getAriaValueText` para decirlo en otro idioma, por ejemplo `(value) => \`${value} grados\``.
- Lo que el usuario escribe en el campo gira el dial al momento. El campo vuelve a mostrar el ángulo del dial cuando el usuario sale de él o pulsa Enter: `400` pasa a ser `40°`.
- Para un número en una escala recta, usa un Slider.
