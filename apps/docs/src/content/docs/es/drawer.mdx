Usa un drawer para contenido que necesita más espacio que un diálogo pero deja la página a la vista: filtros, ajustes, un menú. Entra desde un borde, atenúa la página y mantiene el foco dentro hasta que se cierra.

## Instalación

<Install pkg="@moderno-ui/react" />

## Referencia de la API

### Drawer.Root

`placement` es lo que añade Moderno. Las demás props vienen del Dialog de Ark. El Root no renderiza ningún elemento propio.

<PropsTable component="Drawer" />

| Prop                     | Tipo                                   | Por defecto | Descripción                                                                                         |
| ------------------------ | -------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------- |
| `open`                   | `boolean`                              | —           | Estado abierto controlado. Úsalo con `onOpenChange` (`bind:open` en Svelte, `v-model:open` en Vue). |
| `defaultOpen`            | `boolean`                              | `false`     | Estado abierto inicial cuando no está controlado.                                                   |
| `onOpenChange`           | `(details: { open: boolean }) => void` | —           | Se llama en cada apertura o cierre, también con Escape y con clics fuera.                           |
| `modal`                  | `boolean`                              | `true`      | Atrapa el foco, bloquea el scroll de la página y la oculta a los lectores de pantalla.              |
| `initialFocusEl`         | `() => HTMLElement \| null`            | —           | Elemento que recibe el foco al abrir. Por defecto, el primer elemento enfocable del contenido.      |
| `finalFocusEl`           | `() => HTMLElement \| null`            | —           | Elemento que recibe el foco al cerrar. Por defecto, el trigger.                                     |
| `closeOnEscape`          | `boolean`                              | `true`      | Cierra con Escape.                                                                                  |
| `closeOnInteractOutside` | `boolean`                              | `true`      | Cierra con un clic en el fondo.                                                                     |
| `lazyMount`              | `boolean`                              | `false`     | Monta el contenido solo en la primera apertura.                                                     |
| `unmountOnExit`          | `boolean`                              | `false`     | Quita el contenido del DOM al cerrar.                                                               |

`Drawer.RootProvider` también acepta `placement`, con el `value` de `useDialog()` de Ark.

### Portal

Renderiza sus hijos al final de `document.body`, así ningún `overflow` ni contexto de apilamiento de un padre recorta el drawer.

### Partes

Cada parte acepta los atributos de su elemento; `Drawer.Trigger` y `Drawer.CloseTrigger` aceptan además `asChild` para renderizar tu propio `Button`.

| Parte                 | Elemento   | Descripción                                                                                           |
| --------------------- | ---------- | ----------------------------------------------------------------------------------------------------- |
| `Drawer.Trigger`      | `<button>` | Abre el drawer. El foco vuelve a él al cerrar.                                                        |
| `Drawer.Backdrop`     | `<div>`    | El fondo atenuado detrás del drawer. Un clic en él cierra el drawer.                                  |
| `Drawer.Positioner`   | `<div>`    | Cubre la pantalla y sujeta el contenido contra su borde. Lleva `data-placement`.                      |
| `Drawer.Content`      | `<div>`    | El panel, con `role="dialog"`. Lleva `data-placement`. Una columna con scroll.                        |
| `Drawer.Title`        | `<h2>`     | El nombre accesible, conectado vía `aria-labelledby`.                                                 |
| `Drawer.Description`  | `<div>`    | Conectada vía `aria-describedby`, en `--muted-foreground`. Un `<p>` en Svelte.                        |
| `Drawer.CloseTrigger` | `<button>` | Cierra el drawer. Sin `asChild`, es un botón de icono pequeño en la esquina; Ark lo etiqueta `close`. |

### Atributos data

| Atributo         | Valores                                                                      |
| ---------------- | ---------------------------------------------------------------------------- |
| `data-scope`     | `"drawer"` en cada parte (son las partes del Dialog de Ark, con otro scope)  |
| `data-placement` | En el posicionador y el contenido: `"left"`, `"right"`, `"top"` o `"bottom"` |
| `data-state`     | `"open"` o `"closed"`, en el trigger, el fondo y el contenido                |

### Teclado

| Tecla               | Acción                                          |
| ------------------- | ----------------------------------------------- |
| `Enter` / `Space`   | En el trigger, abre el drawer.                  |
| `Esc`               | Cierra el drawer y devuelve el foco al trigger. |
| `Tab` / `Shift+Tab` | Mueve el foco dentro del drawer; no sale de él. |

## Notas

- Drawer es el Dialog de Ark: cada parte se envuelve solo para renderizar con `data-scope="drawer"`, y el Root, el Positioner y el Content para añadir `placement`.
- El foco, el bloqueo del scroll y el cierre vienen de Ark; no los reimplementes.
- Un `Dialog` ya se presenta como un drawer inferior en pantallas pequeñas. Usa un Drawer cuando quieras un drawer en cualquier ancho.
