## Referencia de la API

### Props

| Prop          | Tipo              | Por defecto            | Descripción                                                                          |
| ------------- | ----------------- | ---------------------- | ------------------------------------------------------------------------------------ |
| `product`     | `Product \| null` | un producto de muestra | El producto que se muestra. `null` muestra el mensaje de vacío.                      |
| `error`       | `string`          | —                      | No se pudo cargar el producto; un Alert de error con reintento sustituye la tarjeta. |
| `loading`     | `boolean`         | `false`                | Una tarjeta de marcador en una región ocupada sustituye la tarjeta.                  |
| `disabled`    | `boolean`         | `false`                | El producto se queda; su enlace queda inerte y cada botón deshabilitado.             |
| `onAddToCart` | `() => void`      | —                      | Se pulsó "Add to cart". Svelte: `onaddtocart`. Vue: `@add-to-cart`.                  |
| `onRetry`     | `() => void`      | —                      | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                          |

### Product

| Campo            | Tipo           | Descripción                                                          |
| ---------------- | -------------- | -------------------------------------------------------------------- |
| `name`           | `string`       | El nombre del producto.                                              |
| `price`          | `string`       | El precio tal como se lee, como `"€28"`.                             |
| `compareAtPrice` | `string`       | Opcional. El precio anterior, tachado después de `price`.            |
| `description`    | `string`       | Opcional. Una o dos frases cortas bajo el nombre.                    |
| `badge`          | `string`       | Opcional. Una palabra sobre la imagen, como `"New"` o `"Sale"`.      |
| `href`           | `string`       | Opcional. Convierte el nombre en un enlace a la página del producto. |
| `image`          | `ProductImage` | Opcional. La foto: `{ src, alt }`. Sin ella, una caja atenuada.      |

### Estados

| Estado        | Prop             | Qué se muestra                                                   |
| ------------- | ---------------- | ---------------------------------------------------------------- |
| Por defecto   | —                | La imagen, el nombre, la descripción, el precio y "Add to cart". |
| Vacío         | `product={null}` | "This product is no longer available." en una caja discontinua.  |
| Cargando      | `loading`        | Una tarjeta de marcador.                                         |
| Error         | `error`          | Un Alert de error con "Try again" en lugar de la tarjeta.        |
| Deshabilitado | `disabled`       | El mismo producto con su enlace inerte y los botones apagados.   |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------- |
| bajo `@sm`               | La imagen arriba, el texto debajo y un botón a todo el ancho.                      |
| `@sm` (`--container-sm`) | La imagen pasa al lado del texto; el botón se ajusta a su texto.                   |
| `@md` (`--container-md`) | El nombre sube un tamaño.                                                          |
| `@lg` (`--container-lg`) | La imagen y el texto se reparten el ancho a partes iguales; la imagen es cuadrada. |

## Notas

- Usa una foto que se siga entendiendo recortada en cuadrado: el producto en el centro, con aire alrededor.
- En una cuadrícula de tarjetas, da a cada tarjeta el mismo tipo de foto, para que la fila se vea pareja.
