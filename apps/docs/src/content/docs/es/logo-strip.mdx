## Referencia de la API

### Props

| Prop       | Tipo              | Por defecto               | Descripción                                                                      |
| ---------- | ----------------- | ------------------------- | -------------------------------------------------------------------------------- |
| `heading`  | `string`          | una frase                 | La línea breve sobre los logotipos. Se muestra como `h2`.                        |
| `logos`    | `LogoStripLogo[]` | seis logotipos de muestra | Los logotipos, en orden. `[]` muestra el mensaje de vacío.                       |
| `error`    | `string`          | —                         | Falló la carga de los logotipos; un Alert de error con reintento los sustituye.  |
| `loading`  | `boolean`         | `false`                   | Líneas de esqueleto en una región ocupada sustituyen a los logotipos.            |
| `disabled` | `boolean`         | `false`                   | Los logotipos se quedan; cada enlace queda inerte y el reintento, deshabilitado. |
| `onRetry`  | `() => void`      | —                         | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                      |

### Logotipo

| Campo  | Tipo                                                                     | Descripción                                         |
| ------ | ------------------------------------------------------------------------ | --------------------------------------------------- |
| `id`   | `string`                                                                 | Una clave estable para el logotipo.                 |
| `name` | `string`                                                                 | El nombre escrito. También es el nombre del enlace. |
| `mark` | `"circle" \| "ring" \| "square" \| "triangle" \| "diamond" \| "hexagon"` | La forma que va antes del nombre.                   |
| `href` | `string`                                                                 | Adónde lleva el logotipo, como un caso de cliente.  |

### Estados

| Estado        | Prop         | Qué se muestra                                                   |
| ------------- | ------------ | ---------------------------------------------------------------- |
| Por defecto   | —            | El encabezado y cada logotipo.                                   |
| Vacío         | `logos={[]}` | El encabezado y "No logos to show yet." en un recuadro punteado. |
| Cargando      | `loading`    | El encabezado y seis líneas de marcador.                         |
| Error         | `error`      | El encabezado y un Alert de error con "Try again".               |
| Deshabilitado | `disabled`   | Los mismos logotipos, cada enlace inerte.                        |

### Tamaño

| Paso del contenedor      | Qué cambia                                                      |
| ------------------------ | --------------------------------------------------------------- |
| bajo `@sm`               | Dos logotipos por fila.                                         |
| `@sm` (`--container-sm`) | Tres logotipos por fila.                                        |
| `@md` (`--container-md`) | Las formas y los nombres suben un tamaño.                       |
| `@lg` (`--container-lg`) | Los seis logotipos en una fila, con más espacio arriba y abajo. |

## Notas

- Muestra un logotipo solo con el permiso de su cliente.
- Mantenlos todos de un solo color. Un logotipo a todo color aparta la vista del resto.
