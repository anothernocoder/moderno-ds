## Uso

Una lista de barras ordena unos pocos elementos con nombre según un valor. Úsala para las páginas más visitadas, las fuentes de tráfico o las ventas por región. Cada fila muestra el nombre, una barra tan larga como su valor y el valor, de mayor a menor.

<ForFramework fw="react">

```tsx
import { BarList } from "@moderno-ui/react";

const pages = [
  { name: "/", value: 1240 },
  { name: "/pricing", value: 860 },
  { name: "/docs", value: 540 },
];
```

```tsx
<BarList width={420} data={pages} aria-label="Visits by page" />
```

</ForFramework>

## Referencia de API

### BarList

<PropsTable component="BarList" />

### Datos

Cada entrada de `data` es una fila.

| Campo   | Tipo     | Descripción                                      |
| ------- | -------- | ------------------------------------------------ |
| `name`  | `string` | El texto al inicio de la fila.                   |
| `value` | `number` | Fija el largo de la barra y se muestra al final. |

Un valor de 0 o menos deja la pista vacía. Un valor que no es un número finito (`NaN`, `Infinity`) no dibuja barra ni se muestra. Queda fuera del `max` por defecto, y una lista ordenada pone su fila al final.

### Valores por defecto

| Prop         | Por defecto                         |
| ------------ | ----------------------------------- |
| `max`        | El mayor valor finito de `data`     |
| `sort`       | `"descending"`, de mayor a menor    |
| `labelWidth` | `120`                               |
| `valueWidth` | `64`                                |
| `rowHeight`  | `32`                                |
| `barHeight`  | `8`                                 |
| `format`     | El número, redondeado a 4 decimales |

### Atributos de datos

| Atributo      | En              | Valores                                                   |
| ------------- | --------------- | --------------------------------------------------------- |
| `data-chart`  | `svg` raíz      | `bar-list`                                                |
| `data-part`   | Cada elemento   | `root`, `series`, `row`, `label`, `track`, `bar`, `value` |
| `data-series` | `g` de la serie | `0`, asignado a `--chart-1`                               |

## Ejemplos

### Orden

Pasa `sort="none"` para mantener el orden de `data`, en filas con un orden propio como los días. `"ascending"` pone primero el menor.

### Máximo

Fija `max` para medir cada barra contra un total fijo, como una meta del 100 %. Un valor mayor que `max` llena su pista.

### Tamaño de fila

`rowHeight` fija el espacio de cada fila y `barHeight` el grosor de su barra. Con filas más pequeñas cabe una lista más larga.

## Notas

- No hay prop de color: las barras se pintan de `--chart-1`, y cada pista es del mismo color, tenue.
- Los nombres usan `--foreground` y los valores `--muted-foreground`.
- Los nombres no se recortan. Mantenlos cortos, o dales más espacio con `labelWidth`.
- La lista es tan alta como sus filas. Como todo gráfico, llena el ancho de su contenedor y escala su texto con él.
- La geometría viene de `@moderno-ui/charts-core`, matemática pura sin DOM, así se renderiza en el servidor.
