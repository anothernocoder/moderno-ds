## Uso

Un accordion es una pila de secciones. Cada encabezado abre su propia sección. Úsalo para detalles opcionales, como unas preguntas frecuentes: el lector ve primero los encabezados y abre solo lo que necesita.

<ForFramework fw="react">

```tsx
import { Accordion } from "@moderno-ui/react";
```

```tsx
<Accordion.Root defaultValue={["shipping"]} collapsible>
  <Accordion.Item value="shipping">
    <Accordion.ItemTrigger>
      How long does shipping take?
      <Accordion.ItemIndicator>▾</Accordion.ItemIndicator>
    </Accordion.ItemTrigger>
    <Accordion.ItemContent>Three to five working days.</Accordion.ItemContent>
  </Accordion.Item>
  <Accordion.Item value="returns">
    <Accordion.ItemTrigger>
      Can I return an order?
      <Accordion.ItemIndicator>▾</Accordion.ItemIndicator>
    </Accordion.ItemTrigger>
    <Accordion.ItemContent>Yes, within 30 days of delivery.</Accordion.ItemContent>
  </Accordion.Item>
</Accordion.Root>
```

</ForFramework>

Por defecto hay un solo ítem abierto a la vez. `collapsible` deja que el lector lo vuelva a cerrar.

## Referencia de la API

### Accordion.Root

`variant` y `size` son los añadidos de Moderno; todos los ítems los siguen. El resto de props vienen del Accordion de Ark.

<PropsTable component="Accordion" />

| Prop            | Tipo                                     | Por defecto  | Descripción                                                        |
| --------------- | ---------------------------------------- | ------------ | ------------------------------------------------------------------ |
| `value`         | `string[]`                               | —            | Ítems abiertos, controlado. Úsalo junto a `onValueChange`.         |
| `defaultValue`  | `string[]`                               | `[]`         | Ítems abiertos al principio, sin control.                          |
| `onValueChange` | `(details: { value: string[] }) => void` | —            | Se llama cuando un ítem se abre o se cierra.                       |
| `multiple`      | `boolean`                                | `false`      | Deja varios ítems abiertos a la vez.                               |
| `collapsible`   | `boolean`                                | `false`      | Deja cerrar el ítem abierto, de modo que no quede ninguno abierto. |
| `disabled`      | `boolean`                                | `false`      | Deshabilita todos los ítems.                                       |
| `orientation`   | `"horizontal" \| "vertical"`             | `"vertical"` | Define las flechas: arriba y abajo, o izquierda y derecha.         |
| `lazyMount`     | `boolean`                                | `false`      | Renderiza un contenido solo la primera vez que se abre su ítem.    |
| `unmountOnExit` | `boolean`                                | `false`      | Quita un contenido cuando su ítem se cierra.                       |

En Vue, escucha con `@value-change` o enlaza el valor con `v-model`.

### Accordion.Item

| Prop       | Tipo      | Por defecto | Descripción                     |
| ---------- | --------- | ----------- | ------------------------------- |
| `value`    | `string`  | —           | Obligatorio. El valor del ítem. |
| `disabled` | `boolean` | `false`     | Deshabilita solo este ítem.     |

### Partes

| Parte                     | Elemento   | Descripción                                                             |
| ------------------------- | ---------- | ----------------------------------------------------------------------- |
| `Accordion.Root`          | `<div>`    | Lleva `data-variant` y `data-size`.                                     |
| `Accordion.Item`          | `<div>`    | Una sección. Contiene su trigger y su contenido.                        |
| `Accordion.ItemTrigger`   | `<button>` | El encabezado, con `aria-expanded`. Abre y cierra su ítem.              |
| `Accordion.ItemIndicator` | `<div>`    | Opcional. Contiene tu icono y gira cuando el ítem se abre.              |
| `Accordion.ItemContent`   | `<div>`    | `role="region"`, nombrado por su trigger. Oculto mientras está cerrado. |

### Atributos data

| Atributo           | Valores                                                        |
| ------------------ | -------------------------------------------------------------- |
| `data-state`       | `"open"` o `"closed"`, en el ítem y sus partes                 |
| `data-disabled`    | Presente en un ítem deshabilitado, su contenido y su indicador |
| `data-orientation` | `"vertical"` o `"horizontal"`, en todas las partes             |
| `data-variant`     | En la raíz: `"line"` o `"enclosed"`                            |
| `data-size`        | En la raíz: `"sm"`, `"md"` o `"lg"`                            |

## Notas

- `Accordion.Root` está envuelto para añadir `variant` y `size`; el resto de partes son las de Ark sin cambios.
- La altura del contenido se anima al abrirse y al cerrarse. No se anima cuando el usuario pide movimiento reducido.
- Para vistas hermanas donde siempre se muestra exactamente una, usa Tabs.
