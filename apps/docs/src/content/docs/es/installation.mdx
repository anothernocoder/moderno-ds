## Paquetes

| Paquete                                          | Función                                                                |
| ------------------------------------------------ | ---------------------------------------------------------------------- |
| `@moderno-ui/react` · `vue` · `svelte` · `solid` | Los componentes para tu framework.                                     |
| `@moderno-ui/core`                               | Recetas compartidas. Se instala con cada enlace.                       |
| `@moderno-ui/css`                                | La hoja de estilos compartida y el tema por defecto. Dependencia peer. |
| `@moderno-ui/cli`                                | Opcional. Copia blocks, screens y temas en tu código.                  |
| `@moderno-ui/mcp`                                | Opcional. Responde a los agentes de código con tu API instalada.       |

Requisitos peer: React 19, Vue 3.5, Svelte 5 o Solid 1.9.

## Instalar

1. Instala el enlace de tu framework.

   <Install pkg="@moderno-ui/react" />

2. Instala el paquete de la hoja de estilos.

   ```sh
   npm install @moderno-ui/css
   ```

3. Importa la hoja de estilos una vez, en la raíz de tu app.

   ```ts
   import "@moderno-ui/css";
   ```

4. Muestra un componente.

   <ForFramework fw="react">

   ```tsx
   import { Button } from "@moderno-ui/react";

   <Button>Guardar cambios</Button>;
   ```

   </ForFramework>

   <ForFramework fw="vue">

   ```vue
   <script setup lang="ts">
   import { Button } from "@moderno-ui/vue";
   </script>

   <template>
     <Button>Guardar cambios</Button>
   </template>
   ```

   </ForFramework>

   <ForFramework fw="svelte">

   ```svelte
   <script lang="ts">
     import { Button } from "@moderno-ui/svelte";
   </script>

   <Button>Guardar cambios</Button>
   ```

   </ForFramework>

   <ForFramework fw="solid">

   ```tsx
   import { Button } from "@moderno-ui/solid";

   <Button>Guardar cambios</Button>;
   ```

   </ForFramework>

## Tailwind v4 (opcional)

Importa el preset después de la hoja de estilos para tener utilidades como `bg-primary` y `@md:`.

```css
@import "tailwindcss";
@import "@moderno-ui/css";
@import "@moderno-ui/css/preset";
```

Consulta [Contrato de tokens](/es/token-contract#tailwind-v4) para ver cada slot mapeado.

## Generar con la CLI (opcional)

1. Inicializa el proyecto.

   ```sh
   npx @moderno-ui/cli init
   ```

2. Importa una vez la hoja de estilos generada, en lugar de `@moderno-ui/css`.

   ```ts
   import "@/styles/moderno.css";
   ```

3. Añade un tema o un block.

   ```sh
   npx @moderno-ui/cli add theme-moderno
   ```

### Comandos

| Comando                    | Qué hace                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------ |
| `moderno init`             | Escribe `components.json`, `src/styles/moderno.css` y el stanza de `AGENTS.md`.      |
| `moderno init --claude`    | Lo mismo, más un `CLAUDE.md` gemelo del stanza.                                      |
| `moderno add <item...>`    | Copia items del registro y sus dependencias. Un tema se `@import`a en `moderno.css`. |
| `moderno update [item...]` | Actualiza los items instalados. Los archivos que editaste localmente se conservan.   |
| `moderno diff <item>`      | Muestra el diff entre tu copia y la versión del registro.                            |
| `moderno list`             | Lista los items instalados con su versión instalada y la más reciente.               |

### Notas

- Todos los comandos aceptan `--registry <url|path>`.
- Orden de búsqueda del registro: `--registry`, luego `components.json`, luego `MODERNO_REGISTRY_URL`, luego `https://moderno.style/r/registry.json`.
- Volver a ejecutar `init` actualiza el stanza de `AGENTS.md` en el sitio y conserva el resto del archivo.
- La CLI y el servidor MCP necesitan Node 22 o superior.
