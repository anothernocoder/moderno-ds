## Uso

Usa un avatar para mostrar quién es alguien: junto a un nombre, en un comentario o en un menú. Pon las iniciales en `Avatar.Fallback`; se ven hasta que carga la imagen, y se quedan si falla.

<ForFramework fw="react">

```tsx
import { Avatar } from "@moderno-ui/react";
```

```tsx
<Avatar.Root>
  <Avatar.Fallback>AL</Avatar.Fallback>
  <Avatar.Image src="/ada.png" alt="Ada Lovelace" />
</Avatar.Root>
```

</ForFramework>

## Referencia de API

### Avatar.Root

<PropsTable component="Avatar" />

Las props de comportamiento vienen de Ark. La que puedes necesitar:

| Prop             | Tipo                                                 | Por defecto | Descripción                              |
| ---------------- | ---------------------------------------------------- | ----------- | ---------------------------------------- |
| `onStatusChange` | `(details: { status: "loaded" \| "error" }) => void` | —           | Se llama cuando la imagen carga o falla. |

### Partes

| Parte             | Elemento | Descripción                                                                  |
| ----------------- | -------- | ---------------------------------------------------------------------------- |
| `Avatar.Root`     | `<div>`  | La caja. Recibe `size`, `shape` y las props de comportamiento.               |
| `Avatar.Image`    | `<img>`  | La imagen. Se ve cuando ha cargado. Necesita `src` y `alt`.                  |
| `Avatar.Fallback` | `<span>` | Las iniciales. Se ven mientras carga la imagen, si falla o si no hay imagen. |

### Atributos de datos

| Atributo     | En              | Significado                                                   |
| ------------ | --------------- | ------------------------------------------------------------- |
| `data-size`  | Root            | `sm`, `md` (por defecto), `lg`                                |
| `data-shape` | Root            | `circle` (por defecto), `square`                              |
| `data-state` | Image, Fallback | `visible` o `hidden`. La parte oculta también lleva `hidden`. |

## Notas

- Solo `Avatar.Root` está envuelto, para añadir `size` y `shape`. Las demás partes son las de Ark.
- La imagen y el fallback nunca se ven a la vez. Ark los cambia cuando la imagen carga.
