## Referencia de API

### Propiedades

| Propiedad           | Tipo                            | Por defecto     | Descripción                                                                           |
| ------------------- | ------------------------------- | --------------- | ------------------------------------------------------------------------------------- |
| `variant`           | `"page" \| "section" \| "card"` | `"page"`        | Lo que encabeza. Fija el rango del título (h1, h2, h3) y su tamaño.                   |
| `heading`           | `string`                        | `"Q3 redesign"` | El título.                                                                            |
| `description`       | `string`                        | una frase       | La línea bajo el título; `""` la oculta.                                              |
| `breadcrumbs`       | `SectionHeaderCrumb[]`          | una ruta        | Solo página. La ruta sobre el título, terminada en la página actual.                  |
| `status`            | `SectionHeaderStatus \| null`   | `Active`        | Solo página. Una insignia con punto al inicio de la línea de datos; `null` la oculta. |
| `meta`              | `string[]`                      | dos datos       | Solo página. Datos breves tras el estado, como una fecha límite o un responsable.     |
| `count`             | `number`                        | —               | Cuántos elementos encabeza, como una insignia tras el título.                         |
| `primaryLabel`      | `string`                        | `"New task"`    | El texto del botón principal; `""` lo oculta.                                         |
| `secondaryLabel`    | `string`                        | `"Share"`       | El texto del botón con borde; `""` lo oculta.                                         |
| `error`             | `string`                        | —               | Los detalles no cargaron; una alerta con reintento va bajo el título.                 |
| `loading`           | `boolean`                       | `false`         | Marcadores en una región ocupada reemplazan el título y su contexto.                  |
| `disabled`          | `boolean`                       | `false`         | Todos los botones quedan desactivados.                                                |
| `onPrimaryAction`   | `() => void`                    | —               | El botón principal. Svelte: `onprimaryaction`. Vue: `@primary-action`.                |
| `onSecondaryAction` | `() => void`                    | —               | El botón con borde. Svelte: `onsecondaryaction`. Vue: `@secondary-action`.            |
| `onRetry`           | `() => void`                    | —               | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                           |

### SectionHeaderCrumb

| Campo   | Tipo     | Descripción                                                       |
| ------- | -------- | ----------------------------------------------------------------- |
| `label` | `string` | El texto del paso.                                                |
| `href`  | `string` | A dónde enlaza. El último paso nunca enlaza: es la página actual. |

### SectionHeaderStatus

| Campo   | Tipo                                                       | Descripción                                       |
| ------- | ---------------------------------------------------------- | ------------------------------------------------- |
| `label` | `string`                                                   | El estado, en palabras.                           |
| `tone`  | `"neutral" \| "info" \| "success" \| "warning" \| "error"` | El tinte de la insignia. Por defecto `"neutral"`. |

### Estados

| Estado        | Propiedad   | Qué se muestra                                                                            |
| ------------- | ----------- | ----------------------------------------------------------------------------------------- |
| Por defecto   | —           | El título, su contexto y las dos acciones.                                                |
| Vacío         | `count={0}` | El recuento marca 0; la acción con borde se desactiva y la principal sigue disponible.    |
| Cargando      | `loading`   | Marcadores en una región `status` ocupada; las dos acciones desactivadas.                 |
| Error         | `error`     | El título y, debajo, una alerta de error con el botón "Try again"; acciones desactivadas. |
| Deshabilitado | `disabled`  | Todo legible y todos los botones desactivados. Los enlaces de la ruta siguen funcionando. |

### Dimensionado

| Paso del contenedor      | Qué cambia                                                                              |
| ------------------------ | --------------------------------------------------------------------------------------- |
| bajo `@sm`               | Las acciones van bajo el título y se reparten su ancho; la ruta solo muestra la vuelta. |
| `@sm` (`--container-sm`) | Las acciones pasan junto al título; se ve la ruta completa.                             |
| `@md` (`--container-md`) | Los títulos de página y de sección suben un tamaño.                                     |
| `@lg` (`--container-lg`) | El título de página toma el tamaño mayor y la descripción sube a texto de cuerpo.       |
