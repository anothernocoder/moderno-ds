## Uso

Usa un spinner para una espera corta cuando no puedes mostrar la forma de lo que viene: un formulario que se guarda, un panel que se actualiza.

## Referencia de API

### Spinner

Renderiza un `<span role="status">`. `size` vale `md` por defecto y `label`, `"Loading"`.

<PropsTable component="Spinner" />

### Partes

| Parte    | Elemento | Descripción                                                  |
| -------- | -------- | ------------------------------------------------------------ |
| `root`   | `<span>` | `role="status"`. Lleva `data-size`.                          |
| `circle` | `<span>` | El anillo que gira. Pinta con `currentColor`; `aria-hidden`. |
| `label`  | `<span>` | El texto de `label`, oculto a la vista.                      |

Di qué está cargando. Los lectores de pantalla leen la etiqueta; no se muestra. En una interfaz en español, pasa siempre un `label` en español: el valor por defecto está en inglés.

## Notas

- Spinner es solo CSS: un `<span>` con `data-scope="spinner"`, sin máquina de Ark.
- El anillo toma el color del texto que lo rodea, así encaja dentro de un botón o en una línea atenuada.
- El anillo gira más despacio cuando el usuario pide menos movimiento. No se detiene, porque un anillo quieto ya no diría que algo está en curso.
