## Referencia de API

### Field.Root

`size` es el añadido de Moderno y vale `md` por defecto; el resto de props vienen del Field de Ark.

<PropsTable component="Field" />

| Prop       | Tipo      | Por defecto | Descripción                                                                                  |
| ---------- | --------- | ----------- | -------------------------------------------------------------------------------------------- |
| `invalid`  | `boolean` | `false`     | Cambia el borde, el tinte y el anillo de foco a `--destructive` y muestra `Field.ErrorText`. |
| `disabled` | `boolean` | `false`     | Deshabilita el control y atenúa todas las partes.                                            |
| `required` | `boolean` | `false`     | Pone `required` en el control y `data-required` en la etiqueta.                              |
| `readOnly` | `boolean` | `false`     | Pone `readOnly` en el control.                                                               |

### Field.Textarea

Comparte el borde, el radio, el anillo de foco y el tratamiento inválido del input, con una altura mínima por tamaño y redimensionado solo vertical.

| Prop         | Tipo      | Por defecto | Descripción                               |
| ------------ | --------- | ----------- | ----------------------------------------- |
| `autoresize` | `boolean` | `false`     | Hace crecer el textarea con su contenido. |

### Partes

| Parte                     | Elemento             | Descripción                                                                                    |
| ------------------------- | -------------------- | ---------------------------------------------------------------------------------------------- |
| `Field.Root`              | `<div role="group">` | Lleva `data-size`, `data-invalid`, `data-disabled` y `data-readonly`.                          |
| `Field.Label`             | `<label>`            | Vinculada al `id` del control automáticamente.                                                 |
| `Field.Input`             | `<input>`            | Control de una línea.                                                                          |
| `Field.Textarea`          | `<textarea>`         | Control de varias líneas.                                                                      |
| `Field.HelperText`        | `<span>`             | Vinculado al control vía `aria-describedby`.                                                   |
| `Field.ErrorText`         | `<span>`             | Solo se renderiza con `invalid`; vinculado vía `aria-describedby` y anunciado de forma cortés. |
| `Field.RequiredIndicator` | `<span>`             | Solo se renderiza con `required`; oculto a las tecnologías de asistencia.                      |

## Notas

- Pon `size` en `Field.Root`, no en el control: un solo `data-size` dimensiona todas las partes.
- No añadas `htmlFor` ni ids a mano; las partes conectan la etiqueta, el control y los mensajes.
- Pon el texto de validación en `Field.ErrorText`, no en un elemento hermano, para que se anuncie con el campo.
- El borde del input usa `--input` y el anillo de foco `--ring`; deshabilitado se rellena con `--muted`.
