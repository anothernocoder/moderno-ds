## Referencia de la API

### Props

| Prop           | Tipo         | Por defecto                    | Descripción                                                                                   |
| -------------- | ------------ | ------------------------------ | --------------------------------------------------------------------------------------------- |
| `heading`      | `string`     | `"Frequently asked questions"` | El encabezado de la sección. Va en la fuente con serifa.                                      |
| `description`  | `string`     | una frase                      | Una frase bajo el encabezado; `""` la oculta.                                                 |
| `items`        | `FaqItem[]`  | cinco preguntas de ejemplo     | Las preguntas, en orden. `[]` muestra el mensaje de vacío.                                    |
| `contactText`  | `string`     | una frase                      | La frase de la línea de soporte.                                                              |
| `contactLabel` | `string`     | `"Contact support"`            | La etiqueta del botón de soporte; `""` oculta la línea de soporte.                            |
| `error`        | `string`     | —                              | Falló la carga de las preguntas; un Alert de error con reintento las sustituye.               |
| `loading`      | `boolean`    | `false`                        | Filas de esqueleto en una región ocupada sustituyen a las preguntas.                          |
| `disabled`     | `boolean`    | `false`                        | Las preguntas se quedan pero no se abren; los botones de soporte y reintento, deshabilitados. |
| `onContact`    | `() => void` | —                              | Se pulsó el botón de soporte. Svelte: `oncontact`. Vue: `@contact`.                           |
| `onRetry`      | `() => void` | —                              | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                                   |

### Pregunta

| Campo      | Tipo     | Descripción                                                           |
| ---------- | -------- | --------------------------------------------------------------------- |
| `id`       | `string` | Una clave estable para la pregunta. También su valor en el Accordion. |
| `question` | `string` | La pregunta. Se muestra como `h3` alrededor de su disparador.         |
| `answer`   | `string` | La respuesta, visible cuando la pregunta se abre.                     |

### Estados

| Estado        | Prop         | Qué se muestra                                                                     |
| ------------- | ------------ | ---------------------------------------------------------------------------------- |
| Por defecto   | —            | Encabezado, introducción, cada pregunta y la línea de soporte.                     |
| Vacío         | `items={[]}` | Encabezado, introducción, "No questions here yet." y la línea de soporte.          |
| Cargando      | `loading`    | Encabezado, introducción, cinco filas de marcador y la línea de soporte.           |
| Error         | `error`      | Encabezado, introducción, un Alert de error con "Try again" y la línea de soporte. |
| Deshabilitado | `disabled`   | Las mismas preguntas, que no se abren, y el botón de soporte deshabilitado.        |

### Tamaño

| Paso del contenedor      | Qué cambia                                         |
| ------------------------ | -------------------------------------------------- |
| bajo `@sm`               | La frase de soporte va sobre su botón.             |
| `@sm` (`--container-sm`) | La frase de soporte y su botón comparten una fila. |
| `@md` (`--container-md`) | El encabezado sube un tamaño.                      |
| `@lg` (`--container-lg`) | Más espacio arriba y abajo de la sección.          |

## Notas

- Escribe cada pregunta como la haría un lector y respóndela en su primera frase.
- Mantén la lista corta. Pon arriba las preguntas que más se hacen.
