## Referencia de la API

### Props

| Prop          | Tipo                | Por defecto                         | Descripción                                                                               |
| ------------- | ------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------- |
| `heading`     | `string`            | `"Everything you need to get paid"` | El encabezado de la sección. Va en la fuente con serifa.                                  |
| `description` | `string`            | una frase                           | Una frase bajo el encabezado; `""` la oculta.                                             |
| `features`    | `FeatureGridItem[]` | seis funciones de ejemplo           | Las funciones, en orden. `[]` muestra el mensaje de vacío.                                |
| `action`      | `string`            | `"See all features"`                | La etiqueta del botón con contorno bajo la cuadrícula; `""` lo oculta.                    |
| `error`       | `string`            | —                                   | Falló la carga de las funciones; un Alert de error con reintento sustituye la cuadrícula. |
| `loading`     | `boolean`           | `false`                             | Funciones de esqueleto en una región ocupada sustituyen a la cuadrícula.                  |
| `disabled`    | `boolean`           | `false`                             | El contenido se queda y todos los botones se deshabilitan.                                |
| `onAction`    | `() => void`        | —                                   | Se pulsó el botón bajo la cuadrícula. Svelte: `onaction`. Vue: `@action`.                 |
| `onRetry`     | `() => void`        | —                                   | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                               |

### Función

| Campo         | Tipo                                                              | Descripción                           |
| ------------- | ----------------------------------------------------------------- | ------------------------------------- |
| `id`          | `string`                                                          | Una clave estable para la función.    |
| `icon`        | `"zap" \| "clock" \| "receipt" \| "chart" \| "shield" \| "users"` | El glifo de la baldosa.               |
| `title`       | `string`                                                          | Pocas palabras. Se muestra como `h3`. |
| `description` | `string`                                                          | Una frase sobre lo que hace.          |

### Estados

| Estado        | Prop            | Qué se muestra                                                        |
| ------------- | --------------- | --------------------------------------------------------------------- |
| Por defecto   | —               | Encabezado, introducción, todas las funciones y la acción.            |
| Vacío         | `features={[]}` | Encabezado, introducción y "No features to show yet."                 |
| Cargando      | `loading`       | Encabezado, introducción y tres funciones de marcador.                |
| Error         | `error`         | Encabezado, introducción y después un Alert de error con "Try again". |
| Deshabilitado | `disabled`      | El mismo contenido con la acción deshabilitada.                       |

### Tamaño

| Paso del contenedor      | Qué cambia                                                 |
| ------------------------ | ---------------------------------------------------------- |
| bajo `@sm`               | Una función por fila.                                      |
| `@sm` (`--container-sm`) | Dos columnas.                                              |
| `@md` (`--container-md`) | El encabezado sube un tamaño.                              |
| `@lg` (`--container-lg`) | Tres columnas, y más espacio arriba y abajo de la sección. |

## Notas

- Tres o seis funciones se leen mejor: llenan cada fila a dos y a tres columnas.
- Deja cada descripción en una frase. Pon los detalles en la página que abre la acción.
