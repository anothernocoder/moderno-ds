## Referencia de API

### Props

| Prop        | Tipo                   | Por defecto          | Descripción                                                            |
| ----------- | ---------------------- | -------------------- | ---------------------------------------------------------------------- |
| `banners`   | `AppBannerItem[]`      | una lista de muestra | Los banners, de arriba abajo. `[]` no muestra nada.                    |
| `error`     | `string`               | —                    | Los banners no cargaron; una alerta con reintento los sustituye.       |
| `loading`   | `boolean`              | `false`              | Un banner esqueleto en una región ocupada los sustituye.               |
| `disabled`  | `boolean`              | `false`              | Los banners siguen legibles y todos sus botones quedan deshabilitados. |
| `onAction`  | `(id: string) => void` | —                    | Se pulsó la acción de un banner. Svelte: `onaction`. Vue: `@action`.   |
| `onDismiss` | `(id: string) => void` | —                    | Se pulsó descartar en un banner. Svelte: `ondismiss`. Vue: `@dismiss`. |
| `onRetry`   | `() => void`           | —                    | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.            |

### AppBannerItem

| Campo         | Tipo                                       | Descripción                                                      |
| ------------- | ------------------------------------------ | ---------------------------------------------------------------- |
| `id`          | `string`                                   | Identidad estable, la que devuelven `onAction` y `onDismiss`.    |
| `kind`        | `"impersonation" \| "trial" \| "incident"` | El tinte y el icono: aviso, información o error.                 |
| `title`       | `string`                                   | El mensaje del banner, como "12 days left in your trial".        |
| `description` | `string`                                   | Opcional. Una línea más, como qué pasa cuando termina.           |
| `actionLabel` | `string`                                   | Opcional. El texto del botón de acción, como "Upgrade".          |
| `dismissible` | `boolean`                                  | Opcional. Añade un botón para descartar, nombrado con el banner. |

### Estados

| Estado        | Prop           | Qué se muestra                                                        |
| ------------- | -------------- | --------------------------------------------------------------------- |
| Por defecto   | —              | Un banner teñido por elemento, cada uno con su acción y su descarte.  |
| Vacío         | `banners={[]}` | Nada: el bloque no ocupa espacio.                                     |
| Cargando      | `loading`      | Un banner esqueleto en una región `status` ocupada.                   |
| Error         | `error`        | Una alerta de error con el botón "Try again" en lugar de los banners. |
| Deshabilitado | `disabled`     | Los banners con todos sus botones deshabilitados.                     |

### Tamaño

| Paso del contenedor      | Qué cambia                                                      |
| ------------------------ | --------------------------------------------------------------- |
| bajo `@sm`               | Los botones de acción y de descarte van bajo el mensaje.        |
| `@sm` (`--container-sm`) | Los botones pasan junto al mensaje.                             |
| `@md` (`--container-md`) | El título y la descripción comparten una línea.                 |
| `@lg` (`--container-lg`) | Cada botón de descarte muestra su texto "Dismiss" junto a la ×. |

## Notas

- Presentacional: no cambia nada por sí mismo. Quita un banner en `onDismiss`.
- Ponlo una sola vez, sobre el contenido de la página, para que todas las páginas muestren los mismos banners.
