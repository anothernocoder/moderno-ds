`save` guarda el registro, lo devuelve como `record` y pone `open` en `false`.

## Referencia de la API

### Props

| Prop           | Tipo                                | Por defecto            | Descripción                                                                  |
| -------------- | ----------------------------------- | ---------------------- | ---------------------------------------------------------------------------- |
| `record`       | `SlideOverRecord`                   | una persona de ejemplo | El registro que muestra el panel y del que parte el formulario.              |
| `open`         | `boolean`                           | `false`                | Si el panel lateral está abierto. Svelte: `bind:open`. Vue: `v-model:open`.  |
| `onOpenChange` | `(open: boolean) => void`           | —                      | El panel lateral se abrió o se cerró. Solo React y Solid.                    |
| `error`        | `string`                            | —                      | Falló el guardado; un Alert de error va arriba del formulario.               |
| `loading`      | `boolean`                           | `false`                | Los campos deshabilitados y el botón de guardar ocupado en "Saving".         |
| `disabled`     | `boolean`                           | `false`                | El botón está deshabilitado, así que el panel lateral no se abre.            |
| `onSave`       | `(record: SlideOverRecord) => void` | —                      | Se guardó un formulario con nombre y correo. Svelte: `onsave`. Vue: `@save`. |

### SlideOverRecord

| Campo   | Tipo     | Descripción                               |
| ------- | -------- | ----------------------------------------- |
| `name`  | `string` | Obligatorio. El encabezado del panel.     |
| `email` | `string` | Obligatorio. La línea bajo el encabezado. |
| `role`  | `string` | Opcional. `""` se lee "Not added".        |
| `notes` | `string` | Opcional. `""` se lee "Not added".        |

### Estados

| Estado        | Prop          | Qué se muestra                                                                                                                                         |
| ------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Por defecto   | —             | El panel y su botón; el panel lateral tiene el formulario, lleno desde `record`.                                                                       |
| Vacío         | campos vacíos | Rol o notas vacíos se leen "Not added". Guardado sin nombre o sin correo, esos campos pasan a no válidos, muestran un error y el primero toma el foco. |
| Cargando      | `loading`     | El formulario con los campos deshabilitados y un botón ocupado en "Saving".                                                                            |
| Error         | `error`       | Un Alert de error arriba del formulario; lo escrito se conserva.                                                                                       |
| Deshabilitado | `disabled`    | El panel con su botón deshabilitado.                                                                                                                   |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                               |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| bajo `@sm`               | El botón ocupa todo el ancho y cada término va sobre su valor.                           |
| `@sm` (`--container-sm`) | El botón toma su propio ancho, cada término va junto a su valor y el panel gana relleno. |
| `@md` (`--container-md`) | El encabezado sube un tamaño.                                                            |
| `@lg` (`--container-lg`) | El botón va junto al nombre, con más espacio arriba y abajo.                             |

El panel lateral es el primitivo Drawer: entra desde la derecha, tan ancho como la ventana hasta `--container-sm`.

## Notas

- Cierra el panel lateral solo cuando el guardado salga bien. Si falla, déjalo abierto y pasa `error`, así no se pierde nada de lo escrito.
- Mantén el formulario corto. Los campos que casi nunca cambian van mejor en una página de ajustes.
