## Uso

Usa un chip para un token pequeño que el usuario eligió, como un filtro o una etiqueta, y que quizá quiera quitar.

<ForFramework fw="react">

```tsx
import { Chip } from "@moderno-ui/react";
```

```tsx
<Chip removable removeLabel="Quitar React">
  React
</Chip>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Chip } from "@moderno-ui/vue";
```

```vue
<Chip removable removeLabel="Quitar React">React</Chip>
```

</ForFramework>

<ForFramework fw="svelte">

```ts

```

```svelte
<Chip removable removeLabel="Quitar React">React</Chip>
```

</ForFramework>

## Referencia de API

### Chip

Renderiza un `<span>`; sus hijos son la etiqueta. `variant` vale `outline` por defecto y `size`, `md`.

<PropsTable component="Chip" />

En Vue, escucha `@remove` en lugar de pasar `onRemove`.

### Partes

| Parte            | Elemento   | Descripción                                                    |
| ---------------- | ---------- | -------------------------------------------------------------- |
| `root`           | `<span>`   | El token. Lleva `data-variant` y `data-size`.                  |
| `label`          | `<span>`   | Los hijos. Una etiqueta larga se corta con puntos suspensivos. |
| `remove-trigger` | `<button>` | Solo con `removable`. Su nombre viene de `removeLabel`.        |

## Notas

- Chip es solo CSS: un `<span>` con `data-scope="chip"` y un `<button>` nativo para quitarlo.
- Da a cada botón de quitar su propio nombre con `removeLabel`.
- Para una etiqueta de solo lectura, usa Badge.
