## Referencia de la API

### Props

| Prop          | Tipo              | Por defecto                              | Descripción                                                          |
| ------------- | ----------------- | ---------------------------------------- | -------------------------------------------------------------------- |
| `heading`     | `string`          | `"One calm email a month"`               | Qué recibe el lector. Va en la fuente con serifa.                    |
| `description` | `string`          | una frase                                | Una línea bajo el encabezado; `""` la oculta.                        |
| `note`        | `string`          | `"No spam. Unsubscribe with one click."` | Una línea corta bajo el formulario; `""` la oculta.                  |
| `error`       | `string`          | —                                        | El campo pasa a inválido y muestra este mensaje debajo.              |
| `loading`     | `boolean`         | `false`                                  | El campo deshabilitado y el botón ocupado, "Subscribing".            |
| `disabled`    | `boolean`         | `false`                                  | El campo y el botón deshabilitados.                                  |
| `subscribed`  | `boolean`         | `false`                                  | Un Alert de éxito sustituye al formulario.                           |
| `onSubmit`    | `(event) => void` | —                                        | El evento submit del formulario. Svelte: `onsubmit`. Vue: `@submit`. |

### Estados

| Estado        | Prop                  | Qué se muestra                                                  |
| ------------- | --------------------- | --------------------------------------------------------------- |
| Por defecto   | —                     | Encabezado, descripción, el formulario y la nota.               |
| Vacío         | `description`, `note` | Solo el encabezado y el formulario, cuando ambas son `""`.      |
| Cargando      | `loading`             | El mismo formulario con el campo deshabilitado y "Subscribing". |
| Error         | `error`               | El campo inválido, con tu mensaje debajo.                       |
| Deshabilitado | `disabled`            | El mismo formulario con el campo y el botón deshabilitados.     |
| Suscrito      | `subscribed`          | "You are subscribed" en lugar del formulario.                   |

### Tamaño

| Paso del contenedor      | Qué cambia                                                          |
| ------------------------ | ------------------------------------------------------------------- |
| bajo `@sm`               | Todo va centrado y apilado; el botón ocupa todo el ancho.           |
| `@sm` (`--container-sm`) | El campo y el botón comparten una fila.                             |
| `@md` (`--container-md`) | El encabezado sube un tamaño.                                       |
| `@lg` (`--container-lg`) | El texto pasa al inicio y el formulario a su lado, en dos columnas. |

## Notas

- Di qué recibe el lector y cada cuánto. "Un correo al mes" es mejor que "Mantente al día".
- Mantén `error` corto y di cómo arreglarlo. El campo conserva lo que escribió el lector.
