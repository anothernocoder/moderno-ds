## Uso

Usa Header una vez, arriba en cada página de un sitio público. Enlaza al inicio, a las páginas principales y a una llamada a la acción, como registrarse.

<ForFramework fw="react">

```tsx
import { Header } from "@/components/blocks/header";
```

```tsx
<Header brand="Northwind" navigation={navigation} action="Empezar" onAction={signUp} />
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import Header from "@/components/blocks/Header.vue";
</script>
```

```vue
<Header brand="Northwind" :navigation="navigation" action="Empezar" @action="signUp" />
```

</ForFramework>
<ForFramework fw="svelte">

```svelte
<script lang="ts">
  import Header from "@/components/blocks/Header.svelte";
</script>
```

```svelte
<Header brand="Northwind" {navigation} action="Empezar" onaction={signUp} />
```

</ForFramework>
<ForFramework fw="solid">

```tsx
import { Header } from "@/components/blocks/header";
```

```tsx
<Header brand="Northwind" navigation={navigation()} action="Empezar" onAction={signUp} />
```

</ForFramework>

Un enlace es así: `{ id: "pricing", label: "Precios", href: "/pricing" }`. Un grupo es así: `{ id: "product", label: "Producto", links: [...] }`.

## Referencia de la API

### Props

| Prop         | Tipo              | Por defecto                       | Descripción                                                                        |
| ------------ | ----------------- | --------------------------------- | ---------------------------------------------------------------------------------- |
| `brand`      | `string`          | `"Northwind"`                     | El nombre del sitio, en la fuente serif. Enlaza al inicio y titula el Drawer.      |
| `homeHref`   | `string`          | `"/"`                             | A dónde enlaza la marca.                                                           |
| `navigation` | `HeaderNavItem[]` | un grupo y dos enlaces de ejemplo | La navegación principal, en la barra y en el Drawer.                               |
| `action`     | `string`          | `"Get started"`                   | El texto de la llamada a la acción. `""` la oculta.                                |
| `error`      | `string`          | —                                 | La navegación no cargó; una Alert de error con un reintento aparece bajo la barra. |
| `loading`    | `boolean`         | `false`                           | Marcadores en una región ocupada reemplazan los enlaces.                           |
| `onAction`   | `() => void`      | —                                 | Se pulsó la llamada a la acción. Svelte: `onaction`. Vue: `@action`.               |
| `onRetry`    | `() => void`      | —                                 | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                        |

### HeaderNavItem

`HeaderNavItem` es un `HeaderLink` o un `HeaderMenu`.

Un `HeaderLink`:

| Campo      | Tipo      | Descripción                                                           |
| ---------- | --------- | --------------------------------------------------------------------- |
| `id`       | `string`  | Una clave estable para el enlace.                                     |
| `label`    | `string`  | El texto del enlace.                                                  |
| `href`     | `string`  | A dónde lleva el enlace.                                              |
| `current`  | `boolean` | Opcional. La página en la que está el usuario: `aria-current="page"`. |
| `disabled` | `boolean` | Opcional. El enlace se atenúa, no tiene `href` y no recibe el foco.   |

Un `HeaderMenu`:

| Campo   | Tipo           | Descripción                                                                         |
| ------- | -------------- | ----------------------------------------------------------------------------------- |
| `id`    | `string`       | Una clave estable para el grupo.                                                    |
| `label` | `string`       | El texto del disparador del Menu en la barra, y la etiqueta del grupo en el Drawer. |
| `links` | `HeaderLink[]` | Los enlaces del grupo: elementos del Menu en la barra, una lista en el Drawer.      |

### Estados

| Estado        | Prop                    | Qué se muestra                                                 |
| ------------- | ----------------------- | -------------------------------------------------------------- |
| Por defecto   | `navigation`            | La marca, los enlaces y la llamada a la acción.                |
| Vacío         | `navigation={[]}`       | La marca y la llamada a la acción. Sin botón "Menu".           |
| Cargando      | `loading`               | Tres marcadores donde van los enlaces.                         |
| Error         | `error`                 | Una Alert de error con "Try again" bajo la barra. Sin enlaces. |
| Deshabilitado | `disabled` en un enlace | Ese enlace atenuado, fuera del orden de tabulación.            |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                  |
| ------------------------ | --------------------------------------------------------------------------- |
| bajo `@sm`               | La marca y "Menu". Los enlaces y la llamada a la acción están en el Drawer. |
| `@sm` (`--container-sm`) | La llamada a la acción entra en la barra, junto a "Menu".                   |
| `@md` (`--container-md`) | Los enlaces van en la barra. El botón "Menu" desaparece.                    |
| `@lg` (`--container-lg`) | Más espacio alrededor de la barra y entre sus partes.                       |

## Notas

- Deja una sola llamada a la acción. Una segunda, como "Iniciar sesión", va en la página o en un grupo.
- Deja las etiquetas de los enlaces en una o dos palabras, para que la barra quepa en una línea.
