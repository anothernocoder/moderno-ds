## Referencia de API

### Propiedades

| Prop       | Tipo                     | Por defecto | Descripción                                                          |
| ---------- | ------------------------ | ----------- | -------------------------------------------------------------------- |
| `error`    | `string`                 | —           | Alerta de formulario sobre el primer grupo.                          |
| `errors`   | `Record<string, string>` | —           | Mensajes por campo según su `name`; cada uno lo marca como inválido. |
| `loading`  | `boolean`                | `false`     | Deshabilita todos los controles y marca el envío con `aria-busy`.    |
| `disabled` | `boolean`                | `false`     | El formulario es de solo lectura.                                    |
| `onSubmit` | `(event) => void`        | —           | El evento submit nativo. Svelte: `onsubmit`. Vue: `@submit`.         |
| `onCancel` | `() => void`             | —           | El botón "Cancel". Svelte: `oncancel`. Vue: `@cancel`.               |

### Campos

| Grupo         | Campo           | `name`           |
| ------------- | --------------- | ---------------- |
| Profile       | Full name       | `fullName`       |
| Profile       | Email           | `email`          |
| Profile       | About           | `about`          |
| Notifications | Product updates | `productUpdates` |
| Notifications | Security alerts | `securityAlerts` |

### Estados

| Estado           | Prop       | Qué se muestra                                                                      |
| ---------------- | ---------- | ----------------------------------------------------------------------------------- |
| Por defecto      | —          | El formulario vacío con placeholders y texto de ayuda.                              |
| Error            | `error`    | Una alerta de formulario para el guardado.                                          |
| Errores de campo | `errors`   | Cada campo nombrado queda inválido e imprime su propio mensaje.                     |
| Cargando         | `loading`  | Todos los controles y las dos acciones deshabilitados; el envío muestra un spinner. |
| Deshabilitado    | `disabled` | Todos los controles y las dos acciones deshabilitados.                              |

### Dimensionado

| Paso del contenedor      | Qué cambia                                                 |
| ------------------------ | ---------------------------------------------------------- |
| `@sm` (`--container-sm`) | La fila de acciones deja de apilarse y se alinea al final. |
| `@md` (`--container-md`) | Los campos se emparejan, dos por fila.                     |
| `@lg` (`--container-lg`) | El título de cada grupo pasa junto a sus campos.           |

## Notas

- Es presentacional: los controles no están controlados y no envía peticiones. Lee el formulario en tu handler de submit.
- `error` y `errors` son independientes. Pasar solo `errors` marca los campos sin alerta.
- Para credenciales, usa el [formulario de acceso](/es/login-form/).
