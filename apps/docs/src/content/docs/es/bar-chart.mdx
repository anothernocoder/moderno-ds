## Referencia de API

### BarChart

<PropsTable component="BarChart" />

### Series

Cada entrada de `series` es un conjunto de barras, una por categoría.

| Campo    | Tipo       | Descripción                                                                                        |
| -------- | ---------- | -------------------------------------------------------------------------------------------------- |
| `name`   | `string`   | Etiqueta opcional de la serie.                                                                     |
| `values` | `number[]` | Un valor por categoría, alineado con `categories` por índice. Un valor que falta se dibuja como 0. |

### Valores por defecto

| Prop      | Por defecto                                                             |
| --------- | ----------------------------------------------------------------------- |
| `padding` | `0.2`                                                                   |
| `yDomain` | Todos los valores más el 0, redondeados hacia afuera a números limpios. |
| `yTicks`  | `5`                                                                     |
| `margin`  | `{ top: 16, right: 16, bottom: 28, left: 36 }`                          |
| `format`  | El número, redondeado a 4 decimales                                     |

### Atributos de datos

| Atributo      | En              | Valores                                                                 |
| ------------- | --------------- | ----------------------------------------------------------------------- |
| `data-chart`  | `svg` raíz      | `bar`                                                                   |
| `data-part`   | Cada elemento   | `root`, `grid`, `grid-line`, `axis-line`, `tick-label`, `series`, `bar` |
| `data-series` | `g` de la serie | Índice desde 0, asignado de `--chart-1` a `--chart-5`                   |

## Notas

- Las series no tienen clave de categoría, así que cada serie necesita un valor por categoría.
- No hay prop de color: las series se pintan de `--chart-1` a `--chart-5` por índice.
- La cuadrícula, los ejes y las etiquetas usan `--border` y `--muted-foreground`.
