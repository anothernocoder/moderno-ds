## Uso

Slider permite elegir un número arrastrando un control por una pista. Úsalo cuando importa más la posición aproximada que la cifra exacta, como el volumen. Con dos controles se elige un rango.

<ForFramework fw="react">

```tsx
import { Slider } from "@moderno-ui/react";
```

```tsx
<Slider.Root value={volume} onValueChange={(details) => setVolume(details.value)}>
  <Slider.Label>Volumen</Slider.Label>
  <Slider.ValueText />
  <Slider.Control>
    <Slider.Track>
      <Slider.Range />
    </Slider.Track>
    <Slider.Thumb index={0}>
      <Slider.HiddenInput />
    </Slider.Thumb>
  </Slider.Control>
</Slider.Root>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Slider } from "@moderno-ui/vue";
```


El valor es un array con un número por control. Va de 0 a 100 por defecto.

## Referencia de la API

### Slider.Root

`size` es el añadido de Moderno; todas las partes lo siguen. El resto de props vienen del Slider de Ark.

<PropsTable component="Slider" />

| Prop                    | Tipo                                                    | Por defecto    | Descripción                                                |
| ----------------------- | ------------------------------------------------------- | -------------- | ---------------------------------------------------------- |
| `value`                 | `number[]`                                              | —              | Valor controlado, un número por control.                   |
| `defaultValue`          | `number[]`                                              | `[min]`        | Valor al principio, sin control.                           |
| `onValueChange`         | `(details: { value: number[] }) => void`                | —              | Se llama mientras cambia el valor.                         |
| `onValueChangeEnd`      | `(details: { value: number[] }) => void`                | —              | Se llama una vez, cuando el usuario suelta.                |
| `min`                   | `number`                                                | `0`            | El valor más bajo.                                         |
| `max`                   | `number`                                                | `100`          | El valor más alto.                                         |
| `step`                  | `number`                                                | `1`            | Cuánto avanza un movimiento.                               |
| `minStepsBetweenThumbs` | `number`                                                | `0`            | Cuántos pasos separan los controles de un rango.           |
| `orientation`           | `"horizontal" \| "vertical"`                            | `"horizontal"` | Tiende la pista o la pone de pie.                          |
| `origin`                | `"start" \| "center" \| "end"`                          | `"start"`      | Desde dónde se llena el rango de un solo control.          |
| `disabled`              | `boolean`                                               | `false`        | Atenúa el slider e ignora la entrada.                      |
| `readOnly`              | `boolean`                                               | `false`        | Muestra el valor pero ignora la entrada.                   |
| `invalid`               | `boolean`                                               | `false`        | Marca el valor como erróneo.                               |
| `name`                  | `string`                                                | —              | El nombre de campo de los inputs ocultos.                  |
| `getAriaValueText`      | `(details: { value: number; index: number }) => string` | —              | Lo que dice un lector de pantalla del valor de un control. |

En Vue, enlaza el valor con `:model-value` o `v-model`, y escucha con `@value-change`.

### Slider.Thumb

| Prop    | Tipo     | Por defecto | Descripción                                |
| ------- | -------- | ----------- | ------------------------------------------ |
| `index` | `number` | —           | Obligatorio. Qué valor mueve este control. |
| `name`  | `string` | —           | El nombre de campo de su input oculto.     |

### Slider.Marker

| Prop    | Tipo     | Por defecto | Descripción                                  |
| ------- | -------- | ----------- | -------------------------------------------- |
| `value` | `number` | —           | Obligatorio. El valor en el que va la marca. |

### Partes

| Parte                      | Elemento  | Descripción                                                                   |
| -------------------------- | --------- | ----------------------------------------------------------------------------- |
| `Slider.Root`              | `<div>`   | Lleva `data-size`.                                                            |
| `Slider.Label`             | `<label>` | Opcional. Nombra el valor. Al pulsarla, el foco va al control.                |
| `Slider.ValueText`         | `<span>`  | Opcional. El valor, o los dos extremos de un rango.                           |
| `Slider.Control`           | `<div>`   | La zona donde se pulsa o arrastra. Contiene la pista y los controles.         |
| `Slider.Track`             | `<div>`   | La línea completa de valores posibles.                                        |
| `Slider.Range`             | `<div>`   | La parte llena de la pista, hasta los controles o entre ellos.                |
| `Slider.Thumb`             | `<div>`   | El control, con `role="slider"` y `aria-valuenow`.                            |
| `Slider.HiddenInput`       | `<input>` | Dentro de un control. Lleva su valor a un formulario.                         |
| `Slider.DraggingIndicator` | `<span>`  | Opcional, dentro de un control. El valor en una burbuja mientras se arrastra. |
| `Slider.MarkerGroup`       | `<div>`   | Opcional. Contiene las marcas, bajo la pista.                                 |
| `Slider.Marker`            | `<span>`  | Una marca en un valor, con tu propio texto.                                   |

### Atributos data

| Atributo           | Valores                                                                                   |
| ------------------ | ----------------------------------------------------------------------------------------- |
| `data-orientation` | `"horizontal"` o `"vertical"`, en todas las partes                                        |
| `data-dragging`    | Mientras se arrastra un control, en la raíz, el control, la pista, el rango y ese control |
| `data-focus`       | Mientras un control tiene el foco, en la raíz y sus partes                                |
| `data-disabled`    | Con `disabled`, en todas las partes                                                       |
| `data-invalid`     | Con `invalid`, en la raíz y sus partes                                                    |
| `data-state`       | En cada marca: `"under-value"`, `"at-value"` o `"over-value"`                             |
| `data-size`        | En la raíz: `"sm"`, `"md"` o `"lg"`                                                       |

## Notas

- `Slider.Root` está envuelto para añadir `size`; el resto de partes son las de Ark sin cambios.
- Cada control se nombra con `Slider.Label`. Los dos controles de un rango la comparten; pasa `aria-label` como array para nombrar cada uno.
- Ark oculta un control hasta que lo ha medido, para que quede dentro de la pista en los dos extremos.
- En Solid, `Slider.ValueText` une los valores de un rango con una coma sin espacio (`20,80`); los demás frameworks añaden un espacio.
- Para un número exacto que el usuario escribe, usa un Field con un input numérico.
