## Uso

Un toggle es un botón que se queda pulsado. Púlsalo una vez para activar una opción y otra vez para desactivarla. Úsalo para una opción de una barra de herramientas; para varias opciones relacionadas, usa Toggle Group.

<ForFramework fw="react">

```tsx
import { Toggle } from "@moderno-ui/react";
```

```tsx
<Toggle.Root>Bold</Toggle.Root>
```

</ForFramework>

## Referencia de la API

### Toggle.Root

`variant` y `size` son los añadidos de Moderno; el resto de props vienen del Toggle de Ark.

<PropsTable component="Toggle" />

| Prop              | Tipo                         | Por defecto | Descripción                                     |
| ----------------- | ---------------------------- | ----------- | ----------------------------------------------- |
| `pressed`         | `boolean`                    | —           | Estado controlado. Úsalo con `onPressedChange`. |
| `defaultPressed`  | `boolean`                    | `false`     | Estado inicial cuando no está controlado.       |
| `onPressedChange` | `(pressed: boolean) => void` | —           | Se llama cuando el toggle se pulsa o se suelta. |
| `disabled`        | `boolean`                    | `false`     | Deshabilita el botón y lo atenúa.               |

En Vue, escucha con `@pressed-change` o enlaza el estado con `v-model:pressed`.

### Partes

| Parte              | Elemento   | Descripción                                                                                                                 |
| ------------------ | ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| `Toggle.Root`      | `<button>` | El botón. Lleva `aria-pressed`, `data-variant` y `data-size`.                                                               |
| `Toggle.Indicator` | `<div>`    | Opcional. Muestra sus hijos cuando está activado y su `fallback` cuando no (en Vue es un `<span>` con un slot `#fallback`). |

### Atributos data

| Atributo        | Valores                                     |
| --------------- | ------------------------------------------- |
| `data-state`    | `"on"` u `"off"`, en la raíz y el indicador |
| `data-pressed`  | Presente mientras está pulsado              |
| `data-disabled` | Presente con `disabled`                     |
| `data-variant`  | En la raíz: `"ghost"` u `"outline"`         |
| `data-size`     | En la raíz: `"sm"`, `"md"` o `"lg"`         |

## Notas

- `Toggle.Root` está envuelto para añadir `variant` y `size`; el resto de partes son las de Ark sin cambios.
- Estiliza el estado desde `data-state` y los atributos `data-*`; `variant` y `size` son las únicas props visuales.
- Toggle es un botón que se pulsa. Para un ajuste de encendido y apagado con riel y perilla, usa Switch.
