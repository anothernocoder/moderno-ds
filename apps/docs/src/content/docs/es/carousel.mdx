## Uso

Un Carousel muestra diapositivas de una página en una. Úsalo cuando unas pocas imágenes, tarjetas o citas comparten un mismo lugar de la página. Los botones de anterior y siguiente pasan una página, y cada punto salta a la suya.

<ForFramework fw="react">

```tsx
import { Carousel } from "@moderno-ui/react";
```

```tsx
<Carousel.Root slideCount={slides.length}>
  <Carousel.ItemGroup>
    {slides.map((slide, index) => (
      <Carousel.Item key={slide.id} index={index}>
        <img src={slide.src} alt={slide.alt} />
      </Carousel.Item>
    ))}
  </Carousel.ItemGroup>
  <Carousel.Control>
    <Carousel.PrevTrigger>‹</Carousel.PrevTrigger>
    <Carousel.IndicatorGroup>
      {slides.map((slide, index) => (
        <Carousel.Indicator key={slide.id} index={index} />
      ))}
    </Carousel.IndicatorGroup>
    <Carousel.NextTrigger>›</Carousel.NextTrigger>
  </Carousel.Control>
</Carousel.Root>
```

</ForFramework>

`slideCount` es cuántas diapositivas pintas. Da a cada `Carousel.Item` su `index`, desde 0. Las páginas también empiezan en 0.

## Referencia de la API

### Carousel.Root

`size` es lo que añade Moderno; los botones, los puntos y el texto de progreso lo siguen. El resto de props vienen del Carousel de Ark.

<PropsTable component="Carousel" />

| Prop             | Tipo                                                         | Por defecto    | Descripción                                                                   |
| ---------------- | ------------------------------------------------------------ | -------------- | ----------------------------------------------------------------------------- |
| `slideCount`     | `number`                                                     | —              | Obligatoria. Cuántas diapositivas hay.                                        |
| `slidesPerPage`  | `number`                                                     | `1`            | Cuántas diapositivas se ven a la vez.                                         |
| `slidesPerMove`  | `number \| "auto"`                                           | `"auto"`       | Cuántas diapositivas avanza un paso. `"auto"` avanza una página entera.       |
| `spacing`        | `string`                                                     | `"0px"`        | El espacio entre diapositivas, como longitud CSS.                             |
| `padding`        | `string`                                                     | —              | Espacio en cada extremo, para que asome la siguiente diapositiva.             |
| `page`           | `number`                                                     | —              | Página actual controlada, desde 0.                                            |
| `defaultPage`    | `number`                                                     | `0`            | Página inicial, sin control.                                                  |
| `onPageChange`   | `(details: { page: number; pageSnapPoint: number }) => void` | —              | Se llama al cambiar de página.                                                |
| `loop`           | `boolean`                                                    | `false`        | Volver de la última página a la primera. Activo por defecto con `autoplay`.   |
| `autoplay`       | `boolean \| { delay: number }`                               | `false`        | Avanzar cada 4 segundos, o cada `delay` ms. En pausa con movimiento reducido. |
| `allowMouseDrag` | `boolean`                                                    | `false`        | Dejar que el ratón arrastre las diapositivas, no solo el dedo.                |
| `orientation`    | `"horizontal" \| "vertical"`                                 | `"horizontal"` | Hacia dónde se desplazan las diapositivas.                                    |
| `translations`   | `IntlTranslations`                                           | —              | Lo que dice un lector de pantalla de cada diapositiva, punto y botón.         |

En Vue, enlaza la página con `v-model:page` y escucha con `@page-change`.

### Partes

| Parte                        | Elemento   | Descripción                                                            |
| ---------------------------- | ---------- | ---------------------------------------------------------------------- |
| `Carousel.Root`              | `<div>`    | La región que un lector de pantalla llama carrusel. Lleva `data-size`. |
| `Carousel.ItemGroup`         | `<div>`    | Desplaza las diapositivas y se ajusta a cada página.                   |
| `Carousel.Item`              | `<div>`    | Una diapositiva. Recibe su `index`, desde 0.                           |
| `Carousel.Control`           | `<div>`    | Pone los botones y los puntos en una fila centrada.                    |
| `Carousel.PrevTrigger`       | `<button>` | Retrocede una página. Desactivado en la primera, salvo en bucle.       |
| `Carousel.NextTrigger`       | `<button>` | Avanza una página. Desactivado en la última, salvo en bucle.           |
| `Carousel.IndicatorGroup`    | `<div>`    | Agrupa los puntos. Aquí las flechas del teclado cambian de página.     |
| `Carousel.Indicator`         | `<button>` | Un punto por página. Recibe el `index` de su página.                   |
| `Carousel.AutoplayTrigger`   | `<button>` | Opcional. Inicia y detiene el avance automático.                       |
| `Carousel.AutoplayIndicator` | `<span>`   | Opcional. Muestra su contenido mientras avanza, y `fallback` en pausa. |
| `Carousel.ProgressText`      | `<span>`   | Opcional. La página como texto, por ejemplo "2 / 5".                   |
| `Carousel.Context`           | —          | Te da el carrusel: `page`, `pageSnapPoints`, `isPlaying`.              |

### Atributos data

| Atributo       | Valores                                          |
| -------------- | ------------------------------------------------ |
| `data-current` | En el punto de la página actual                  |
| `data-inview`  | En cada diapositiva a la vista                   |
| `data-pressed` | En el botón de avance automático mientras avanza |
| `data-index`   | En cada diapositiva y punto: su índice           |
| `data-size`    | En la raíz: `"sm"`, `"md"` o `"lg"`              |

## Notas

- `Carousel.Root` está envuelto para añadir `size` y respetar el movimiento reducido; el resto de partes son las de Ark sin cambios.
- Si el lector prefiere movimiento reducido, `autoplay` no arranca, y los botones y los puntos no se animan. El lector aún puede iniciarlo con `Carousel.AutoplayTrigger`.
- Un carrusel toma el ancho de su contenedor. Dale una altura a uno vertical.
- En una página de derecha a izquierda, las diapositivas empiezan por la derecha. Pasa los signos al revés: `›` para anterior y `‹` para siguiente.
