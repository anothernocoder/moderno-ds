Los componentes referencian slots, nunca valores: sobrescribir un slot es la única forma de re-tematizar.
`@moderno-ui/css` trae un valor neutro por defecto para cada slot de esta página.

## Ámbitos

| Selector           | Contiene                                    |
| ------------------ | ------------------------------------------- |
| `:root`            | Valores claros.                             |
| `.dark`            | Overrides oscuros.                          |
| `[data-brand="…"]` | Overrides de marca. Se compone con `.dark`. |

```css
:root {
  --primary: oklch(0.55 0.2 260);
  --radius: 0.5rem;
}

.dark {
  --primary: oklch(0.75 0.15 260);
}
```

## Slots obligatorios

Un tema debe definir todos los slots de esta sección. Crea uno visualmente en el [Editor de temas](/es/theme-builder).

Las tablas salen del contrato de tokens. Los roles están en inglés, igual que los leen los agentes.

## Tailwind v4

Importa el preset para registrar los slots como claves de tema de Tailwind.

```css
@import "tailwindcss";
@import "@moderno-ui/css";
@import "@moderno-ui/css/preset";
```

| Slot                                           | Utilidades                                                                  |
| ---------------------------------------------- | --------------------------------------------------------------------------- |
| Slots de color                                 | `bg-primary`, `text-muted-foreground`, `border-input`, …                    |
| `--radius`                                     | `rounded-sm` (−4px), `rounded-md` (−2px), `rounded-lg`, `rounded-xl` (+4px) |
| `--radius-full`                                | `rounded-full`                                                              |
| `--font-sans` / `--font-serif` / `--font-mono` | `font-sans`, `font-serif`, `font-mono`                                      |
| `--shadow-*`                                   | `shadow-sm`, `shadow-md`, `shadow-lg`                                       |
| `--container-*`                                | `max-w-sm`, `max-w-md`, `max-w-lg`, `w-*`, `@sm:` / `@md:` / `@lg:`         |
| `--text-*` / `--leading-*`                     | `text-ui-sm`, `text-body`, … (tamaño e interlineado), `leading-body`, …     |
| `--font-weight-*`                              | `font-normal`, `font-medium`, `font-semibold`, `font-bold`                  |
| `--spacing-*`, `--motion-*`                    | Sin mapear. Usa `var(--spacing-4)` y similares.                             |

### Notas

- Los pasos tipográficos conviven con los `text-xs` … `text-9xl` de Tailwind, sin pisarlos: `text-sm` conserva su tamaño.
- Los pesos usan las mismas claves y valores que Tailwind: un `font-semibold` de serie ya lee el slot, incluso sin el preset, y se ve igual hasta que un tema lo sobrescribe.
- Las utilidades de color, radio, tipografía y sombra apuntan a `var(--slot)` (`@theme inline`), así que un override en tiempo de ejecución las re-tematiza sin recompilar.
- `@sm:` / `@md:` / `@lg:` se disparan en 24rem / 36rem / 48rem fijos, porque una container query no puede leer `var()`.
- `max-w-*` y `w-*` siguen resolviendo a `var(--container-*)` y respetan el override del tema.
- El preset resetea la escala de contenedor de Tailwind (`--container-*: initial`): `max-w-xl`, `@xl:` y superiores no existen.
- ¿Necesitas un tamaño más ancho? Declara tu propia clave en un bloque `@theme` de tu aplicación.
- Sin el preset, `@moderno-ui/css` solo sobrescribe `sm|md|lg` en la escala de Tailwind, así que `max-w-lg` (48rem) queda más ancho que `max-w-xl` (36rem).

## Leerlo como datos

| Fuente                             | Devuelve                                                                       |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| `@moderno-ui/css/contract`         | `CONTRACT`: cada slot con su tipo DTCG, su grupo del Editor de temas y su rol. |
| `get_contract` (`@moderno-ui/mcp`) | Los mismos slots, más las reglas de tematización, para agentes.                |

```ts
import { CONTRACT, COLOR_SLOTS, EXTENDED_SLOTS } from "@moderno-ui/css/contract";
```
