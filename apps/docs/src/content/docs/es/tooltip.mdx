## Uso

Un Tooltip es una etiqueta corta para un control. Aparece mientras el puntero se detiene sobre el control, o mientras el control tiene el foco del teclado, y se oculta con Escape. Úsalo para nombrar un botón de icono o mostrar un atajo.

<ForFramework fw="react">

```tsx
import { Button, Portal, Tooltip } from "@moderno-ui/react";
```

```tsx
<Tooltip.Root>
  <Tooltip.Trigger asChild>
    <Button variant="outline">Save</Button>
  </Tooltip.Trigger>
  <Portal>
    <Tooltip.Positioner>
      <Tooltip.Content>
        <Tooltip.Arrow>
          <Tooltip.ArrowTip />
        </Tooltip.Arrow>
        Save your changes
      </Tooltip.Content>
    </Tooltip.Positioner>
  </Portal>
</Tooltip.Root>
```

</ForFramework>

```vue
  </Portal>
```


</ForFramework>

`asChild` pone el disparador en tu propio botón, así el tooltip lo describe. `Portal` saca el tooltip de cualquier contenedor que lo recorte.

## Referencia de la API

### Tooltip.Root

`size` es lo que añade Moderno; el relleno, el texto y la flecha del contenido lo siguen. El resto de props vienen del Tooltip de Ark.

<PropsTable component="Tooltip" />

| Prop            | Tipo                                   | Por defecto               | Descripción                                                             |
| --------------- | -------------------------------------- | ------------------------- | ----------------------------------------------------------------------- |
| `openDelay`     | `number`                               | `400`                     | Milisegundos que el puntero se detiene en el disparador antes de abrir. |
| `closeDelay`    | `number`                               | `150`                     | Milisegundos antes de cerrar cuando el puntero se va.                   |
| `positioning`   | `PositioningOptions`                   | `{ placement: "bottom" }` | Dónde se coloca: `placement`, `gutter`, `offset`, …                     |
| `open`          | `boolean`                              | —                         | Estado abierto controlado.                                              |
| `defaultOpen`   | `boolean`                              | `false`                   | Abierto al inicio, sin control.                                         |
| `onOpenChange`  | `(details: { open: boolean }) => void` | —                         | Se llama al abrir o cerrar.                                             |
| `disabled`      | `boolean`                              | `false`                   | No abrir nunca.                                                         |
| `interactive`   | `boolean`                              | `false`                   | Dejar que el puntero pase al contenido sin cerrarlo.                    |
| `closeOnClick`  | `boolean`                              | `true`                    | Cerrar al hacer clic en el disparador.                                  |
| `closeOnEscape` | `boolean`                              | `true`                    | Cerrar con Escape.                                                      |
| `aria-label`    | `string`                               | —                         | Una etiqueta para lectores de pantalla si el contenido no es texto.     |

En Vue, enlaza el estado con `v-model:open` y escucha con `@open-change`. En Svelte, usa `bind:open`.

### Partes

| Parte                | Elemento   | Descripción                                                           |
| -------------------- | ---------- | --------------------------------------------------------------------- |
| `Tooltip.Root`       | —          | Guarda el estado. No pinta ningún elemento; pasa `size` al contenido. |
| `Tooltip.Trigger`    | `<button>` | El control que describe. Usa `asChild` para ponerlo en el tuyo.       |
| `Tooltip.Positioner` | `<div>`    | Coloca el contenido junto al disparador.                              |
| `Tooltip.Content`    | `<div>`    | La etiqueta, con el rol `tooltip`. Lleva `data-size`.                 |
| `Tooltip.Arrow`      | `<div>`    | Opcional. Apunta el contenido hacia el disparador.                    |
| `Tooltip.ArrowTip`   | `<div>`    | La punta que se ve, dentro de la flecha.                              |
| `Tooltip.Context`    | —          | Te da el tooltip: `open`, `setOpen`, `reposition`.                    |

### Atributos data

| Atributo       | Valores                                                    |
| -------------- | ---------------------------------------------------------- |
| `data-state`   | En el disparador y el contenido: `"open"` o `"closed"`     |
| `data-side`    | En el contenido: `"top"`, `"right"`, `"bottom"` o `"left"` |
| `data-instant` | En el contenido, si se abrió al instante tras otro tooltip |
| `data-size`    | En el contenido: `"sm"`, `"md"` o `"lg"`                   |

## Notas

- `Tooltip.Root` y `Tooltip.Content` están envueltos para llevar `size`; el resto de partes son las de Ark sin cambios.
- Al pasar de un tooltip al siguiente, este se abre al instante, sin fundido. Si el lector prefiere movimiento reducido, no hay fundido nunca.
- Las pantallas táctiles no tienen hover. Deja lo que dice el tooltip disponible de otra forma.
