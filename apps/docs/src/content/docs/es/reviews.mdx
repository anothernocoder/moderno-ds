## Referencia de la API

### Props

| Prop            | Tipo            | Por defecto             | Descripción                                                                   |
| --------------- | --------------- | ----------------------- | ----------------------------------------------------------------------------- |
| `heading`       | `string`        | `"Customer reviews"`    | El encabezado de la sección. Va en la fuente con serifa.                      |
| `reviews`       | `Review[]`      | tres reseñas de ejemplo | Las reseñas que se muestran, en orden. `[]` muestra el mensaje de vacío.      |
| `breakdown`     | `RatingCount[]` | contado de `reviews`    | Cuántas reseñas dieron cada valoración. La media y el total salen de aquí.    |
| `error`         | `string`        | —                       | Falló la carga de las reseñas; un Alert de error con reintento las reemplaza. |
| `loading`       | `boolean`       | `false`                 | Marcadores reemplazan la media, las barras y las reseñas.                     |
| `disabled`      | `boolean`       | `false`                 | Las reseñas se quedan; "Write a review" y el reintento quedan deshabilitados. |
| `onWriteReview` | `() => void`    | —                       | Se pulsó "Write a review". Svelte: `onwritereview`. Vue: `@write-review`.     |
| `onRetry`       | `() => void`    | —                       | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                   |

Si omites `reviews` y `breakdown`, las reseñas de ejemplo van con su desglose de ejemplo (132 reseñas, 4.4 de media).

### Review

| Campo       | Tipo      | Descripción                                                       |
| ----------- | --------- | ----------------------------------------------------------------- |
| `id`        | `string`  | Una clave estable para la reseña.                                 |
| `author`    | `string`  | El nombre del autor.                                              |
| `initials`  | `string`  | Una o dos letras. El avatar las muestra hasta que carga una foto. |
| `avatarUrl` | `string`  | Opcional. La foto del autor.                                      |
| `rating`    | `number`  | Las estrellas que dio el autor, de 1 a 5.                         |
| `date`      | `string`  | Cuándo se escribió la reseña, con el formato que elijas.          |
| `content`   | `string`  | Lo que escribió el autor.                                         |
| `verified`  | `boolean` | Opcional. Añade un Badge "Verified purchase".                     |

### RatingCount

| Campo    | Tipo     | Descripción                        |
| -------- | -------- | ---------------------------------- |
| `rating` | `number` | Un número de estrellas, de 1 a 5.  |
| `count`  | `number` | Cuántas reseñas dieron ese número. |

### Estados

| Estado        | Prop           | Qué se muestra                                                               |
| ------------- | -------------- | ---------------------------------------------------------------------------- |
| Por defecto   | —              | Encabezado, media, una barra por valoración, "Write a review" y las reseñas. |
| Vacío         | `reviews={[]}` | Encabezado, "Write a review" y "No reviews yet."                             |
| Cargando      | `loading`      | Encabezado, "Write a review" y marcadores para el resumen y las reseñas.     |
| Error         | `error`        | Encabezado, "Write a review" y después un Alert de error con "Try again".    |
| Deshabilitado | `disabled`     | Las mismas reseñas con "Write a review" deshabilitado.                       |

### Tamaño

| Paso del contenedor      | Qué cambia                                                           |
| ------------------------ | -------------------------------------------------------------------- |
| bajo `@sm`               | Todo en una columna, con las reseñas en tamaño pequeño.              |
| `@sm` (`--container-sm`) | Las reseñas suben un tamaño.                                         |
| `@md` (`--container-md`) | La media se pone junto a las barras, y el encabezado sube un tamaño. |
| `@lg` (`--container-lg`) | El resumen pasa a una columna junto a las reseñas, con más espacio.  |

## Notas

- Muestra las últimas reseñas y pasa el `breakdown` completo, así la media cuenta todas las reseñas.
- Conecta "Write a review" con tu propio formulario mediante `onWriteReview`.
