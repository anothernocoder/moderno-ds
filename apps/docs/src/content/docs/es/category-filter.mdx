## Referencia de la API

### Props

| Prop              | Tipo                                 | Por defecto             | Descripción                                                                         |
| ----------------- | ------------------------------------ | ----------------------- | ----------------------------------------------------------------------------------- |
| `heading`         | `string`                             | `"New arrivals"`        | El `h2` del bloque.                                                                 |
| `description`     | `string`                             | una frase de ejemplo    | La línea bajo el título. `""` la oculta.                                            |
| `facets`          | `FilterFacet[]`                      | tres facetas de ejemplo | Un elemento de Accordion por faceta, con un Checkbox por opción.                    |
| `price`           | `PriceFilter \| null`                | de `0` a `200` en EUR   | El Slider del rango de precio. `null` lo quita.                                     |
| `error`           | `string`                             | —                       | Los filtros no cargaron; un Alert de error ocupa su lugar.                          |
| `loading`         | `boolean`                            | `false`                 | Marcadores de carga en lugar de los filtros.                                        |
| `disabled`        | `boolean`                            | `false`                 | Todos los controles apagados.                                                       |
| `children`        | productos                            | —                       | Tus productos, junto a la barra lateral o bajo el título. Vue: el slot por defecto. |
| `onFiltersChange` | `(filters: CategoryFilters) => void` | —                       | Los filtros cambiaron. Svelte: `onfilterschange`. Vue: `@filters-change`.           |
| `onRetry`         | `() => void`                         | —                       | Se pulsó "Try again". Svelte: `onretry`. Vue: `@retry`.                             |

### FilterFacet

| Campo     | Tipo                                                 | Descripción                                                |
| --------- | ---------------------------------------------------- | ---------------------------------------------------------- |
| `id`      | `string`                                             | La clave de esta faceta en `CategoryFilters.options`.      |
| `label`   | `string`                                             | El título del elemento de Accordion.                       |
| `options` | `{ value: string; label: string; count?: number }[]` | Un Checkbox por opción. `count` aparece atenuado al final. |

### PriceFilter

| Campo      | Tipo     | Descripción                                                    |
| ---------- | -------- | -------------------------------------------------------------- |
| `min`      | `number` | El precio más bajo.                                            |
| `max`      | `number` | El precio más alto.                                            |
| `step`     | `number` | Cuánto mueve un tirador cada tecla de flecha. Por defecto `1`. |
| `currency` | `string` | Un código de moneda ISO. Por defecto `EUR`.                    |

### CategoryFilters

| Campo     | Tipo                       | Descripción                                             |
| --------- | -------------------------- | ------------------------------------------------------- |
| `options` | `Record<string, string[]>` | Los valores marcados, por `id` de faceta.               |
| `price`   | `[number, number] \| null` | El rango de precio elegido, o `null` si no hay `price`. |

### Estados

| Estado        | Prop                       | Qué se muestra                                                                |
| ------------- | -------------------------- | ----------------------------------------------------------------------------- |
| Por defecto   | —                          | Los filtros, cada faceta abierta, nada marcado y el rango de precio completo. |
| Vacío         | sin `facets` y sin `price` | "No filters for this category." en un recuadro discontinuo.                   |
| Cargando      | `loading`                  | Marcadores de carga en una región `status` ocupada.                           |
| Error         | `error`                    | Un Alert de error con "Try again".                                            |
| Deshabilitado | `disabled`                 | Cada casilla, el rango de precio y cada botón apagados.                       |

### Tamaños

| Paso del contenedor      | Qué cambia                                                                               |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| por debajo de `@sm`      | Los filtros están en un panel lateral; el botón Filters ocupa su fila bajo el título.    |
| `@sm` (`--container-sm`) | El botón Filters se coloca junto al título.                                              |
| `@md` (`--container-md`) | Los filtros pasan a una barra lateral junto a los productos, y el título sube un tamaño. |
| `@lg` (`--container-lg`) | La barra lateral se ensancha, con más espacio arriba y abajo.                            |
