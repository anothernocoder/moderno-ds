## Uso

Usa un indicador para mostrar un estado en vivo con un solo punto: alguien está en línea, un servicio está caído, una grabación está en curso.

<ForFramework fw="react">

```tsx
import { Indicator } from "@moderno-ui/react";
```

```tsx
<Indicator variant="success">En línea</Indicator>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Indicator } from "@moderno-ui/vue";
```

```vue
<Indicator variant="success">En línea</Indicator>
```

</ForFramework>

<ForFramework fw="svelte">



## Referencia de API

### Indicator

Renderiza un `<span>`; sus hijos son la etiqueta. `variant` vale `neutral` por defecto, `size`, `md` y `pulse`, `false`.

<PropsTable component="Indicator" />

### Partes

| Parte   | Elemento | Descripción                                                                                                                 |
| ------- | -------- | --------------------------------------------------------------------------------------------------------------------------- |
| `root`  | `<span>` | Lleva `data-variant`, `data-size` y, con `pulse`, `data-pulse`. Un punto solo con `aria-label` también recibe `role="img"`. |
| `dot`   | `<span>` | El punto de color. Siempre se renderiza; `aria-hidden`.                                                                     |
| `label` | `<span>` | Solo se renderiza cuando hay hijos.                                                                                         |

## Notas

- Indicator es solo CSS: un `<span>` con `data-scope="indicator"`, sin máquina de Ark.
- Acompaña siempre el color con texto: una etiqueta, o un `aria-label` en un punto solo. Un `<span>` simple no puede llevar un nombre; por eso un punto solo con nombre recibe `role="img"`.
- Reserva `pulse` para el único estado que está ocurriendo ahora mismo.
