## Referencia de API

### Props

| Prop            | Tipo               | Por defecto               | Descripción                                                     |
| --------------- | ------------------ | ------------------------- | --------------------------------------------------------------- |
| `heading`       | `string`           | `"Ada Lovelace"`          | De quién o de qué trata el objeto. Se muestra como un h3.       |
| `meta`          | `string`           | `"Commented 2 hours ago"` | Una línea corta junto al título, como una hora; `""` la oculta. |
| `body`          | `string`           | un comentario de muestra  | El texto bajo el título. `""` muestra el estado vacío.          |
| `initials`      | `string`           | `"AL"`                    | Se ven en el avatar mientras no hay foto.                       |
| `avatarUrl`     | `string`           | —                         | La foto. Si no carga, se quedan las iniciales.                  |
| `mediaPosition` | `"start" \| "end"` | `"start"`                 | A qué lado del texto va el avatar, desde `@sm`.                 |
| `actionLabel`   | `string`           | `"Reply"`                 | El botón fantasma bajo el texto; `""` lo oculta.                |
| `error`         | `string`           | —                         | El texto no cargó; una alerta con reintento lo sustituye.       |
| `loading`       | `boolean`          | `false`                   | Marcadores en una región ocupada sustituyen todo el objeto.     |
| `disabled`      | `boolean`          | `false`                   | Todo sigue legible y los botones quedan deshabilitados.         |
| `onAction`      | `() => void`       | —                         | Se pulsó la acción. Svelte: `onaction`. Vue: `@action`.         |
| `onRetry`       | `() => void`       | —                         | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.     |

### Estados

| Estado        | Prop       | Qué se muestra                                                         |
| ------------- | ---------- | ---------------------------------------------------------------------- |
| Por defecto   | —          | El avatar, el título y la meta, el texto y la acción.                  |
| Vacío         | `body=""`  | El avatar y el título, y una línea tenue "Nothing written yet.".       |
| Cargando      | `loading`  | Un marcador redondo y tres líneas en una región `status` ocupada.      |
| Error         | `error`    | El avatar y el título, y una alerta de error con el botón "Try again". |
| Deshabilitado | `disabled` | Todo legible; la acción queda deshabilitada.                           |

### Tamaño

| Paso del contenedor      | Qué cambia                                                          |
| ------------------------ | ------------------------------------------------------------------- |
| bajo `@sm`               | El avatar va sobre el texto.                                        |
| `@sm` (`--container-sm`) | El avatar pasa junto al texto, del lado que indica `mediaPosition`. |
| `@md` (`--container-md`) | El título y el texto suben un tamaño.                               |
| `@lg` (`--container-lg`) | La meta pasa al extremo de la línea del título.                     |
