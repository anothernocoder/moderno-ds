## Referencia de API

### Props

| Prop                | Tipo                              | Por defecto         | Descripción                                                                            |
| ------------------- | --------------------------------- | ------------------- | -------------------------------------------------------------------------------------- |
| `icon`              | `"folder" \| "search" \| "inbox"` | `"folder"`          | El glifo del recuadro sobre el título.                                                 |
| `title`             | `string`                          | `"No projects yet"` | Lo que falta, en pocas palabras.                                                       |
| `description`       | `string`                          | una frase           | Una línea sobre por qué importa o qué hacer; `""` la oculta.                           |
| `primaryAction`     | `string`                          | `"New project"`     | El texto del botón principal; `""` lo oculta.                                          |
| `secondaryAction`   | `string`                          | `"Import"`          | El texto del botón con contorno; `""` lo oculta.                                       |
| `error`             | `string`                          | —                   | El contenido no cargó; tu mensaje sustituye el título y un reintento las acciones.     |
| `loading`           | `boolean`                         | `false`             | Marcadores esqueleto en una región ocupada sustituyen el mensaje.                      |
| `disabled`          | `boolean`                         | `false`             | El mensaje se queda y todos los botones quedan deshabilitados.                         |
| `onPrimaryAction`   | `() => void`                      | —                   | Se pulsó el botón principal. Svelte: `onprimaryaction`. Vue: `@primary-action`.        |
| `onSecondaryAction` | `() => void`                      | —                   | Se pulsó el botón con contorno. Svelte: `onsecondaryaction`. Vue: `@secondary-action`. |
| `onRetry`           | `() => void`                      | —                   | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                            |

### Estados

| Estado        | Prop       | Qué se muestra                                                                                         |
| ------------- | ---------- | ------------------------------------------------------------------------------------------------------ |
| Vacío         | —          | El de por defecto: icono, título, descripción y las dos acciones. Muéstralo donde irían los elementos. |
| Cargando      | `loading`  | Marcadores para el icono, el texto y un botón, en una región `status` ocupada.                         |
| Error         | `error`    | Un glifo de alerta, tu mensaje, una pista fija y un botón "Try again", como `alert`.                   |
| Deshabilitado | `disabled` | El mismo mensaje con los dos botones deshabilitados.                                                   |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                      |
| ------------------------ | ------------------------------------------------------------------------------- |
| bajo `@sm`               | Las acciones se apilan, cada una tan ancha como el bloque, la principal arriba. |
| `@sm` (`--container-sm`) | Las acciones van una junto a otra, centradas, con su propio ancho.              |
| `@md` (`--container-md`) | El recuadro del icono y el título suben un tamaño.                              |
| `@lg` (`--container-lg`) | El bloque toma el doble de espacio arriba y abajo.                              |

## Notas

- Muestra el estado vacío en lugar de la lista, no encima de ella.
- Di qué falta y qué hacer después. A menudo basta con una acción.
