## Referencia de la API

### Props

| Prop           | Tipo              | Por defecto                    | Descripción                                                      |
| -------------- | ----------------- | ------------------------------ | ---------------------------------------------------------------- |
| `name`         | `string`          | `"Lena Ortiz"`                 | Tu nombre, el `h1` de la página. Va con serifa.                  |
| `role`         | `string`          | `"Product designer in Lisbon"` | A qué te dedicas, bajo el nombre; `""` lo oculta.                |
| `bio`          | `string`          | dos frases                     | Una breve biografía bajo el rol; `""` la oculta.                 |
| `initials`     | `string`          | `"LO"`                         | Una o dos letras. El avatar las muestra hasta que carga la foto. |
| `avatarUrl`    | `string`          | —                              | Tu foto.                                                         |
| `availability` | `string`          | `"Available for new projects"` | Un estado junto a un punto verde; `""` lo oculta.                |
| `links`        | `PortfolioLink[]` | cuatro enlaces de ejemplo      | Dónde encontrarte. `[]` oculta la fila.                          |
| `error`        | `string`          | —                              | Falló la carga del perfil; se muestra un Alert con reintento.    |
| `loading`      | `boolean`         | `false`                        | Marcadores en una región ocupada reemplazan el encabezado.       |
| `disabled`     | `boolean`         | `false`                        | El encabezado se queda; los enlaces y el reintento, no.          |
| `onRetry`      | `() => void`      | —                              | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.      |

### PortfolioLink

| Campo   | Tipo     | Descripción                                   |
| ------- | -------- | --------------------------------------------- |
| `id`    | `string` | Una clave única para el enlace.               |
| `label` | `string` | El texto que lee la gente, como `"LinkedIn"`. |
| `href`  | `string` | A dónde lleva, como un perfil o un `mailto:`. |

### Estados

| Estado        | Prop                                                      | Qué se muestra                                                |
| ------------- | --------------------------------------------------------- | ------------------------------------------------------------- |
| Por defecto   | —                                                         | Avatar, disponibilidad, nombre, rol, biografía y enlaces.     |
| Vacío         | todo texto `""` salvo `name`, `initials=""`, `links={[]}` | Solo el nombre.                                               |
| Cargando      | `loading`                                                 | Marcadores para el avatar, el estado, el texto y los enlaces. |
| Error         | `error`                                                   | Un Alert de error con "Try again".                            |
| Deshabilitado | `disabled`                                                | El mismo encabezado con todos los enlaces inertes.            |

### Tamaño

| Paso del contenedor      | Qué cambia                                           |
| ------------------------ | ---------------------------------------------------- |
| bajo `@sm`               | El avatar va sobre el texto.                         |
| `@sm` (`--container-sm`) | El rol y la biografía suben un tamaño.               |
| `@md` (`--container-md`) | El nombre sube un tamaño y el avatar pasa a su lado. |
| `@lg` (`--container-lg`) | Más espacio arriba, abajo y entre las partes.        |
