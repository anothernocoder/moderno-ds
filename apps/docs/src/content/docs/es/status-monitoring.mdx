Cada servicio es `{ id, name, status, uptime, history }`. `history` lleva un día por entrada, del más antiguo al más reciente.

## Referencia de API

### Props

| Prop          | Tipo                        | Por defecto              | Descripción                                                          |
| ------------- | --------------------------- | ------------------------ | -------------------------------------------------------------------- |
| `services`    | `StatusMonitoringService[]` | un conjunto de muestra   | Los servicios, en orden de lectura. `[]` muestra el estado vacío.    |
| `heading`     | `string`                    | `"System status"`        | El título sobre los servicios.                                       |
| `description` | `string`                    | una frase                | La línea bajo el título; `""` la oculta.                             |
| `actionLabel` | `string`                    | `"Subscribe to updates"` | La etiqueta del botón de la cabecera; `""` oculta el botón.          |
| `error`       | `string`                    | —                        | El estado no cargó; una alerta con reintento lo sustituye.           |
| `loading`     | `boolean`                   | `false`                  | Tarjetas de marcador en una región ocupada sustituyen los servicios. |
| `disabled`    | `boolean`                   | `false`                  | Los servicios siguen legibles y todos los botones se deshabilitan.   |
| `onAction`    | `() => void`                | —                        | El botón de la cabecera. Svelte: `onaction`. Vue: `@action`.         |
| `onRetry`     | `() => void`                | —                        | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.          |

### StatusMonitoringService

| Campo     | Tipo                                                       | Descripción                                         |
| --------- | ---------------------------------------------------------- | --------------------------------------------------- |
| `id`      | `string`                                                   | Identidad estable.                                  |
| `name`    | `string`                                                   | El nombre del servicio.                             |
| `status`  | `"operational" \| "degraded" \| "outage" \| "maintenance"` | Cómo está el servicio ahora.                        |
| `uptime`  | `string`                                                   | La disponibilidad en `history`, ya formateada.      |
| `history` | `UptimeDay[]`                                              | Una entrada por día, de la más antigua a la última. |

`UptimeDay` es un valor de `status` o `"no-data"`.

### Estados

| Estado        | Prop            | Qué se muestra                                                          |
| ------------- | --------------- | ----------------------------------------------------------------------- |
| Por defecto   | —               | La insignia del estado general y una tarjeta por servicio.              |
| Vacío         | `services={[]}` | Una tarjeta "No services yet".                                          |
| Cargando      | `loading`       | Cuatro tarjetas de marcador en una región `status` ocupada.             |
| Error         | `error`         | Una alerta de error con el botón "Try again" en lugar de los servicios. |
| Deshabilitado | `disabled`      | Los servicios, con todos los botones deshabilitados.                    |

### Tamaño

| Paso del contenedor      | Qué cambia                                                            |
| ------------------------ | --------------------------------------------------------------------- |
| bajo `@sm`               | Todo se apila: el botón bajo el título, el estado bajo el nombre.     |
| `@sm` (`--container-sm`) | El título y el botón comparten fila; también cada nombre y su estado. |
| `@md` (`--container-md`) | Barras más altas y un título más grande.                              |
| `@lg` (`--container-lg`) | Dos servicios por fila.                                               |
