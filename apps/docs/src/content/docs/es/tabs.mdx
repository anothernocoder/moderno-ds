## Uso

Las pestañas muestran un panel a la vez. Úsalas para vistas hermanas de un mismo tema, como las secciones de una página de ajustes. Cada trigger selecciona el panel con el mismo `value`.

<ForFramework fw="react">

```tsx
import { Tabs } from "@moderno-ui/react";
```

```tsx
<Tabs.Root defaultValue="account">
  <Tabs.List aria-label="Settings">
    <Tabs.Trigger value="account">Account</Tabs.Trigger>
    <Tabs.Trigger value="password">Password</Tabs.Trigger>
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Content value="account">Change your name and email.</Tabs.Content>
  <Tabs.Content value="password">Change your password.</Tabs.Content>
</Tabs.Root>
```

</ForFramework>

## Referencia de la API

### Tabs.Root

`variant` y `size` son los añadidos de Moderno; la lista, sus triggers y el indicador los siguen. El resto de props vienen del Tabs de Ark.

<PropsTable component="Tabs" />

| Prop             | Tipo                                   | Por defecto    | Descripción                                                                               |
| ---------------- | -------------------------------------- | -------------- | ----------------------------------------------------------------------------------------- |
| `value`          | `string`                               | —              | Pestaña seleccionada, controlado. Úsalo con `onValueChange`.                              |
| `defaultValue`   | `string`                               | —              | Pestaña seleccionada al inicio cuando no está controlado.                                 |
| `onValueChange`  | `(details: { value: string }) => void` | —              | Se llama cuando se selecciona una pestaña.                                                |
| `orientation`    | `"horizontal" \| "vertical"`           | `"horizontal"` | Coloca las pestañas en fila o en columna; define las flechas del teclado.                 |
| `activationMode` | `"automatic" \| "manual"`              | `"automatic"`  | `automatic` selecciona una pestaña al recibir el foco; `manual` espera a Enter o Espacio. |
| `loopFocus`      | `boolean`                              | `true`         | Las flechas pasan de la última pestaña a la primera.                                      |
| `lazyMount`      | `boolean`                              | `false`        | Renderiza un panel solo la primera vez que se selecciona su pestaña.                      |
| `unmountOnExit`  | `boolean`                              | `false`        | Quita un panel cuando su pestaña deja de estar seleccionada.                              |

En Vue, escucha con `@value-change` o enlaza el valor con `v-model`.

### Tabs.Trigger

| Prop       | Tipo      | Por defecto | Descripción                                                          |
| ---------- | --------- | ----------- | -------------------------------------------------------------------- |
| `value`    | `string`  | —           | Obligatorio. El valor de la pestaña; coincide con un `Tabs.Content`. |
| `disabled` | `boolean` | `false`     | Deshabilita solo esta pestaña.                                       |

### Tabs.Content

| Prop    | Tipo     | Por defecto | Descripción                                                 |
| ------- | -------- | ----------- | ----------------------------------------------------------- |
| `value` | `string` | —           | Obligatorio. El valor de la pestaña que muestra este panel. |

### Partes

| Parte            | Elemento   | Descripción                                                        |
| ---------------- | ---------- | ------------------------------------------------------------------ |
| `Tabs.Root`      | `<div>`    | Lleva `data-variant`, `data-size` y `data-orientation`.            |
| `Tabs.List`      | `<div>`    | `role="tablist"`. Contiene los triggers y el indicador.            |
| `Tabs.Trigger`   | `<button>` | `role="tab"` con `aria-selected`. Selecciona su panel.             |
| `Tabs.Indicator` | `<div>`    | Opcional. La barra o la píldora que marca la pestaña seleccionada. |
| `Tabs.Content`   | `<div>`    | `role="tabpanel"`. Oculto salvo que su pestaña esté seleccionada.  |

### Atributos data

| Atributo           | Valores                                            |
| ------------------ | -------------------------------------------------- |
| `data-selected`    | Presente en el trigger seleccionado y en su panel  |
| `data-disabled`    | Presente en un trigger deshabilitado               |
| `data-orientation` | `"horizontal"` o `"vertical"`, en todas las partes |
| `data-variant`     | En la raíz: `"line"` o `"enclosed"`                |
| `data-size`        | En la raíz: `"sm"`, `"md"` o `"lg"`                |

## Notas

- `Tabs.Root` está envuelto para añadir `variant` y `size`; el resto de partes son las de Ark sin cambios.
- Estiliza el estado desde `data-selected` y los atributos `data-*` de cada parte; `variant` y `size` son las únicas props visuales.
- Para una elección que el usuario envía, o un modo de vista como lista o cuadrícula, usa Toggle Group.
