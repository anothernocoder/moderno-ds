Cada fila es `{ id, title, subtitle, meta, initials, avatarUrl, status, statusVariant }`. Solo `id`, `title` e `initials` son obligatorios.

## Referencia de API

### Propiedades

| Propiedad     | Tipo                  | Por defecto        | Descripción                                                          |
| ------------- | --------------------- | ------------------ | -------------------------------------------------------------------- |
| `items`       | `ListContainerItem[]` | un ejemplo         | Las filas, en orden de lectura. `[]` muestra el estado vacío.        |
| `heading`     | `string`              | `"Sprint tasks"`   | El título de la cabecera. También nombra la zona con desplazamiento. |
| `description` | `string`              | una frase          | La línea bajo el título; `""` la oculta.                             |
| `actionLabel` | `string`              | `"View all tasks"` | El texto del botón del pie; `""` oculta el botón.                    |
| `error`       | `string`              | —                  | Las filas no cargaron; una alerta con reintento ocupa el cuerpo.     |
| `loading`     | `boolean`             | `false`            | Filas de marcador en una región ocupada llenan el cuerpo.            |
| `disabled`    | `boolean`             | `false`            | Las filas siguen legibles y todos los botones quedan desactivados.   |
| `onAction`    | `() => void`          | —                  | El botón del pie. Svelte: `onaction`. Vue: `@action`.                |
| `onRetry`     | `() => void`          | —                  | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.          |

### ListContainerItem

| Campo           | Tipo           | Descripción                                          |
| --------------- | -------------- | ---------------------------------------------------- |
| `id`            | `string`       | Identidad estable.                                   |
| `title`         | `string`       | La línea principal. Se corta con puntos suspensivos. |
| `subtitle`      | `string`       | Segunda línea opcional.                              |
| `meta`          | `string`       | Dato corto opcional, como una fecha de entrega.      |
| `initials`      | `string`       | Se ven en el avatar cuando no hay imagen.            |
| `avatarUrl`     | `string`       | Imagen opcional para el avatar.                      |
| `status`        | `string`       | Texto de estado opcional, en una insignia.           |
| `statusVariant` | `BadgeVariant` | El color de la insignia. Por defecto `"neutral"`.    |

### Estados

| Estado        | Propiedad    | Qué se muestra                                                   |
| ------------- | ------------ | ---------------------------------------------------------------- |
| Por defecto   | —            | Las filas en una zona con desplazamiento y el total en el pie.   |
| Vacío         | `items={[]}` | "No tasks yet" en el cuerpo; el botón del pie queda desactivado. |
| Cargando      | `loading`    | Cuatro filas de marcador en una región `status` ocupada.         |
| Error         | `error`      | Una alerta de error con el botón "Try again" en el cuerpo.       |
| Deshabilitado | `disabled`   | Las filas con todos los botones desactivados.                    |

### Dimensionado

| Paso del contenedor      | Qué cambia                                                |
| ------------------------ | --------------------------------------------------------- |
| bajo `@sm`               | Estado y fecha quedan bajo el título de cada fila.        |
| `@sm` (`--container-sm`) | Estado y fecha pasan a una columna final, uno sobre otro. |
| `@md` (`--container-md`) | Estado y fecha van lado a lado; el título crece.          |
| `@lg` (`--container-lg`) | Las fechas se alinean en una sola columna.                |
