Alert es una primitiva solo-CSS: Ark no tiene una máquina para alert porque una
alerta no tiene comportamiento que gobernar — es una región estática. Así que,
como Button, es el contrato en su forma más pura: elementos que llevan
`data-scope`/`data-part` más el `data-variant`/`data-size` de la receta, con cada
píxel proveniente de `components.css`.

La anatomía es `root > icon + content(> title + description + action)`. `Icon` es
una ranura, nunca un set de iconos: las primitivas siguen siendo agnósticas del
icono, así que pasas tu propio glifo y la parte le entrega el tono del estado a
través de `currentColor`.

## Estados

`info`, `success`, `warning` y `error` tiñen una superficie desde el slot del
contrato correspondiente — `--info`, `--success`, `--warning`, y `--destructive`
para `error`, de modo que una acción destructiva y un mensaje de error hablen con
una sola voz. La urgencia sigue al estado: `warning` y `error` renderizan
`role="alert"` (asertivo), `info` y `success` `role="status"` (cortés).
