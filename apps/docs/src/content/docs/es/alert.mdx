## Referencia de API

### Alert.Root

`variant` vale `info` por defecto y `size`, `md`.

<PropsTable component="Alert" />

| Prop   | Tipo     | Por defecto     | Descripción                                      |
| ------ | -------- | --------------- | ------------------------------------------------ |
| `role` | `string` | Según `variant` | Sobrescribe el rol de región viva (ver Estados). |

### Alert.Icon

Un slot para tu propio glifo; la parte lo colorea con el tono del estado vía `currentColor`.

| Prop          | Tipo      | Por defecto | Descripción                                                 |
| ------------- | --------- | ----------- | ----------------------------------------------------------- |
| `aria-hidden` | `boolean` | `true`      | Oculta el glifo decorativo a las tecnologías de asistencia. |

### Partes

Cada parte renderiza un `<div>` y acepta cualquier atributo de div.

| Parte               | `data-part`   | Descripción                                                     |
| ------------------- | ------------- | --------------------------------------------------------------- |
| `Alert.Root`        | `root`        | La región. Lleva `data-variant` y `data-size`.                  |
| `Alert.Icon`        | `icon`        | Glifo opcional antes del contenido.                             |
| `Alert.Content`     | `content`     | Columna con el título, la descripción y la acción.              |
| `Alert.Title`       | `title`       | El titular.                                                     |
| `Alert.Description` | `description` | Texto de apoyo.                                                 |
| `Alert.Action`      | `action`      | Acción opcional, dentro de `Alert.Content` bajo la descripción. |

### Estados

| `variant` | Slot de color   | `role`             |
| --------- | --------------- | ------------------ |
| `info`    | `--info`        | `status` (cortés)  |
| `success` | `--success`     | `status` (cortés)  |
| `warning` | `--warning`     | `alert` (asertivo) |
| `error`   | `--destructive` | `alert` (asertivo) |

## Notas

- Alert es solo CSS: sin máquina de Ark, solo partes con `data-scope="alert"` y su `data-part`.
- La primitiva no trae set de iconos; pasa tu propio glifo a `Alert.Icon`.
- Una alerta que ya está en la página al cargar no se anuncia; renderízala en respuesta al evento que reporta.
