## Referencia de API

### Button

Renderiza un `<button>` nativo. `variant` vale `primary` por defecto y `size`, `md`.

<PropsTable component="Button" />

### Atributos data

| Atributo       | Valores               |
| -------------- | --------------------- |
| `data-scope`   | `"button"`            |
| `data-part`    | `"root"`              |
| `data-variant` | El `variant` resuelto |
| `data-size`    | El `size` resuelto    |

## Notas

- Button no tiene color ni radio propios; cambiar de tema lo repinta sin tocar el marcado.
- `destructive` pinta desde `--destructive`, el mismo slot que usan una Alert de error y un Field inválido.
- `type` vale `"button"` por defecto, así que un Button dentro de un formulario no lo envía salvo que pases `type="submit"`.
- `disabled` es el atributo nativo: el botón sale del orden de tabulación e ignora los clics.
- Elige un `variant` en lugar de sobrescribir el color con una clase, y pasa `disabled` en lugar de estilizarlo.
