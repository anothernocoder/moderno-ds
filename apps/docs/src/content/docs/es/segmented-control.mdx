## Uso

Un segmented control muestra unas pocas opciones en una fila, y el usuario elige exactamente una. Úsalo para un ajuste que cambia un valor en el sitio, como la forma en que una imagen llena su marco.

**¿Segmented control o Tabs?** Un segmented control cambia un valor. Las Tabs cambian la vista: cada pestaña muestra su propio panel de contenido. Si elegir una opción cambia el contenido de abajo, usa Tabs.

<ForFramework fw="react">

```tsx
import { SegmentedControl } from "@moderno-ui/react";
```

```tsx
<SegmentedControl.Root defaultValue="fit" aria-label="Image scale">
  <SegmentedControl.Indicator />
  <SegmentedControl.Item value="fit">
    <SegmentedControl.ItemText>Fit</SegmentedControl.ItemText>
    <SegmentedControl.ItemHiddenInput />
  </SegmentedControl.Item>
  <SegmentedControl.Item value="fill">
    <SegmentedControl.ItemText>Fill</SegmentedControl.ItemText>
    <SegmentedControl.ItemHiddenInput />
  </SegmentedControl.Item>
</SegmentedControl.Root>
```

## Referencia de API

### SegmentedControl.Root

`size` y `fullWidth` son lo que añade Moderno; `size` vale `md` por defecto y coincide con los tamaños de Field. Las demás props vienen del SegmentGroup de Ark.

<PropsTable component="SegmentedControl" />

| Prop            | Tipo                                   | Por defecto | Descripción                                                               |
| --------------- | -------------------------------------- | ----------- | ------------------------------------------------------------------------- |
| `value`         | `string \| null`                       | —           | Valor controlado. Úsalo con `onValueChange`.                              |
| `defaultValue`  | `string \| null`                       | —           | Valor inicial cuando no está controlado.                                  |
| `onValueChange` | `(details: { value: string }) => void` | —           | Se llama cuando el usuario elige una opción.                              |
| `disabled`      | `boolean`                              | `false`     | Deshabilita todos los segmentos y atenúa el control.                      |
| `invalid`       | `boolean`                              | `false`     | Pone `aria-invalid` en cada radio y bordea la pista con `--destructive`.  |
| `readOnly`      | `boolean`                              | `false`     | Muestra la elección pero ignora los clics.                                |
| `name`          | `string`                               | —           | Nombre del campo en el formulario, compartido por todos los radios.       |
| `aria-label`    | `string`                               | —           | Da nombre al grupo. No hace falta dentro de un `Field` con `Field.Label`. |

En Vue, enlaza el valor con `v-model`. En Svelte, usa `bind:value`.

### SegmentedControl.Item

| Prop       | Tipo      | Por defecto | Descripción                                         |
| ---------- | --------- | ----------- | --------------------------------------------------- |
| `value`    | `string`  | —           | El valor que representa este segmento. Obligatorio. |
| `disabled` | `boolean` | `false`     | Deshabilita solo este segmento.                     |

### Partes

| Parte                              | Elemento               | Descripción                                                                                   |
| ---------------------------------- | ---------------------- | --------------------------------------------------------------------------------------------- |
| `SegmentedControl.Root`            | `<div>`                | La pista. `role="radiogroup"`; lleva `data-size` y `data-full-width`.                         |
| `SegmentedControl.Indicator`       | `<div>`                | La píldora que se desliza detrás del segmento elegido. Renderízala primero en la raíz.        |
| `SegmentedControl.Item`            | `<label>`              | Un segmento; un clic en cualquier punto elige la opción. Un icono va dentro.                  |
| `SegmentedControl.ItemText`        | `<span>`               | La etiqueta del segmento; da nombre al radio. Una etiqueta larga acaba en puntos suspensivos. |
| `SegmentedControl.ItemHiddenInput` | `<input type="radio">` | Radio nativo oculto; lleva el foco, las flechas, `name` y `value`.                            |

### Atributos data

| Atributo             | Valores                                                         |
| -------------------- | --------------------------------------------------------------- |
| `data-state`         | `"checked"` o `"unchecked"`, en todas las partes de un segmento |
| `data-disabled`      | Presente en un control o segmento deshabilitados                |
| `data-invalid`       | Presente con `invalid`                                          |
| `data-focus-visible` | En el segmento cuyo radio tiene el foco del teclado             |
| `data-size`          | En la raíz: `"sm"`, `"md"` o `"lg"`                             |
| `data-full-width`    | Presente en la raíz con `fullWidth`                             |

## Notas

- Cada segmento es un radio nativo: Tab entra en el grupo, y las flechas mueven y eligen.
- La píldora se desliza hasta el segmento elegido. Con el movimiento reducido activado, salta hasta él.
- El segmento elegido es una píldora elevada con borde y sombra, así que la elección no depende solo del color.
- `SegmentedControl.Root` y `SegmentedControl.ItemText` están envueltos; las demás partes son el SegmentGroup de Ark sin cambios. El `Label` de Ark queda fuera, porque la raíz es la pista.
