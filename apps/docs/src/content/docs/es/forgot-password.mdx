## Referencia de API

### Props

Los callbacks son props `on…` en React y Solid, en minúsculas (`onsubmit`) en Svelte y eventos (`submit`, `navigate`) en Vue.

| Prop          | Tipo                     | Por defecto | Descripción                                                                |
| ------------- | ------------------------ | ----------- | -------------------------------------------------------------------------- |
| `sent`        | `boolean`                | `false`     | El enlace ya salió: la tarjeta confirma en vez de preguntar.               |
| `sentTo`      | `string`                 | `""`        | La dirección que nombra la confirmación y que reenvía «Send it again».     |
| `error`       | `string`                 | —           | No se pudo enviar el enlace: muestra la alerta del formulario.             |
| `errors`      | `Record<string, string>` | —           | Mensajes por campo; aquí solo `email`.                                     |
| `loading`     | `boolean`                | `false`     | Envío en curso: todos los controles inertes, el botón ocupado.             |
| `disabled`    | `boolean`                | `false`     | No se puede recuperar (espacio solo SSO, cuenta bloqueada).                |
| `onSubmit`    | `(event) => void`        | —           | Envío nativo del formulario, tanto la petición como el reenvío.            |
| `onNavigate`  | `(to, event) => void`    | —           | Se pulsó un enlace de la pantalla: `home`, `support`, `privacy` o `terms`. |
| `signInHref`  | `string`                 | `"#"`       | Destino de «Sign in» en el pie de la tarjeta.                              |
| `homeHref`    | `string`                 | `"#"`       | Destino del logotipo.                                                      |
| `supportHref` | `string`                 | `"#"`       | Destino de «Contact support».                                              |
| `privacyHref` | `string`                 | `"#"`       | Destino del enlace de privacidad.                                          |
| `termsHref`   | `string`                 | `"#"`       | Destino del enlace de términos.                                            |

### Estados

| Estado         | Props                | Qué se renderiza                                                    |
| -------------- | -------------------- | ------------------------------------------------------------------- |
| Por defecto    | —                    | La tarjeta pidiendo una dirección, centrada entre cabecera y pie.   |
| Enviado        | `sent`, `sentTo`     | La misma tarjeta, confirmando en su sitio; nada alrededor se mueve. |
| Error          | `error`              | Una alerta de formulario.                                           |
| Error de campo | `errors={{ email }}` | El campo de correo inválido, con su propio mensaje.                 |
| Cargando       | `loading`            | Controles inertes, envío con `aria-busy`.                           |
| Deshabilitado  | `disabled`           | El formulario se ve pero no se puede usar.                          |

### Campos del formulario

| Nombre  | Control      | Se envía                                   |
| ------- | ------------ | ------------------------------------------ |
| `email` | Correo       | Antes de `sent`.                           |
| `email` | Campo oculto | Tras `sent`, con `sentTo` para el reenvío. |

### Tamaño

| Paso del contenedor      | Cambio                            |
| ------------------------ | --------------------------------- |
| `@sm` (`--container-sm`) | La cabecera pasa a una sola fila. |
| `@md` (`--container-md`) | El pie pasa a una sola fila.      |

## Notas

- La confirmación dice «If … has an account, a link … is on its way» exista o no la cuenta.
- Tu `onSubmit` debe responder igual, y en el mismo tiempo, para cualquier dirección; limita su frecuencia.
- `errors.email` es solo para una dirección mal formada, nunca para una desconocida.
- La cabecera de la tarjeta es una región viva `status`, así que el paso a `sent` se anuncia.
- La tarjeta enviada lleva la dirección en un campo oculto, así que «Send it again» funciona antes de hidratar.
- Presentacional: `sent` vive en tu página, y un solo `onSubmit` atiende la petición y el reenvío.
