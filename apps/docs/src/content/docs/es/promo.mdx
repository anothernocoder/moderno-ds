## Referencia de API

### Props

| Prop          | Tipo                     | Por defecto      | Descripción                                                        |
| ------------- | ------------------------ | ---------------- | ------------------------------------------------------------------ |
| `offer`       | `string`                 | texto de muestra | La oferta, en negrita.                                             |
| `detail`      | `string`                 | `"Ends Sunday"`  | Una línea corta tras la oferta, como la fecha de fin.              |
| `code`        | `string`                 | `"MONTHEND20"`   | El código de promoción. Al pulsarlo se copia. `""` quita el botón. |
| `actionLabel` | `string`                 | `"Claim offer"`  | El texto del botón de acción. `""` quita el botón.                 |
| `dismissible` | `boolean`                | `true`           | Muestra el botón para descartar.                                   |
| `error`       | `string`                 | —                | La oferta no cargó; una alerta con reintento la sustituye.         |
| `loading`     | `boolean`                | `false`          | Una barra esqueleto en una región ocupada la sustituye.            |
| `disabled`    | `boolean`                | `false`          | La barra sigue legible y todos sus botones quedan deshabilitados.  |
| `onAction`    | `() => void`             | —                | Se pulsó la acción. Svelte: `onaction`. Vue: `@action`.            |
| `onCopy`      | `(code: string) => void` | —                | Se copió el código. Svelte: `oncopy`. Vue: `@copy`.                |
| `onDismiss`   | `() => void`             | —                | Se descartó la barra. Svelte: `ondismiss`. Vue: `@dismiss`.        |
| `onRetry`     | `() => void`             | —                | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.        |

### Estados

| Estado        | Prop                   | Qué se muestra                                                     |
| ------------- | ---------------------- | ------------------------------------------------------------------ |
| Por defecto   | —                      | La barra con su oferta, detalle, código, acción y descarte.        |
| Copiado       | pulsar el código       | Una marca en lugar del icono de copiar, y se lee "Code copied".    |
| Descartado    | pulsar descartar       | Nada: la barra se oculta y llama a `onDismiss`.                    |
| Vacío         | `offer=""` `detail=""` | Nada: el bloque no ocupa espacio.                                  |
| Cargando      | `loading`              | Una barra esqueleto en una región `status` ocupada.                |
| Error         | `error`                | Una alerta de error con el botón "Try again" en lugar de la barra. |
| Deshabilitado | `disabled`             | La barra con todos sus botones deshabilitados.                     |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                    |
| ------------------------ | ----------------------------------------------------------------------------- |
| bajo `@sm`               | La oferta y el detalle se apilan; los botones debajo.                         |
| `@sm` (`--container-sm`) | El detalle pasa a la línea de la oferta.                                      |
| `@md` (`--container-md`) | El código y la acción pasan junto al texto; el detalle vuelve bajo la oferta. |
| `@lg` (`--container-lg`) | Todo comparte una línea, centrado en la barra.                                |

## Notas

- Ponla una sola vez, sobre la cabecera de la página, para que ocupe todo el ancho.
- Mantén la oferta corta: en una página ancha comparte línea con el detalle, el código y la acción.
- Para que siga descartada en la próxima visita, guárdalo en `onDismiss` y deja de mostrar el bloque.
