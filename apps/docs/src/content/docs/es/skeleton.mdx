## Uso

Usa un esqueleto mientras carga un contenido cuya forma ya conoces. Muestra la forma de lo que viene, así la página no salta cuando llega el contenido.

<ForFramework fw="react">

```tsx
import { Skeleton } from "@moderno-ui/react";
```

```tsx
<Skeleton />
```

## Referencia de API

### Skeleton

Renderiza un `<span>` vacío con `aria-hidden="true"`. `shape` vale `text` por defecto. Define el tamaño con `style` o una clase.

<PropsTable component="Skeleton" />

### Partes

| Parte  | Elemento | Descripción                                                                             |
| ------ | -------- | --------------------------------------------------------------------------------------- |
| `root` | `<span>` | El marcador. Lleva `data-shape`. Un bloque que ocupa todo el ancho, salvo con `circle`. |

## Notas

- Skeleton es solo CSS: un `<span>` con `data-scope="skeleton"`, sin máquina de Ark.
- Un esqueleto no le dice nada a un lector de pantalla. `aria-busy` en la región que carga le pide a la tecnología de asistencia que espere.
- El esqueleto pulsa despacio. Se queda quieto cuando el usuario pide menos movimiento.
