## Uso

<ForFramework fw="react">

```tsx

  {
    name: "Sessions",
    points: [

  },
```

## Referencia de API

### LineChart

<PropsTable component="LineChart" />

### Series

Cada entrada de `series` es una línea.

| Campo    | Tipo                         | Descripción                                        |
| -------- | ---------------------------- | -------------------------------------------------- |
| `name`   | `string`                     | Etiqueta opcional de la serie.                     |
| `points` | `{ x: number; y: number }[]` | Los puntos de datos, unidos en el orden del array. |

### Valores por defecto

| Prop               | Por defecto                                                               |
| ------------------ | ------------------------------------------------------------------------- |
| `xDomain`          | El rango de todos los valores x de todas las series.                      |
| `yDomain`          | Todos los valores y más el 0, redondeados hacia afuera a números limpios. |
| `xTicks`, `yTicks` | `5`                                                                       |
| `margin`           | `{ top: 16, right: 16, bottom: 28, left: 36 }`                            |
| `curve`            | Segmentos rectos                                                          |
| `format`           | El número, redondeado a 4 decimales                                       |

### Atributos de datos

| Atributo      | En              | Valores                                                                  |
| ------------- | --------------- | ------------------------------------------------------------------------ |
| `data-chart`  | `svg` raíz      | `line`                                                                   |
| `data-part`   | Cada elemento   | `root`, `grid`, `grid-line`, `axis-line`, `tick-label`, `series`, `line` |
| `data-series` | `g` de la serie | Índice desde 0, asignado de `--chart-1` a `--chart-5`                    |

## Notas

- No hay prop de color: las series se pintan de `--chart-1` a `--chart-5` por índice.
- La sexta serie y las siguientes vuelven a `--chart-1`.
- La cuadrícula, los ejes y las etiquetas usan `--border` y `--muted-foreground`.
- La geometría viene de `@moderno-ui/charts-core`, matemática pura sin DOM, así se renderiza en el servidor.
