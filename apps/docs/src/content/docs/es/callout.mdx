<Install pkg="@moderno-ui/react" />

## Uso

Usa un callout para una nota que forma parte del contenido: un consejo, una advertencia o un aviso. Es más discreto que un [Alert](/es/alert/), que informa de algo que acaba de pasar.

<ForFramework fw="react">

```tsx
import { Callout } from "@moderno-ui/react";
```

```tsx
<Callout.Root variant="warning">
  <Callout.Content>
    <Callout.Title>Renombrar rompe los enlaces antiguos</Callout.Title>
    <Callout.Description>Comparte la nueva dirección con tu equipo.</Callout.Description>
  </Callout.Content>
</Callout.Root>
```

</ForFramework>

## Referencia de API

### Callout.Root

`variant` vale `info` por defecto.

<PropsTable component="Callout" />

| Prop   | Tipo     | Por defecto | Descripción                                           |
| ------ | -------- | ----------- | ----------------------------------------------------- |
| `role` | `string` | `note`      | Sobrescribe el rol de nota, por ejemplo con `region`. |

### Callout.Icon

Un slot para tu propio glifo; la parte lo colorea con el tono de la variante vía `currentColor`.

| Prop          | Tipo      | Por defecto | Descripción                                                 |
| ------------- | --------- | ----------- | ----------------------------------------------------------- |
| `aria-hidden` | `boolean` | `true`      | Oculta el glifo decorativo a las tecnologías de asistencia. |

### Partes

Cada parte renderiza un `<div>` y acepta cualquier atributo de div.

| Parte                 | `data-part`   | Descripción                             |
| --------------------- | ------------- | --------------------------------------- |
| `Callout.Root`        | `root`        | La nota. Lleva `data-variant`.          |
| `Callout.Icon`        | `icon`        | Glifo opcional antes del contenido.     |
| `Callout.Content`     | `content`     | Columna con el título y la descripción. |
| `Callout.Title`       | `title`       | Titular opcional.                       |
| `Callout.Description` | `description` | El texto de la nota.                    |

### Variantes

| `variant` | Slot de color   |
| --------- | --------------- |
| `info`    | `--info`        |
| `success` | `--success`     |
| `warning` | `--warning`     |
| `error`   | `--destructive` |

## Notas

- Callout es solo CSS: sin máquina de Ark, solo partes con `data-scope="callout"` y su `data-part`.
- Un callout no se anuncia al aparecer. Si el mensaje informa de un evento, usa un Alert.
