## Referencia de API

### Props

| Prop          | Tipo                                   | Por defecto          | Descripción                                                              |
| ------------- | -------------------------------------- | -------------------- | ------------------------------------------------------------------------ |
| `actions`     | `ModalAction[]`                        | una lista de muestra | Las filas, en el orden en que se muestran. `[]` muestra el estado vacío. |
| `heading`     | `string`                               | `"Workspace"`        | El título junto a la lista o sobre ella.                                 |
| `description` | `string`                               | una frase            | La línea bajo el título; `""` la oculta.                                 |
| `error`       | `string`                               | —                    | Las acciones no cargaron; una alerta con reintento sustituye las filas.  |
| `loading`     | `boolean`                              | `false`              | Filas esqueleto en una región ocupada sustituyen las filas.              |
| `disabled`    | `boolean`                              | `false`              | Las filas siguen legibles y todos sus botones quedan deshabilitados.     |
| `onConfirm`   | `(id: string, value?: string) => void` | —                    | Se confirmó una acción. Svelte: `onconfirm`. Vue: `@confirm`.            |
| `onRetry`     | `() => void`                           | —                    | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.              |

### ModalAction

| Campo               | Tipo                         | Descripción                                                             |
| ------------------- | ---------------------------- | ----------------------------------------------------------------------- |
| `id`                | `string`                     | Identidad estable, la que devuelve `onConfirm`.                         |
| `title`             | `string`                     | El nombre de la acción en la fila, como "Export data".                  |
| `description`       | `string`                     | Una línea sobre lo que hace la acción. Describe el botón de la fila.    |
| `trigger`           | `string`                     | El texto del botón de la fila, como "Export".                           |
| `dialogTitle`       | `string`                     | El título del diálogo. Da nombre al diálogo.                            |
| `dialogDescription` | `string`                     | La línea bajo el título del diálogo. Describe el diálogo.               |
| `confirm`           | `string`                     | El texto del botón que confirma o envía.                                |
| `tone`              | `"default" \| "destructive"` | Opcional. `destructive` añade la insignia Irreversible y un botón rojo. |
| `field`             | `ModalActionField`           | Opcional. Convierte el diálogo en un formulario con este único campo.   |

### ModalActionField

| Campo          | Tipo     | Descripción                                       |
| -------------- | -------- | ------------------------------------------------- |
| `label`        | `string` | La etiqueta del campo.                            |
| `defaultValue` | `string` | Opcional. El valor con el que empieza el campo.   |
| `placeholder`  | `string` | Opcional. La pista que se ve mientras está vacío. |

### Estados

| Estado        | Prop           | Qué se muestra                                                                       |
| ------------- | -------------- | ------------------------------------------------------------------------------------ |
| Por defecto   | —              | Una fila por acción, cada una con un botón que abre su diálogo.                      |
| Vacío         | `actions={[]}` | Un mensaje "No actions yet" dentro de la lista.                                      |
| Cargando      | `loading`      | Tres filas esqueleto en una región `status` ocupada.                                 |
| Error         | `error`        | Una alerta de error con el botón "Try again" en lugar de las filas.                  |
| Deshabilitado | `disabled`     | Las filas con todos sus botones deshabilitados.                                      |
| Inválido      | un campo vacío | El diálogo del formulario sigue abierto; el campo muestra un error y recibe el foco. |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                 |
| ------------------------ | -------------------------------------------------------------------------- |
| bajo `@sm`               | Cada botón va bajo su título y su descripción.                             |
| `@sm` (`--container-sm`) | Cada botón pasa junto a su texto, y el relleno de la lista crece un paso.  |
| `@md` (`--container-md`) | El título sube un tamaño.                                                  |
| `@lg` (`--container-lg`) | El título va en una columna junto a la lista, de un tercio de ancho.       |
| diálogo bajo `@sm`       | Los botones del diálogo se apilan a todo el ancho, el de confirmar arriba. |
| diálogo desde `@sm`      | Los botones del diálogo van en fila, al final.                             |

## Notas

- Presentacional: no cambia nada por sí mismo. Haz el trabajo en `onConfirm`.
- Para ver el error del formulario, abre "Rename", vacía el campo y pulsa "Save".
