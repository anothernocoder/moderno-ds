## Referencia de API

### Props

| Prop          | Tipo                   | Por defecto          | Descripción                                                              |
| ------------- | ---------------------- | -------------------- | ------------------------------------------------------------------------ |
| `items`       | `StackedListItem[]`    | un equipo de muestra | Las filas, en el orden en que se muestran. `[]` muestra el estado vacío. |
| `heading`     | `string`               | `"Team members"`     | El título sobre la lista.                                                |
| `description` | `string`               | una frase            | La línea bajo el título; `""` la oculta.                                 |
| `error`       | `string`               | —                    | La lista no cargó; una alerta con reintento la sustituye.                |
| `loading`     | `boolean`              | `false`              | Filas esqueleto en una región ocupada sustituyen las filas.              |
| `disabled`    | `boolean`              | `false`              | Las filas siguen legibles y todos los botones quedan deshabilitados.     |
| `onView`      | `(id: string) => void` | —                    | El botón View de una fila. Svelte: `onview`. Vue: `@view`.               |
| `onInvite`    | `() => void`           | —                    | "Invite member". Svelte: `oninvite`. Vue: `@invite`.                     |
| `onRetry`     | `() => void`           | —                    | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.              |

### StackedListItem

| Campo           | Tipo                                                       | Descripción                                       |
| --------------- | ---------------------------------------------------------- | ------------------------------------------------- |
| `id`            | `string`                                                   | Identidad estable, la que devuelve `onView`.      |
| `title`         | `string`                                                   | El nombre de la fila.                             |
| `subtitle`      | `string`                                                   | Línea opcional bajo el nombre, como un correo.    |
| `initials`      | `string`                                                   | El respaldo del avatar cuando no hay imagen.      |
| `image`         | `string`                                                   | URL opcional de la foto del avatar.               |
| `status`        | `string`                                                   | Texto opcional de la insignia.                    |
| `statusVariant` | `"neutral" \| "info" \| "success" \| "warning" \| "error"` | El color de la insignia. Por defecto `"neutral"`. |
| `meta`          | `string`                                                   | Línea tenue opcional, como "Last seen 3 hrs ago". |

### Estados

| Estado        | Prop         | Qué se muestra                                                       |
| ------------- | ------------ | -------------------------------------------------------------------- |
| Por defecto   | —            | Una fila por elemento, separadas por líneas finas.                   |
| Vacío         | `items={[]}` | "No members yet" dentro de la tarjeta.                               |
| Cargando      | `loading`    | Tres filas esqueleto en una región `status` ocupada.                 |
| Error         | `error`      | Una alerta de error con un botón "Try again" en lugar de la tarjeta. |
| Deshabilitado | `disabled`   | Las filas con todos los botones deshabilitados.                      |

### Dimensionado

| Paso del contenedor      | Qué cambia                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------- |
| `@sm` (`--container-sm`) | El título y "Invite member" comparten fila; cada botón View pasa junto a su registro. |
| `@md` (`--container-md`) | Insignia y línea de datos pasan a una columna final; el título sube un tamaño.        |
| `@lg` (`--container-lg`) | Insignia y línea de datos comparten una línea.                                        |
