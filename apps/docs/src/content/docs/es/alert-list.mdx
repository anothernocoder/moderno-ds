## Referencia de API

### Propiedades

| Prop           | Tipo                   | Por defecto        | Descripción                                                                |
| -------------- | ---------------------- | ------------------ | -------------------------------------------------------------------------- |
| `alerts`       | `AlertListItem[]`      | un feed de ejemplo | Las notificaciones, la más reciente primero. `[]` muestra el estado vacío. |
| `heading`      | `string`               | `"Notifications"`  | El título sobre la lista.                                                  |
| `description`  | `string`               | una frase          | La línea bajo el título; `""` la oculta.                                   |
| `error`        | `string`               | —                  | La lista no cargó; una alerta con reintento la sustituye.                  |
| `loading`      | `boolean`              | `false`            | Una región ocupada sustituye a la lista.                                   |
| `disabled`     | `boolean`              | `false`            | Las alertas siguen legibles y todos los controles quedan deshabilitados.   |
| `onDismiss`    | `(id: string) => void` | —                  | El descarte de una fila. Svelte: `ondismiss`. Vue: `@dismiss`.             |
| `onDismissAll` | `() => void`           | —                  | "Dismiss all". Svelte: `ondismissall`. Vue: `@dismiss-all`.                |
| `onAction`     | `(id: string) => void` | —                  | El botón de acción de una fila. Svelte: `onaction`. Vue: `@action`.        |
| `onRetry`      | `() => void`           | —                  | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                |

### AlertListItem

| Campo         | Tipo                                          | Descripción                                            |
| ------------- | --------------------------------------------- | ------------------------------------------------------ |
| `id`          | `string`                                      | Identidad estable, la que devuelven los callbacks.     |
| `variant`     | `"info" \| "success" \| "warning" \| "error"` | La variante de estado del Alert.                       |
| `title`       | `string`                                      | El título de la alerta.                                |
| `description` | `string`                                      | Línea de detalle opcional.                             |
| `meta`        | `string`                                      | Marca de tiempo opcional, ya redactada para el lector. |
| `actionLabel` | `string`                                      | Acción opcional de la fila; dispara `onAction`.        |

### Estados

| Estado        | Prop          | Qué se muestra                                                     |
| ------------- | ------------- | ------------------------------------------------------------------ |
| Por defecto   | —             | Un Alert por elemento, en su propia variante de estado.            |
| Vacío         | `alerts={[]}` | Una tarjeta "You are all caught up".                               |
| Cargando      | `loading`     | Una región `status` ocupada en lugar de la lista.                  |
| Error         | `error`       | Una alerta de error con un botón "Try again" en lugar de la lista. |
| Deshabilitado | `disabled`    | La lista con todos los controles deshabilitados.                   |

### Dimensionado

| Paso del contenedor      | Qué cambia                                                      |
| ------------------------ | --------------------------------------------------------------- |
| `@sm` (`--container-sm`) | El título y "Dismiss all" comparten fila.                       |
| `@md` (`--container-md`) | Cada control de descarte muestra su etiqueta, no solo un glifo. |
| `@lg` (`--container-lg`) | Las marcas de tiempo pasan al borde final de cada fila.         |

## Notas

- Es presentacional: no elimina nada. Los callbacks informan de lo que pidió el lector; el array sigue siendo tuyo.
- Cada fila conserva el rol de región viva de Alert, así que un elemento añadido a una lista montada se anuncia.
- El nombre accesible de cada control de descarte incluye el título de la alerta, a cualquier ancho.
