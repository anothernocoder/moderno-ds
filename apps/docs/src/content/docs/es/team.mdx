## Referencia de la API

### Props

| Prop          | Tipo           | Por defecto       | Descripción                                                                              |
| ------------- | -------------- | ----------------- | ---------------------------------------------------------------------------------------- |
| `heading`     | `string`       | `"Meet the team"` | El encabezado de la sección. Va en la fuente con serifa.                                 |
| `description` | `string`       | una frase         | Una frase bajo el encabezado; `""` la oculta.                                            |
| `members`     | `TeamMember[]` | seis personas     | Las personas, en orden. `[]` muestra el mensaje de vacío.                                |
| `error`       | `string`       | —                 | Falló la carga del equipo; un Alert de error con reintento reemplaza la cuadrícula.      |
| `loading`     | `boolean`      | `false`           | Personas de marcador en una región ocupada reemplazan la cuadrícula.                     |
| `disabled`    | `boolean`      | `false`           | Las personas se quedan; cada enlace de nombre queda inerte y el reintento deshabilitado. |
| `onRetry`     | `() => void`   | —                 | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                              |

### TeamMember

| Campo       | Tipo     | Descripción                                                       |
| ----------- | -------- | ----------------------------------------------------------------- |
| `id`        | `string` | Una clave estable para la persona.                                |
| `name`      | `string` | El nombre de la persona.                                          |
| `role`      | `string` | Su cargo, como `"Head of Design"`.                                |
| `bio`       | `string` | Una o dos frases sobre ella.                                      |
| `initials`  | `string` | Una o dos letras. El avatar las muestra hasta que carga una foto. |
| `avatarUrl` | `string` | Opcional. Su foto.                                                |
| `href`      | `string` | Opcional. Convierte el nombre en un enlace a esta página.         |

### Estados

| Estado        | Prop           | Qué se muestra                                                        |
| ------------- | -------------- | --------------------------------------------------------------------- |
| Por defecto   | —              | Encabezado, introducción y una entrada por persona.                   |
| Vacío         | `members={[]}` | Encabezado, introducción y "No team members to show yet."             |
| Cargando      | `loading`      | Encabezado, introducción y tres personas de marcador.                 |
| Error         | `error`        | Encabezado, introducción y después un Alert de error con "Try again". |
| Deshabilitado | `disabled`     | Las mismas personas con cada enlace de nombre inerte.                 |

### Tamaño

| Paso del contenedor      | Qué cambia                                              |
| ------------------------ | ------------------------------------------------------- |
| bajo `@sm`               | Una columna, con cada avatar encima de su nombre.       |
| `@sm` (`--container-sm`) | El avatar pasa al lado del nombre.                      |
| `@md` (`--container-md`) | Dos columnas, y el encabezado sube un tamaño.           |
| `@lg` (`--container-lg`) | Tres columnas, con más espacio entre ellas y alrededor. |
