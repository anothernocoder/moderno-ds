## Uso

<ForFramework fw="react">

```tsx
import { Select, Portal, createListCollection } from "@moderno-ui/react";

const frameworks = createListCollection({
  items: [
    { label: "React", value: "react" },
    { label: "Vue", value: "vue" },
  ],
});
```

```tsx
<Select.Root collection={frameworks}>
  <Select.Label>Framework</Select.Label>
  <Select.Control>
    <Select.Trigger>
      <Select.ValueText placeholder="Pick one" />
    </Select.Trigger>
  </Select.Control>
  <Portal>
    <Select.Positioner>
      <Select.Content>
        {frameworks.items.map((item) => (
          <Select.Item key={item.value} item={item}>
            <Select.ItemText>{item.label}</Select.ItemText>
          </Select.Item>
        ))}
      </Select.Content>
    </Select.Positioner>
  </Portal>
</Select.Root>
```

</ForFramework>

## Referencia de API

### Select.Root

<PropsTable component="Select" />

Las props de selección vienen de Ark. Las que usan los ejemplos:

| Prop           | Tipo             | Por defecto | Descripción                                                                          |
| -------------- | ---------------- | ----------- | ------------------------------------------------------------------------------------ |
| `collection`   | `ListCollection` | —           | Las opciones, creadas con `createListCollection`. Obligatoria.                       |
| `defaultValue` | `string[]`       | —           | Selección inicial, no controlada. Siempre es un array, incluso para una sola opción. |
| `value`        | `string[]`       | —           | Selección controlada. Actualízala desde `onValueChange`.                             |
| `multiple`     | `boolean`        | `false`     | Permite elegir varias opciones. El menú sigue abierto entre elecciones.              |

### Partes

| Parte                  | Descripción                                                             |
| ---------------------- | ----------------------------------------------------------------------- |
| `Select.Root`          | Guarda el estado. Recibe `collection`, `size` y las props de selección. |
| `Select.Label`         | La etiqueta visible.                                                    |
| `Select.Control`       | Envuelve el trigger.                                                    |
| `Select.Trigger`       | El botón que abre el menú.                                              |
| `Select.ValueText`     | La etiqueta o etiquetas elegidas, o `placeholder` si no hay ninguna.    |
| `Select.Indicator`     | La señal de abrir/cerrar dentro del trigger.                            |
| `Select.Positioner`    | Posiciona el menú. Envuélvelo en `Portal`.                              |
| `Select.Content`       | La superficie del menú.                                                 |
| `Select.Item`          | Una opción. Recibe un `item` de la colección.                           |
| `Select.ItemText`      | La etiqueta de la opción.                                               |
| `Select.ItemIndicator` | Se muestra mientras la opción está marcada.                             |

### Atributos de datos

| Atributo           | En      | Valores                                        |
| ------------------ | ------- | ---------------------------------------------- |
| `data-size`        | Root    | `sm`, `md` (por defecto), `lg`                 |
| `data-state`       | Content | `open`, `closed`                               |
| `data-state`       | Item    | `checked`, `unchecked`                         |
| `data-highlighted` | Item    | Presente en el resaltado de teclado o puntero  |
| `data-disabled`    | Item    | Presente cuando el item tiene `disabled: true` |

## Notas

- Solo `Select.Root` está envuelto, para añadir `size`. Todas las demás partes son las de Ark.
- El menú se renderiza en un `Portal` y se desmonta mientras está cerrado, así SSR e hidratación quedan limpios.
- Un item deshabilitado se salta en la navegación por teclado y el typeahead, y no se puede seleccionar.
- Estiliza el menú con `[data-scope="select"][data-part="content"]`, no con una clase envolvente.
- La superficie del menú se pinta desde `--popover` y `--popover-foreground`.
