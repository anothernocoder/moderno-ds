## Referencia de la API

### Props

| Prop                | Tipo         | Por defecto                              | Descripción                                                                                  |
| ------------------- | ------------ | ---------------------------------------- | -------------------------------------------------------------------------------------------- |
| `title`             | `string`     | `"Close the month in minutes, not days"` | Qué obtiene el lector, en pocas palabras. Va en la fuente con serifa.                        |
| `description`       | `string`     | una frase                                | Una línea bajo el título; `""` la oculta.                                                    |
| `primaryAction`     | `string`     | `"Start free trial"`                     | La etiqueta del botón principal; `""` lo oculta.                                             |
| `secondaryAction`   | `string`     | `"Talk to sales"`                        | La etiqueta del botón con contorno; `""` lo oculta.                                          |
| `error`             | `string`     | —                                        | Algo detrás de las acciones falló; un Alert de error con reintento sustituye a las acciones. |
| `loading`           | `boolean`    | `false`                                  | Marcadores de esqueleto en una región ocupada sustituyen al contenido.                       |
| `disabled`          | `boolean`    | `false`                                  | El contenido se queda y todos los botones se deshabilitan.                                   |
| `onPrimaryAction`   | `() => void` | —                                        | Se pulsó el botón principal. Svelte: `onprimaryaction`. Vue: `@primary-action`.              |
| `onSecondaryAction` | `() => void` | —                                        | Se pulsó el botón con contorno. Svelte: `onsecondaryaction`. Vue: `@secondary-action`.       |
| `onRetry`           | `() => void` | —                                        | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                                  |

### Estados

| Estado        | Prop                     | Qué se muestra                                                           |
| ------------- | ------------------------ | ------------------------------------------------------------------------ |
| Por defecto   | —                        | Título, descripción y las dos acciones.                                  |
| Vacío         | todo texto menos `title` | Solo el título, cuando pasas `""` a la descripción y a las dos acciones. |
| Cargando      | `loading`                | Marcadores para el título, la descripción y dos botones.                 |
| Error         | `error`                  | El título y la descripción, y después un Alert de error con "Try again". |
| Deshabilitado | `disabled`               | El mismo contenido con los dos botones deshabilitados.                   |

### Tamaño

| Paso del contenedor      | Qué cambia                                                                  |
| ------------------------ | --------------------------------------------------------------------------- |
| bajo `@sm`               | Todo va centrado; las acciones se apilan, cada una tan ancha como el panel. |
| `@sm` (`--container-sm`) | Las acciones van una junto a otra, centradas, con su propio ancho.          |
| `@md` (`--container-md`) | El título sube un tamaño.                                                   |
| `@lg` (`--container-lg`) | El texto pasa al inicio y las acciones al final, en una sola fila.          |

## Notas

- Pide una sola cosa. La acción secundaria es para quien aún no está listo.
- Mantén el título en una línea a tamaños anchos: di qué obtiene el lector.
