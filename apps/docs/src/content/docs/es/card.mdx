## Referencia de API

### Card.Root

<PropsTable component="Card" />

### Partes

Las partes distintas de `Card.Root` solo reciben atributos nativos.

| Parte              | Elemento | Descripción                                                                        |
| ------------------ | -------- | ---------------------------------------------------------------------------------- |
| `Card.Root`        | `div`    | La superficie. Recibe `variant` y `size`.                                          |
| `Card.Header`      | `div`    | Contiene el título y la descripción.                                               |
| `Card.Title`       | `h3`     | El encabezado de la card. Pasa `role`/`aria-level` para cambiar su rango.          |
| `Card.Description` | `p`      | La línea atenuada bajo el título.                                                  |
| `Card.Content`     | `div`    | El cuerpo. La única parte que crece, así los footers de una fila quedan alineados. |
| `Card.Footer`      | `div`    | La fila de acciones.                                                               |

### Atributos de datos

| Atributo       | En               | Valores                                                       |
| -------------- | ---------------- | ------------------------------------------------------------- |
| `data-scope`   | Todas las partes | `card`                                                        |
| `data-part`    | Todas las partes | `root`, `header`, `title`, `description`, `content`, `footer` |
| `data-variant` | Root             | `outline` (por defecto), `muted`, `ghost`                     |
| `data-size`    | Root             | `sm`, `md` (por defecto), `lg`                                |

## Notas

- Las partes adyacentes comparten un solo paso de padding en vez de apilar dos.
- La raíz llena su contenedor; la cuadrícula o la fila flex le corresponden a la página.
- La profundidad es un paso de superficie y un borde, nunca una sombra.
- La esquina es `--radius`, así un tema que lo fija en 0 da cards cuadradas.
