## Referencia de la API

### Props

| Prop           | Tipo            | Por defecto                | Descripción                                                                          |
| -------------- | --------------- | -------------------------- | ------------------------------------------------------------------------------------ |
| `heading`      | `string`        | `"What our customers say"` | El encabezado de la sección. Va en la fuente con serifa.                             |
| `description`  | `string`        | una frase                  | Una frase bajo el encabezado; `""` la oculta.                                        |
| `testimonials` | `Testimonial[]` | seis citas de ejemplo      | Las citas, en orden. `[]` muestra el mensaje de vacío.                               |
| `error`        | `string`        | —                          | Falló la carga de las citas; un Alert de error con reintento reemplaza las tarjetas. |
| `loading`      | `boolean`       | `false`                    | Tarjetas de marcador en una región ocupada reemplazan las citas.                     |
| `disabled`     | `boolean`       | `false`                    | Las citas se quedan; cada enlace de autor queda inerte y el reintento deshabilitado. |
| `onRetry`      | `() => void`    | —                          | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.                          |

### Testimonial

| Campo       | Tipo     | Descripción                                                         |
| ----------- | -------- | ------------------------------------------------------------------- |
| `id`        | `string` | Una clave estable para la cita.                                     |
| `quote`     | `string` | Lo que dijo el cliente, sin comillas.                               |
| `name`      | `string` | El nombre del autor.                                                |
| `role`      | `string` | El cargo y la empresa del autor, como `"Founder, Northwind"`.       |
| `initials`  | `string` | Una o dos letras. El avatar las muestra hasta que carga una foto.   |
| `avatarUrl` | `string` | Opcional. La foto del autor.                                        |
| `href`      | `string` | Opcional. Convierte el nombre del autor en un enlace a esta página. |

### Estados

| Estado        | Prop                | Qué se muestra                                                        |
| ------------- | ------------------- | --------------------------------------------------------------------- |
| Por defecto   | —                   | Encabezado, introducción y una tarjeta por cita.                      |
| Vacío         | `testimonials={[]}` | Encabezado, introducción y "No testimonials yet."                     |
| Cargando      | `loading`           | Encabezado, introducción y tres tarjetas de marcador.                 |
| Error         | `error`             | Encabezado, introducción y después un Alert de error con "Try again". |
| Deshabilitado | `disabled`          | Las mismas citas con cada enlace de autor inerte.                     |

### Tamaño

| Paso del contenedor      | Qué cambia                                                |
| ------------------------ | --------------------------------------------------------- |
| bajo `@sm`               | Una columna de tarjetas, con las citas en tamaño pequeño. |
| `@sm` (`--container-sm`) | Las citas suben un tamaño.                                |
| `@md` (`--container-md`) | Dos columnas de tarjetas, y el encabezado sube un tamaño. |
| `@lg` (`--container-lg`) | Tres columnas, con más espacio entre ellas y alrededor.   |
