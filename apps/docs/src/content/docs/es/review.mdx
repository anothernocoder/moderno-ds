Cada dato es una fila. Su `id` vuelve a `onEdit`, así sabes qué paso abrir:

```ts
const details = [
  {
    id: "address",
    term: "Ship to",
    value: "Margot Foster, 18 Rue des Lilas, Paris",
    action: "Change",
  },
  { id: "payment", term: "Payment", value: "Visa ending in 4242", action: "Change" },
];
```

## Referencia de API

### Props

Los callbacks son props `on…` en React y Solid, en minúsculas (`onconfirm`) en Svelte y eventos (`confirm`, `back`, `edit`, `retry`, `navigate`) en Vue.

| Prop          | Tipo                    | Por defecto                      | Descripción                                                                        |
| ------------- | ----------------------- | -------------------------------- | ---------------------------------------------------------------------------------- |
| `heading`     | `string`                | `"Review your order"`            | El `h1` de la página.                                                              |
| `description` | `string`                | una línea corta                  | La línea bajo el título; `""` la oculta.                                           |
| `details`     | `DescriptionListItem[]` | contacto, dirección, envío, pago | Las filas que eligió el cliente: `{ id, term, value, action? }`.                   |
| `items`       | `OrderItem[]`           | los ejemplos del bloque          | Los artículos del pedido. `[]` muestra el mensaje de vacío.                        |
| `totals`      | `OrderTotal[]`          | los ejemplos del bloque          | Las filas sobre el total: `{ label, amount }`.                                     |
| `total`       | `string`                | el ejemplo del bloque            | El importe a pagar tal como se lee, como `"€168"`.                                 |
| `error`       | `string`                | —                                | Falló el pedido: una alerta bajo el título.                                        |
| `submitting`  | `boolean`               | `false`                          | Se está haciendo el pedido: Place order gira y todos los controles quedan inertes. |
| `loading`     | `boolean`               | `false`                          | El pedido está cargando: líneas de marcador reemplazan los datos y el resumen.     |
| `orderError`  | `string`                | —                                | Falló la carga del pedido: una alerta con reintento reemplaza el resumen.          |
| `disabled`    | `boolean`               | `false`                          | Todo se queda en pantalla; todos los controles quedan inertes.                     |
| `onConfirm`   | `() => void`            | —                                | Se pulsó Place order.                                                              |
| `onBack`      | `() => void`            | —                                | Se pulsó Back to payment.                                                          |
| `onEdit`      | `(id) => void`          | —                                | Se pulsó el botón de un dato, con el `id` de ese dato.                             |
| `onRetry`     | `() => void`            | —                                | «Try again» tras `orderError`.                                                     |
| `onNavigate`  | `(to, event) => void`   | —                                | Se pulsó un enlace de la pantalla: `home`, `cart`, `privacy` o `terms`.            |
| `homeHref`    | `string`                | `"#"`                            | Destino del logotipo.                                                              |
| `cartHref`    | `string`                | `"#"`                            | Destino de «Edit cart».                                                            |
| `privacyHref` | `string`                | `"#"`                            | Destino del enlace de privacidad.                                                  |
| `termsHref`   | `string`                | `"#"`                            | Destino del enlace de términos.                                                    |

### Estados

| Estado             | Props        | Qué se renderiza                                                  |
| ------------------ | ------------ | ----------------------------------------------------------------- |
| Por defecto        | —            | Los datos, el resumen del pedido con su total y Place order.      |
| Pedido fallido     | `error`      | Una alerta bajo el título; todo sigue usable.                     |
| Haciendo el pedido | `submitting` | «Placing order» con un indicador; todos los controles inertes.    |
| Cargando           | `loading`    | Líneas de marcador para los datos y el resumen; sin Place order.  |
| Error del pedido   | `orderError` | Una alerta con «Try again» en lugar del resumen; sin Place order. |
| Vacío              | `items=[]`   | «Your order is empty.» en lugar del resumen; sin Place order.     |
| Deshabilitado      | `disabled`   | Todo se muestra, todos los controles inertes.                     |

### Tamaño

| Paso del contenedor      | Cambio                                                  |
| ------------------------ | ------------------------------------------------------- |
| `@sm` (`--container-sm`) | La cabecera y los dos botones pasan a una sola fila.    |
| `@md` (`--container-md`) | El título crece y el pie pasa a una sola fila.          |
| `@lg` (`--container-lg`) | El resumen del pedido pasa junto a los datos y botones. |

## Notas

- Presentacional: no se hace ningún pedido y no hay router. La página que la monta hace las dos cosas.
- `onNavigate` pasa el evento del clic: ignora los clics con `metaKey`/`ctrlKey` y luego llama a `preventDefault()` para enrutar.
- La raíz es un `<div>`, no un `<main>`. Conviértela en tu `<main>` si la ruta no tiene uno.
- La pantalla importa sus dos bloques desde `@/components/blocks/…`; cambia esas líneas si tu alias es otro.
