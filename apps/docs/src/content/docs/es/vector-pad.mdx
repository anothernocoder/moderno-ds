## Uso

Vector Pad fija dos números a la vez, x e y. Úsalo para una posición, un desplazamiento o la dirección de una luz. El usuario arrastra el tirador sobre el panel cuadrado, o escribe cada número en su campo.

**y crece hacia arriba**, como en una gráfica: la parte de arriba del panel es la y más grande.

<ForFramework fw="react">

```tsx
import { VectorPad } from "@moderno-ui/react";
```

```tsx
<VectorPad.Root value={offset} onValueChange={(details) => setOffset(details.value)}>
  <VectorPad.Label>Desplazamiento</VectorPad.Label>
  <VectorPad.Control>
    <VectorPad.Thumb />
  </VectorPad.Control>
  <VectorPad.Input axis="x" />
  <VectorPad.Input axis="y" />
</VectorPad.Root>
```

</ForFramework>

El valor es `{ x, y }`. Va de -100 a 100 en cada eje y empieza en el centro, `{ x: 0, y: 0 }`.

## Referencia de la API

### VectorPad.Root

<PropsTable component="VectorPad" />

| Prop               | Tipo                                     | Por defecto      | Descripción                                                                   |
| ------------------ | ---------------------------------------- | ---------------- | ----------------------------------------------------------------------------- |
| `value`            | `{ x: number; y: number }`               | —                | Valor controlado.                                                             |
| `defaultValue`     | `{ x: number; y: number }`               | centro del rango | Valor inicial cuando no está controlado. Home y un doble clic vuelven aquí.   |
| `onValueChange`    | `(details: { value: { x, y } }) => void` | —                | Se llama mientras cambia el valor.                                            |
| `onValueChangeEnd` | `(details: { value: { x, y } }) => void` | —                | Se llama una vez, cuando el usuario suelta o una tecla fija el valor.         |
| `min`              | `number \| { x: number; y: number }`     | `-100`           | Valor más pequeño, para los dos ejes o por eje.                               |
| `max`              | `number \| { x: number; y: number }`     | `100`            | Valor más grande, para los dos ejes o por eje.                                |
| `step`             | `number \| { x: number; y: number }`     | `1`              | Cuánto avanza cada paso, para los dos ejes o por eje.                         |
| `invertY`          | `boolean`                                | `false`          | Hace que y crezca hacia abajo, como en pantalla. El tirador sigue al puntero. |
| `size`             | `"sm" \| "md" \| "lg"`                   | `"md"`           | El tamaño del panel, igual a los tamaños de Field.                            |
| `disabled`         | `boolean`                                | `false`          | Atenúa el panel y los campos e ignora la entrada.                             |
| `readOnly`         | `boolean`                                | `false`          | Muestra el valor pero ignora la entrada.                                      |
| `invalid`          | `boolean`                                | `false`          | Marca el valor como incorrecto.                                               |
| `getAriaValueText` | `(value: { x, y }) => string`            | `"X 20, Y -10"`  | Lo que dice un lector de pantalla para un valor.                              |

En Vue, enlaza el valor con `v-model` y escucha con `@value-change`.

### VectorPad.Input

| Prop    | Tipo         | Por defecto  | Descripción                                 |
| ------- | ------------ | ------------ | ------------------------------------------- |
| `axis`  | `"x" \| "y"` | —            | Obligatorio. El eje que muestra este campo. |
| `label` | `string`     | `"X"`, `"Y"` | El nombre del campo, dentro de su caja.     |

### Partes

| Parte                 | Elemento  | Descripción                                                    |
| --------------------- | --------- | -------------------------------------------------------------- |
| `VectorPad.Root`      | `<div>`   | Un grupo nombrado por la etiqueta. Lleva `data-size`.          |
| `VectorPad.Label`     | `<label>` | Nombra el panel y los campos. Al hacer clic enfoca el tirador. |
| `VectorPad.Control`   | `<div>`   | El panel cuadrado donde se pulsa o se arrastra.                |
| `VectorPad.Grid`      | `<div>`   | Opcional. Líneas en cada cuarto del panel.                     |
| `VectorPad.Crosshair` | `<div>`   | Opcional. Líneas que cruzan el centro del panel.               |
| `VectorPad.Thumb`     | `<div>`   | El tirador, con `role="slider"`. Recibe el foco.               |
| `VectorPad.Input`     | `<div>`   | Un campo numérico para un eje.                                 |

### Teclado

| Tecla                     | Acción                                               |
| ------------------------- | ---------------------------------------------------- |
| `ArrowRight`, `ArrowLeft` | Mueve el tirador un `step` a la derecha o izquierda. |
| `ArrowUp`, `ArrowDown`    | Mueve el tirador un `step` arriba o abajo.           |
| `Shift` + flecha          | Mueve el tirador diez pasos.                         |
| `Home`                    | Vuelve a `defaultValue`.                             |

### Atributos data

| Atributo        | Valores                                              |
| --------------- | ---------------------------------------------------- |
| `data-dragging` | Mientras se arrastra el tirador, en todas las partes |
| `data-disabled` | Con `disabled`, en todas las partes                  |
| `data-readonly` | Con `readOnly`, en todas las partes                  |
| `data-invalid`  | Con `invalid`, en todas las partes                   |
| `data-size`     | En la raíz: `"sm"`, `"md"` o `"lg"`                  |

## Notas

- Un lector de pantalla dice los dos valores ("X 20, Y -10"). Pasa `getAriaValueText` para decirlos en otro idioma, por ejemplo `({ x, y }) => \`${x} a la derecha, ${y} arriba\``.
- Los campos numéricos son una alternativa completa con teclado: escribe un valor o cámbialo con las flechas.
- Lo que el usuario escribe mueve el tirador al momento. El campo vuelve a mostrar el valor del tirador cuando el usuario sale de él o pulsa Enter: `250` pasa a ser `100`.
- Un arrastre sigue cuando el puntero sale del panel; el tirador se queda en el borde.
