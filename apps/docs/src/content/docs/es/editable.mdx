## Uso

Editable muestra un valor como texto. El usuario lo convierte en un campo para renombrarlo en su sitio, como una capa en un panel de capas o un archivo en una lista. Úsalo cuando un diálogo sería demasiado para un nombre corto.

Haz **doble clic** en el texto para editarlo, o pulsa Enter o F2 cuando tiene el foco. Todo el texto queda seleccionado. Enter guarda, Escape cancela y un clic fuera guarda.

<ForFramework fw="react">

```tsx
import { Editable } from "@moderno-ui/react";
```

```tsx
<Editable.Root value={name} onValueChange={(details) => setName(details.value)}>
  <Editable.Label>Layer name</Editable.Label>
  <Editable.Area>
    <Editable.Input />
    <Editable.Preview />
  </Editable.Area>
</Editable.Root>
```

</ForFramework>

## Referencia de la API

### Editable.Root

`size` es lo que añade Moderno, y `activationMode` empieza con un doble clic. Las demás props vienen del Editable de Ark.

<PropsTable component="Editable" />

| Prop             | Tipo                                          | Por defecto  | Descripción                                                                  |
| ---------------- | --------------------------------------------- | ------------ | ---------------------------------------------------------------------------- |
| `value`          | `string`                                      | —            | Valor controlado. Actualízalo en `onValueChange`.                            |
| `defaultValue`   | `string`                                      | `""`         | Valor inicial cuando no está controlado.                                     |
| `onValueChange`  | `(details: { value: string }) => void`        | —            | Se llama en cada cambio, y cuando Escape devuelve el valor.                  |
| `onValueCommit`  | `(details: { value: string }) => void`        | —            | Se llama una vez cuando se guarda el valor.                                  |
| `onValueRevert`  | `(details: { value: string }) => void`        | —            | Se llama cuando se cancela una edición, con el valor devuelto.               |
| `activationMode` | `"dblclick" \| "click" \| "focus" \| "none"`  | `"dblclick"` | Lo que convierte el texto en un campo. Con `"none"`, solo el botón Editar.   |
| `submitMode`     | `"both" \| "enter" \| "blur" \| "none"`       | `"both"`     | Lo que guarda: Enter, un clic fuera, los dos o solo el botón Guardar.        |
| `selectOnFocus`  | `boolean`                                     | `true`       | Selecciona todo el texto al empezar una edición.                             |
| `placeholder`    | `string \| { edit: string; preview: string }` | —            | Se muestra cuando el valor está vacío.                                       |
| `maxLength`      | `number`                                      | —            | Los caracteres que admite el campo como máximo.                              |
| `size`           | `"sm" \| "md" \| "lg"`                        | `"md"`       | Altura del texto y del campo, igual a los tamaños de Field.                  |
| `disabled`       | `boolean`                                     | `false`      | Atenúa el texto e ignora la entrada.                                         |
| `readOnly`       | `boolean`                                     | `false`      | Muestra el valor pero nunca se convierte en un campo.                        |
| `invalid`        | `boolean`                                     | `false`      | Marca el valor como incorrecto.                                              |
| `name`           | `string`                                      | —            | El nombre del campo en un formulario.                                        |
| `translations`   | `{ edit, submit, cancel, input: string }`     | Inglés       | Los nombres de los botones (`"Edit"`, `"Save"`, `"Cancel"`), en otro idioma. |

En Vue, enlaza el valor con `:model-value` o `v-model`, y escucha con `@value-commit`.

### Partes

| Parte                    | Elemento   | Descripción                                                                          |
| ------------------------ | ---------- | ------------------------------------------------------------------------------------ |
| `Editable.Root`          | `<div>`    | Lleva `data-size`.                                                                   |
| `Editable.Label`         | `<label>`  | Opcional. Nombra el texto y el campo.                                                |
| `Editable.Area`          | `<div>`    | Contiene el texto y el campo, uno en lugar del otro.                                 |
| `Editable.Preview`       | `<span>`   | El valor como texto, un botón que recibe el foco. Lo nombran la etiqueta y el valor. |
| `Editable.Input`         | `<input>`  | Sustituye al texto mientras el usuario edita. Lo nombra la etiqueta.                 |
| `Editable.Control`       | `<div>`    | Opcional. Contiene los botones, después del texto.                                   |
| `Editable.EditTrigger`   | `<button>` | Empieza una edición. Se oculta mientras se edita.                                    |
| `Editable.SubmitTrigger` | `<button>` | Guarda. Se muestra mientras se edita.                                                |
| `Editable.CancelTrigger` | `<button>` | Cancela. Se muestra mientras se edita.                                               |

### Teclado

| Tecla                  | Acción                                            |
| ---------------------- | ------------------------------------------------- |
| `Enter`, `F2`, `Space` | En el texto con foco: empieza una edición.        |
| `Enter`                | En el campo: guarda.                              |
| `Escape`               | En el campo: cancela y devuelve el valor.         |
| `Tab`                  | Sale del campo, lo que guarda (ver `submitMode`). |

Después de guardar o cancelar, el foco vuelve al texto.

### Atributos data

| Atributo                 | Valores                                           |
| ------------------------ | ------------------------------------------------- |
| `data-focus`             | En el área, mientras se edita                     |
| `data-placeholder-shown` | En el área y el texto, cuando el valor está vacío |
| `data-disabled`          | Con `disabled`, en el área, el texto y el campo   |
| `data-invalid`           | Con `invalid`, en el texto y el campo             |
| `data-size`              | En la raíz: `"sm"`, `"md"` o `"lg"`               |

## Notas

- `Editable.Root`, `Editable.Preview` y `Editable.Input` están envueltos; las demás partes son las de Ark sin cambios.
- El texto y el campo son la misma caja, así que nada se mueve al empezar una edición.
- Escape devuelve el valor de antes de la edición, aunque estuviera vacío.
- Los botones se llaman "Edit", "Save" y "Cancel" por defecto. Pasa `translations` para nombrarlos en otro idioma, por ejemplo `{ edit: "Editar", submit: "Guardar", cancel: "Cancelar", input: "Valor" }`.
- Para un valor que el usuario siempre escribe, usa un Field.
