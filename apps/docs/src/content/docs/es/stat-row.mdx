Cada métrica es `{ id, label, value, delta, tone, caption }`. Pon en `tone` lo que significa el cambio: una baja en la tasa de abandono es `positive`.

## Referencia de API

### Propiedades

| Propiedad     | Tipo            | Por defecto     | Descripción                                                           |
| ------------- | --------------- | --------------- | --------------------------------------------------------------------- |
| `stats`       | `StatRowItem[]` | un ejemplo      | Las métricas, en orden de lectura. `[]` muestra el estado vacío.      |
| `heading`     | `string`        | `"Overview"`    | El título sobre la fila.                                              |
| `description` | `string`        | una frase       | La línea bajo el título; `""` la oculta.                              |
| `actionLabel` | `string`        | `"View report"` | El texto del botón de la cabecera; `""` oculta el botón.              |
| `error`       | `string`        | —               | Las métricas no cargaron; una alerta con reintento las reemplaza.     |
| `loading`     | `boolean`       | `false`         | Tarjetas de marcador en una región ocupada reemplazan las métricas.   |
| `disabled`    | `boolean`       | `false`         | Las métricas siguen legibles y todos los botones quedan desactivados. |
| `onAction`    | `() => void`    | —               | El botón de la cabecera. Svelte: `onaction`. Vue: `@action`.          |
| `onRetry`     | `() => void`    | —               | "Try again" tras `error`. Svelte: `onretry`. Vue: `@retry`.           |

### StatRowItem

| Campo     | Tipo                                    | Descripción                                          |
| --------- | --------------------------------------- | ---------------------------------------------------- |
| `id`      | `string`                                | Identidad estable.                                   |
| `label`   | `string`                                | Lo que se mide.                                      |
| `value`   | `string`                                | El número, ya formateado.                            |
| `delta`   | `string`                                | Cambio opcional, con su signo: `+12.5%`, `−0.4 pts`. |
| `tone`    | `"positive" \| "negative" \| "neutral"` | Lo que significa el cambio. Por defecto `"neutral"`. |
| `caption` | `string`                                | Contexto opcional tras el cambio: `vs last month`.   |

### Estados

| Estado        | Propiedad    | Qué se muestra                                                    |
| ------------- | ------------ | ----------------------------------------------------------------- |
| Por defecto   | —            | Una tarjeta por métrica.                                          |
| Vacío         | `stats={[]}` | Una tarjeta "No numbers yet".                                     |
| Cargando      | `loading`    | Cuatro tarjetas de marcador en una región `status` ocupada.       |
| Error         | `error`      | Una alerta de error con el botón "Try again" en lugar de la fila. |
| Deshabilitado | `disabled`   | Las métricas con todos los botones desactivados.                  |

### Dimensionado

| Paso del contenedor      | Qué cambia                                                  |
| ------------------------ | ----------------------------------------------------------- |
| bajo `@sm`               | Una métrica por fila; el botón queda bajo el título.        |
| `@sm` (`--container-sm`) | Dos métricas por fila; el título y el botón comparten fila. |
| `@md` (`--container-md`) | Valores y título más grandes.                               |
| `@lg` (`--container-lg`) | Cuatro métricas por fila.                                   |
