Each detail is one row. Its `id` comes back to `onEdit`, so you know which step to open:

```ts
const details = [
  {
    id: "address",
    term: "Ship to",
    value: "Margot Foster, 18 Rue des Lilas, Paris",
    action: "Change",
  },
  { id: "payment", term: "Payment", value: "Visa ending in 4242", action: "Change" },
];
```

## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`onconfirm`) in Svelte, and emits (`confirm`, `back`, `edit`, `retry`, `navigate`) in Vue.

| Prop          | Type                    | Default                             | Description                                                           |
| ------------- | ----------------------- | ----------------------------------- | --------------------------------------------------------------------- |
| `heading`     | `string`                | `"Review your order"`               | The page's `h1`.                                                      |
| `description` | `string`                | a short line                        | The line under the heading; `""` hides it.                            |
| `details`     | `DescriptionListItem[]` | contact, address, delivery, payment | The rows the shopper chose: `{ id, term, value, action? }`.           |
| `items`       | `OrderItem[]`           | the block's samples                 | The lines being ordered. `[]` shows the empty message.                |
| `totals`      | `OrderTotal[]`          | the block's samples                 | The rows above the total: `{ label, amount }`.                        |
| `total`       | `string`                | the block's sample                  | The amount to pay as people read it, like `"€168"`.                   |
| `error`       | `string`                | —                                   | Placing the order failed: an alert under the heading.                 |
| `submitting`  | `boolean`               | `false`                             | The order is being placed: Place order spins, every control is inert. |
| `loading`     | `boolean`               | `false`                             | The order is loading: placeholder lines replace details and summary.  |
| `orderError`  | `string`                | —                                   | The order failed to load: an alert with a retry replaces the summary. |
| `disabled`    | `boolean`               | `false`                             | Everything stays on screen; every control is inert.                   |
| `onConfirm`   | `() => void`            | —                                   | Place order was pressed.                                              |
| `onBack`      | `() => void`            | —                                   | Back to payment was pressed.                                          |
| `onEdit`      | `(id) => void`          | —                                   | A detail's button was pressed, with that detail's `id`.               |
| `onRetry`     | `() => void`            | —                                   | "Try again" after `orderError`.                                       |
| `onNavigate`  | `(to, event) => void`   | —                                   | A screen link was clicked: `home`, `cart`, `privacy` or `terms`.      |
| `homeHref`    | `string`                | `"#"`                               | Target of the wordmark.                                               |
| `cartHref`    | `string`                | `"#"`                               | Target of "Edit cart".                                                |
| `privacyHref` | `string`                | `"#"`                               | Target of the privacy link.                                           |
| `termsHref`   | `string`                | `"#"`                               | Target of the terms link.                                             |

### States

| State         | Props        | Renders                                                            |
| ------------- | ------------ | ------------------------------------------------------------------ |
| Default       | —            | The details, the order summary with its total, and Place order.    |
| Order failed  | `error`      | An alert under the heading; everything stays usable.               |
| Placing order | `submitting` | "Placing order" with a spinner; every control inert.               |
| Loading       | `loading`    | Placeholder lines for the details and the summary; no Place order. |
| Order error   | `orderError` | An alert with "Try again" for the summary; no Place order.         |
| Empty         | `items=[]`   | "Your order is empty." for the summary; no Place order.            |
| Disabled      | `disabled`   | Everything shown, every control inert.                             |

### Sizing

| Container step           | Change                                                  |
| ------------------------ | ------------------------------------------------------- |
| `@sm` (`--container-sm`) | The masthead and the two buttons move onto one row.     |
| `@md` (`--container-md`) | The heading grows and the footer moves onto one row.    |
| `@lg` (`--container-lg`) | The order summary moves beside the details and buttons. |

### Composition

| Part                                      | Role                                                          |
| ----------------------------------------- | ------------------------------------------------------------- |
| [Description List](/en/description-list/) | The contact, address, delivery and payment, each with Change. |
| [Order Summary](/en/order-summary/)       | The read-only lines and totals being ordered.                 |

## Notes

- Presentational: no order is placed and no router is used. The page that mounts it does both.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The root is a `<div>`, not a `<main>`. Make it your `<main>` if the route has none.
- The screen imports its two blocks from `@/components/blocks/…`; edit those lines if your alias differs.
