agent:
  intent: A stack of dismissible status alerts — the notification centre of an app.
  whenToUse: "Anywhere a collection of statuses is shown together: a notification drawer, an activity or alerts page, the top of a dashboard, a per-resource health list."
  whenNotToUse:
    - case: One status message about the thing the reader just did
      use: the Alert primitive on its own — a list of one is not a list
    - case: A form's validation failures
      use: FormLayout, which raises a form-level Alert and marks each field
    - case: A view with no data yet
      use: EmptyState — this block's empty render is for a list that emptied, not for a feature that has never been used
  gotchas:
    - "Presentational: it removes nothing. `onDismiss` and `onDismissAll` report what the reader asked for; the array stays yours, which is what makes an optimistic removal or an undo possible."
    - "`alerts` defaults to a sample feed so the block renders standalone. Pass your own array — or edit the constant, the file is yours after `moderno add`."
    - "`alerts={[]}` is the empty state, not a bug: the list loaded and there is nothing in it."
    - "`loading` replaces the list rather than dimming it, so nobody acts on a row that is about to change; `error` replaces it too, because an empty list and a list that failed to load are different facts."
    - "Each row keeps Alert's live-region role, so a notification appended to a mounted list is announced. A list rendered with the page is not — live regions only announce changes."
    - "The dismiss control is a glyph below `--container-md` and gains its label above it; its accessible name carries the alert's title at every width, so voice control and screen readers always hear which alert is being dismissed."
  theming:
    - "Nothing is painted here. The rows are Alert's four status variants, the controls are Button's secondary, outline and ghost variants, and the empty and loading renders are Card."
    - "The heading and its sentence are props, defaulting to the notification-centre wording: the same stack is a service-status panel on the sign-in screen and an audit trail on a settings page."
    - "Layout comes from the Tailwind preset's contract-backed utilities; the three steps are --container-sm, --container-md and --container-lg."
    - "The status hue reaches each glyph through the alert's icon part and currentColor, so the icons re-skin with the theme and no icon package is installed."

## API Reference

### Props

| Prop           | Type                   | Default           | Description                                                    |
| -------------- | ---------------------- | ----------------- | -------------------------------------------------------------- |
| `alerts`       | `AlertListItem[]`      | a sample feed     | The notifications, newest first. `[]` renders the empty state. |
| `heading`      | `string`               | `"Notifications"` | The heading over the list.                                     |
| `description`  | `string`               | a sentence        | The line under the heading; `""` hides it.                     |
| `error`        | `string`               | —                 | The list failed to load; an alert with a retry replaces it.    |
| `loading`      | `boolean`              | `false`           | A busy region replaces the list.                               |
| `disabled`     | `boolean`              | `false`           | The alerts stay readable and every control is disabled.        |
| `onDismiss`    | `(id: string) => void` | —                 | A row's dismiss. Svelte: `ondismiss`. Vue: `@dismiss`.         |
| `onDismissAll` | `() => void`           | —                 | "Dismiss all". Svelte: `ondismissall`. Vue: `@dismiss-all`.    |
| `onAction`     | `(id: string) => void` | —                 | A row's action button. Svelte: `onaction`. Vue: `@action`.     |
| `onRetry`      | `() => void`           | —                 | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.   |

### AlertListItem

| Field         | Type                                          | Description                                       |
| ------------- | --------------------------------------------- | ------------------------------------------------- |
| `id`          | `string`                                      | Stable identity, reported by the callbacks.       |
| `variant`     | `"info" \| "success" \| "warning" \| "error"` | The Alert status variant.                         |
| `title`       | `string`                                      | The alert title.                                  |
| `description` | `string`                                      | Optional detail line.                             |
| `meta`        | `string`                                      | Optional timestamp, already phrased for a reader. |
| `actionLabel` | `string`                                      | Optional row action; fires `onAction`.            |

### States

| State    | Prop          | What renders                                                    |
| -------- | ------------- | --------------------------------------------------------------- |
| Default  | —             | One Alert per item, in its own status variant.                  |
| Empty    | `alerts={[]}` | A "You are all caught up" card.                                 |
| Loading  | `loading`     | A busy `status` region in place of the list.                    |
| Error    | `error`       | One error alert with a "Try again" button in place of the list. |
| Disabled | `disabled`    | The list with every control disabled.                           |

### Sizing

| Container step           | What changes                                            |
| ------------------------ | ------------------------------------------------------- |
| `@sm` (`--container-sm`) | The heading and "Dismiss all" share a row.              |
| `@md` (`--container-md`) | Each dismiss control shows its label, not just a glyph. |
| `@lg` (`--container-lg`) | Timestamps move to the trailing edge of each row.       |

## Notes

- Presentational: it removes nothing. The callbacks report what the reader asked for; the array stays yours.
- Each row keeps Alert's live-region role, so an item added to a mounted list is announced.
- Every dismiss control's accessible name includes the alert's title, at every width.
