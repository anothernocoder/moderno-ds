    - "Each icon sits in a --muted tile with a --border edge and --radius-lg corners; the empty box is a dashed --border."
    - "The links read --foreground, underline on hover and draw the --ring outline on keyboard focus."

## API Reference

### Props

| Prop          | Type                   | Default                | Description                                                               |
| ------------- | ---------------------- | ---------------------- | ------------------------------------------------------------------------- |
| `heading`     | `string`               | a sentence             | The title above the incentives. Rendered as an `h2`.                      |
| `description` | `string`               | a sentence             | One short line under the heading. `""` hides it.                          |
| `incentives`  | `IncentiveStripItem[]` | four sample incentives | The incentives, in order. `[]` shows the empty message.                   |
| `error`       | `string`               | —                      | Loading the incentives failed; an error Alert with a retry replaces them. |
| `loading`     | `boolean`              | `false`                | Skeleton placeholders in a busy region replace the incentives.            |
| `disabled`    | `boolean`              | `false`                | The incentives stay; their links and the retry button are out of reach.   |
| `onRetry`     | `() => void`           | —                      | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.              |

### Incentive

| Field         | Type                                         | Description                                       |
| ------------- | -------------------------------------------- | ------------------------------------------------- |
| `id`          | `string`                                     | A stable key for the incentive.                   |
| `icon`        | `"truck" \| "returns" \| "shield" \| "gift"` | The icon in the tile.                             |
| `title`       | `string`                                     | The promise, in a few words. Rendered as an `h3`. |
| `description` | `string`                                     | One sentence that backs it up.                    |
| `link`        | `{ label: string; href: string }`            | Optional. A link to the policy behind it.         |

### States

| State    | Prop              | What renders                                                   |
| -------- | ----------------- | -------------------------------------------------------------- |
| Default  | —                 | The heading and every incentive.                               |
| Empty    | `incentives={[]}` | The heading and "No incentives to show yet." in a dashed box.  |
| Loading  | `loading`         | The heading and four placeholders.                             |
| Error    | `error`           | The heading and an error Alert with "Try again".               |
| Disabled | `disabled`        | The same incentives; the links are muted and cannot be opened. |

### Sizing

| Container step           | What changes                                                |
| ------------------------ | ----------------------------------------------------------- |
| below `@sm`              | One incentive per row, its icon beside the text.            |
| `@sm` (`--container-sm`) | Two incentives per row, each icon above its text.           |
| `@md` (`--container-md`) | The heading steps up one size.                              |
| `@lg` (`--container-lg`) | Four incentives on one row, with more room above and below. |

## Notes

- Promise only what the store keeps. Put the numbers in the sentence: "over €50", "within 30 days".
- Link each promise to the page that explains it, so a shopper can check the fine print.
