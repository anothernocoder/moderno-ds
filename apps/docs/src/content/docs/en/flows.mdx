A flow composes screens only. Its assembly is example code you rewire to your own router; installing it brings every screen, block and primitive it needs.

## Available flows

- [Auth](/en/auth/) — sign-in, sign-up, forgot-password, reset-password and verify, with link interception and the resend countdown.
