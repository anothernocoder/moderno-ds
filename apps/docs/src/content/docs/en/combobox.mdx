## Usage

Combobox is a text input with a list of options under it. The user types a few letters, the list shows only the matches, and they pick one. Use it when the list is too long to scan. When nothing matches, `Combobox.Empty` says so.

<ForFramework fw="react">

```tsx
import { Combobox, Portal, useFilter, useListCollection } from "@moderno-ui/react";
```

```tsx
const { contains } = useFilter({ sensitivity: "base" });
const { collection, filter } = useListCollection({ initialItems: frameworks, filter: contains });

<Combobox.Root collection={collection} onInputValueChange={(details) => filter(details.inputValue)}>
  <Combobox.Label>Framework</Combobox.Label>
  <Combobox.Control>
    <Combobox.Input placeholder="Search frameworks" />
    <Combobox.Trigger>▾</Combobox.Trigger>
  </Combobox.Control>
  <Portal>
    <Combobox.Positioner>
      <Combobox.Content>
        <Combobox.Empty>No frameworks found</Combobox.Empty>
        {collection.items.map((item) => (
          <Combobox.Item key={item.value} item={item}>
            <Combobox.ItemText>{item.label}</Combobox.ItemText>
            <Combobox.ItemIndicator>✓</Combobox.ItemIndicator>
          </Combobox.Item>
        ))}
      </Combobox.Content>
    </Combobox.Positioner>
  </Portal>
</Combobox.Root>;
```

</ForFramework>

<ForFramework fw="vue">

```ts
import {
  Combobox,
  Portal,
  useFilter,
  useListCollection,
  type ComboboxInputValueChangeDetails,
} from "@moderno-ui/vue";
```

```vue
<script setup lang="ts">
const filters = useFilter({ sensitivity: "base" });
const { collection, filter } = useListCollection({
  initialItems: frameworks,
  filter: (text, query) => filters.value.contains(text, query),
});

const onInputValueChange = (details: ComboboxInputValueChangeDetails) => filter(details.inputValue);
</script>

<template>
  <Combobox.Root :collection="collection" @input-value-change="onInputValueChange">
    <Combobox.Label>Framework</Combobox.Label>
    <Combobox.Control>
      <Combobox.Input placeholder="Search frameworks" />
      <Combobox.Trigger>▾</Combobox.Trigger>
    </Combobox.Control>
    <Portal>
      <Combobox.Positioner>
        <Combobox.Content>
          <Combobox.Empty>No frameworks found</Combobox.Empty>
          <Combobox.Item v-for="item in collection.items" :key="item.value" :item="item">
            <Combobox.ItemText>{{ item.label }}</Combobox.ItemText>
            <Combobox.ItemIndicator>✓</Combobox.ItemIndicator>
          </Combobox.Item>
        </Combobox.Content>
      </Combobox.Positioner>
    </Portal>
  </Combobox.Root>
</template>
```

</ForFramework>

`frameworks` is a plain array of `{ label, value }` objects. Ark does not filter the list itself: `useListCollection` keeps the items, and `filter` narrows them to what the user typed. `useFilter` gives a `contains` check that ignores case and accents.

## API Reference

### Combobox.Root

`size` is the Moderno addition; it sets the height and type of the control. The other props come from Ark's Combobox.

<PropsTable component="Combobox" />

| Prop                 | Type                                                 | Default     | Description                                                   |
| -------------------- | ---------------------------------------------------- | ----------- | ------------------------------------------------------------- |
| `collection`         | `ListCollection`                                     | —           | Required. The options, from `useListCollection`.              |
| `onInputValueChange` | `(details: { inputValue: string }) => void`          | —           | Called as the user types. Filter the collection here.         |
| `value`              | `string[]`                                           | —           | Controlled picks.                                             |
| `defaultValue`       | `string[]`                                           | `[]`        | Picks at the start, uncontrolled.                             |
| `onValueChange`      | `(details: { value: string[]; items: T[] }) => void` | —           | Called when the picks change.                                 |
| `multiple`           | `boolean`                                            | `false`     | Lets the user pick more than one option.                      |
| `inputValue`         | `string`                                             | —           | Controlled text in the input.                                 |
| `open`               | `boolean`                                            | —           | Controlled open state of the list.                            |
| `onOpenChange`       | `(details: { open: boolean }) => void`               | —           | Called when the list opens or closes.                         |
| `openOnClick`        | `boolean`                                            | `false`     | Opens the list when the input is clicked.                     |
| `allowCustomValue`   | `boolean`                                            | `false`     | Keeps typed text that matches no option.                      |
| `closeOnSelect`      | `boolean`                                            | `true`      | Closes the list after a pick.                                 |
| `selectionBehavior`  | `"replace" \| "clear" \| "preserve"`                 | `"replace"` | What the input shows after a pick. `"clear"` with `multiple`. |
| `placeholder`        | `string`                                             | —           | Text shown in the empty input.                                |
| `disabled`           | `boolean`                                            | `false`     | Dims the control and ignores input.                           |
| `readOnly`           | `boolean`                                            | `false`     | Shows the value but ignores input.                            |
| `invalid`            | `boolean`                                            | —           | Marks the value as wrong.                                     |
| `required`           | `boolean`                                            | `false`     | Marks the field as required in a form.                        |
| `name`               | `string`                                             | —           | The form field name of the input.                             |
| `positioning`        | `PositioningOptions`                                 | —           | Where the list opens, like `{ placement: "top-start" }`.      |

In Vue, bind the value with `:model-value` or `v-model`, and listen with `@value-change` and `@input-value-change`.

### Hooks

| Hook                | Returns                              | Description                                                                                |
| ------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------ |
| `useListCollection` | `{ collection, filter, … }`          | Keeps `initialItems` as a collection. `filter(text)` narrows it with your `filter` check.  |
| `useFilter`         | `{ contains, startsWith, endsWith }` | Text checks that follow the page's locale. `sensitivity: "base"` ignores case and accents. |

In Vue, `collection` and `useFilter`'s result are refs; in Svelte and Solid, call them: `collection()`, `filters()`.

### Parts

| Part                      | Element    | Description                                                         |
| ------------------------- | ---------- | ------------------------------------------------------------------- |
| `Combobox.Root`           | `<div>`    | Carries `data-size`.                                                |
| `Combobox.Label`          | `<label>`  | Optional. Names the input.                                          |
| `Combobox.Control`        | `<div>`    | The bordered box. Holds the input and its buttons.                  |
| `Combobox.Input`          | `<input>`  | The text box the user types in. Its role is `combobox`.             |
| `Combobox.Trigger`        | `<button>` | Optional. Opens and closes the list.                                |
| `Combobox.ClearTrigger`   | `<button>` | Optional. Clears the value. Hidden while it is empty.               |
| `Combobox.Positioner`     | `<div>`    | Placed by Ark below the control. Wrap it in `Portal`.               |
| `Combobox.Content`        | `<div>`    | The list surface. Its role is `listbox`.                            |
| `Combobox.List`           | `<div>`    | Optional. Wraps the items inside the content.                       |
| `Combobox.ItemGroup`      | `<div>`    | Optional. A group of items.                                         |
| `Combobox.ItemGroupLabel` | `<div>`    | The group's heading.                                                |
| `Combobox.Item`           | `<div>`    | One option. Takes `item`.                                           |
| `Combobox.ItemText`       | `<span>`   | The option's text.                                                  |
| `Combobox.ItemIndicator`  | `<div>`    | Shown while the option is picked, like a ✓.                         |
| `Combobox.Empty`          | `<div>`    | Shown while the collection is empty: the no-results message.        |
| `Combobox.Context`        | —          | Hands you the combobox, such as `valueAsString`: the picked labels. |

### Data attributes

| Attribute          | Values                                                         |
| ------------------ | -------------------------------------------------------------- |
| `data-state`       | `"open"` or `"closed"` on the control, input, trigger, content |
| `data-state`       | `"checked"` or `"unchecked"` on each item                      |
| `data-highlighted` | On the item chosen with the arrow keys or the pointer          |
| `data-focus`       | While the input has focus, on the label and control            |
| `data-invalid`     | When `invalid`, on the root, label, control and input          |
| `data-disabled`    | When `disabled`, on the label, control and buttons; on an item |
| `data-empty`       | On the content while the collection is empty                   |
| `data-size`        | On the root: `"sm"`, `"md"` or `"lg"`                          |

## Notes

- `Combobox.Root` is wrapped to add `size`; every other part is Ark's unchanged. `size` sets the control; the list keeps one density.
- The keyboard: Arrow Down opens the list and moves the highlight, Enter picks the highlighted option, and Escape closes the list.
- The trigger and the clear trigger are out of the tab order; the input's keys do their jobs.
