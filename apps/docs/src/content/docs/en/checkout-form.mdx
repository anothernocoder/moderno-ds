## API Reference

### Props

| Prop              | Type                      | Default           | Description                                                  |
| ----------------- | ------------------------- | ----------------- | ------------------------------------------------------------ |
| `step`            | `"shipping" \| "payment"` | `"shipping"`      | Which step the form asks for.                                |
| `heading`         | `string`                  | per step          | The heading. Set in the serif face.                          |
| `description`     | `string`                  | per step          | One sentence under the heading; `""` hides it.               |
| `headingLevel`    | `1 \| 2`                  | `2`               | `1` makes the heading an h1 and each group's title an h2.    |
| `deliveryOptions` | `DeliveryOption[]`        | standard, express | The delivery methods on the shipping step. `[]` hides them.  |
| `error`           | `string`                  | —                 | The step failed; an error Alert sits at the top of the form. |
| `errors`          | `Record<string, string>`  | —                 | A message per field, under the field's name.                 |
| `loading`         | `boolean`                 | `false`           | Every control disabled and the continue button busy.         |
| `disabled`        | `boolean`                 | `false`           | Every control and both buttons disabled.                     |
| `onSubmit`        | `(event) => void`         | —                 | The form's submit event. Svelte: `onsubmit`. Vue: `@submit`. |
| `onBack`          | `() => void`              | —                 | The back button was pressed. Svelte: `onback`. Vue: `@back`. |

### Fields

| Step       | Group            | Field names                                                        |
| ---------- | ---------------- | ------------------------------------------------------------------ |
| `shipping` | Contact          | `email`                                                            |
| `shipping` | Shipping address | `fullName`, `address`, `city`, `region`, `postalCode`, `country`   |
| `shipping` | Delivery method  | `delivery` (the picked option's `id`)                              |
| `payment`  | Card details     | `cardName`, `cardNumber`, `expiry`, `cvc`, `saveCard` (the switch) |

### DeliveryOption

| Field         | Type     | Description                                        |
| ------------- | -------- | -------------------------------------------------- |
| `id`          | `string` | The value the form sends under `delivery`.         |
| `label`       | `string` | The option's name, like `"Express"`.               |
| `description` | `string` | How long it takes, like `"2–5 business days"`.     |
| `price`       | `string` | What it costs, already formatted, like `"$16.00"`. |

### States

| State    | Prop                   | What renders                                               |
| -------- | ---------------------- | ---------------------------------------------------------- |
| Default  | —                      | The shipping step: contact, address and delivery method.   |
| Payment  | `step="payment"`       | The card details and the save switch.                      |
| Empty    | `deliveryOptions={[]}` | The shipping step without a delivery method.               |
| Loading  | `loading`              | Every control disabled and a busy "Saving".                |
| Error    | `error`/`errors`       | An error Alert at the top of the form, and invalid fields. |
| Disabled | `disabled`             | Every control and both buttons disabled.                   |

### Sizing

| Container step           | What changes                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| below `@sm`              | Every field on its own row. The buttons stack, full width, continue on top.                |
| `@sm` (`--container-sm`) | City and state, postal code and country, expiry and CVC pair off. The buttons share a row. |
| `@md` (`--container-md`) | The heading steps up a size. The delivery options sit side by side.                        |
| `@lg` (`--container-lg`) | Each group's title sits beside its fields, with more room above and below.                 |

## Notes

- Send card details straight to your payment provider, never to your own server.
- Keep `error` short and say what failed. The form keeps what was typed, so the shopper can fix it and try again.
