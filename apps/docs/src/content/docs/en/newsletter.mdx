## API Reference

### Props

| Prop          | Type              | Default                                  | Description                                                  |
| ------------- | ----------------- | ---------------------------------------- | ------------------------------------------------------------ |
| `heading`     | `string`          | `"One calm email a month"`               | What the reader gets. Set in the serif face.                 |
| `description` | `string`          | a sentence                               | One line under the heading; `""` hides it.                   |
| `note`        | `string`          | `"No spam. Unsubscribe with one click."` | A short line under the form; `""` hides it.                  |
| `error`       | `string`          | —                                        | The field turns invalid and shows this message under it.     |
| `loading`     | `boolean`         | `false`                                  | The field disabled and the button a busy "Subscribing".      |
| `disabled`    | `boolean`         | `false`                                  | The field and the button disabled.                           |
| `subscribed`  | `boolean`         | `false`                                  | A success Alert replaces the form.                           |
| `onSubmit`    | `(event) => void` | —                                        | The form's submit event. Svelte: `onsubmit`. Vue: `@submit`. |

### States

| State      | Prop                  | What renders                                             |
| ---------- | --------------------- | -------------------------------------------------------- |
| Default    | —                     | Heading, description, the form and the note.             |
| Empty      | `description`, `note` | The heading and the form alone, when both are `""`.      |
| Loading    | `loading`             | The same form with the field disabled and "Subscribing". |
| Error      | `error`               | The field invalid, with your message under it.           |
| Disabled   | `disabled`            | The same form with the field and the button disabled.    |
| Subscribed | `subscribed`          | "You are subscribed" in place of the form.               |

### Sizing

| Container step           | What changes                                                    |
| ------------------------ | --------------------------------------------------------------- |
| below `@sm`              | Everything is centred and stacked; the button is full width.    |
| `@sm` (`--container-sm`) | The field and the button share one row.                         |
| `@md` (`--container-md`) | The heading steps up a size.                                    |
| `@lg` (`--container-lg`) | The text moves to the start and the form beside it, in columns. |
