## Usage

Angle Slider lets the user pick an angle by turning a round dial. Use it for a direction or a rotation, like the direction of a gradient. The number field beside the dial shows the same angle, and the user can type it there too.

**0° points up**, and the angle grows clockwise: 90° points right, 180° down, 270° left.

<ForFramework fw="react">

```tsx
import { AngleSlider } from "@moderno-ui/react";
```

```tsx
<AngleSlider.Root value={angle} onValueChange={(details) => setAngle(details.value)}>
  <AngleSlider.Label>Rotation</AngleSlider.Label>
  <AngleSlider.Control>
    <AngleSlider.Thumb />
  </AngleSlider.Control>
  <AngleSlider.Input />
  <AngleSlider.HiddenInput />
</AngleSlider.Root>
```

</ForFramework>

The value is a number of degrees, from 0 up to 359. A drag past 360° carries on from 0°, without a jump.

## API Reference

### AngleSlider.Root

`size`, `marks` and `getAriaValueText` are the Moderno additions. The other props come from Ark's Angle Slider.

<PropsTable component="AngleSlider" />

| Prop               | Type                                                          | Default        | Description                                                 |
| ------------------ | ------------------------------------------------------------- | -------------- | ----------------------------------------------------------- |
| `value`            | `number`                                                      | —              | Controlled angle, in degrees.                               |
| `defaultValue`     | `number`                                                      | `0`            | Angle at first when uncontrolled.                           |
| `onValueChange`    | `(details: { value: number; valueAsDegree: string }) => void` | —              | Called while the angle changes.                             |
| `onValueChangeEnd` | `(details: { value: number; valueAsDegree: string }) => void` | —              | Called once, when the user lets go or a key sets the angle. |
| `step`             | `number`                                                      | `1`            | How far one move turns the dial, in degrees.                |
| `marks`            | `number[]`                                                    | —              | Angles that Shift while dragging snaps to.                  |
| `size`             | `"sm" \| "md" \| "lg"`                                        | `"md"`         | The dial's size, matched to the Field sizes.                |
| `disabled`         | `boolean`                                                     | `false`        | Dims the dial and the field and ignores input.              |
| `readOnly`         | `boolean`                                                     | `false`        | Shows the angle but ignores input.                          |
| `invalid`          | `boolean`                                                     | `false`        | Marks the angle as wrong.                                   |
| `name`             | `string`                                                      | —              | The form field name of the hidden input.                    |
| `getAriaValueText` | `(value: number) => string`                                   | `"45 degrees"` | What a screen reader says for an angle.                     |

In Vue, bind the value with `:model-value` or `v-model`, and listen with `@value-change`.

### AngleSlider.Marker

| Prop    | Type     | Default | Description                           |
| ------- | -------- | ------- | ------------------------------------- |
| `value` | `number` | —       | Required. The angle the tick sits at. |

### Parts

| Part                      | Element   | Description                                                 |
| ------------------------- | --------- | ----------------------------------------------------------- |
| `AngleSlider.Root`        | `<div>`   | Carries `data-size` and the angle as `--angle`.             |
| `AngleSlider.Label`       | `<label>` | Names the dial and the field. Clicking it focuses the dial. |
| `AngleSlider.Control`     | `<div>`   | The round dial you click or drag on.                        |
| `AngleSlider.Thumb`       | `<div>`   | The needle, with `role="slider"`. It takes focus.           |
| `AngleSlider.MarkerGroup` | `<div>`   | Optional. Holds the ticks, inside the control.              |
| `AngleSlider.Marker`      | `<div>`   | A tick at one angle.                                        |
| `AngleSlider.Input`       | `<div>`   | The number field with a `°` after it. Moderno's part.       |
| `AngleSlider.HiddenInput` | `<input>` | Carries the angle into a form.                              |
| `AngleSlider.ValueText`   | `<div>`   | Optional. The angle as text.                                |

### Keyboard

| Key                       | Action                               |
| ------------------------- | ------------------------------------ |
| `ArrowRight`, `ArrowDown` | Turns the dial one `step` clockwise. |
| `ArrowLeft`, `ArrowUp`    | Turns the dial one `step` back.      |
| `PageUp`, `PageDown`      | Turns the dial 15° forward or back.  |
| `Home`                    | Goes to 0°.                          |
| `End`                     | Goes to 359°.                        |

### Data attributes

| Attribute       | Values                                                          |
| --------------- | --------------------------------------------------------------- |
| `data-disabled` | When `disabled`, on every part                                  |
| `data-invalid`  | When `invalid`, on the root, label, control and thumb           |
| `data-readonly` | When `readOnly`, on the root, label, control and thumb          |
| `data-state`    | On each marker: `"under-value"`, `"at-value"` or `"over-value"` |
| `data-size`     | On the root: `"sm"`, `"md"` or `"lg"`                           |

## Notes

- `AngleSlider.Root` and `AngleSlider.Thumb` are wrapped, and `AngleSlider.Input` is Moderno's; every other part is Ark's unchanged.
- A screen reader says the angle in degrees ("45 degrees"). Pass `getAriaValueText` to say it in another language.
- What the user types in the field turns the dial at once. The field shows the dial's angle again when the user leaves it or presses Enter: `400` becomes `40°`.
- For a number on a straight scale, use a Slider.
