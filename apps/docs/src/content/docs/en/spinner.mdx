## Usage

Use a spinner for a short wait when you cannot show the shape of what is coming: a form that is saving, a panel that is refreshing.

<ForFramework fw="react">


## API Reference

### Spinner

Renders a `<span role="status">`. `size` defaults to `md` and `label` to `"Loading"`.

<PropsTable component="Spinner" />

### Parts

| Part     | Element  | Description                                                   |
| -------- | -------- | ------------------------------------------------------------- |
| `root`   | `<span>` | `role="status"`. Carries `data-size`.                         |
| `circle` | `<span>` | The spinning ring. Paints with `currentColor`; `aria-hidden`. |
| `label`  | `<span>` | The `label` text, visually hidden.                            |

## Notes

- Spinner is CSS-only: a `<span>` with `data-scope="spinner"`, no Ark machine.
- The ring takes the text colour around it, so it fits inside a button or on a muted line.
- The ring turns slower for users who ask for reduced motion. It does not stop, because a still ring would not say that work is going on.
