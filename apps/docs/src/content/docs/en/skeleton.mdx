## Usage

Use a skeleton while content loads and you already know its layout. It shows the shape of what is coming, so the page does not jump when the content arrives.

<ForFramework fw="react">

```tsx
import { Skeleton } from "@moderno-ui/react";
```

```tsx
<Skeleton />
```

</ForFramework>

## API Reference

### Skeleton

Renders an empty `<span>` with `aria-hidden="true"`. `shape` defaults to `text`. Set the size with `style` or a class.

<PropsTable component="Skeleton" />

### Parts

| Part   | Element  | Description                                                                               |
| ------ | -------- | ----------------------------------------------------------------------------------------- |
| `root` | `<span>` | The placeholder. Carries `data-shape`. A block that fills the width, except for `circle`. |

## Notes

- Skeleton is CSS-only: a `<span>` with `data-scope="skeleton"`, no Ark machine.
- A skeleton says nothing to a screen reader. `aria-busy` on the loading region tells assistive tech to wait.
- The skeleton pulses slowly. It holds still for users who ask for reduced motion.
