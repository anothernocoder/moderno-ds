Each panel is `{ id, title, description, actionLabel }`. Leave out `actionLabel` for a panel with no button.

## API Reference

### Props

| Prop          | Type                   | Default              | Description                                                                   |
| ------------- | ---------------------- | -------------------- | ----------------------------------------------------------------------------- |
| `panels`      | `PanelItem[]`          | a sample set         | The panels, in reading order. `[]` renders the empty state.                   |
| `heading`     | `string`               | `"Account settings"` | The heading over the panels.                                                  |
| `description` | `string`               | a sentence           | The line under the heading; `""` hides it.                                    |
| `error`       | `string`               | —                    | The panels failed to load; an alert with a retry replaces them.               |
| `loading`     | `boolean`              | `false`              | Placeholder panels in a busy region replace the panels.                       |
| `disabled`    | `boolean`              | `false`              | The panels stay readable and every button is disabled.                        |
| `onAction`    | `(id: string) => void` | —                    | A panel's button, with that panel's `id`. Svelte: `onaction`. Vue: `@action`. |
| `onRetry`     | `() => void`           | —                    | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                  |

### PanelItem

| Field         | Type     | Description                                  |
| ------------- | -------- | -------------------------------------------- |
| `id`          | `string` | Stable identity, handed back by `onAction`.  |
| `title`       | `string` | What the panel groups.                       |
| `description` | `string` | One sentence on what is inside.              |
| `actionLabel` | `string` | Optional button label; name the panel in it. |

### States

| State    | Prop          | What renders                                                      |
| -------- | ------------- | ----------------------------------------------------------------- |
| Default  | —             | One card per panel.                                               |
| Empty    | `panels={[]}` | A "Nothing to set up yet" card.                                   |
| Loading  | `loading`     | Four placeholder panels in a busy `status` region.                |
| Error    | `error`       | One error alert with a "Try again" button in place of the panels. |
| Disabled | `disabled`    | The panels with every button disabled.                            |

### Sizing

| Container step           | What changes                                  |
| ------------------------ | --------------------------------------------- |
| below `@sm`              | One panel a row; each button spans its panel. |
| `@sm` (`--container-sm`) | Each button shrinks to its label.             |
| `@md` (`--container-md`) | Two panels a row and a larger heading.        |
| `@lg` (`--container-lg`) | Wider gaps between the panels.                |
