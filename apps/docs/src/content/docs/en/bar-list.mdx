## Usage

A Bar List ranks a few named things by one value. Use it for top pages, traffic sources or sales by region. Each row shows the name, a bar as long as its value, and the value itself, largest first.

<ForFramework fw="react">

```tsx
import { BarList } from "@moderno-ui/react";

const pages = [
  { name: "/", value: 1240 },
  { name: "/pricing", value: 860 },
  { name: "/docs", value: 540 },
];
```

```tsx
<BarList width={420} data={pages} aria-label="Visits by page" />
```

</ForFramework>

## API Reference

### BarList

<PropsTable component="BarList" />

### Data

Each entry in `data` is one row.

| Field   | Type     | Description                         |
| ------- | -------- | ----------------------------------- |
| `name`  | `string` | The text at the start of the row.   |
| `value` | `number` | Sets the bar length and is printed. |

A value of 0 or less draws an empty track. A value that is not a finite number (`NaN`, `Infinity`) draws no bar and prints nothing. It is left out of the default `max`, and a sorted list puts its row last.

### Defaults

| Prop         | Default                            |
| ------------ | ---------------------------------- |
| `max`        | The largest finite value in `data` |
| `sort`       | `"descending"`, largest first      |
| `labelWidth` | `120`                              |
| `valueWidth` | `64`                               |
| `rowHeight`  | `32`                               |
| `barHeight`  | `8`                                |
| `format`     | The number, rounded to 4 decimals  |

### Data attributes

| Attribute     | On            | Values                                                    |
| ------------- | ------------- | --------------------------------------------------------- |
| `data-chart`  | Root `svg`    | `bar-list`                                                |
| `data-part`   | Every element | `root`, `series`, `row`, `label`, `track`, `bar`, `value` |
| `data-series` | Series `g`    | `0`, mapped to `--chart-1`                                |

## Examples

### Sort order

Pass `sort="none"` to keep the order of `data`, for rows with a natural order like days. `"ascending"` puts the smallest first.

### Maximum

Set `max` to measure every bar against a fixed total, like a goal of 100%. A value above `max` fills its track.

`rowHeight` sets the space each row takes and `barHeight` the thickness of its bar. Smaller rows fit a longer list.

## Notes

- There is no colour prop: bars paint from `--chart-1`, and each track is the same colour, faint.
- Names use `--foreground` and values `--muted-foreground`.
- Names are not cut short. Keep them short, or give them more room with `labelWidth`.
- The list is as tall as its rows. Like every chart, it fills its container's width and scales its text with it.
- The geometry comes from `@moderno-ui/charts-core`, pure math with no DOM, so it renders on the server.
