## API Reference

### Alert.Root

`variant` defaults to `info` and `size` to `md`.

<PropsTable component="Alert" />

| Prop   | Type     | Default        | Description                                    |
| ------ | -------- | -------------- | ---------------------------------------------- |
| `role` | `string` | From `variant` | Overrides the live-region role (see Statuses). |

### Alert.Icon

A slot for your own glyph; the part colours it with the status hue through `currentColor`.

| Prop          | Type      | Default | Description                                     |
| ------------- | --------- | ------- | ----------------------------------------------- |
| `aria-hidden` | `boolean` | `true`  | Hides the decorative glyph from assistive tech. |

### Parts

Every part renders a `<div>` and accepts any div attribute.

| Part                | `data-part`   | Description                                                           |
| ------------------- | ------------- | --------------------------------------------------------------------- |
| `Alert.Root`        | `root`        | The region. Carries `data-variant` and `data-size`.                   |
| `Alert.Icon`        | `icon`        | Optional glyph before the content.                                    |
| `Alert.Content`     | `content`     | Column that holds the title, description and action.                  |
| `Alert.Title`       | `title`       | The headline.                                                         |
| `Alert.Description` | `description` | Supporting copy.                                                      |
| `Alert.Action`      | `action`      | Optional action, placed inside `Alert.Content` under the description. |

### Statuses

| `variant` | Colour slot     | `role`              |
| --------- | --------------- | ------------------- |
| `info`    | `--info`        | `status` (polite)   |
| `success` | `--success`     | `status` (polite)   |
| `warning` | `--warning`     | `alert` (assertive) |
| `error`   | `--destructive` | `alert` (assertive) |

## Notes

- Alert is CSS-only: no Ark machine, just parts carrying `data-scope="alert"` and their `data-part`.
- The primitive ships no icon set; pass your own glyph to `Alert.Icon`.
- An alert already on the page at load is not announced; render it in response to the event it reports.
