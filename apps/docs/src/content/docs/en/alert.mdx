Alert is a CSS-only primitive: Ark has no alert machine because an alert has no
behaviour to own — it is a static region. So, like Button, it is the contract in
its purest form: elements carrying `data-scope`/`data-part` plus the recipe's
`data-variant`/`data-size`, with every pixel coming from `components.css`.

The anatomy is `root > icon + content(> title + description + action)`. `Icon`
is a slot, never an icon set: primitives stay icon-agnostic, so you pass your own
glyph and the part hands it the status hue through `currentColor`.

## Statuses

`info`, `success`, `warning` and `error` each tint one surface from the matching
contract slot — `--info`, `--success`, `--warning`, and `--destructive` for
`error`, so a destructive action and an error message speak with one voice.
Urgency follows the status: `warning` and `error` render `role="alert"`
(assertive), `info` and `success` `role="status"` (polite).
