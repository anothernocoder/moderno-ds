## API Reference

### BarChart

<PropsTable component="BarChart" />

### Series

Each entry in `series` is one set of bars, one per category.

| Field    | Type       | Description                                                                           |
| -------- | ---------- | ------------------------------------------------------------------------------------- |
| `name`   | `string`   | Optional label for the series.                                                        |
| `values` | `number[]` | One value per category, aligned to `categories` by index. A missing value draws as 0. |

### Defaults

| Prop      | Default                                              |
| --------- | ---------------------------------------------------- |
| `padding` | `0.2`                                                |
| `yDomain` | Every value plus 0, rounded outward to nice numbers. |
| `yTicks`  | `5`                                                  |
| `margin`  | `{ top: 16, right: 16, bottom: 28, left: 36 }`       |
| `format`  | The number, rounded to 4 decimals                    |

### Data attributes

| Attribute     | On            | Values                                                                  |
| ------------- | ------------- | ----------------------------------------------------------------------- |
| `data-chart`  | Root `svg`    | `bar`                                                                   |
| `data-part`   | Every element | `root`, `grid`, `grid-line`, `axis-line`, `tick-label`, `series`, `bar` |
| `data-series` | Series `g`    | 0-based index, mapped to `--chart-1` through `--chart-5`                |

## Notes

- Series have no category key, so every series needs one value per category.
- There is no colour prop: series paint from `--chart-1` to `--chart-5` by index.
- Grid, axes and tick labels use `--border` and `--muted-foreground`.
