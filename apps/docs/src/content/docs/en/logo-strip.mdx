    - "The empty box is a dashed --border."

## API Reference

### Props

| Prop       | Type              | Default          | Description                                                          |
| ---------- | ----------------- | ---------------- | -------------------------------------------------------------------- |
| `heading`  | `string`          | a sentence       | The short line above the logos. Rendered as an `h2`.                 |
| `logos`    | `LogoStripLogo[]` | six sample logos | The logos, in order. `[]` shows the empty message.                   |
| `error`    | `string`          | —                | Loading the logos failed; an error Alert with a retry replaces them. |
| `loading`  | `boolean`         | `false`          | Skeleton lines in a busy region replace the logos.                   |
| `disabled` | `boolean`         | `false`          | The logos stay; every link is inert and the retry button disabled.   |
| `onRetry`  | `() => void`      | —                | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.         |

### Logo

| Field  | Type                                                                     | Description                                  |
| ------ | ------------------------------------------------------------------------ | -------------------------------------------- |
| `id`   | `string`                                                                 | A stable key for the logo.                   |
| `name` | `string`                                                                 | The wordmark. It is also the link's name.    |
| `mark` | `"circle" \| "ring" \| "square" \| "triangle" \| "diamond" \| "hexagon"` | The shape drawn before the wordmark.         |
| `href` | `string`                                                                 | Where the logo links, like a customer story. |

### States

| State    | Prop         | What renders                                             |
| -------- | ------------ | -------------------------------------------------------- |
| Default  | —            | The heading and every logo.                              |
| Empty    | `logos={[]}` | The heading and "No logos to show yet." in a dashed box. |
| Loading  | `loading`    | The heading and six placeholder lines.                   |
| Error    | `error`      | The heading and an error Alert with "Try again".         |
| Disabled | `disabled`   | The same logos, each link inert.                         |

### Sizing

| Container step           | What changes                                          |
| ------------------------ | ----------------------------------------------------- |
| below `@sm`              | Two logos per row.                                    |
| `@sm` (`--container-sm`) | Three logos per row.                                  |
| `@md` (`--container-md`) | The marks and wordmarks step up one size.             |
| `@lg` (`--container-lg`) | Six logos on one row, with more room above and below. |

## Notes

- Show logos only with each customer's permission.
- Keep them all one colour. A single logo in full colour pulls the eye away from the rest.
