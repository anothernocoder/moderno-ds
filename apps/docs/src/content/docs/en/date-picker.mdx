Use a date picker when the user enters a date: a due date, a birthday, a trip. They can type it or pick it from a calendar. It picks one date or a range, and writes dates the way the user's locale does.

## Installation

<Install pkg="@moderno-ui/react" />

## Usage

Dates are `DateValue` objects. Use `parseDate("2024-05-01")` to make one.

<ForFramework fw="react">

```tsx
import { DatePicker, Portal } from "@moderno-ui/react";
```

```tsx
<DatePicker.Root>
  <DatePicker.Label>Due date</DatePicker.Label>
  <DatePicker.Control>
    <DatePicker.Input />
    <DatePicker.Trigger aria-label="Open calendar">▾</DatePicker.Trigger>
  </DatePicker.Control>
  <Portal>
    <DatePicker.Positioner>
      <DatePicker.Content>
        <DatePicker.View view="day">
          <DatePicker.Context>
            {(datePicker) => (
              <>
                <DatePicker.ViewControl>
                  <DatePicker.PrevTrigger>‹</DatePicker.PrevTrigger>
                  <DatePicker.RangeText />
                  <DatePicker.NextTrigger>›</DatePicker.NextTrigger>
                </DatePicker.ViewControl>
                <DatePicker.Table>
                  <DatePicker.TableHead>
                    <DatePicker.TableRow>
                      {datePicker.weekDays.map((weekDay, i) => (
                        <DatePicker.TableHeader key={i}>{weekDay.short}</DatePicker.TableHeader>
                      ))}
                    </DatePicker.TableRow>
                  </DatePicker.TableHead>
                  <DatePicker.TableBody>
                    {datePicker.weeks.map((week, i) => (
                      <DatePicker.TableRow key={i}>
                        {week.map((day, j) => (
                          <DatePicker.TableCell key={j} value={day}>
                            <DatePicker.TableCellTrigger>{day.day}</DatePicker.TableCellTrigger>
                          </DatePicker.TableCell>
                        ))}
                      </DatePicker.TableRow>
                    ))}
                  </DatePicker.TableBody>
                </DatePicker.Table>
              </>
            )}
          </DatePicker.Context>
        </DatePicker.View>
      </DatePicker.Content>
    </DatePicker.Positioner>
  </Portal>
</DatePicker.Root>
```

</ForFramework>

## API Reference

### DatePicker.Root

`size` is the Moderno addition. The other props come from Ark's DatePicker.

<PropsTable component="DatePicker" />

| Prop                | Type                                                | Default    | Description                                                                                   |
| ------------------- | --------------------------------------------------- | ---------- | --------------------------------------------------------------------------------------------- |
| `value`             | `DateValue[]`                                       | —          | Controlled value. Pair with `onValueChange` (`bind:value` in Svelte, `v-model` in Vue).       |
| `defaultValue`      | `DateValue[]`                                       | `[]`       | Value at first when uncontrolled.                                                             |
| `onValueChange`     | `(details: { value, valueAsString, view }) => void` | —          | Called when the user picks or types a date.                                                   |
| `selectionMode`     | `"single" \| "multiple" \| "range"`                 | `"single"` | One date, several dates, or a start and an end.                                               |
| `locale`            | `string`                                            | `"en-US"`  | Language and region for the input format, the month names and the weekdays.                   |
| `timeZone`          | `string`                                            | `"UTC"`    | Time zone used to find today.                                                                 |
| `startOfWeek`       | `number`                                            | —          | First day of the week, `0` (Sunday) to `6`. Defaults to the locale's.                         |
| `min` / `max`       | `DateValue`                                         | —          | The earliest and latest date the user can pick.                                               |
| `isDateUnavailable` | `(date, locale) => boolean`                         | —          | Marks single days that cannot be picked.                                                      |
| `open`              | `boolean`                                           | —          | Controlled open state. Pair with `onOpenChange`.                                              |
| `defaultOpen`       | `boolean`                                           | `false`    | Open state at first when uncontrolled.                                                        |
| `closeOnSelect`     | `boolean`                                           | `true`     | Closes the calendar once a date (or the end of a range) is picked.                            |
| `numOfMonths`       | `number`                                            | `1`        | Months shown side by side.                                                                    |
| `defaultView`       | `"day" \| "month" \| "year"`                        | `"day"`    | The view the calendar opens on. `minView` and `maxView` limit the views.                      |
| `fixedWeeks`        | `boolean`                                           | `false`    | Always shows six weeks, so the calendar keeps its height.                                     |
| `disabled`          | `boolean`                                           | `false`    | Turns the whole field off.                                                                    |
| `readOnly`          | `boolean`                                           | `false`    | Shows the value but the user cannot change it.                                                |
| `invalid`           | `boolean`                                           | `false`    | Marks the value as wrong: the box turns `--destructive`.                                      |
| `name`              | `string`                                            | —          | Name of the input, for forms.                                                                 |
| `positioning`       | `PositioningOptions`                                | —          | Where the calendar goes: `placement`, `gutter`, `flip`, …                                     |
| `inline`            | `boolean`                                           | `false`    | Shows the calendar in the page, always open. Render the Content without Positioner or Portal. |

### Portal

Renders its children at the end of `document.body`, so no parent's `overflow` or stacking clips the calendar.

### Parts

Every part accepts its element's attributes.

| Part                          | Element    | Description                                                             |
| ----------------------------- | ---------- | ----------------------------------------------------------------------- |
| `DatePicker.Root`             | `<div>`    | Holds the field and its calendar. Carries `data-size`.                  |
| `DatePicker.Label`            | `<label>`  | Names the field. Clicking it focuses the input.                         |
| `DatePicker.Control`          | `<div>`    | The bordered box around the input and the buttons.                      |
| `DatePicker.Input`            | `<input>`  | Takes a typed date. Two in range mode: `index={0}` and `index={1}`.     |
| `DatePicker.Trigger`          | `<button>` | Opens and closes the calendar.                                          |
| `DatePicker.ClearTrigger`     | `<button>` | Optional. Clears the value. Hidden while nothing is picked.             |
| `DatePicker.ValueText`        | `<span>`   | Optional. The picked date as text, for a trigger with no input.         |
| `DatePicker.Positioner`       | `<div>`    | Ark places it under the control. Holds the content.                     |
| `DatePicker.Content`          | `<div>`    | The calendar surface. Carries `data-size`.                              |
| `DatePicker.View`             | `<div>`    | One view: `view="day"`, `"month"` or `"year"`. Ark shows one at a time. |
| `DatePicker.Context`          | —          | Hands you the picker's state: `weekDays`, `weeks`, `getMonthsGrid()`, … |
| `DatePicker.ViewControl`      | `<div>`    | The row above the grid.                                                 |
| `DatePicker.PrevTrigger`      | `<button>` | Shows the previous month, year or decade.                               |
| `DatePicker.ViewTrigger`      | `<button>` | The title. Switches to the next wider view.                             |
| `DatePicker.RangeText`        | `<div>`    | The visible month or year, as text.                                     |
| `DatePicker.NextTrigger`      | `<button>` | Shows the next month, year or decade.                                   |
| `DatePicker.Table`            | `<table>`  | The grid, with `role="grid"`.                                           |
| `DatePicker.TableHead`        | `<thead>`  | Holds the weekday names.                                                |
| `DatePicker.TableHeader`      | `<th>`     | One weekday's name.                                                     |
| `DatePicker.TableBody`        | `<tbody>`  | Holds the weeks.                                                        |
| `DatePicker.TableRow`         | `<tr>`     | One week, or one row of months or years.                                |
| `DatePicker.TableCell`        | `<td>`     | One cell. Takes the day, month or year as `value`.                      |
| `DatePicker.TableCellTrigger` | `<div>`    | The button inside a cell. A `<button>` in Svelte.                       |
| `DatePicker.MonthSelect`      | `<select>` | Optional. A native list of months.                                      |
| `DatePicker.YearSelect`       | `<select>` | Optional. A native list of years.                                       |
| `DatePicker.PresetTrigger`    | `<button>` | Optional. Picks a preset range, like `value="last7Days"`.               |

### Data attributes

| Attribute            | Values                                                                                                                                 |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `data-size`          | On the root and the content: `"sm"`, `"md"` or `"lg"`                                                                                  |
| `data-state`         | `"open"` or `"closed"`, on the root, the trigger and the content                                                                       |
| `data-selected`      | On a picked day (or each end of a range)                                                                                               |
| `data-today`         | On today                                                                                                                               |
| `data-in-range`      | On the days of a range, ends included                                                                                                  |
| `data-range-start`   | On the first day of a range                                                                                                            |
| `data-range-end`     | On the last day of a range                                                                                                             |
| `data-outside-range` | On a day of the previous or next month                                                                                                 |
| `data-unavailable`   | On a day outside `min` / `max` (it also has `aria-invalid`), or one `isDateUnavailable` turned off. Only the second kind is struck out |
| `data-disabled`      | On a day that cannot be picked, and on every part of a disabled root                                                                   |

### Keyboard

| Key                     | Action                                                         |
| ----------------------- | -------------------------------------------------------------- |
| `Enter`                 | In the input, takes the typed date.                            |
| `Arrow keys`            | In the grid, move one day or one week.                         |
| `Page Up` / `Page Down` | In the grid, move one month.                                   |
| `Home` / `End`          | In the grid, go to the first or last day of the visible month. |
| `Enter` / `Space`       | In the grid, pick the focused day.                             |
| `Esc`                   | Closes the calendar and moves focus to the trigger.            |

## Notes

- `DatePicker.Root` and `DatePicker.Content` are wrapped to add `size`; every other part is Ark's unchanged.
- Parsing, formatting, keyboard moves and `min` / `max` come from Ark; don't reimplement them.
- `onValueChange` gives `details.valueAsString` formatted for the locale. Use `details.value.map(String)` for ISO dates.
