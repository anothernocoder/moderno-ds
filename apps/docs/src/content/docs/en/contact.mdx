## API Reference

### Props

| Prop          | Type                     | Default              | Description                                                  |
| ------------- | ------------------------ | -------------------- | ------------------------------------------------------------ |
| `heading`     | `string`                 | `"Get in touch"`     | The section's heading. Set in the serif face.                |
| `description` | `string`                 | a sentence           | One sentence under the heading; `""` hides it.               |
| `channels`    | `ContactChannel[]`       | email, phone, office | The ways to reach you, in order. `[]` hides them.            |
| `error`       | `string`                 | —                    | Sending failed; an error Alert sits at the top of the form.  |
| `errors`      | `Record<string, string>` | —                    | A message per field, under `name`, `email` or `message`.     |
| `loading`     | `boolean`                | `false`              | Every field disabled and the button a busy "Sending".        |
| `disabled`    | `boolean`                | `false`              | Every field and the button disabled. The channel links stay. |
| `sent`        | `boolean`                | `false`              | A success Alert replaces the form.                           |
| `onSubmit`    | `(event) => void`        | —                    | The form's submit event. Svelte: `onsubmit`. Vue: `@submit`. |

### Channel

| Field   | Type                             | Description                                            |
| ------- | -------------------------------- | ------------------------------------------------------ |
| `id`    | `string`                         | A stable key for the channel.                          |
| `kind`  | `"email" \| "phone" \| "office"` | Picks the icon: an envelope, a phone or a map pin.     |
| `label` | `string`                         | The small line above the value, like `"Email"`.        |
| `value` | `string`                         | What the visitor reads, like `"hello@example.com"`.    |
| `href`  | `string`                         | Optional. The value becomes a link, like `"mailto:…"`. |

### States

| State    | Prop             | What renders                                               |
| -------- | ---------------- | ---------------------------------------------------------- |
| Default  | —                | Heading, introduction, the channels and the form.          |
| Empty    | `channels={[]}`  | Heading, introduction and the form alone.                  |
| Loading  | `loading`        | The same form with its fields disabled and "Sending".      |
| Error    | `error`/`errors` | An error Alert at the top of the form, and invalid fields. |
| Disabled | `disabled`       | The same form with its fields and button disabled.         |
| Sent     | `sent`           | The channels and "Message sent" in place of the form.      |

### Sizing

| Container step           | What changes                                                      |
| ------------------------ | ----------------------------------------------------------------- |
| below `@sm`              | Everything stacks. The send button is full width.                 |
| `@sm` (`--container-sm`) | The reply note sits beside the send button.                       |
| `@md` (`--container-md`) | The heading steps up a size. Name and email sit side by side.     |
| `@lg` (`--container-lg`) | The channels sit beside the form, with more room above and below. |

## Notes

- Keep `error` short and say what failed. The form keeps what the visitor typed, so they can send it again.
- List only the channels someone answers. An email nobody reads is worse than none.
