## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`oncontinue`) in Svelte, and emits (`continue`, `skip`, `retry`, `navigate`) in Vue.

| Prop          | Type                  | Default | Description                                                         |
| ------------- | --------------------- | ------- | ------------------------------------------------------------------- |
| `name`        | `string`              | —       | The reader's first name. The title greets them: "Welcome, Ana".     |
| `error`       | `string`              | —       | The workspace could not be prepared: an alert with a retry.         |
| `loading`     | `boolean`             | `false` | The workspace is being prepared: placeholders in a busy region.     |
| `disabled`    | `boolean`             | `false` | Continue and Skip are shown but inert.                              |
| `onContinue`  | `() => void`          | —       | "Continue" was pressed.                                             |
| `onSkip`      | `() => void`          | —       | "Skip for now" was pressed.                                         |
| `onRetry`     | `() => void`          | —       | "Try again" was pressed, inside the error.                          |
| `onNavigate`  | `(to, event) => void` | —       | A screen link was clicked: `home`, `support`, `privacy` or `terms`. |
| `homeHref`    | `string`              | `"#"`   | Target of the wordmark.                                             |
| `supportHref` | `string`              | `"#"`   | Target of "Contact support".                                        |
| `privacyHref` | `string`              | `"#"`   | Target of the privacy link.                                         |
| `termsHref`   | `string`              | `"#"`   | Target of the terms link.                                           |

### States

| State    | Props      | Renders                                                          |
| -------- | ---------- | ---------------------------------------------------------------- |
| Default  | —          | The hero, centred between the masthead and the footer.           |
| Loading  | `loading`  | Placeholders in a busy region; no buttons.                       |
| Error    | `error`    | The title stays; an alert with "Try again" replaces the buttons. |
| Disabled | `disabled` | Continue and Skip are shown but can't be used.                   |

### Sizing

| Container step           | Change                           |
| ------------------------ | -------------------------------- |
| `@sm` (`--container-sm`) | The masthead moves onto one row. |
| `@md` (`--container-md`) | The footer moves onto one row.   |

### Composition

| Part              | Role                                                             |
| ----------------- | ---------------------------------------------------------------- |
| [Hero](/en/hero/) | The greeting, the subtitle and the buttons, with its own states. |

## Notes

- Presentational: no request, no router. The page that mounts it decides where Continue and Skip go.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The root is a `<div>`, not a `<main>`. Make it your `<main>` if the route has none.
- The screen imports the Hero block from `@/components/blocks/…`; edit that line if your alias differs.
