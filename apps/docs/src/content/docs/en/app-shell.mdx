## Usage

Use App Shell once, around every page of a signed-in app. It holds the navigation and the account menu, and your page goes inside it.

<ForFramework fw="react">

```tsx
import { AppShell } from "@/components/blocks/app-shell";
```

```tsx
<AppShell heading="Invoices" navigation={navigation} user={user}>
  <InvoiceList />
</AppShell>
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import AppShell from "@/components/blocks/AppShell.vue";
</script>
```

```vue
<AppShell heading="Invoices" :navigation="navigation" :user="user">
  <InvoiceList />
</AppShell>
```

</ForFramework>
<ForFramework fw="svelte">

```tsx
import { AppShell } from "@/components/blocks/app-shell";
```


Each link looks like `{ id: "invoices", label: "Invoices", href: "/invoices", current: true }`. The user looks like `{ name: "Ada Lovelace", email: "ada@acme.com" }`.

## API Reference

### Props

| Prop           | Type                                   | Default           | Description                                                                                  |
| -------------- | -------------------------------------- | ----------------- | -------------------------------------------------------------------------------------------- |
| `brand`        | `string`                               | `"Acme"`          | The product's name, at the top of the sidebar and the Drawer.                                |
| `heading`      | `string`                               | `"Overview"`      | The page's `h1`, in the top bar. It is set in the serif face.                                |
| `navigation`   | `AppShellNavItem[]`                    | five sample links | The main navigation, in the sidebar and in the Drawer.                                       |
| `user`         | `AppShellUser`                         | a sample user     | The signed-in user, on the account menu.                                                     |
| `error`        | `string`                               | —                 | Loading the page failed; an error Alert with a retry replaces the content.                   |
| `loading`      | `boolean`                              | `false`           | Placeholders in a busy region replace the content.                                           |
| `children`     | page content                           | —                 | The page. Svelte: a `children` snippet. Vue: the default slot. Without it, an empty message. |
| `onRetry`      | `() => void`                           | —                 | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                                 |
| `onUserSelect` | `(action: AppShellUserAction) => void` | —                 | An item of the account menu. Svelte: `onuserselect`. Vue: `@user-select`.                    |

### AppShellNavItem

| Field      | Type      | Description                                                        |
| ---------- | --------- | ------------------------------------------------------------------ |
| `id`       | `string`  | A stable key for the link.                                         |
| `label`    | `string`  | The link's text.                                                   |
| `href`     | `string`  | Where the link goes.                                               |
| `current`  | `boolean` | Optional. The page the user is on: `aria-current="page"`, filled.  |
| `disabled` | `boolean` | Optional. The link is dimmed, has no `href` and cannot be focused. |

### AppShellUser

| Field   | Type     | Description                                                                  |
| ------- | -------- | ---------------------------------------------------------------------------- |
| `name`  | `string` | The user's name. The trigger shows it, or its initials when narrow.          |
| `email` | `string` | Shown under the name at the top of the account menu.                         |
| `image` | `string` | Optional. The avatar's image URL. Without it, the avatar shows the initials. |

`AppShellUserAction` is `"profile" | "settings" | "sign-out"`.

### States

| State    | Prop                 | What renders                                    |
| -------- | -------------------- | ----------------------------------------------- |
| Default  | children             | The sidebar, the top bar and your page.         |
| Empty    | no children          | "Nothing here yet" in a dashed box.             |
| Loading  | `loading`            | Three placeholders in the content.              |
| Error    | `error`              | An error Alert with "Try again" in the content. |
| Disabled | `disabled` on a link | That link dimmed, out of the tab order.         |

### Sizing

| Container step           | What changes                                                                 |
| ------------------------ | ---------------------------------------------------------------------------- |
| below `@sm`              | The navigation is in a Drawer, opened by "Menu". The trigger shows initials. |
| `@sm` (`--container-sm`) | The trigger shows the user's name. More room around the content.             |
| `@md` (`--container-md`) | The sidebar shows the navigation. The "Menu" button goes away.               |
| `@lg` (`--container-lg`) | A wider sidebar, and more room around the content.                           |

## Notes

- Keep link labels to one or two words, so they fit the sidebar on one line.
- Put a page's own tabs, filters and actions in the content, not in the top bar.
