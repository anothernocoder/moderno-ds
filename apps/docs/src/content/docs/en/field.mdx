## API Reference

### Field.Root

`size` is the Moderno addition and defaults to `md`; the other props come from Ark's Field.

<PropsTable component="Field" />

| Prop       | Type      | Default | Description                                                                          |
| ---------- | --------- | ------- | ------------------------------------------------------------------------------------ |
| `invalid`  | `boolean` | `false` | Switches border, tint and focus ring to `--destructive` and shows `Field.ErrorText`. |
| `disabled` | `boolean` | `false` | Disables the control and dims every part.                                            |
| `required` | `boolean` | `false` | Sets `required` on the control and `data-required` on the label.                     |
| `readOnly` | `boolean` | `false` | Sets `readOnly` on the control.                                                      |

### Field.Textarea

Shares the input's border, radius, focus ring and invalid treatment, with a minimum height per size and vertical resize only.

| Prop         | Type      | Default | Description                          |
| ------------ | --------- | ------- | ------------------------------------ |
| `autoresize` | `boolean` | `false` | Grows the textarea with its content. |

### Parts

| Part                      | Element              | Description                                                                              |
| ------------------------- | -------------------- | ---------------------------------------------------------------------------------------- |
| `Field.Root`              | `<div role="group">` | Carries `data-size`, `data-invalid`, `data-disabled` and `data-readonly`.                |
| `Field.Label`             | `<label>`            | Bound to the control's `id` automatically.                                               |
| `Field.Input`             | `<input>`            | Single-line control.                                                                     |
| `Field.Textarea`          | `<textarea>`         | Multi-line control.                                                                      |
| `Field.HelperText`        | `<span>`             | Linked to the control through `aria-describedby`.                                        |
| `Field.ErrorText`         | `<span>`             | Rendered only while `invalid`; linked through `aria-describedby` and announced politely. |
| `Field.RequiredIndicator` | `<span>`             | Rendered only while `required`; hidden from assistive tech.                              |

## Notes

- Put `size` on `Field.Root`, not on the control: one `data-size` sizes every part.
- Don't add `htmlFor` or ids by hand; the parts wire the label, control and messages together.
- Put validation copy in `Field.ErrorText`, not in a sibling element, so it is announced with the field.
- The input border uses `--input` and the focus ring `--ring`; disabled fills with `--muted`.
