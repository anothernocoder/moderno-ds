## API Reference

### Button

Renders a native `<button>`. `variant` defaults to `primary` and `size` to `md`.

<PropsTable component="Button" />

### Data attributes

| Attribute      | Values                 |
| -------------- | ---------------------- |
| `data-scope`   | `"button"`             |
| `data-part`    | `"root"`               |
| `data-variant` | The resolved `variant` |
| `data-size`    | The resolved `size`    |

## Notes

- Button holds no colour or radius of its own; switching the theme re-skins it without touching the markup.
- `destructive` paints from `--destructive`, the same slot an error Alert and an invalid Field use.
- `type` defaults to `"button"`, so a Button inside a form never submits it unless you pass `type="submit"`.
- `disabled` is the native attribute: the button leaves the tab order and ignores clicks.
- Pick a `variant` instead of overriding colour with a class, and pass `disabled` instead of styling it.
