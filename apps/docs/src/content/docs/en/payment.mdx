Use it for the payment step of checkout. The shopper enters a card and sees what they pay for; your page charges the card.

`pay` gets the form's submit event. Stop the page from reloading, then send the card:

```ts
function pay(event) {
  event.preventDefault();
  const card = new FormData(event.currentTarget);
  // Send card.get("cardNumber"), card.get("expiry"), … to your payment provider.
}
```

## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`onsubmit`) in Svelte, and emits (`submit`, `back`, `retry`, `navigate`) in Vue.

| Prop          | Type                     | Default             | Description                                                           |
| ------------- | ------------------------ | ------------------- | --------------------------------------------------------------------- |
| `heading`     | `string`                 | `"Payment"`         | The page's `h1`, the checkout-form block's heading.                   |
| `description` | `string`                 | the block's line    | The line under the heading; `""` hides it.                            |
| `items`       | `OrderItem[]`            | the block's samples | The lines being paid for. `[]` shows the empty message.               |
| `totals`      | `OrderTotal[]`           | the block's samples | The rows above the total: `{ label, amount }`.                        |
| `total`       | `string`                 | the block's sample  | The amount to pay as people read it, like `"€168"`.                   |
| `error`       | `string`                 | —                   | The payment failed: an alert above the card fields.                   |
| `errors`      | `Record<string, string>` | —                   | A message under each wrong card field, keyed by its `name`.           |
| `submitting`  | `boolean`                | `false`             | The order is being placed: Place order spins, every control is inert. |
| `loading`     | `boolean`                | `false`             | The order is loading: placeholder lines replace the summary.          |
| `orderError`  | `string`                 | —                   | The order failed to load: an alert with a retry replaces the summary. |
| `disabled`    | `boolean`                | `false`             | Everything stays on screen; every control is inert.                   |
| `onSubmit`    | `(event) => void`        | —                   | Place order was pressed. Call `preventDefault()` to stay on the page. |
| `onBack`      | `() => void`             | —                   | Back to shipping was pressed.                                         |
| `onRetry`     | `() => void`             | —                   | "Try again" after `orderError`.                                       |
| `onNavigate`  | `(to, event) => void`    | —                   | A screen link was clicked: `home`, `cart`, `privacy` or `terms`.      |
| `homeHref`    | `string`                 | `"#"`               | Target of the wordmark.                                               |
| `cartHref`    | `string`                 | `"#"`               | Target of "Edit cart".                                                |
| `privacyHref` | `string`                 | `"#"`               | Target of the privacy link.                                           |
| `termsHref`   | `string`                 | `"#"`               | Target of the terms link.                                             |

The card fields are named `cardName`, `cardNumber`, `expiry`, `cvc` and `saveCard`.

### States

| State         | Props        | Renders                                                       |
| ------------- | ------------ | ------------------------------------------------------------- |
| Default       | —            | The card form and the order summary with its total.           |
| Declined      | `error`      | An alert above the card fields; `errors` marks each field.    |
| Placing order | `submitting` | "Placing order" with a spinner; every control inert.          |
| Loading       | `loading`    | The card form, and placeholder lines in place of the summary. |
| Order error   | `orderError` | The card form, and an alert with "Try again" for the summary. |
| Empty         | `items=[]`   | The card form, and "Your order is empty." for the summary.    |
| Disabled      | `disabled`   | Everything shown, every control inert.                        |

### Sizing

| Container step           | Change                                   |
| ------------------------ | ---------------------------------------- |
| `@sm` (`--container-sm`) | The masthead moves onto one row.         |
| `@md` (`--container-md`) | The footer moves onto one row.           |
| `@lg` (`--container-lg`) | The order summary moves beside the form. |

### Composition

| Part                                | Role                                                         |
| ----------------------------------- | ------------------------------------------------------------ |
| [Checkout Form](/en/checkout-form/) | The card form, with `step="payment"` and `headingLevel={1}`. |
| [Order Summary](/en/order-summary/) | The read-only lines and totals being paid for.               |

## Notes

- Presentational: no card is charged and no router is used. The page that mounts it does both.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The root is a `<div>`, not a `<main>`. Make it your `<main>` if the route has none.
- The screen imports its two blocks from `@/components/blocks/…`; edit those lines if your alias differs.
