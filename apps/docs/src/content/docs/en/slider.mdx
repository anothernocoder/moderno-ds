## Usage

Slider lets the user pick a number by dragging a thumb along a track. Use it when the rough position matters more than the exact digit, like volume. Two thumbs pick a range.

<ForFramework fw="react">

```tsx
import { Slider } from "@moderno-ui/react";
```

```tsx
<Slider.Root value={volume} onValueChange={(details) => setVolume(details.value)}>
  <Slider.Label>Volume</Slider.Label>
  <Slider.ValueText />
  <Slider.Control>
    <Slider.Track>
      <Slider.Range />
    </Slider.Track>
    <Slider.Thumb index={0}>
      <Slider.HiddenInput />
    </Slider.Thumb>
  </Slider.Control>
</Slider.Root>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Slider } from "@moderno-ui/vue";
```

```vue

    </Slider.Track>
```

</ForFramework>

The value is an array with one number per thumb. It runs from 0 to 100 by default.

## API Reference

### Slider.Root

`size` is the Moderno addition; every part follows it. The other props come from Ark's Slider.

<PropsTable component="Slider" />

| Prop                    | Type                                                    | Default        | Description                                       |
| ----------------------- | ------------------------------------------------------- | -------------- | ------------------------------------------------- |
| `value`                 | `number[]`                                              | —              | Controlled value, one number per thumb.           |
| `defaultValue`          | `number[]`                                              | `[min]`        | Value at first when uncontrolled.                 |
| `onValueChange`         | `(details: { value: number[] }) => void`                | —              | Called while the value changes.                   |
| `onValueChangeEnd`      | `(details: { value: number[] }) => void`                | —              | Called once, when the user lets go.               |
| `min`                   | `number`                                                | `0`            | The lowest value.                                 |
| `max`                   | `number`                                                | `100`          | The highest value.                                |
| `step`                  | `number`                                                | `1`            | How far one move goes.                            |
| `minStepsBetweenThumbs` | `number`                                                | `0`            | How many steps a range's thumbs keep apart.       |
| `orientation`           | `"horizontal" \| "vertical"`                            | `"horizontal"` | Lays the track across or stands it up.            |
| `origin`                | `"start" \| "center" \| "end"`                          | `"start"`      | Where the range of one thumb starts filling from. |
| `disabled`              | `boolean`                                               | `false`        | Dims the slider and ignores input.                |
| `readOnly`              | `boolean`                                               | `false`        | Shows the value but ignores input.                |
| `invalid`               | `boolean`                                               | `false`        | Marks the value as wrong.                         |
| `name`                  | `string`                                                | —              | The form field name of the hidden inputs.         |
| `getAriaValueText`      | `(details: { value: number; index: number }) => string` | —              | What a screen reader says for a thumb's value.    |

In Vue, bind the value with `:model-value` or `v-model`, and listen with `@value-change`.

### Slider.Thumb

| Prop    | Type     | Default | Description                              |
| ------- | -------- | ------- | ---------------------------------------- |
| `index` | `number` | —       | Required. Which value this thumb moves.  |
| `name`  | `string` | —       | The form field name of its hidden input. |

### Slider.Marker

| Prop    | Type     | Default | Description                           |
| ------- | -------- | ------- | ------------------------------------- |
| `value` | `number` | —       | Required. The value the mark sits at. |

### Parts

| Part                       | Element   | Description                                                     |
| -------------------------- | --------- | --------------------------------------------------------------- |
| `Slider.Root`              | `<div>`   | Carries `data-size`.                                            |
| `Slider.Label`             | `<label>` | Optional. Names the value. Clicking it focuses the thumb.       |
| `Slider.ValueText`         | `<span>`  | Optional. The value, or both ends of a range.                   |
| `Slider.Control`           | `<div>`   | The area you click or drag in. Holds the track and thumbs.      |
| `Slider.Track`             | `<div>`   | The full line of possible values.                               |
| `Slider.Range`             | `<div>`   | The filled part of the track, up to or between the thumbs.      |
| `Slider.Thumb`             | `<div>`   | The handle, with `role="slider"` and `aria-valuenow`.           |
| `Slider.HiddenInput`       | `<input>` | Inside a thumb. Carries its value into a form.                  |
| `Slider.DraggingIndicator` | `<span>`  | Optional, inside a thumb. The value in a bubble while dragging. |
| `Slider.MarkerGroup`       | `<div>`   | Optional. Holds the marks, under the track.                     |
| `Slider.Marker`            | `<span>`  | A mark at one value, with your own text.                        |

### Data attributes

| Attribute          | Values                                                                      |
| ------------------ | --------------------------------------------------------------------------- |
| `data-orientation` | `"horizontal"` or `"vertical"`, on every part                               |
| `data-dragging`    | While a thumb is dragged, on the root, control, track, range and that thumb |
| `data-focus`       | While a thumb has focus, on the root and its parts                          |
| `data-disabled`    | When `disabled`, on every part                                              |
| `data-invalid`     | When `invalid`, on the root and its parts                                   |
| `data-state`       | On each marker: `"under-value"`, `"at-value"` or `"over-value"`             |
| `data-size`        | On the root: `"sm"`, `"md"` or `"lg"`                                       |

## Notes

- `Slider.Root` is wrapped to add `size`; every other part is Ark's unchanged.
- Each thumb is named by `Slider.Label`. A range's two thumbs share it; pass `aria-label` as an array to name each one.
- Ark hides a thumb until it has measured it, so the thumb stays inside the track at both ends.
- In Solid, `Slider.ValueText` joins a range's values with a bare comma (`20,80`); the other frameworks add a space.
- For an exact number the user types, use a Number Input.
