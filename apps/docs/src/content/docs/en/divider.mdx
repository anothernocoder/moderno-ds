## API Reference

### Divider

Renders a `<div>`; its children become the label. `orientation` defaults to `horizontal` and `align` to `center`.

<PropsTable component="Divider" />

### Parts

| Part    | Element  | Description                                                                                    |
| ------- | -------- | ---------------------------------------------------------------------------------------------- |
| `root`  | `<div>`  | The rule. Carries `data-orientation` and `data-align`; the stroke is its `::before`/`::after`. |
| `label` | `<span>` | Rendered only when there are children.                                                         |

### Semantics

| Divider            | `role`      | `aria-orientation` |
| ------------------ | ----------- | ------------------ |
| Bare (no children) | `separator` | The `orientation`  |
| Labelled           | none        | none               |

## Notes

- A labelled divider drops `role="separator"`, because that role would hide the label from assistive tech.
- `align` only moves the label; it does nothing on a bare divider.
- A vertical divider stretches to the height of its row, with a `--spacing-4` minimum.
- The stroke is `--border` and the label is `--muted-foreground`; never pass a colour.
