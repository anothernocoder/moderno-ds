## Usage

Use Shopping Cart for a shop's cart page. Shoppers see what they picked, change quantities, remove items and go to checkout.

<ForFramework fw="react">

```tsx
import { ShoppingCart } from "@/components/blocks/shopping-cart";
```

```tsx
<ShoppingCart
  items={items}
  subtotal={subtotal}
  onQuantityChange={setQuantity}
  onRemove={removeItem}
  onCheckout={goToCheckout}
/>
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import ShoppingCart from "@/components/blocks/ShoppingCart.vue";
</script>
```

```vue
<ShoppingCart
  :items="items"
  :subtotal="subtotal"
  @quantity-change="setQuantity"
  @remove="removeItem"
  @checkout="goToCheckout"
/>
```

</ForFramework>

The block does no maths. When a quantity changes, work out the line's price and the subtotal, and pass them back in.

## API Reference

### Props

| Prop               | Type                                     | Default                                       | Description                                                                                                                    |
| ------------------ | ---------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `heading`          | `string`                                 | `"Shopping cart"`                             | The section's heading. It is set in the serif face.                                                                            |
| `headingLevel`     | `1 \| 2`                                 | `2`                                           | Heading rank of the heading; the item names and "Order summary" sit one rank below. A full-page screen passes `1`.             |
| `items`            | `CartItem[]`                             | three sample items                            | The lines in the cart. `[]` shows the empty message.                                                                           |
| `subtotal`         | `string`                                 | `"€134"` with the samples                     | The subtotal as people read it. Left out, the summary has no subtotal row.                                                     |
| `note`             | `string`                                 | `"Shipping and taxes are added at checkout."` | A line under the subtotal; `""` hides it.                                                                                      |
| `error`            | `string`                                 | —                                             | Loading the cart failed; an error Alert with a retry replaces the lines and the summary.                                       |
| `loading`          | `boolean`                                | `false`                                       | Placeholder lines in a busy region replace the lines and the summary.                                                          |
| `disabled`         | `boolean`                                | `false`                                       | The lines stay; every link is inert and every quantity box and button is off.                                                  |
| `onQuantityChange` | `(id: string, quantity: number) => void` | —                                             | A line's quantity changed, always a whole number from 1 to `maxQuantity`. Svelte: `onquantitychange`. Vue: `@quantity-change`. |
| `onRemove`         | `(id: string) => void`                   | —                                             | A line's "Remove" was pressed. Svelte: `onremove`. Vue: `@remove`.                                                             |
| `onCheckout`       | `() => void`                             | —                                             | "Checkout" was pressed. Svelte: `oncheckout`. Vue: `@checkout`.                                                                |
| `onRetry`          | `() => void`                             | —                                             | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                                                                   |

### CartItem

| Field         | Type            | Description                                                   |
| ------------- | --------------- | ------------------------------------------------------------- |
| `id`          | `string`        | A stable key for the line. The callbacks report it.           |
| `name`        | `string`        | The product's name.                                           |
| `price`       | `string`        | The line's price for its whole quantity, like `"€56"`.        |
| `quantity`    | `number`        | How many are in the cart. The quantity box starts at it.      |
| `maxQuantity` | `number`        | Optional. The most a shopper can pick; `99` when left out.    |
| `options`     | `string`        | Optional. What the shopper chose, like `"Sage · 350 ml"`.     |
| `href`        | `string`        | Optional. Turns the name into a link to the product's page.   |
| `image`       | `CartItemImage` | Optional. The photo: `{ src, alt }`. Without it, a muted box. |

### States

| State    | Prop         | What renders                                                         |
| -------- | ------------ | -------------------------------------------------------------------- |
| Default  | —            | The heading, one line per item and the order summary.                |
| Empty    | `items={[]}` | The heading and "Your cart is empty." in a dashed box.               |
| Loading  | `loading`    | The heading and three placeholder lines.                             |
| Error    | `error`      | The heading and an error Alert with "Try again".                     |
| Disabled | `disabled`   | The same lines with links inert, and quantity boxes and buttons off. |

### Sizing

| Container step           | What changes                                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------------------------------- |
| below `@sm`              | A small image. The quantity and Remove sit on their own row, under the image. The summary sits under the lines. |
| `@sm` (`--container-sm`) | The image grows, and the quantity and Remove move beside it, under the name.                                    |
| `@md` (`--container-md`) | The image grows again, and the heading steps up.                                                                |
| `@lg` (`--container-lg`) | The summary moves beside the lines.                                                                             |
