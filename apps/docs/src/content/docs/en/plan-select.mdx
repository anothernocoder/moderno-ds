## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`onselect`) in Svelte, and emits (`select`, `retry`, `navigate`) in Vue.

| Prop          | Type                   | Default              | Description                                                          |
| ------------- | ---------------------- | -------------------- | -------------------------------------------------------------------- |
| `title`       | `string`               | `"Choose your plan"` | The page's `h1`, the pricing block's title.                          |
| `description` | `string`               | a sentence           | One or two sentences under the title; `""` hides them.               |
| `plans`       | `PricingPlan[]`        | the block's samples  | The plans, in order. `[]` shows the empty message.                   |
| `error`       | `string`               | —                    | Loading the plans failed; an error alert with a retry replaces them. |
| `loading`     | `boolean`              | `false`              | Placeholder cards in a busy region replace the plans.                |
| `disabled`    | `boolean`              | `false`              | The plans stay and every button is disabled.                         |
| `onSelect`    | `(id: string) => void` | —                    | A plan's button was pressed, with that plan's `id`.                  |
| `onRetry`     | `() => void`           | —                    | "Try again" after `error`.                                           |
| `onNavigate`  | `(to, event) => void`  | —                    | A screen link was clicked: `home`, `sales`, `privacy` or `terms`.    |
| `homeHref`    | `string`               | `"#"`                | Target of the wordmark.                                              |
| `salesHref`   | `string`               | `"#"`                | Target of "Talk to sales".                                           |
| `privacyHref` | `string`               | `"#"`                | Target of the privacy link.                                          |
| `termsHref`   | `string`               | `"#"`                | Target of the terms link.                                            |

### States

| State    | Props      | Renders                                         |
| -------- | ---------- | ----------------------------------------------- |
| Default  | —          | The plans, the recommended one outlined.        |
| Empty    | `plans=[]` | The title and a "No plans to show yet" message. |
| Loading  | `loading`  | The title and three placeholder cards.          |
| Error    | `error`    | The title and an error alert with "Try again".  |
| Disabled | `disabled` | The same plans with every button disabled.      |

### Sizing

| Container step           | Change                           |
| ------------------------ | -------------------------------- |
| `@sm` (`--container-sm`) | The masthead moves onto one row. |
| `@md` (`--container-md`) | The footer moves onto one row.   |

The plans stack or sit side by side by the Pricing block's own container steps.

### Composition

| Part                    | Role                              |
| ----------------------- | --------------------------------- |
| [Pricing](/en/pricing/) | The plans, with `titleLevel={1}`. |

## Notes

- Presentational: no request, no checkout, no router. The page that mounts it owns them.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The root is a `<div>`, not a `<main>`. Make it your `<main>` if the route has none.
- The screen imports the Pricing block from `@/components/blocks/…`; edit that line if your alias differs.
