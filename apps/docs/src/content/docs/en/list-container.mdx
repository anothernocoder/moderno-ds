Each row is `{ id, title, subtitle, meta, initials, avatarUrl, status, statusVariant }`. Only `id`, `title` and `initials` are required.

## API Reference

### Props

| Prop          | Type                  | Default            | Description                                                    |
| ------------- | --------------------- | ------------------ | -------------------------------------------------------------- |
| `items`       | `ListContainerItem[]` | a sample set       | The rows, in reading order. `[]` renders the empty state.      |
| `heading`     | `string`              | `"Sprint tasks"`   | The heading in the header. It also names the scroll area.      |
| `description` | `string`              | a sentence         | The line under the heading; `""` hides it.                     |
| `actionLabel` | `string`              | `"View all tasks"` | The footer button's label; `""` hides the button.              |
| `error`       | `string`              | —                  | The rows failed to load; an alert with a retry fills the body. |
| `loading`     | `boolean`             | `false`            | Placeholder rows in a busy region fill the body.               |
| `disabled`    | `boolean`             | `false`            | The rows stay readable and every button is disabled.           |
| `onAction`    | `() => void`          | —                  | The footer button. Svelte: `onaction`. Vue: `@action`.         |
| `onRetry`     | `() => void`          | —                  | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.   |

### ListContainerItem

| Field           | Type           | Description                                          |
| --------------- | -------------- | ---------------------------------------------------- |
| `id`            | `string`       | Stable identity.                                     |
| `title`         | `string`       | The row's main line. Cut with an ellipsis when long. |
| `subtitle`      | `string`       | Optional second line.                                |
| `meta`          | `string`       | Optional short fact, such as a due date.             |
| `initials`      | `string`       | Shown in the avatar when there is no picture.        |
| `avatarUrl`     | `string`       | Optional picture for the avatar.                     |
| `status`        | `string`       | Optional status text, shown as a badge.              |
| `statusVariant` | `BadgeVariant` | The badge's colour. Default `"neutral"`.             |

### States

| State    | Prop         | What renders                                               |
| -------- | ------------ | ---------------------------------------------------------- |
| Default  | —            | The rows in a scroll area, with a count in the footer.     |
| Empty    | `items={[]}` | "No tasks yet" in the body; the footer button is disabled. |
| Loading  | `loading`    | Four placeholder rows in a busy `status` region.           |
| Error    | `error`      | One error alert with a "Try again" button in the body.     |
| Disabled | `disabled`   | The rows with every button disabled.                       |

### Sizing

| Container step           | What changes                                                    |
| ------------------------ | --------------------------------------------------------------- |
| below `@sm`              | Status and time sit under each row's title.                     |
| `@sm` (`--container-sm`) | Status and time move to a trailing column, one above the other. |
| `@md` (`--container-md`) | Status and time sit side by side; the heading grows.            |
| `@lg` (`--container-lg`) | The times line up in one column.                                |
