## Usage

A toggle is a button that stays pressed. Press it once to turn an option on, and again to turn it off. Use it for one option in a toolbar; for several related options, use Toggle Group.

<ForFramework fw="react">

```tsx
import { Toggle } from "@moderno-ui/react";
```

```tsx
<Toggle.Root>Bold</Toggle.Root>
```

</ForFramework>

<ForFramework fw="vue">



## API Reference

### Toggle.Root

`variant` and `size` are the Moderno additions; the other props come from Ark's Toggle.

<PropsTable component="Toggle" />

| Prop              | Type                         | Default | Description                                    |
| ----------------- | ---------------------------- | ------- | ---------------------------------------------- |
| `pressed`         | `boolean`                    | —       | Controlled state. Pair with `onPressedChange`. |
| `defaultPressed`  | `boolean`                    | `false` | Initial state when uncontrolled.               |
| `onPressedChange` | `(pressed: boolean) => void` | —       | Called when the toggle is pressed or released. |
| `disabled`        | `boolean`                    | `false` | Disables the button and dims it.               |

In Vue, listen with `@pressed-change` or bind the state with `v-model:pressed`.

### Parts

| Part               | Element    | Description                                                                                                     |
| ------------------ | ---------- | --------------------------------------------------------------------------------------------------------------- |
| `Toggle.Root`      | `<button>` | The button. Carries `aria-pressed`, `data-variant` and `data-size`.                                             |
| `Toggle.Indicator` | `<div>`    | Optional. Shows its children while on and its `fallback` while off (a `<span>` with a `#fallback` slot in Vue). |

### Data attributes

| Attribute       | Values                                       |
| --------------- | -------------------------------------------- |
| `data-state`    | `"on"` or `"off"`, on the root and indicator |
| `data-pressed`  | Present while pressed                        |
| `data-disabled` | Present while `disabled`                     |
| `data-variant`  | On the root: `"ghost"` or `"outline"`        |
| `data-size`     | On the root: `"sm"`, `"md"` or `"lg"`        |

## Notes

- `Toggle.Root` is wrapped to add `variant` and `size`; every other part is Ark's unchanged.
- Style state from `data-state` and the `data-*` flags; `variant` and `size` are the only visual props.
- Toggle is a pressable button. For an on/off setting with a track and a thumb, use Switch.
