    - "With `href`, the category's name is a link, and the link covers the whole tile. Without it, the name is plain text."
    - '`imageUrl` fills the top of the tile. Without it, the tile shows the name''s first letter, large, in the serif face. The picture is decorative (`alt=""`), because the name already says what it shows.'
    - "`countLabel` is the text people read, like `32 products`. Write it in the reader's language before you pass it; the tile has no footer without it."
    - "Each name is an `h3` under the block's `h2`, so the categories show in the page outline."

## API Reference

### Props

| Prop                | Type                | Default              | Description                                                                   |
| ------------------- | ------------------- | -------------------- | ----------------------------------------------------------------------------- |
| `heading`           | `string`            | `"Shop by category"` | The section's heading. Set in the serif face.                                 |
| `description`       | `string`            | a sentence           | One sentence under the heading; `""` hides it.                                |
| `allCategoriesHref` | `string`            | `"#"`                | Where "Browse all categories" goes, like your shop page; `""` hides the link. |
| `categories`        | `CategorySummary[]` | four sample tiles    | The categories, in the order to show them. `[]` shows the empty message.      |
| `error`             | `string`            | —                    | Loading the categories failed; an error Alert with a retry replaces the grid. |
| `loading`           | `boolean`           | `false`              | Placeholder tiles in a busy region replace the grid.                          |
| `disabled`          | `boolean`           | `false`              | The tiles stay; every link is inert and the retry button disabled.            |
| `onRetry`           | `() => void`        | —                    | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                  |

### CategorySummary

| Field         | Type     | Description                                                            |
| ------------- | -------- | ---------------------------------------------------------------------- |
| `id`          | `string` | A stable key for the category.                                         |
| `name`        | `string` | The category's name.                                                   |
| `description` | `string` | One line about what is in it.                                          |
| `countLabel`  | `string` | Optional. How many products it holds, as people read it.               |
| `imageUrl`    | `string` | Optional. A picture for the tile. Without it, the name's initial.      |
| `href`        | `string` | Optional. Turns the name, and the whole tile, into a link to the page. |

### States

| State    | Prop              | What renders                                                 |
| -------- | ----------------- | ------------------------------------------------------------ |
| Default  | —                 | Heading, introduction and one tile per category.             |
| Empty    | `categories={[]}` | Heading, introduction and "No categories to show yet."       |
| Loading  | `loading`         | Heading, introduction and four placeholder tiles.            |
| Error    | `error`           | Heading, introduction, then an error Alert with "Try again". |
| Disabled | `disabled`        | The same tiles with every link inert.                        |

### Sizing

| Container step           | What changes                                                       |
| ------------------------ | ------------------------------------------------------------------ |
| below `@sm`              | One column; "Browse all categories" under the introduction.        |
| `@sm` (`--container-sm`) | Two columns, and "Browse all categories" moves beside the heading. |
| `@md` (`--container-md`) | The heading steps up.                                              |
| `@lg` (`--container-lg`) | Four columns, with more room between and around.                   |

## Notes

- Keep each description to one line, so the tiles in a row stay close in height.
- Four categories fill two or four columns evenly. Use pictures of the same shape; the tile crops them to 4:3.
