Use it for the checkout step where a shopper gives the shipping address. It shows the form beside the order; your page saves the address.

Read the address from the form when it is sent:

```ts
function saveAddress(event) {
  event.preventDefault();
  const address = Object.fromEntries(new FormData(event.currentTarget));
  // address.email, address.postalCode, address.delivery…
}
```

## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`onsubmit`) in Svelte, and emits (`submit`, `back`, `retry`, `navigate`) in Vue.

| Prop              | Type                     | Default               | Description                                                           |
| ----------------- | ------------------------ | --------------------- | --------------------------------------------------------------------- |
| `deliveryOptions` | `DeliveryOption[]`       | Standard, express (€) | The ways the order can travel: `id`, `label`, `description`, `price`. |
| `items`           | `OrderItem[]`            | A sample order        | The lines of the order. `[]` shows the empty state.                   |
| `totals`          | `OrderTotal[]`           | —                     | The rows above the total: `label`, `amount`.                          |
| `total`           | `string`                 | —                     | What the shopper pays.                                                |
| `saveError`       | `string`                 | —                     | Saving failed: an alert at the top of the form.                       |
| `fieldErrors`     | `Record<string, string>` | —                     | A message per field, keyed by its `name`.                             |
| `saving`          | `boolean`                | `false`               | The form is inert and its button reads "Saving".                      |
| `orderLoading`    | `boolean`                | `false`               | Placeholder lines in the summary.                                     |
| `orderError`      | `string`                 | —                     | The order could not load: an alert with "Try again".                  |
| `disabled`        | `boolean`                | `false`               | Every control is shown but inert.                                     |
| `onSubmit`        | `(event) => void`        | —                     | The form was sent. The native submit event.                           |
| `onBack`          | `() => void`             | —                     | "Back to cart" was pressed.                                           |
| `onRetry`         | `() => void`             | —                     | "Try again" was pressed.                                              |
| `onNavigate`      | `(to, event) => void`    | —                     | A screen link was clicked: `home`, `help`, `privacy` or `terms`.      |
| `homeHref`        | `string`                 | `"#"`                 | Target of the wordmark.                                               |
| `helpHref`        | `string`                 | `"#"`                 | Target of "Need help?".                                               |
| `privacyHref`     | `string`                 | `"#"`                 | Target of the privacy link.                                           |
| `termsHref`       | `string`                 | `"#"`                 | Target of the terms link.                                             |

`OrderItem` is the [OrderSummary](/en/order-summary/)'s: `{ id, name, price, quantity, options?, href?, image? }`.

### States

| State        | Props          | Renders                                          |
| ------------ | -------------- | ------------------------------------------------ |
| Default      | —              | The form beside the order.                       |
| Field errors | `fieldErrors`  | Each field with its message, marked invalid.     |
| Save error   | `saveError`    | An alert at the top of the form.                 |
| Saving       | `saving`       | The form inert, "Saving" on its button.          |
| Loading      | `orderLoading` | Placeholder lines in the summary, `aria-busy`.   |
| Order error  | `orderError`   | An alert with "Try again" in place of the order. |
| Empty        | `items: []`    | "Your order is empty." in the summary.           |
| Disabled     | `disabled`     | The screen is shown but can't be used.           |

### Sizing

| Container step           | Change                                   |
| ------------------------ | ---------------------------------------- |
| `@sm` (`--container-sm`) | The masthead moves onto one row.         |
| `@md` (`--container-md`) | The footer lines up.                     |
| `@lg` (`--container-lg`) | The order summary moves beside the form. |

### Composition

| Part                               | Role                                                  |
| ---------------------------------- | ----------------------------------------------------- |
| [CheckoutForm](/en/checkout-form/) | The shipping step: contact, address, delivery method. |
| [OrderSummary](/en/order-summary/) | The lines of the order and its totals.                |

## Notes

- Presentational: no request, no router. The page that mounts it saves the address and prices the order.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The screen imports the CheckoutForm and OrderSummary blocks from `@/components/blocks/…`; edit those lines if your alias differs.
