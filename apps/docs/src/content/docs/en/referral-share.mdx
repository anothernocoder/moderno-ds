Use it for the step of a referral program where a member shares their link. It shows the link, the friends invited so far and how the reward works; your page sends the invites.

## Installation

<Install item="referral-share" />

## Usage

<ForFramework fw="react">

```tsx

```

```tsx

```

</ForFramework>



`sendInvite(email)` can return a promise. The button shows "Sending" until it settles, then a toast says whether the invite went out.

## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`oninvite`) in Svelte. In Vue, `invite` and `share` are listeners on function props (`@invite`, `@share`) and `copy`, `retry` and `navigate` are emits.

| Prop          | Type                         | Default                            | Description                                                      |
| ------------- | ---------------------------- | ---------------------------------- | ---------------------------------------------------------------- |
| `link`        | `string`                     | `"https://example.com/r/ana-ruiz"` | The reader's referral link.                                      |
| `reward`      | `string`                     | `"a free month"`                   | What each side gets when a friend joins.                         |
| `friends`     | `ReferralFriend[]`           | `[]`                               | Friends invited so far: `id`, `name`, `email`, `status`.         |
| `channels`    | `{ value, label }[]`         | Email, Slack, LinkedIn, X          | Where the link can be sent.                                      |
| `error`       | `string`                     | —                                  | The referral details could not load: shows the alert and retry.  |
| `loading`     | `boolean`                    | `false`                            | The referral details are loading: placeholders.                  |
| `disabled`    | `boolean`                    | `false`                            | Every control is shown but inert.                                |
| `onInvite`    | `(email) => void \| Promise` | —                                  | An email was invited.                                            |
| `onShare`     | `(channel, link) => …`       | —                                  | The link was sent to a channel.                                  |
| `onCopy`      | `(link) => void`             | —                                  | The link was copied.                                             |
| `onRetry`     | `() => void`                 | —                                  | "Try again" was pressed.                                         |
| `onNavigate`  | `(to, event) => void`        | —                                  | A screen link was clicked: `home`, `skip`, `privacy` or `terms`. |
| `homeHref`    | `string`                     | `"#"`                              | Target of the wordmark.                                          |
| `skipHref`    | `string`                     | `"#"`                              | Target of "Skip for now".                                        |
| `privacyHref` | `string`                     | `"#"`                              | Target of the privacy link.                                      |
| `termsHref`   | `string`                     | `"#"`                              | Target of the terms link.                                        |

### States

| State    | Props      | Renders                                         |
| -------- | ---------- | ----------------------------------------------- |
| Default  | `friends`  | The link, the channels and the invited friends. |
| Empty    | —          | "Only you have access" in place of the friends. |
| Loading  | `loading`  | Placeholders in the card, `aria-busy` on it.    |
| Error    | `error`    | An alert with "Try again" in place of the card. |
| Disabled | `disabled` | The screen is shown but can't be used.          |

### Sizing

| Container step           | Change                                                                  |
| ------------------------ | ----------------------------------------------------------------------- |
| `@sm` (`--container-sm`) | The masthead moves onto one row.                                        |
| `@md` (`--container-md`) | The title grows, the three steps sit side by side, the footer lines up. |

### Composition

| Part                             | Role                                                  |
| -------------------------------- | ----------------------------------------------------- |
| [ShareInvite](/en/share-invite/) | The invite form, the link, the channels, the friends. |

## Notes

- Presentational: no request, no router. The page that mounts it sends the invites.
- The block checks the email before `onInvite` runs: a bad address or a friend already on the list shows a field error.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The screen imports the ShareInvite block from `@/components/blocks/…`; edit that line if your alias differs.
