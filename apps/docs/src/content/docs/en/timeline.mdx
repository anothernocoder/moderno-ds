Use it in an editor that animates properties over time: press play, drag the playhead to scrub, add, move and delete keyframes, and zoom in to place them on the frame. The block shows the time; your app owns it.

The block has no clock. While `playing` is true, your app advances `time` (for example with `requestAnimationFrame`) and stops or loops at `duration`. `moveKeyframe`, `addKeyframe` and `deleteKeyframe` write the change into `tracks`; `addKeyframe` gives the new keyframe an `id` of your choice.

## API Reference

### Props

| Prop               | Type                                             | Default             | Description                                                                                         |
| ------------------ | ------------------------------------------------ | ------------------- | --------------------------------------------------------------------------------------------------- |
| `tracks`           | `TimelineTrack[]`                                | three sample tracks | One row each, with its label and its keyframes.                                                     |
| `duration`         | `number`                                         | `5`                 | The length of the animation, in seconds.                                                            |
| `time`             | `number`                                         | `0`                 | Where the playhead is, in seconds.                                                                  |
| `fps`              | `number`                                         | `30`                | Frames per second. Reported times snap to `1 / fps`; an arrow key moves one frame.                  |
| `playing`          | `boolean`                                        | `false`             | The play button is pressed.                                                                         |
| `loop`             | `boolean`                                        | `false`             | The loop button is pressed.                                                                         |
| `selectedKeyframe` | `KeyframeSelection \| null`                      | `null`              | The keyframe drawn as selected.                                                                     |
| `zoom`             | `number`                                         | `1`                 | How far the time axis is zoomed. `1` fits the whole `duration` in the visible width.                |
| `onTimeChange`     | `(time: number) => void`                         | —                   | The playhead was dragged, clicked or moved by key. Svelte: `ontimechange`. Vue: `@time-change`.     |
| `onPlayingChange`  | `(playing: boolean) => void`                     | —                   | Play or pause was pressed, or Space. Svelte: `onplayingchange`. Vue: `@playing-change`.             |
| `onLoopChange`     | `(loop: boolean) => void`                        | —                   | Loop was pressed. Svelte: `onloopchange`. Vue: `@loop-change`.                                      |
| `onKeyframeSelect` | `(selection: KeyframeSelection \| null) => void` | —                   | A keyframe was clicked or focused. Svelte: `onkeyframeselect`. Vue: `@keyframe-select`.             |
| `onKeyframeChange` | `(change: KeyframeChange) => void`               | —                   | A keyframe was dragged or moved by key. Svelte: `onkeyframechange`. Vue: `@keyframe-change`.        |
| `onKeyframeAdd`    | `(keyframe: KeyframeAdd) => void`                | —                   | Add keyframe was pressed. Svelte: `onkeyframeadd`. Vue: `@keyframe-add`.                            |
| `onKeyframeDelete` | `(keyframe: KeyframeSelection) => void`          | —                   | Delete keyframe or the Delete key was pressed. Svelte: `onkeyframedelete`. Vue: `@keyframe-delete`. |
| `onZoomChange`     | `(zoom: number) => void`                         | —                   | Zoom out, Zoom in or Fit was pressed. Svelte: `onzoomchange`. Vue: `@zoom-change`.                  |

### TimelineTrack

| Field       | Type                             | Description                                                      |
| ----------- | -------------------------------- | ---------------------------------------------------------------- |
| `id`        | `string`                         | Names the track in `KeyframeSelection` and `KeyframeChange`.     |
| `label`     | `string`                         | The row's label, and part of each keyframe's name.               |
| `keyframes` | `{ id: string; time: number }[]` | One thumb each, at `time` seconds. The block sorts them by time. |

### KeyframeSelection, KeyframeChange and KeyframeAdd

| Field        | Type     | Description                                                                          |
| ------------ | -------- | ------------------------------------------------------------------------------------ |
| `trackId`    | `string` | The track's `id`.                                                                    |
| `keyframeId` | `string` | The keyframe's `id`. Not in `KeyframeAdd`: your app names the new keyframe.          |
| `time`       | `number` | `KeyframeChange` and `KeyframeAdd` only: the time, in seconds, snapped to the frame. |

### Parts

| Part          | What it is                                                                                                                                                                       |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Controls      | Play/pause and loop Toggles, Add keyframe and Delete keyframe Buttons, the readout `current / duration` in `m:ss:ff`, and Zoom out, Zoom in and Fit Buttons. Each has a Tooltip. |
| Ruler         | A single-thumb Slider: the thumb is the playhead ("Playhead", announced as "1.20 seconds"); the time marks are its markers.                                                      |
| Tracks        | One row per track: its label, a Toggle that selects the track, then a Slider with one thumb per keyframe and no range.                                                           |
| Playhead line | A line at the playhead's time that crosses every track.                                                                                                                          |

### States

| State          | Prop                                 | What renders                                                                                                                                                              |
| -------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Paused         | —                                    | The play button shows a play icon and is not pressed.                                                                                                                     |
| Playing        | `playing`                            | The play button is pressed and shows a pause icon.                                                                                                                        |
| Looping        | `loop`                               | The loop button is pressed.                                                                                                                                               |
| Selected       | `selectedKeyframe`                   | That keyframe is a larger, filled diamond with an outline; its name ends in "selected".                                                                                   |
| Track selected | `selectedKeyframe`, or a label press | That track's label is pressed; Add keyframe adds to it.                                                                                                                   |
| Zoomed         | `zoom` above `1`                     | The time area is `zoom` times wider and scrolls sideways; the ruler marks get denser.                                                                                     |
| Disabled       | —                                    | Add keyframe with no track selected or with a keyframe on the playhead's frame; Delete keyframe with none selected; Zoom out and Fit at `1`; Zoom in at the deepest zoom. |

### Keyboard

| Key                 | Where                      | Does                                                                   |
| ------------------- | -------------------------- | ---------------------------------------------------------------------- |
| Space               | The timeline, the playhead | Plays or pauses.                                                       |
| Delete              | The timeline               | Deletes the selected keyframe. Backspace does too.                     |
| Left / Right arrow  | The playhead or a keyframe | Moves it one frame.                                                    |
| Page Up / Page Down | The playhead or a keyframe | Moves it one second.                                                   |
| Home / End          | The playhead or a keyframe | Moves it to the start or the end (a keyframe stops at its neighbours). |

### Sizing

| Container step           | What changes                                         |
| ------------------------ | ---------------------------------------------------- |
| below `@sm`              | A narrow label column; every other ruler mark shows. |
| `@sm` (`--container-sm`) | The label column widens.                             |
| `@md` (`--container-md`) | Every ruler mark shows.                              |
