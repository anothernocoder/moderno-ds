## Usage

Use an indicator to show a live status in one small dot: someone is online, a service is down, a recording is running.

<ForFramework fw="react">

```tsx
import { Indicator } from "@moderno-ui/react";
```

```tsx
<Indicator variant="success">Online</Indicator>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Indicator } from "@moderno-ui/vue";
```

```vue
<Indicator variant="success">Online</Indicator>
```

</ForFramework>

## API Reference

### Indicator

Renders a `<span>`; its children become the label. `variant` defaults to `neutral`, `size` to `md` and `pulse` to `false`.

<PropsTable component="Indicator" />

### Parts

| Part    | Element  | Description                                                                                                                  |
| ------- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `root`  | `<span>` | Carries `data-variant`, `data-size` and, with `pulse`, `data-pulse`. A bare dot with an `aria-label` also gets `role="img"`. |
| `dot`   | `<span>` | The coloured dot. Always rendered; `aria-hidden`.                                                                            |
| `label` | `<span>` | Rendered only when there are children.                                                                                       |

## Notes

- Indicator is CSS-only: a `<span>` with `data-scope="indicator"`, no Ark machine.
- Always pair the colour with text: a label, or an `aria-label` on a bare dot. A plain `<span>` cannot carry a name, which is why a named bare dot gets `role="img"`.
- Keep `pulse` for the one status that is happening right now.
