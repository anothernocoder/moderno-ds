## API Reference

### Props

| Prop       | Type                               | Default       | Description                                                  |
| ---------- | ---------------------------------- | ------------- | ------------------------------------------------------------ |
| `size`     | `"sm" \| "md" \| "lg" \| "full"`   | `"lg"`        | The widest the content gets; `full` has no cap.              |
| `children` | content (Vue and Svelte: the slot) | a sample card | What the container centres. Without it, a sample card shows. |

### Sizes

| Size   | Maximum width                |
| ------ | ---------------------------- |
| `sm`   | `--container-sm` (24rem)     |
| `md`   | `--container-md` (36rem)     |
| `lg`   | `--container-lg` (48rem)     |
| `full` | none: the width of its space |

### States

The container has no states of its own. Loading, empty and error belong to its content.

### Sizing

| Container step           | What changes                           |
| ------------------------ | -------------------------------------- |
| below `@sm`              | A narrow gutter on each side.          |
| `@sm` (`--container-sm`) | A wider gutter.                        |
| `@md` (`--container-md`) | A wider gutter again.                  |
| `@lg` (`--container-lg`) | More room above and below the content. |
