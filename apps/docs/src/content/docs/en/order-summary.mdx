## Usage

Use Order Summary to show a shopper what they are paying for, next to a checkout form or on a confirmation page. It only shows the order; nothing in it changes the order.

<ForFramework fw="react">

```tsx
import { OrderSummary } from "@/components/blocks/order-summary";
```

```tsx
<OrderSummary items={items} totals={totals} total={total} />
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import OrderSummary from "@/components/blocks/OrderSummary.vue";
</script>
```

```vue
<OrderSummary :items="items" :totals="totals" :total="total" />
```

</ForFramework>
<ForFramework fw="svelte">

```svelte
<script lang="ts">
  import OrderSummary from "@/components/blocks/OrderSummary.svelte";
</script>
```

```svelte
<OrderSummary {items} {totals} {total} />
```

</ForFramework>
<ForFramework fw="solid">

```tsx
import { OrderSummary } from "@/components/blocks/order-summary";
```

```tsx
<OrderSummary items={items()} totals={totals()} total={total()} />
```

</ForFramework>

`totals` is a list of rows, like `[{ label: "Subtotal", amount: "€134" }, { label: "Shipping", amount: "€6" }]`. The block does no maths: pass every amount as people read it.

## API Reference

### Props

| Prop       | Type           | Default                    | Description                                                                              |
| ---------- | -------------- | -------------------------- | ---------------------------------------------------------------------------------------- |
| `heading`  | `string`       | `"Order summary"`          | The section's heading. It is set in the serif face.                                      |
| `items`    | `OrderItem[]`  | three sample items         | The lines in the order. `[]` shows the empty message.                                    |
| `totals`   | `OrderTotal[]` | three rows with the sample | The rows above the total, in order. Left out, there are none.                            |
| `total`    | `string`       | `"€168"` with the samples  | The grand total, last and larger. Left out, there is no total row.                       |
| `error`    | `string`       | —                          | Loading the order failed; an error Alert with a retry replaces the lines and the totals. |
| `loading`  | `boolean`      | `false`                    | Placeholder lines in a busy region replace the lines and the totals.                     |
| `disabled` | `boolean`      | `false`                    | The lines stay; every link is inert and the retry is off.                                |
| `onRetry`  | `() => void`   | —                          | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                             |

### OrderItem

| Field      | Type             | Description                                                   |
| ---------- | ---------------- | ------------------------------------------------------------- |
| `id`       | `string`         | A stable key for the line.                                    |
| `name`     | `string`         | The product's name.                                           |
| `price`    | `string`         | The line's price for its whole quantity, like `"€56"`.        |
| `quantity` | `number`         | How many are in the order. It reads "Qty 2".                  |
| `options`  | `string`         | Optional. What the shopper chose, like `"Sage · 350 ml"`.     |
| `href`     | `string`         | Optional. Turns the name into a link to the product's page.   |
| `image`    | `OrderItemImage` | Optional. The photo: `{ src, alt }`. Without it, a muted box. |

### OrderTotal

| Field    | Type     | Description                                            |
| -------- | -------- | ------------------------------------------------------ |
| `label`  | `string` | What the row is, like `"Shipping"`.                    |
| `amount` | `string` | The amount as people read it, like `"€6"` or `"Free"`. |

### States

| State    | Prop         | What renders                                                 |
| -------- | ------------ | ------------------------------------------------------------ |
| Default  | —            | The heading, one line per item and the totals.               |
| Empty    | `items={[]}` | The heading and "Your order is empty." in a dashed box.      |
| Loading  | `loading`    | The heading and three placeholder lines.                     |
| Error    | `error`      | The heading and an error Alert with "Try again".             |
| Disabled | `disabled`   | The same lines and totals, with the links and the retry off. |

### Sizing

| Container step           | What changes                                                                        |
| ------------------------ | ----------------------------------------------------------------------------------- |
| below `@sm`              | A small image. The quantity sits under the name. The totals sit under the lines.    |
| `@sm` (`--container-sm`) | The image grows, and the quantity moves into its own column, just before the price. |
| `@md` (`--container-md`) | The image grows again, and the heading steps up.                                    |
| `@lg` (`--container-lg`) | The totals move beside the lines.                                                   |

## Notes

- Keep `options` short: the colour and the size are enough.
- Keep the totals rows few. Subtotal, shipping and taxes are usually all a shopper needs.
