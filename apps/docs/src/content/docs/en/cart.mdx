## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`oncheckout`) in Svelte, and emits (`quantity-change`, `remove`, `checkout`, `retry`, `navigate`) in Vue.

| Prop               | Type                                     | Default             | Description                                                                 |
| ------------------ | ---------------------------------------- | ------------------- | --------------------------------------------------------------------------- |
| `heading`          | `string`                                 | `"Your cart"`       | The page's `h1`, the shopping-cart block's heading.                         |
| `items`            | `CartItem[]`                             | the block's samples | The lines, in order. `[]` shows the empty message.                          |
| `subtotal`         | `string`                                 | —                   | The subtotal as people read it, like `"€134"`. Without it, no subtotal row. |
| `note`             | `string`                                 | the block's note    | A short line under the subtotal; `""` hides it.                             |
| `error`            | `string`                                 | —                   | Loading the cart failed; an error alert with a retry replaces it.           |
| `loading`          | `boolean`                                | `false`             | Placeholder lines in a busy region replace the cart.                        |
| `disabled`         | `boolean`                                | `false`             | The lines stay; every link, quantity box and button is inert.               |
| `onQuantityChange` | `(id: string, quantity: number) => void` | —                   | A line's quantity changed, always a whole number from 1 to its maximum.     |
| `onRemove`         | `(id: string) => void`                   | —                   | A line's Remove button was pressed.                                         |
| `onCheckout`       | `() => void`                             | —                   | Checkout was pressed.                                                       |
| `onRetry`          | `() => void`                             | —                   | "Try again" after `error`.                                                  |
| `onNavigate`       | `(to, event) => void`                    | —                   | A screen link was clicked: `home`, `shop`, `privacy` or `terms`.            |
| `homeHref`         | `string`                                 | `"#"`               | Target of the wordmark.                                                     |
| `shopHref`         | `string`                                 | `"#"`               | Target of "Continue shopping".                                              |
| `privacyHref`      | `string`                                 | `"#"`               | Target of the privacy link.                                                 |
| `termsHref`        | `string`                                 | `"#"`               | Target of the terms link.                                                   |

### States

| State    | Props      | Renders                                               |
| -------- | ---------- | ----------------------------------------------------- |
| Default  | —          | The lines and the order summary with Checkout.        |
| Empty    | `items=[]` | The heading and "Your cart is empty."                 |
| Loading  | `loading`  | The heading and three placeholder lines.              |
| Error    | `error`    | The heading and an error alert with "Try again".      |
| Disabled | `disabled` | The same lines with every link, box and button inert. |

### Sizing

| Container step           | Change                           |
| ------------------------ | -------------------------------- |
| `@sm` (`--container-sm`) | The masthead moves onto one row. |
| `@md` (`--container-md`) | The footer moves onto one row.   |

The summary sits under the lines, and moves beside them once the Shopping Cart block's own container reaches `--container-lg`.

### Composition

| Part                                | Role                                                |
| ----------------------------------- | --------------------------------------------------- |
| [Shopping Cart](/en/shopping-cart/) | The lines and the summary, with `headingLevel={1}`. |

## Notes

- Presentational: no request, no prices worked out, no router. The page that mounts it owns them.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The root is a `<div>`, not a `<main>`. Make it your `<main>` if the route has none.
- The screen imports the Shopping Cart block from `@/components/blocks/…`; edit that line if your alias differs.
