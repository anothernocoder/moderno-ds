## Usage

Use a badge to label the state of something already on the page: an invoice that is **Paid**, a feature in **Beta**, **3** new messages.

<ForFramework fw="react">

```tsx
import { Badge } from "@moderno-ui/react";
```

```tsx
<Badge variant="success">Paid</Badge>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Badge } from "@moderno-ui/vue";
```

```vue
<Badge variant="success">Paid</Badge>
```

</ForFramework>

<ForFramework fw="svelte">

```ts

```


</ForFramework>

## API Reference

### Badge

Renders a `<span>`; its children are the text. `variant` defaults to `neutral` and `size` to `md`.

<PropsTable component="Badge" />

### Parts

| Part   | Element  | Description                                                     |
| ------ | -------- | --------------------------------------------------------------- |
| `root` | `<span>` | The label. Carries `data-variant` and `data-size`.              |
| `dot`  | `<span>` | Rendered only with `dot`. Takes the text colour; `aria-hidden`. |

## Notes

- Badge is CSS-only: a `<span>` with `data-scope="badge"`, no Ark machine.
- A badge is not interactive. For something the user can remove, use Chip.
- The dot is decorative; the text must still say the status.
