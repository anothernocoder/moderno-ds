## Usage

A segmented control shows a few options in one row, and the user picks exactly one. Use it for a setting that changes a value in place, like how an image fills its frame.

**Segmented control or Tabs?** A segmented control changes a value. Tabs change the view: each tab shows its own panel of content. If picking an option swaps the content below it, use Tabs.

<ForFramework fw="react">

```tsx
import { SegmentedControl } from "@moderno-ui/react";
```

```tsx
<SegmentedControl.Root defaultValue="fit" aria-label="Image scale">
  <SegmentedControl.Indicator />
  <SegmentedControl.Item value="fit">
    <SegmentedControl.ItemText>Fit</SegmentedControl.ItemText>
    <SegmentedControl.ItemHiddenInput />
  </SegmentedControl.Item>
  <SegmentedControl.Item value="fill">
    <SegmentedControl.ItemText>Fill</SegmentedControl.ItemText>
    <SegmentedControl.ItemHiddenInput />
  </SegmentedControl.Item>
</SegmentedControl.Root>
```

## API Reference

### SegmentedControl.Root

`size` and `fullWidth` are the Moderno additions; `size` defaults to `md`, and matches Field's sizes. The other props come from Ark's SegmentGroup.

<PropsTable component="SegmentedControl" />

| Prop            | Type                                   | Default | Description                                                                |
| --------------- | -------------------------------------- | ------- | -------------------------------------------------------------------------- |
| `value`         | `string \| null`                       | —       | Controlled value. Pair with `onValueChange`.                               |
| `defaultValue`  | `string \| null`                       | —       | Initial value when uncontrolled.                                           |
| `onValueChange` | `(details: { value: string }) => void` | —       | Called when the user picks an option.                                      |
| `disabled`      | `boolean`                              | `false` | Disables every segment and dims the control.                               |
| `invalid`       | `boolean`                              | `false` | Sets `aria-invalid` on every radio and edges the track in `--destructive`. |
| `readOnly`      | `boolean`                              | `false` | Shows the choice but ignores clicks.                                       |
| `name`          | `string`                               | —       | Form field name shared by every radio.                                     |
| `aria-label`    | `string`                               | —       | Names the group. Not needed inside a `Field` with a `Field.Label`.         |

In Vue, bind the value with `v-model`. In Svelte, use `bind:value`.

### SegmentedControl.Item

| Prop       | Type      | Default | Description                                  |
| ---------- | --------- | ------- | -------------------------------------------- |
| `value`    | `string`  | —       | The value this segment stands for. Required. |
| `disabled` | `boolean` | `false` | Disables this segment only.                  |

### Parts

| Part                               | Element                | Description                                                                      |
| ---------------------------------- | ---------------------- | -------------------------------------------------------------------------------- |
| `SegmentedControl.Root`            | `<div>`                | The track. `role="radiogroup"`; carries `data-size` and `data-full-width`.       |
| `SegmentedControl.Indicator`       | `<div>`                | The pill that slides behind the selected segment. Render it first in the root.   |
| `SegmentedControl.Item`            | `<label>`              | One segment; clicking anywhere on it picks the option. An icon goes inside it.   |
| `SegmentedControl.ItemText`        | `<span>`               | The segment's label; it names the radio. A long label ends in an ellipsis.       |
| `SegmentedControl.ItemHiddenInput` | `<input type="radio">` | Visually hidden native radio; it carries focus, the arrow keys, `name`, `value`. |

### Data attributes

| Attribute            | Values                                                   |
| -------------------- | -------------------------------------------------------- |
| `data-state`         | `"checked"` or `"unchecked"`, on every part of a segment |
| `data-disabled`      | Present on a disabled control or segment                 |
| `data-invalid`       | Present while `invalid`                                  |
| `data-focus-visible` | On the segment whose radio has keyboard focus            |
| `data-size`          | On the root: `"sm"`, `"md"` or `"lg"`                    |
| `data-full-width`    | Present on the root while `fullWidth`                    |

## Notes

- Each segment is a native radio: Tab moves into the group, and the arrow keys move and select.
- The pill slides to the selected segment. With reduced motion turned on, it jumps there instead.
- The selected segment is a raised pill with an edge and a shadow, so the choice does not rely on colour alone.
- `SegmentedControl.Root` and `SegmentedControl.ItemText` are wrapped; every other part is Ark's SegmentGroup unchanged. Ark's `Label` is left out, because the root is the track.
