## Usage

Tags Input is a text box that turns what the user types into tags. Use it for a short list of free values, like keywords or topics. Enter or a comma adds a tag; the × on a tag removes it.

<ForFramework fw="react">

```tsx
import { TagsInput } from "@moderno-ui/react";
```

```tsx
<TagsInput.Root value={tags} onValueChange={(details) => setTags(details.value)}>
  <TagsInput.Label>Frameworks</TagsInput.Label>
  <TagsInput.Control>
    <TagsInput.Context>
      {(tagsInput) =>
        tagsInput.value.map((value, index) => (
          <TagsInput.Item key={index} index={index} value={value}>
            <TagsInput.ItemPreview>
              <TagsInput.ItemText>{value}</TagsInput.ItemText>
              <TagsInput.ItemDeleteTrigger>×</TagsInput.ItemDeleteTrigger>
            </TagsInput.ItemPreview>
            <TagsInput.ItemInput />
          </TagsInput.Item>
        ))
      }
    </TagsInput.Context>
    <TagsInput.Input placeholder="Add a framework" />
  </TagsInput.Control>
</TagsInput.Root>
```

</ForFramework>

The value is an array of strings, like `["React", "Vue"]`. `TagsInput.Context` hands it to you so you can draw one item per tag.

## API Reference

### TagsInput.Root

`size` is the Moderno addition; every part follows it. The other props come from Ark's TagsInput.

<PropsTable component="TagsInput" />

| Prop              | Type                                                             | Default    | Description                                                   |
| ----------------- | ---------------------------------------------------------------- | ---------- | ------------------------------------------------------------- |
| `value`           | `string[]`                                                       | —          | Controlled tags.                                              |
| `defaultValue`    | `string[]`                                                       | `[]`       | Tags at the start, uncontrolled.                              |
| `onValueChange`   | `(details: { value: string[] }) => void`                         | —          | Called when a tag is added, edited or removed.                |
| `inputValue`      | `string`                                                         | —          | Controlled text in the input.                                 |
| `max`             | `number`                                                         | `Infinity` | The most tags allowed. Past it, a new tag is refused.         |
| `allowOverflow`   | `boolean`                                                        | `false`    | Takes tags past `max` and marks the field invalid.            |
| `delimiter`       | `string \| RegExp`                                               | `","`      | The key that adds a tag, and what splits pasted text.         |
| `addOnPaste`      | `boolean`                                                        | `false`    | Turns pasted text into tags, split by the delimiter.          |
| `blurBehavior`    | `"add" \| "clear"`                                               | —          | What happens to typed text when the input loses focus.        |
| `editable`        | `boolean`                                                        | `true`     | Lets the user edit a tag with a double click or Enter.        |
| `allowDuplicates` | `boolean`                                                        | `false`    | Keeps a tag that is already in the list.                      |
| `validate`        | `(details: { inputValue: string; value: string[] }) => boolean`  | —          | Returns `false` to refuse a tag.                              |
| `onValueInvalid`  | `(details: { reason: "rangeOverflow" \| "invalidTag" }) => void` | —          | Called when `validate` refuses a tag, or tags overflow `max`. |
| `maxLength`       | `number`                                                         | —          | The most characters in one tag.                               |
| `disabled`        | `boolean`                                                        | `false`    | Dims the field and ignores input.                             |
| `readOnly`        | `boolean`                                                        | `false`    | Shows the tags but ignores input.                             |
| `invalid`         | `boolean`                                                        | —          | Marks the tags as wrong.                                      |
| `required`        | `boolean`                                                        | `false`    | Marks the field as required in a form.                        |
| `name`            | `string`                                                         | —          | The form field name of the hidden input.                      |

In Vue, bind the value with `:model-value` or `v-model`, and listen with `@value-change`.

### Parts

| Part                          | Element    | Description                                                     |
| ----------------------------- | ---------- | --------------------------------------------------------------- |
| `TagsInput.Root`              | `<div>`    | Carries `data-size`.                                            |
| `TagsInput.Label`             | `<label>`  | Optional. Names the field. Clicking it focuses the input.       |
| `TagsInput.Control`           | `<div>`    | The bordered box. Holds the tags and the input.                 |
| `TagsInput.Item`              | `<div>`    | One tag. Takes `index` and `value`.                             |
| `TagsInput.ItemPreview`       | `<div>`    | The tag's chip. Double click it to edit the tag.                |
| `TagsInput.ItemText`          | `<span>`   | The tag's text.                                                 |
| `TagsInput.ItemDeleteTrigger` | `<button>` | Removes the tag. Ark names it for screen readers.               |
| `TagsInput.ItemInput`         | `<input>`  | Replaces the chip while the tag is edited.                      |
| `TagsInput.Input`             | `<input>`  | The text box. Enter or the delimiter turns its text into a tag. |
| `TagsInput.ClearTrigger`      | `<button>` | Optional. Removes every tag. Hidden while there are none.       |
| `TagsInput.HiddenInput`       | `<input>`  | Optional. Sends the tags with a form.                           |
| `TagsInput.Context`           | —          | Hands you the tags as `value`, to draw one item each.           |

### Data attributes

| Attribute          | Values                                                        |
| ------------------ | ------------------------------------------------------------- |
| `data-focus`       | While the field has focus, on the root and control            |
| `data-invalid`     | When the tags are invalid, on the root, label, control, input |
| `data-disabled`    | When `disabled`, on every part                                |
| `data-readonly`    | When `readOnly`, on the root, label, control and input        |
| `data-empty`       | While there are no tags, on the root and input                |
| `data-highlighted` | On the tag chosen with the arrow keys                         |
| `data-size`        | On the root: `"sm"`, `"md"` or `"lg"`                         |

## Notes

- `TagsInput.Root` is wrapped to add `size`; every other part is Ark's unchanged.
- The keyboard: Arrow Left and Right move between tags, Backspace or Delete removes the highlighted one, Enter edits it and Escape cancels the edit.
- The delete triggers are out of the tab order; Backspace does the same job from the input.
