## Usage

An accordion is a stack of sections. Each header opens its own section. Use it for optional detail, like an FAQ, so the reader sees the headers first and opens only what they need.

<ForFramework fw="react">

```tsx
import { Accordion } from "@moderno-ui/react";
```

```tsx
<Accordion.Root defaultValue={["shipping"]} collapsible>
  <Accordion.Item value="shipping">
    <Accordion.ItemTrigger>
      How long does shipping take?
      <Accordion.ItemIndicator>▾</Accordion.ItemIndicator>
    </Accordion.ItemTrigger>
    <Accordion.ItemContent>Three to five working days.</Accordion.ItemContent>
  </Accordion.Item>
  <Accordion.Item value="returns">
    <Accordion.ItemTrigger>
      Can I return an order?
      <Accordion.ItemIndicator>▾</Accordion.ItemIndicator>
    </Accordion.ItemTrigger>
    <Accordion.ItemContent>Yes, within 30 days of delivery.</Accordion.ItemContent>
  </Accordion.Item>
</Accordion.Root>
```

</ForFramework>

By default one item is open at a time. `collapsible` lets the reader close it again.

## API Reference

### Accordion.Root

`variant` and `size` are the Moderno additions; every item follows them. The other props come from Ark's Accordion.

<PropsTable component="Accordion" />

| Prop            | Type                                     | Default      | Description                                           |
| --------------- | ---------------------------------------- | ------------ | ----------------------------------------------------- |
| `value`         | `string[]`                               | —            | Controlled open items. Pair with `onValueChange`.     |
| `defaultValue`  | `string[]`                               | `[]`         | Items open at first when uncontrolled.                |
| `onValueChange` | `(details: { value: string[] }) => void` | —            | Called when an item opens or closes.                  |
| `multiple`      | `boolean`                                | `false`      | Lets several items stay open at once.                 |
| `collapsible`   | `boolean`                                | `false`      | Lets the open item close, so no item is open.         |
| `disabled`      | `boolean`                                | `false`      | Disables every item.                                  |
| `orientation`   | `"horizontal" \| "vertical"`             | `"vertical"` | Sets the arrow keys: up and down, or left and right.  |
| `lazyMount`     | `boolean`                                | `false`      | Renders a content only the first time its item opens. |
| `unmountOnExit` | `boolean`                                | `false`      | Removes a content when its item closes.               |

In Vue, listen with `@value-change` or bind the value with `v-model`.

### Accordion.Item

| Prop       | Type      | Default | Description                 |
| ---------- | --------- | ------- | --------------------------- |
| `value`    | `string`  | —       | Required. The item's value. |
| `disabled` | `boolean` | `false` | Disables this item only.    |

### Parts

| Part                      | Element    | Description                                                  |
| ------------------------- | ---------- | ------------------------------------------------------------ |
| `Accordion.Root`          | `<div>`    | Carries `data-variant` and `data-size`.                      |
| `Accordion.Item`          | `<div>`    | One section. Holds its trigger and its content.              |
| `Accordion.ItemTrigger`   | `<button>` | The header, with `aria-expanded`. Opens and closes its item. |
| `Accordion.ItemIndicator` | `<div>`    | Optional. Holds your icon and turns when the item opens.     |
| `Accordion.ItemContent`   | `<div>`    | `role="region"`, named by its trigger. Hidden while closed.  |

### Data attributes

| Attribute          | Values                                                    |
| ------------------ | --------------------------------------------------------- |
| `data-state`       | `"open"` or `"closed"`, on the item and its parts         |
| `data-disabled`    | Present on a disabled item, its content and its indicator |
| `data-orientation` | `"vertical"` or `"horizontal"`, on every part             |
| `data-variant`     | On the root: `"line"` or `"enclosed"`                     |
| `data-size`        | On the root: `"sm"`, `"md"` or `"lg"`                     |

## Notes

- `Accordion.Root` is wrapped to add `variant` and `size`; every other part is Ark's unchanged.
- The content's height animates as it opens and closes. It does not animate when the user asks for reduced motion.
- For sibling views where exactly one is always shown, use Tabs.
