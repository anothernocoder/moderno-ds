Dialog composes as `Root > Trigger + Portal(> Backdrop + Positioner > Content)`.
Ark drives focus trap, focus restore, scroll lock, and the `aria-labelledby`/
`aria-describedby` wiring. An SSR render emits only the trigger; after
hydration the content stays in the DOM between openings and Ark takes it out of
the layout with the `hidden` attribute, which `components.css` honours for every
part. No CVA variants — the surface comes straight from the `--popover` /
`--popover-foreground` token slots via `components.css`.
