## API Reference

### Dialog.Root

Ark's Dialog, re-exported unchanged; it renders no element of its own.

| Prop                     | Type                                   | Default    | Description                                                                                                              |
| ------------------------ | -------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| `open`                   | `boolean`                              | —          | Controlled open state. Pair with `onOpenChange` (`bind:open` in Svelte, `v-model:open` in Vue).                          |
| `defaultOpen`            | `boolean`                              | `false`    | Initial open state when uncontrolled.                                                                                    |
| `onOpenChange`           | `(details: { open: boolean }) => void` | —          | Called on every open or close, including Escape and backdrop clicks.                                                     |
| `role`                   | `"dialog" \| "alertdialog"`            | `"dialog"` | Use `alertdialog` for confirmations that cannot be undone.                                                               |
| `modal`                  | `boolean`                              | `true`     | Blocks interaction outside and hides the content below from assistive tech.                                              |
| `trapFocus`              | `boolean`                              | `true`     | Keeps focus inside the dialog while open.                                                                                |
| `preventScroll`          | `boolean`                              | `true`     | Locks page scroll while open.                                                                                            |
| `restoreFocus`           | `boolean`                              | `true`     | Returns focus to the previously focused element on close.                                                                |
| `closeOnEscape`          | `boolean`                              | `true`     | Closes on Escape.                                                                                                        |
| `closeOnInteractOutside` | `boolean`                              | `true`     | Closes on a click outside; `false` when `role="alertdialog"`.                                                            |
| `initialFocusEl`         | `() => HTMLElement \| null`            | —          | Element to focus on open. Defaults to the first focusable element, or the first `Dialog.CloseTrigger` for `alertdialog`. |
| `finalFocusEl`           | `() => HTMLElement \| null`            | —          | Element to focus on close.                                                                                               |
| `lazyMount`              | `boolean`                              | `false`    | Mount the content only on first open.                                                                                    |
| `unmountOnExit`          | `boolean`                              | `false`    | Remove the content from the DOM when closed.                                                                             |

### Portal

Renders its children at the end of `document.body`, outside the page's stacking context.

### Parts

Every part accepts its element's attributes; `Dialog.Trigger` and `Dialog.CloseTrigger` also take `asChild` to render your own `Button`.

| Part                  | Element    | Description                                                                 |
| --------------------- | ---------- | --------------------------------------------------------------------------- |
| `Dialog.Trigger`      | `<button>` | Opens the dialog.                                                           |
| `Dialog.Backdrop`     | `<div>`    | The scrim behind the content: `--overlay` over a blurred page.              |
| `Dialog.Positioner`   | `<div>`    | Centres the content in the viewport.                                        |
| `Dialog.Content`      | `<div>`    | The surface, painted from `--popover` and `--popover-foreground`. A column. |
| `Dialog.Title`        | `<h2>`     | The accessible name, wired through `aria-labelledby`.                       |
| `Dialog.Description`  | `<div>`    | Wired through `aria-describedby`.                                           |
| `Dialog.CloseTrigger` | `<button>` | Closes the dialog.                                                          |

### Keyboard

| Key                 | Action                                                              |
| ------------------- | ------------------------------------------------------------------- |
| `Esc`               | Closes the dialog.                                                  |
| `Tab` / `Shift+Tab` | Moves focus between focusable elements, wrapping inside the dialog. |

## Notes

- Always render `Dialog.Title`; it is the dialog's accessible name.
- Focus trap, scroll lock and focus restore come from Ark; don't reimplement them.
- An SSR render emits only the trigger; after hydration the content stays in the DOM, hidden with the `hidden` attribute.
- Dialog has no variants; the destructive tone belongs to the `Button`s inside it.
