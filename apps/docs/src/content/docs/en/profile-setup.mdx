Use it for the onboarding step where a new member adds a photo and a few details. It shows the photo and the form; your page uploads the file and saves the form.

## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`onavatarchange`) in Svelte, and emits (`avatarChange`, `submit`, `navigate`) in Vue.

| Prop              | Type                     | Default | Description                                                        |
| ----------------- | ------------------------ | ------- | ------------------------------------------------------------------ |
| `avatarSrc`       | `string`                 | —       | URL of the current photo. Adds the Change and Remove buttons.      |
| `initials`        | `string`                 | —       | Letters shown when there is no photo. Without them, a person icon. |
| `avatarUploading` | `boolean`                | `false` | A photo is uploading: the photo buttons are inert and busy.        |
| `avatarError`     | `string`                 | —       | The photo was rejected. Shown as an alert under the photo.         |
| `error`           | `string`                 | —       | Saving failed: shows the form alert.                               |
| `errors`          | `Record<string, string>` | —       | Field errors by name: `fullName`, `email`, `about`.                |
| `loading`         | `boolean`                | `false` | Save in flight: every control inert, the save button busy.         |
| `disabled`        | `boolean`                | `false` | The profile cannot be edited right now.                            |
| `onAvatarChange`  | `(file, event) => void`  | —       | The reader picked a photo.                                         |
| `onAvatarRemove`  | `(event) => void`        | —       | The reader pressed Remove.                                         |
| `onSubmit`        | `(event) => void`        | —       | Native form submit.                                                |
| `onCancel`        | `() => void`             | —       | The form's Cancel button was pressed.                              |
| `onNavigate`      | `(to, event) => void`    | —       | A screen link was clicked: `home`, `skip`, `privacy` or `terms`.   |
| `homeHref`        | `string`                 | `"#"`   | Target of the wordmark.                                            |
| `skipHref`        | `string`                 | `"#"`   | Target of "Skip for now".                                          |
| `privacyHref`     | `string`                 | `"#"`   | Target of the privacy link.                                        |
| `termsHref`       | `string`                 | `"#"`   | Target of the terms link.                                          |

### States

| State       | Props             | Renders                                           |
| ----------- | ----------------- | ------------------------------------------------- |
| Default     | `initials`        | The initials in the avatar, "Upload photo".       |
| Empty       | —                 | A person icon in the avatar.                      |
| With photo  | `avatarSrc`       | The photo, "Change photo" and "Remove".           |
| Uploading   | `avatarUploading` | Photo buttons inert, the upload button busy.      |
| Photo error | `avatarError`     | An alert under the photo.                         |
| Save error  | `error`, `errors` | The form alert and the invalid fields.            |
| Saving      | `loading`         | Every control inert, the save button `aria-busy`. |
| Disabled    | `disabled`        | The screen is shown but can't be used.            |

### Form fields

| Name             | Control  | Posted                  |
| ---------------- | -------- | ----------------------- |
| `fullName`       | Text     | Always.                 |
| `email`          | Email    | Always.                 |
| `about`          | Textarea | Always.                 |
| `productUpdates` | Checkbox | Only when it is ticked. |
| `securityAlerts` | Checkbox | Only when it is ticked. |

### Sizing

| Container step           | Change                                             |
| ------------------------ | -------------------------------------------------- |
| `@sm` (`--container-sm`) | The masthead and the photo row move onto one row.  |
| `@md` (`--container-md`) | The title grows and the footer moves onto one row. |

### Composition

| Part                           | Role                                           |
| ------------------------------ | ---------------------------------------------- |
| [Avatar](/en/avatar/)          | The photo, or the initials when there is none. |
| [FormLayout](/en/form-layout/) | The profile fields and the save button.        |

## Notes

- Presentational: no upload, no request, no router. The page that mounts it owns them.
- The file input only accepts PNG and JPG. Check the size yourself and pass `avatarError` when a file is too big.
- The file input is cleared after each pick, so picking the same file again still calls `onAvatarChange`.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The screen imports the FormLayout block from `@/components/blocks/…`; edit that line if your alias differs.
