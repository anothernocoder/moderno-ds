## Usage

A switch turns one setting on or off, and the change applies right away. Use it for preferences, not for answers the user submits with a form.

<ForFramework fw="react">

```tsx
import { Switch } from "@moderno-ui/react";
```

```tsx
<Switch.Root>
  <Switch.Control>
    <Switch.Thumb />
  </Switch.Control>
  <Switch.Label>Email notifications</Switch.Label>
  <Switch.HiddenInput />
</Switch.Root>
```

</ForFramework>

## API Reference

### Switch.Root

`size` is the Moderno addition and defaults to `md`; the other props come from Ark's Switch.

<PropsTable component="Switch" />

| Prop              | Type                             | Default | Description                                                 |
| ----------------- | -------------------------------- | ------- | ----------------------------------------------------------- |
| `checked`         | `boolean`                        | —       | Controlled state. Pair with `onCheckedChange`.              |
| `defaultChecked`  | `boolean`                        | `false` | Initial state when uncontrolled.                            |
| `onCheckedChange` | `(details: { checked }) => void` | —       | Called when the switch turns on or off.                     |
| `disabled`        | `boolean`                        | `false` | Disables the hidden input and dims every part.              |
| `invalid`         | `boolean`                        | `false` | Sets `aria-invalid` and rings the track in `--destructive`. |
| `readOnly`        | `boolean`                        | `false` | Shows the state but ignores clicks.                         |
| `required`        | `boolean`                        | `false` | Marks the input as required.                                |
| `name`            | `string`                         | —       | Form field name.                                            |
| `value`           | `string`                         | `"on"`  | Value submitted with the form when on.                      |

### Parts

| Part                 | Element                   | Description                                                                                                |
| -------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `Switch.Root`        | `<label>`                 | Carries `data-size`; clicking anywhere on it toggles the switch.                                           |
| `Switch.Control`     | `<span>`                  | The track.                                                                                                 |
| `Switch.Thumb`       | `<span>`                  | The knob inside the track; it slides to the far end when on.                                               |
| `Switch.Label`       | `<span>`                  | The text beside the track.                                                                                 |
| `Switch.HiddenInput` | `<input type="checkbox">` | Visually hidden native input with `role="switch"`; it carries focus, `name` and `value`. Always render it. |

### Data attributes

| Attribute       | Values                                      |
| --------------- | ------------------------------------------- |
| `data-state`    | `"checked"` or `"unchecked"`, on every part |
| `data-disabled` | Present while `disabled`                    |
| `data-invalid`  | Present while `invalid`                     |
| `data-readonly` | Present while `readOnly`                    |
| `data-size`     | On the root: `"sm"`, `"md"` or `"lg"`       |

## Notes

- `Switch.Root` is wrapped to add `size`, and `Switch.HiddenInput` to add `role="switch"`; every other part is Ark's unchanged.
- Style state from `data-state` and the `data-*` flags; `size` is the only visual prop.
- The thumb slides with `margin-inline-start`, so it moves the other way in right-to-left pages.
- Switch replaces the predecessor's Toggle.
