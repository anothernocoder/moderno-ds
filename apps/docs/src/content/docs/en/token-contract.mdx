Components reference slots, never values: overriding a slot is the only way to re-theme.
`@moderno-ui/css` ships a neutral default for every slot on this page.

## Scopes

| Selector           | Holds                                   |
| ------------------ | --------------------------------------- |
| `:root`            | Light values.                           |
| `.dark`            | Dark overrides.                         |
| `[data-brand="…"]` | Brand overrides. Composes with `.dark`. |

```css
:root {
  --primary: oklch(0.55 0.2 260);
  --radius: 0.5rem;
}

.dark {
  --primary: oklch(0.75 0.15 260);
}
```

## Required slots

A theme must define every slot in this section. Build one visually in the [Theme Builder](/en/theme-builder).

### Colour

OKLCH values, defined in both `:root` and `.dark`. Each `*-foreground` slot must reach WCAG AA (4.5:1) on its surface when the theme compiles.

## Tailwind v4

Import the preset to register the slots as Tailwind theme keys.

```css
@import "tailwindcss";
@import "@moderno-ui/css";
@import "@moderno-ui/css/preset";
```

| Slot                                           | Utilities                                                                   |
| ---------------------------------------------- | --------------------------------------------------------------------------- |
| Colour slots                                   | `bg-primary`, `text-muted-foreground`, `border-input`, …                    |
| `--radius`                                     | `rounded-sm` (−4px), `rounded-md` (−2px), `rounded-lg`, `rounded-xl` (+4px) |
| `--radius-full`                                | `rounded-full`                                                              |
| `--font-sans` / `--font-serif` / `--font-mono` | `font-sans`, `font-serif`, `font-mono`                                      |
| `--shadow-*`                                   | `shadow-sm`, `shadow-md`, `shadow-lg`                                       |
| `--container-*`                                | `max-w-sm`, `max-w-md`, `max-w-lg`, `w-*`, `@sm:` / `@md:` / `@lg:`         |
| `--text-*` / `--leading-*`                     | `text-ui-sm`, `text-body`, … (size and line height), `leading-body`, …      |
| `--font-weight-*`                              | `font-normal`, `font-medium`, `font-semibold`, `font-bold`                  |
| `--spacing-*`, `--motion-*`                    | Not mapped. Use `var(--spacing-4)` and friends.                             |

### Notes

- The type steps sit beside Tailwind's own `text-xs` … `text-9xl`, not over them: `text-sm` keeps its size.
- The weights are Tailwind's own keys at its own values, so a stock `font-semibold` reads the slot even without the preset, and looks the same until a theme overrides it.
- Colour, radius, font and shadow utilities point at `var(--slot)` (`@theme inline`), so a runtime override re-themes them without a rebuild.
- `@sm:` / `@md:` / `@lg:` fire at fixed 24rem / 36rem / 48rem, because a container query can't read `var()`.
- `max-w-*` and `w-*` still resolve to `var(--container-*)` and follow a theme override.
- The preset resets Tailwind's container scale (`--container-*: initial`): `max-w-xl`, `@xl:` and wider don't exist.
- Need a wider size? Add your own key in an app-level `@theme` block.
- Without the preset, `@moderno-ui/css` overrides only `sm|md|lg` in Tailwind's scale, so `max-w-lg` (48rem) ends up wider than `max-w-xl` (36rem).

## Reading it as data

| Source                             | Returns                                                                  |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `@moderno-ui/css/contract`         | `CONTRACT`: every slot with its DTCG type, Theme Builder group and role. |
| `get_contract` (`@moderno-ui/mcp`) | The same slots, plus the theming rules, for coding agents.               |

```ts
import { CONTRACT, COLOR_SLOTS, EXTENDED_SLOTS } from "@moderno-ui/css/contract";
```
