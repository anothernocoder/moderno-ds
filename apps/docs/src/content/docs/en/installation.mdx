## Packages

| Package                                          | Role                                                        |
| ------------------------------------------------ | ----------------------------------------------------------- |
| `@moderno-ui/react` · `vue` · `svelte` · `solid` | The components for your framework.                          |
| `@moderno-ui/core`                               | Shared recipes. Installed with every binding.               |
| `@moderno-ui/css`                                | The shared stylesheet and default theme. Peer dependency.   |
| `@moderno-ui/cli`                                | Optional. Copies blocks, screens and themes into your code. |
| `@moderno-ui/mcp`                                | Optional. Answers coding agents with your installed API.    |

Peer requirements: React 19, Vue 3.5, Svelte 5 or Solid 1.9.

## Install

1. Install the binding for your framework.

   <Install pkg="@moderno-ui/react" />

2. Install the stylesheet package.

   ```sh
   npm install @moderno-ui/css
   ```

3. Import the stylesheet once, at your app root.

   ```ts
   import "@moderno-ui/css";
   ```

4. Render a component.

   <ForFramework fw="react">

   ```tsx
   import { Button } from "@moderno-ui/react";

   <Button>Save changes</Button>;
   ```

   </ForFramework>

   <ForFramework fw="vue">

   ```vue
   <script setup lang="ts">
   import { Button } from "@moderno-ui/vue";
   </script>

   <template>
     <Button>Save changes</Button>
   </template>
   ```

   </ForFramework>

   <ForFramework fw="svelte">

   ```svelte
   <script lang="ts">
     import { Button } from "@moderno-ui/svelte";
   </script>

   <Button>Save changes</Button>
   ```

   </ForFramework>

   <ForFramework fw="solid">

   ```tsx
   import { Button } from "@moderno-ui/solid";

   <Button>Save changes</Button>;
   ```

   </ForFramework>

## Tailwind v4 (optional)

Import the preset after the stylesheet to get utilities such as `bg-primary` and `@md:`.

```css
@import "tailwindcss";
@import "@moderno-ui/css";
@import "@moderno-ui/css/preset";
```

See [Token contract](/en/token-contract#tailwind-v4) for every mapped slot.

## Scaffold with the CLI (optional)

1. Initialise the project.

   ```sh
   npx @moderno-ui/cli init
   ```

2. Import the generated stylesheet once, instead of `@moderno-ui/css`.

   ```ts
   import "@/styles/moderno.css";
   ```

3. Add a theme or a block.

   ```sh
   npx @moderno-ui/cli add theme-moderno
   ```

   <Install item="pricing" />

### Commands

| Command                    | What it does                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| `moderno init`             | Writes `components.json`, `src/styles/moderno.css` and the `AGENTS.md` stanza.           |
| `moderno init --claude`    | Same, plus a `CLAUDE.md` twin of the stanza.                                             |
| `moderno add <item...>`    | Copies registry items and their dependencies. A theme is `@import`ed into `moderno.css`. |
| `moderno update [item...]` | Updates installed items. Files you edited locally are kept.                              |
| `moderno diff <item>`      | Prints the diff between your copy and the registry version.                              |
| `moderno list`             | Lists installed items with their installed and latest versions.                          |

### Notes

- Every command takes `--registry <url|path>`.
- Registry lookup order: `--registry`, then `components.json`, then `MODERNO_REGISTRY_URL`, then `https://moderno.style/r/registry.json`.
- Re-running `init` updates the `AGENTS.md` stanza in place and keeps the rest of the file.
- The CLI and the MCP server need Node 22 or later.

## Change the font

A theme names its faces in `--font-sans`, `--font-serif` and `--font-mono`, but ships no font files. Load the font yourself: `theme-moderno` names Hedvig Letters and falls back to the system face until you do.

1. Install the font, or load it from Google Fonts or your own server.

   ```sh
   npm install @fontsource/inter
   ```

2. Override the slot in a stylesheet of your own. Don't edit the copied theme file: `moderno add` overwrites it, and `moderno update` stops updating it once edited.

   ```css
   /* src/styles/fonts.css */
   :root,
   .dark {
     --font-sans: "Inter", system-ui, sans-serif;
   }
   ```

3. Import the font and the override, the override after `moderno.css` (or after `@moderno-ui/css` without the CLI).

   ```ts
   import "@fontsource/inter";
   import "@/styles/moderno.css";
   import "@/styles/fonts.css";
   ```

Every component and the Tailwind `font-sans` utility read the slot, so nothing else changes.

- Keep `.dark` in the selector: the theme sets the fonts again there.
- `@fontsource/inter` loads weight 400 only. Import each other weight you use, such as `@fontsource/inter/600.css`.
- A brand theme needs its own scope, e.g. `[data-brand="contrast"], .dark [data-brand="contrast"], [data-brand="contrast"].dark` for `theme-contrast`.
