## Usage

<ForFramework fw="react">

```tsx
import { SparkChart } from "@moderno-ui/react";

const points = [
  { x: 0, y: 12 },
  { x: 1, y: 18 },
  { x: 2, y: 15 },
];
```

```tsx
<SparkChart points={points} aria-label="Revenue, last 3 weeks" />
```

</ForFramework>

## API Reference

### SparkChart

<PropsTable component="SparkChart" />

### Defaults

| Prop            | Default                                           |
| --------------- | ------------------------------------------------- |
| `width`         | `120`                                             |
| `height`        | `32`                                              |
| `yDomain`       | The lowest to the highest y value (0 not forced). |
| `curve`         | Straight segments                                 |
| `area`          | `false`                                           |
| `showLastPoint` | `false`                                           |

### Data attributes

| Attribute     | On            | Values                                        |
| ------------- | ------------- | --------------------------------------------- |
| `data-chart`  | Root `svg`    | `spark`                                       |
| `data-part`   | Every element | `root`, `series`, `area`, `line`, `point`     |
| `data-series` | Series `g`    | Always `0`, so every shape paints `--chart-1` |

## Notes

- There are no axes, grid or labels. Give each chart an `aria-label`.
- There is no colour prop: the line, fill and marker paint from `--chart-1`.
- To compare several sparks, pass them the same `yDomain`.
