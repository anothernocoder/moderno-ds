## API Reference

### DonutChart

<PropsTable component="DonutChart" />

### Data

Each entry in `data` is one slice.

| Field   | Type     | Description                                                  |
| ------- | -------- | ------------------------------------------------------------ |
| `name`  | `string` | Optional label for the slice.                                |
| `value` | `number` | Its share of the total. A value of 0 or less, or one that is not a finite number, draws no slice. |

### Defaults

| Prop          | Default                             |
| ------------- | ----------------------------------- |
| `innerRadius` | `0.6` (the hole is 60% of the ring) |
| `padAngle`    | `0` (slices touch)                  |

### Data attributes

| Attribute     | On            | Values                                                                 |
| ------------- | ------------- | ---------------------------------------------------------------------- |
| `data-chart`  | Root `svg`    | `donut`                                                                |
| `data-part`   | Every element | `root`, `series`, `slice`                                              |
| `data-series` | Series `g`    | The slice's index in `data`, mapped to `--chart-1` through `--chart-5` |

## Notes

- Slices start at 12 o'clock and go clockwise, in the order of `data`.
- There is no colour prop: slices paint from `--chart-1` to `--chart-5` by index. A sixth slice and beyond fall back to `--chart-1`.
- The chart fills the width of its container. Size it with CSS on a wrapper or a `class`.
- Give it an `aria-label`: the chart is one image to a screen reader.
- The geometry comes from `@moderno-ui/charts-core`, pure math with no DOM, so it renders on the server.
