## Usage

Use Product Details at the top of a product page. Shoppers look through the photos, pick a colour or a size, choose how many and add the product to their cart.

<ForFramework fw="react">

```tsx
import { ProductDetails } from "@/components/blocks/product-details";
```

```tsx
<ProductDetails product={product} adding={adding} onAddToCart={addToCart} />
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import ProductDetails from "@/components/blocks/ProductDetails.vue";
</script>
```

```vue
<ProductDetails :product="product" :adding="adding" @add-to-cart="addToCart" />
```

</ForFramework>
<ForFramework fw="svelte">

```svelte
<script lang="ts">
  import ProductDetails from "@/components/blocks/ProductDetails.svelte";
</script>
```

```svelte
<ProductDetails {product} {adding} onaddtocart={addToCart} />
```

</ForFramework>
<ForFramework fw="solid">

```tsx
import { ProductDetails } from "@/components/blocks/product-details";
```

```tsx
<ProductDetails product={product()} adding={adding()} onAddToCart={addToCart} />
```

</ForFramework>

`addToCart` receives the chosen options and the quantity, like `{ options: { Colour: "sage", Size: "350" }, quantity: 2 }`. Set `adding` while you save it.

## API Reference

### Props

| Prop          | Type                                    | Default          | Description                                                                                                  |
| ------------- | --------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------ |
| `product`     | `Product \| null`                       | a sample product | The product to show. `null` shows the empty message.                                                         |
| `error`       | `string`                                | —                | Loading the product failed; an error Alert with a retry replaces it.                                         |
| `loading`     | `boolean`                               | `false`          | Placeholders in a busy region replace the product.                                                           |
| `disabled`    | `boolean`                               | `false`          | The product stays readable; every option, the quantity box and every button are off.                         |
| `adding`      | `boolean`                               | `false`          | The button shows a spinner, reads "Adding" and cannot be pressed.                                            |
| `onAddToCart` | `(selection: ProductSelection) => void` | —                | "Add to cart" was pressed, with the chosen options and quantity. Svelte: `onaddtocart`. Vue: `@add-to-cart`. |
| `onRetry`     | `() => void`                            | —                | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                                                 |

### Product

| Field            | Type               | Description                                                           |
| ---------------- | ------------------ | --------------------------------------------------------------------- |
| `name`           | `string`           | The product's name, the block's heading.                              |
| `price`          | `string`           | The price as people read it, like `"€28"`.                            |
| `compareAtPrice` | `string`           | Optional. The old price, struck through beside the price.             |
| `description`    | `string`           | Optional. A short paragraph under the price.                          |
| `images`         | `ProductImage[]`   | Optional. The photos, `{ src, alt }`. Without them, one muted square. |
| `options`        | `ProductOption[]`  | Optional. `{ name, values }`, one RadioGroup each.                    |
| `sections`       | `ProductSection[]` | Optional. `{ title, body }`, one tab each.                            |
| `maxQuantity`    | `number`           | Optional. The most a shopper can pick; `99` when left out.            |

### ProductOptionValue

| Field     | Type      | Description                                             |
| --------- | --------- | ------------------------------------------------------- |
| `value`   | `string`  | What `onAddToCart` reports for this choice.             |
| `label`   | `string`  | What the shopper reads, like `"Sage"`.                  |
| `soldOut` | `boolean` | Optional. Marks the choice "Sold out" and turns it off. |

### ProductSelection

| Field      | Type                     | Description                                        |
| ---------- | ------------------------ | -------------------------------------------------- |
| `options`  | `Record<string, string>` | Each option's `name` mapped to the chosen `value`. |
| `quantity` | `number`                 | How many, a whole number from 1 to `maxQuantity`.  |

### States

| State    | Prop                  | What renders                                                              |
| -------- | --------------------- | ------------------------------------------------------------------------- |
| Default  | —                     | The gallery, the name, the price, the options, the quantity and the tabs. |
| Adding   | `adding`              | The same, with a spinner and "Adding" on the button.                      |
| Sold out | every value `soldOut` | The same, with "Sold out" on the button and the quantity box off.         |
| Empty    | `product={null}`      | "This product is no longer available." in a dashed box.                   |
| Loading  | `loading`             | Placeholders for the gallery and the details.                             |
| Error    | `error`               | An error Alert with "Try again".                                          |
| Disabled | `disabled`            | The same product with every option, the quantity box and the button off.  |

### Sizing

| Container step           | What changes                                    |
| ------------------------ | ----------------------------------------------- |
| below `@sm`              | One column. The quantity sits above the button. |
| `@sm` (`--container-sm`) | The quantity and the button share a row.        |
| `@md` (`--container-md`) | The name steps up.                              |
| `@lg` (`--container-lg`) | The gallery moves beside the details.           |
