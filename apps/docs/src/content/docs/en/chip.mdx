## Usage

Use a chip for a small token the user picked, such as a filter or a tag, and may want to remove.

<ForFramework fw="react">

```tsx
import { Chip } from "@moderno-ui/react";
```

```tsx
<Chip removable removeLabel="Remove React">
  React
</Chip>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Chip } from "@moderno-ui/vue";
```

```vue
<Chip removable removeLabel="Remove React">React</Chip>
```

</ForFramework>

<ForFramework fw="svelte">

```ts
import { Chip } from "@moderno-ui/svelte";
```

```svelte
<Chip removable removeLabel="Remove React">React</Chip>
```

</ForFramework>

## API Reference

### Chip

Renders a `<span>`; its children are the label. `variant` defaults to `outline` and `size` to `md`.

<PropsTable component="Chip" />

In Vue, listen with `@remove` instead of passing `onRemove`.

### Parts

| Part             | Element    | Description                                             |
| ---------------- | ---------- | ------------------------------------------------------- |
| `root`           | `<span>`   | The token. Carries `data-variant` and `data-size`.      |
| `label`          | `<span>`   | The children. A long label is cut with an ellipsis.     |
| `remove-trigger` | `<button>` | Rendered only with `removable`. Named by `removeLabel`. |

## Notes

- Chip is CSS-only: a `<span>` with `data-scope="chip"` and a native `<button>` to remove it.
- Give every remove button its own name with `removeLabel`.
- For a read-only label, use Badge.
