description: A long-form prose section — a serif heading, a lead, titled sections of paragraphs and a pulled quote, in one reading column.
group: Blocks
order: 119
agent:
  intent: A section of a landing, guide or article page that is read, not scanned — a kicker, a serif heading, a lead, then titled sections of paragraphs, a pulled quote and one call to action, in one reading column.
  whenToUse: "A page that explains something in a few paragraphs: a guide, a story, a product's approach, a policy summary."
  whenNotToUse:
    - case: The first section of a landing page, with the main call to action
      use: Hero — it says what the product is in one line; the content section comes after it
    - case: Several short points that each fit in one sentence
      use: FeatureGrid — an icon, a title and a sentence per point
    - case: A title with actions above a page or a list
      use: SectionHeader — it carries breadcrumbs, a status and actions
  gotchas:
    - "`sections` is an array of `{ id, heading, paragraphs }`. Each section renders an `h3` and one `p` per string in `paragraphs`."
    - '`kicker`, `lead` and `action` hide when you pass `""`; `quote` hides when you pass `null`.'
    - '`sections={[]}` shows "Nothing to read here yet." in place of the article, and hides the quote and the action.'
    - "Presentational: `onAction` and `onRetry` report which button was pressed. Opening a page and retrying stay yours."
    - "`loading` keeps the kicker, heading and lead, and replaces the sections with skeleton lines in one busy `status` region."
    - '`error` keeps the kicker, heading and lead, and puts an error Alert with your message and a "Try again" button where the sections were. An empty string counts as no error.'
    - "The text column is capped at `--container-md`, and the sizes follow the block's own width, not the viewport."
  theming:
    - "The only paint of its own is the quote's left rule (--border) and the dashed empty box (--border). The action is Button's outline variant, the error is Alert's error variant and the loading placeholders are Skeleton."
    - "The heading and the quote read --font-serif and --foreground; the kicker, the lead, each paragraph and the quote's author read --muted-foreground."
    - "Type sizes come from the contract scale: text-heading-sm and text-heading for the heading, text-body and text-body-lg for the prose, text-ui-sm and text-ui-md for the kicker and the author. The three steps are --container-sm, --container-md and --container-lg."

## API Reference

### Props

| Prop       | Type                   | Default                                     | Description                                                                   |
| ---------- | ---------------------- | ------------------------------------------- | ----------------------------------------------------------------------------- |
| `kicker`   | `string`               | `"Field notes"`                             | A few words above the heading; `""` hides it.                                 |
| `heading`  | `string`               | `"Close the month without the spreadsheet"` | The section's heading. Set in the serif face.                                 |
| `lead`     | `string`               | a sentence                                  | The introduction under the heading; `""` hides it.                            |
| `sections` | `ContentSection[]`     | two sample sections                         | The article, in order. `[]` shows the empty message.                          |
| `quote`    | `ContentQuote \| null` | a sample quote                              | A pulled quote after the sections; `null` hides it.                           |
| `action`   | `string`               | `"Read the full guide"`                     | The outline button's label under the article; `""` hides it.                  |
| `error`    | `string`               | —                                           | Loading the article failed; an error Alert with a retry replaces it.          |
| `loading`  | `boolean`              | `false`                                     | Skeleton lines in a busy region replace the article.                          |
| `disabled` | `boolean`              | `false`                                     | The content stays and every button is disabled.                               |
| `onAction` | `() => void`           | —                                           | The button under the article was pressed. Svelte: `onaction`. Vue: `@action`. |
| `onRetry`  | `() => void`           | —                                           | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                  |

### Section

| Field        | Type       | Description                           |
| ------------ | ---------- | ------------------------------------- |
| `id`         | `string`   | A stable key for the section.         |
| `heading`    | `string`   | A few words. Rendered as an `h3`.     |
| `paragraphs` | `string[]` | The section's text, one `p` per item. |

### Quote

| Field    | Type     | Description                          |
| -------- | -------- | ------------------------------------ |
| `text`   | `string` | The quoted words, in the serif face. |
| `author` | `string` | Who said it, under the quote.        |

### States

| State    | Prop            | What renders                                                    |
| -------- | --------------- | --------------------------------------------------------------- |
| Default  | —               | Kicker, heading, lead, every section, the quote and the action. |
| Empty    | `sections={[]}` | Kicker, heading, lead and "Nothing to read here yet."           |
| Loading  | `loading`       | Kicker, heading, lead and two placeholder sections.             |
| Error    | `error`         | Kicker, heading, lead, then an error Alert with "Try again".    |
| Disabled | `disabled`      | The same content with the action disabled.                      |

### Sizing

| Container step           | What changes                                      |
| ------------------------ | ------------------------------------------------- |
| below `@sm`              | The lead at body size.                            |
| `@sm` (`--container-sm`) | The lead steps up a size; the quote moves inward. |
| `@md` (`--container-md`) | The heading steps up a size.                      |
| `@lg` (`--container-lg`) | More room above and below the section.            |

## Notes

- Two to four sections read best. Put a longer article on its own page.
- Keep paragraphs short: three or four sentences each.
