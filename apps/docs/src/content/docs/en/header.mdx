    - "`navigation` mixes two kinds of item. A link is `{ id, label, href, current?, disabled? }`. A group is `{ id, label, links }`: it opens a Menu of its links in the bar, and lists them under its label in the Drawer."
    - 'Mark the page the user is on with `current: true`: its link gets `aria-current="page"` and reads in --foreground.'
    - 'A `disabled` link has no `href`, `role="link"` and `aria-disabled="true"`: it is dimmed and out of the tab order. In a group it is a disabled Menu item.'
    - "The links are plain `<a href>`. To use your router's link, edit the copied file."
    - "The same links fill the bar and the Drawer. A click on a link or on the call to action in the Drawer closes it."

    - "`homeHref` is where the brand links to; it defaults to `/`."
    - '`navigation={[]}` is the empty state: no links and no "Menu" button, just the brand and the call to action at every width.'
    - "`loading` shows three placeholders in one busy `status` region where the links go, in the bar and in the Drawer."
    - '`error` hides the links and the "Menu" button and puts an error Alert with your message and a "Try again" button under the bar. An empty string counts as no error.'

    - 'The layout follows the block''s own width, not the viewport: the brand and "Menu" at first; the call to action joins the bar from `--container-sm`; the links replace "Menu" from `--container-md`; more room around and between from `--container-lg`.'

## Usage

Use Header once, at the top of every page of a public site. It links home, to the main pages and to one call to action, like signing up.

<ForFramework fw="react">

```tsx
import { Header } from "@/components/blocks/header";
```

```tsx
<Header brand="Northwind" navigation={navigation} action="Get started" onAction={signUp} />
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import Header from "@/components/blocks/Header.vue";
</script>
```

```vue
<Header brand="Northwind" :navigation="navigation" action="Get started" @action="signUp" />
```

</ForFramework>
<ForFramework fw="svelte">

<script lang="ts">

A link looks like `{ id: "pricing", label: "Pricing", href: "/pricing" }`. A group looks like `{ id: "product", label: "Product", links: [...] }`.

## API Reference

### Props

| Prop         | Type              | Default                      | Description                                                                     |
| ------------ | ----------------- | ---------------------------- | ------------------------------------------------------------------------------- |
| `brand`      | `string`          | `"Northwind"`                | The site's name, in the serif face. It links home, and titles the Drawer.       |
| `homeHref`   | `string`          | `"/"`                        | Where the brand links to.                                                       |
| `navigation` | `HeaderNavItem[]` | a group and two sample links | The main navigation, in the bar and in the Drawer.                              |
| `action`     | `string`          | `"Get started"`              | The call to action's label. `""` hides it.                                      |
| `error`      | `string`          | —                            | Loading the navigation failed; an error Alert with a retry shows under the bar. |
| `loading`    | `boolean`         | `false`                      | Placeholders in a busy region replace the links.                                |
| `onAction`   | `() => void`      | —                            | The call to action was pressed. Svelte: `onaction`. Vue: `@action`.             |
| `onRetry`    | `() => void`      | —                            | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                    |

### HeaderNavItem

`HeaderNavItem` is a `HeaderLink` or a `HeaderMenu`.

A `HeaderLink`:

| Field      | Type      | Description                                                              |
| ---------- | --------- | ------------------------------------------------------------------------ |
| `id`       | `string`  | A stable key for the link.                                               |
| `label`    | `string`  | The link's text.                                                         |
| `href`     | `string`  | Where the link goes.                                                     |
| `current`  | `boolean` | Optional. The page the user is on: `aria-current="page"`, in foreground. |
| `disabled` | `boolean` | Optional. The link is dimmed, has no `href` and cannot be focused.       |

A `HeaderMenu`:

| Field   | Type           | Description                                                              |
| ------- | -------------- | ------------------------------------------------------------------------ |
| `id`    | `string`       | A stable key for the group.                                              |
| `label` | `string`       | The Menu trigger's text in the bar, and the group's label in the Drawer. |
| `links` | `HeaderLink[]` | The group's links: Menu items in the bar, a short list in the Drawer.    |

### States

| State    | Prop                 | What renders                                             |
| -------- | -------------------- | -------------------------------------------------------- |
| Default  | `navigation`         | The brand, the links and the call to action.             |
| Empty    | `navigation={[]}`    | The brand and the call to action. No "Menu" button.      |
| Loading  | `loading`            | Three placeholders where the links go.                   |
| Error    | `error`              | An error Alert with "Try again" under the bar. No links. |
| Disabled | `disabled` on a link | That link dimmed, out of the tab order.                  |

### Sizing

| Container step           | What changes                                                              |
| ------------------------ | ------------------------------------------------------------------------- |
| below `@sm`              | The brand and "Menu". The links and the call to action are in the Drawer. |
| `@sm` (`--container-sm`) | The call to action joins the bar, beside "Menu".                          |
| `@md` (`--container-md`) | The links sit in the bar. The "Menu" button goes away.                    |
| `@lg` (`--container-lg`) | More room around the bar and between its parts.                           |

## Notes

- Keep one call to action. A second one, like "Sign in", goes in the page or in a group.
- Keep link labels to one or two words, so the bar stays on one line.
