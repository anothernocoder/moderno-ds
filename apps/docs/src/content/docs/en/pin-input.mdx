  whenToUse: A fixed-length code where each character deserves its own cell and the whole code is submitted at once.

## Usage

<ForFramework fw="react">

```tsx
import { PinInput } from "@moderno-ui/react";

const cells = [0, 1, 2, 3, 4, 5];
```

```tsx
<PinInput.Root count={cells.length} otp>
  <PinInput.Label>Verification code</PinInput.Label>
  <PinInput.Control>
    {cells.map((index) => (
      <PinInput.Input key={index} index={index} />
    ))}
  </PinInput.Control>
  <PinInput.HiddenInput />
</PinInput.Root>
```

</ForFramework>

<ForFramework fw="vue">

```vue
<script setup lang="ts">
import { PinInput } from "@moderno-ui/vue";

const cells = [0, 1, 2, 3, 4, 5];
```

```vue

  </PinInput.Root>

```

## API Reference

### PinInput.Root

<PropsTable component="PinInput" />

Behaviour props come from Ark. The ones the examples use:

| Prop           | Type                                    | Default   | Description                                                                 |
| -------------- | --------------------------------------- | --------- | --------------------------------------------------------------------------- |
| `count`        | `number`                                | —         | Number of cells. Pass it so server-rendered aria labels match the client's. |
| `type`         | `numeric`, `alphanumeric`, `alphabetic` | `numeric` | Accepted characters. `numeric` renders cells as `type="tel"`.               |
| `mask`         | `boolean`                               | `false`   | Renders every cell as `type="password"`.                                    |
| `otp`          | `boolean`                               | `false`   | Sets `autocomplete="one-time-code"` on the cells.                           |
| `invalid`      | `boolean`                               | `false`   | Sets `aria-invalid` and `data-invalid`.                                     |
| `defaultValue` | `string[]`                              | —         | Initial characters, one per cell.                                           |

### Parts

| Part                   | Description                                              |
| ---------------------- | -------------------------------------------------------- |
| `PinInput.Root`        | Holds the state. Takes `size` and the behaviour props.   |
| `PinInput.Label`       | The visible label.                                       |
| `PinInput.Control`     | Wraps the cells.                                         |
| `PinInput.Input`       | One cell. Render one per `index`, from 0 to `count - 1`. |
| `PinInput.HiddenInput` | The named form field that carries the joined code.       |

### Data attributes

| Attribute       | On                 | Meaning                                          |
| --------------- | ------------------ | ------------------------------------------------ |
| `data-size`     | Root               | `sm`, `md` (default), `lg`                       |
| `data-filled`   | Input              | The cell holds a character.                      |
| `data-complete` | Root, Label, Input | Every cell holds a character.                    |
| `data-invalid`  | Root, Label, Input | `invalid` is set. Wins over filled and complete. |
| `data-disabled` | Root, Label, Input | `disabled` is set.                               |

## Notes

- Focus advances as characters land, retreats on Backspace, and a pasted code fills the cells.
- Only `PinInput.Root` is wrapped, to add `size`. Every other part is Ark's.
- Add `PinInput.HiddenInput` when the code is submitted with a form.
- Filled, complete and invalid are Ark data attributes: style them, don't recreate them.
