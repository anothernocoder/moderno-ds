Use a drawer for content that needs more room than a dialog but keeps the page in view: filters, settings, a menu. It slides in from an edge, dims the page and keeps focus inside until it closes.

## Installation

<Install pkg="@moderno-ui/react" />

## Usage

<ForFramework fw="react">

```tsx
import { Drawer, Portal } from "@moderno-ui/react";
```

```tsx
<Drawer.Root>
  <Drawer.Trigger>Filters</Drawer.Trigger>
  <Portal>
    <Drawer.Backdrop />
    <Drawer.Positioner>
      <Drawer.Content>
        <Drawer.Title>Filters</Drawer.Title>
        <Drawer.Description>Narrow the list of orders.</Drawer.Description>
      </Drawer.Content>
    </Drawer.Positioner>
```

## API Reference

### Drawer.Root

`placement` is the Moderno addition. The other props come from Ark's Dialog. The Root renders no element of its own.

<PropsTable component="Drawer" />

| Prop                     | Type                                   | Default | Description                                                                                     |
| ------------------------ | -------------------------------------- | ------- | ----------------------------------------------------------------------------------------------- |
| `open`                   | `boolean`                              | —       | Controlled open state. Pair with `onOpenChange` (`bind:open` in Svelte, `v-model:open` in Vue). |
| `defaultOpen`            | `boolean`                              | `false` | Open state at first when uncontrolled.                                                          |
| `onOpenChange`           | `(details: { open: boolean }) => void` | —       | Called on every open or close, including Escape and clicks outside.                             |
| `modal`                  | `boolean`                              | `true`  | Traps focus, locks page scroll and hides the page from screen readers.                          |
| `initialFocusEl`         | `() => HTMLElement \| null`            | —       | Element to focus on open. Defaults to the first focusable element in the content.               |
| `finalFocusEl`           | `() => HTMLElement \| null`            | —       | Element to focus on close. Defaults to the trigger.                                             |
| `closeOnEscape`          | `boolean`                              | `true`  | Closes on Escape.                                                                               |
| `closeOnInteractOutside` | `boolean`                              | `true`  | Closes on a click on the backdrop.                                                              |
| `lazyMount`              | `boolean`                              | `false` | Mount the content only on first open.                                                           |
| `unmountOnExit`          | `boolean`                              | `false` | Remove the content from the DOM when closed.                                                    |

`Drawer.RootProvider` takes `placement` too, with the `value` from Ark's `useDialog()`.

### Portal

Renders its children at the end of `document.body`, so no parent's `overflow` or stacking clips the drawer.

### Parts

Every part accepts its element's attributes; `Drawer.Trigger` and `Drawer.CloseTrigger` also take `asChild` to render your own `Button`.

| Part                  | Element    | Description                                                                                  |
| --------------------- | ---------- | -------------------------------------------------------------------------------------------- |
| `Drawer.Trigger`      | `<button>` | Opens the drawer. Focus returns to it on close.                                              |
| `Drawer.Backdrop`     | `<div>`    | The dimmed scrim behind the drawer. A click on it closes the drawer.                         |
| `Drawer.Positioner`   | `<div>`    | Covers the screen and holds the content against its edge. Carries `data-placement`.          |
| `Drawer.Content`      | `<div>`    | The panel, with `role="dialog"`. Carries `data-placement`. A column that scrolls.            |
| `Drawer.Title`        | `<h2>`     | The accessible name, wired through `aria-labelledby`.                                        |
| `Drawer.Description`  | `<div>`    | Wired through `aria-describedby`, in `--muted-foreground`. A `<p>` in Svelte.                |
| `Drawer.CloseTrigger` | `<button>` | Closes the drawer. Bare, it is a small icon button in the top corner; Ark labels it `close`. |

### Data attributes

| Attribute        | Values                                                                    |
| ---------------- | ------------------------------------------------------------------------- |
| `data-scope`     | `"drawer"` on every part (the parts are Ark's Dialog parts, re-scoped)    |
| `data-placement` | On the positioner and content: `"left"`, `"right"`, `"top"` or `"bottom"` |
| `data-state`     | `"open"` or `"closed"`, on the trigger, backdrop and content              |

### Keyboard

| Key                 | Action                                              |
| ------------------- | --------------------------------------------------- |
| `Enter` / `Space`   | On the trigger, opens the drawer.                   |
| `Esc`               | Closes the drawer and returns focus to the trigger. |
| `Tab` / `Shift+Tab` | Moves focus through the drawer; it stays inside.    |

## Notes

- Drawer is Ark's Dialog: every part is wrapped only to render under `data-scope="drawer"`, and the Root, Positioner and Content to add `placement`.
- Focus, scroll lock and dismissal come from Ark; don't reimplement them.
- A `Dialog` already presents as a bottom drawer on small screens. Use a Drawer when you want a drawer at every width.
