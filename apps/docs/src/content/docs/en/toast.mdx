Use a toast to confirm that something happened: a file was saved, a message was sent, an upload failed. It shows in a corner of the screen, does not block the page, and goes away after a few seconds.

## Installation

<Install pkg="@moderno-ui/react" />

## Usage

Make one toaster, render its `Toaster` once, then call it from anywhere.

<ForFramework fw="react">

```tsx
import { Toast, Toaster, createToaster } from "@moderno-ui/react";
```

```tsx
const toaster = createToaster({ placement: "bottom-end" });

toaster.create({ title: "Changes saved" });

<Toaster toaster={toaster}>
  {(toast) => (
    <Toast.Root>
      <Toast.Title>{toast.title}</Toast.Title>
    </Toast.Root>
  )}
</Toaster>;
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Toast, Toaster, createToaster } from "@moderno-ui/vue";
```

```vue
<script setup lang="ts">
const toaster = createToaster({ placement: "bottom-end" });

toaster.create({ title: "Changes saved" });
</script>

<template>
  <Toaster v-slot="toast" :toaster="toaster">
    <Toast.Root>
      <Toast.Title>{{ toast.title }}</Toast.Title>
    </Toast.Root>
  </Toaster>
</template>
```

## API Reference

### Toast.Root

`size` is the Moderno addition. Everything else a toast shows comes from what you pass to the toaster.

<PropsTable component="Toast" />

### createToaster

Makes the toaster: a store that holds the toasts. Create it once, outside your components.

| Option        | Type                   | Default              | Description                                                                                    |
| ------------- | ---------------------- | -------------------- | ---------------------------------------------------------------------------------------------- |
| `placement`   | `ToastPlacement`       | `"bottom"`           | Where toasts show: `top-start`, `top`, `top-end`, `bottom-start`, `bottom` or `bottom-end`.    |
| `max`         | `number`               | `24`                 | How many toasts show at once. The rest wait in a queue.                                        |
| `duration`    | `number`               | —                    | How long a toast stays, in ms. By default 5000, 2000 for `success`, and forever for `loading`. |
| `removeDelay` | `number`               | `200`                | How long a dismissed toast takes to leave, in ms.                                              |
| `gap`         | `number`               | `16`                 | Space between toasts, in px.                                                                   |
| `offsets`     | `string \| { top, … }` | `"1rem"`             | Distance from the edges of the screen.                                                         |
| `overlap`     | `boolean`              | `false`              | Stack toasts on top of each other, and spread them out on hover.                               |
| `hotkey`      | `string[]`             | `["altKey", "KeyT"]` | Keys that move focus to the toasts.                                                            |

### The toaster

Call these from anywhere. Each call that creates a toast returns its `id`.

| Method                                               | What it does                                                     |
| ---------------------------------------------------- | ---------------------------------------------------------------- |
| `create(options)`                                    | Shows a toast.                                                   |
| `success` / `error` / `warning` / `info` / `loading` | Shows a toast with that `type`.                                  |
| `promise(promise, { loading, success, error })`      | Shows a loading toast, then turns it into a success or an error. |
| `update(id, options)`                                | Changes a toast that is showing.                                 |
| `dismiss(id?)`                                       | Dismisses one toast, or all of them without an `id`.             |

A toast's options:

| Option        | Type                                                       | Description                                                         |
| ------------- | ---------------------------------------------------------- | ------------------------------------------------------------------- |
| `title`       | `string`                                                   | The main line.                                                      |
| `description` | `string`                                                   | A second, quieter line.                                             |
| `type`        | `"success" \| "error" \| "warning" \| "info" \| "loading"` | The status. Defaults to `info`.                                     |
| `duration`    | `number`                                                   | How long this toast stays, in ms.                                   |
| `action`      | `{ label: string; onClick: () => void }`                   | A button on the toast. Clicking it runs `onClick` and dismisses it. |
| `closable`    | `boolean`                                                  | Whether the user can dismiss it.                                    |
| `meta`        | `Record<string, any>`                                      | Anything else your render function needs, like a `size`.            |

### Parts

Every part accepts its element's attributes and `asChild`.

| Part                  | Element    | Description                                                                          |
| --------------------- | ---------- | ------------------------------------------------------------------------------------ |
| `Toaster`             | `<div>`    | The region that holds the toasts, pinned to the toaster's placement. Render it once. |
| `Toast.Root`          | `<div>`    | One toast, with `role="status"`. Carries `data-size` and `data-type`. A column.      |
| `Toast.Title`         | `<div>`    | The accessible name, wired through `aria-labelledby`.                                |
| `Toast.Description`   | `<div>`    | Wired through `aria-describedby`, in a muted colour.                                 |
| `Toast.ActionTrigger` | `<button>` | A small outline button under the text. Runs the toast's action, then dismisses it.   |
| `Toast.CloseTrigger`  | `<button>` | A small icon button in the top corner. Ark labels it `Dismiss notification`.         |

### Data attributes

| Attribute        | Values                                                                     |
| ---------------- | -------------------------------------------------------------------------- |
| `data-size`      | On the root: `"sm"`, `"md"` or `"lg"`                                      |
| `data-type`      | On the root: `"success"`, `"error"`, `"warning"`, `"info"`, `"loading"`, … |
| `data-state`     | On the root: `"open"`, or `"closed"` while it leaves                       |
| `data-placement` | On the toaster and each root: the toaster's placement                      |
| `data-paused`    | On the root while the pointer or focus is on the toasts                    |

### Keyboard

| Key     | Action                                      |
| ------- | ------------------------------------------- |
| `Alt+T` | Moves focus to the toasts.                  |
| `Tab`   | Moves through the toasts and their buttons. |
| `Esc`   | On a focused toast, dismisses it.           |

## Notes

- `Toast.Root` is wrapped to add `size`; every other part, `Toaster` and `createToaster` are Ark's unchanged.
- A toast pauses while the pointer or focus is on it, so the user has time to read it.
- Keep toasts short. For anything the user must act on, use a `Dialog`.
