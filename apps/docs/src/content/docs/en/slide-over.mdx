## API Reference

### Props

| Prop           | Type                                | Default         | Description                                                                |
| -------------- | ----------------------------------- | --------------- | -------------------------------------------------------------------------- |
| `record`       | `SlideOverRecord`                   | a sample person | The record the panel shows and the form starts from.                       |
| `open`         | `boolean`                           | `false`         | Whether the drawer is open. Svelte: `bind:open`. Vue: `v-model:open`.      |
| `onOpenChange` | `(open: boolean) => void`           | —               | The drawer opened or closed. React and Solid only.                         |
| `error`        | `string`                            | —               | Saving failed; an error Alert sits at the top of the form.                 |
| `loading`      | `boolean`                           | `false`         | The fields are disabled and the save button is a busy "Saving".            |
| `disabled`     | `boolean`                           | `false`         | The trigger is disabled, so the drawer cannot open.                        |
| `onSave`       | `(record: SlideOverRecord) => void` | —               | A form with a name and an email was saved. Svelte: `onsave`. Vue: `@save`. |

### SlideOverRecord

| Field   | Type     | Description                           |
| ------- | -------- | ------------------------------------- |
| `name`  | `string` | Required. The heading of the panel.   |
| `email` | `string` | Required. The line under the heading. |
| `role`  | `string` | Optional. `""` reads "Not added".     |
| `notes` | `string` | Optional. `""` reads "Not added".     |

### States

| State    | Prop         | What renders                                                                                                                                     |
| -------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Default  | —            | The panel and its trigger; the drawer holds the form, filled from `record`.                                                                      |
| Empty    | empty fields | Role or notes left empty read "Not added". Saved without a name or an email, those fields turn invalid, show an error and the first takes focus. |
| Loading  | `loading`    | The form with its fields disabled and a busy "Saving" button.                                                                                    |
| Error    | `error`      | An error Alert at the top of the form; what was typed stays.                                                                                     |
| Disabled | `disabled`   | The panel with its trigger disabled.                                                                                                             |

### Sizing

| Container step           | What changes                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------ |
| below `@sm`              | The trigger fills its row, and each term sits above its value.                                   |
| `@sm` (`--container-sm`) | The trigger takes its own width, each term sits beside its value, and the panel's padding grows. |
| `@md` (`--container-md`) | The heading steps up a size.                                                                     |
| `@lg` (`--container-lg`) | The trigger sits beside the name, with more room above and below.                                |

The drawer is the Drawer primitive: it slides in from the right, as wide as the viewport up to `--container-sm`.

## Notes

- Close the drawer only once the save succeeds. If it fails, keep it open and set `error`, so nothing typed is lost.
- Keep the form short. Put fields that people rarely change on a settings page instead.
