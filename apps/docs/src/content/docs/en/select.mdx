## Usage

<ForFramework fw="react">

```tsx
import { Select, Portal, createListCollection } from "@moderno-ui/react";

const frameworks = createListCollection({
  items: [
    { label: "React", value: "react" },
    { label: "Vue", value: "vue" },
  ],
});
```

```tsx
<Select.Root collection={frameworks}>
  <Select.Label>Framework</Select.Label>
  <Select.Control>
    <Select.Trigger>
      <Select.ValueText placeholder="Pick one" />
    </Select.Trigger>
  </Select.Control>
  <Portal>
    <Select.Positioner>
      <Select.Content>
        {frameworks.items.map((item) => (
          <Select.Item key={item.value} item={item}>
            <Select.ItemText>{item.label}</Select.ItemText>
          </Select.Item>
        ))}
      </Select.Content>
    </Select.Positioner>
  </Portal>
</Select.Root>
```

</ForFramework>

## API Reference

### Select.Root

<PropsTable component="Select" />

Selection props come from Ark. The ones the examples use:

| Prop           | Type             | Default | Description                                                          |
| -------------- | ---------------- | ------- | -------------------------------------------------------------------- |
| `collection`   | `ListCollection` | —       | The options, built with `createListCollection`. Required.            |
| `defaultValue` | `string[]`       | —       | Initial selection, uncontrolled. Always an array, even for one pick. |
| `value`        | `string[]`       | —       | Controlled selection. Update it from `onValueChange`.                |
| `multiple`     | `boolean`        | `false` | Allows several picks. The menu stays open between picks.             |

### Parts

| Part                   | Description                                                          |
| ---------------------- | -------------------------------------------------------------------- |
| `Select.Root`          | Holds the state. Takes `collection`, `size` and the selection props. |
| `Select.Label`         | The visible label.                                                   |
| `Select.Control`       | Wraps the trigger.                                                   |
| `Select.Trigger`       | The button that opens the menu.                                      |
| `Select.ValueText`     | The selected label(s), or `placeholder` when empty.                  |
| `Select.Indicator`     | The open/close affordance inside the trigger.                        |
| `Select.Positioner`    | Positions the menu. Wrap it in `Portal`.                             |
| `Select.Content`       | The menu surface.                                                    |
| `Select.Item`          | One option. Takes an `item` from the collection.                     |
| `Select.ItemText`      | The option's label.                                                  |
| `Select.ItemIndicator` | Shown while the option is checked.                                   |

### Data attributes

| Attribute          | On      | Values                                       |
| ------------------ | ------- | -------------------------------------------- |
| `data-size`        | Root    | `sm`, `md` (default), `lg`                   |
| `data-state`       | Content | `open`, `closed`                             |
| `data-state`       | Item    | `checked`, `unchecked`                       |
| `data-highlighted` | Item    | Present on the keyboard or pointer highlight |
| `data-disabled`    | Item    | Present when the item has `disabled: true`   |

## Notes

- Only `Select.Root` is wrapped, to add `size`. Every other part is Ark's.
- The menu renders in a `Portal` and unmounts while closed, so SSR and hydration stay clean.
- A disabled item is skipped by keyboard navigation and typeahead, and can't be selected.
- Style the menu through `[data-scope="select"][data-part="content"]`, not a wrapper class.
- The menu surface paints from `--popover` and `--popover-foreground`.
