  gotchas:

    - "Copy link uses `navigator.clipboard`, which needs a secure context (https or localhost). When the browser refuses, the block shows an error toast that asks the user to copy by hand."
    - "The invite field checks the address before calling `onInvite`: an invalid address, or one already in `members`, shows an inline error and calls nothing."
    - "`members` and `channels` default to samples so the block renders standalone. `members={[]}` is the empty state; `channels={[]}` hides the share buttons."

    - "`disabled` keeps the link and the people readable and disables every button and the invite field."

Use it where people share something: invite a teammate by email, see who already has access, copy the link or send it to a channel. Every action ends in a toast that says how it went.

## API Reference

### Props

| Prop          | Type                                                       | Default                | Description                                                           |
| ------------- | ---------------------------------------------------------- | ---------------------- | --------------------------------------------------------------------- |
| `heading`     | `string`                                                   | `"Share this project"` | The card's title.                                                     |
| `description` | `string`                                                   | see source             | The line under the title; `""` hides it.                              |
| `link`        | `string`                                                   | a sample URL           | The link people copy or send.                                         |
| `members`     | `ShareInviteMember[]`                                      | three samples          | Who has access. `[]` renders the empty state.                         |
| `channels`    | `ShareInviteChannel[]`                                     | Email, Slack, …        | The share buttons. `[]` hides them.                                   |
| `error`       | `string`                                                   | —                      | The settings failed to load; an alert with a retry replaces them.     |
| `loading`     | `boolean`                                                  | `false`                | Placeholders in a busy region replace the settings.                   |
| `disabled`    | `boolean`                                                  | `false`                | Everything stays readable; every button and the invite field are off. |
| `onInvite`    | `(email: string) => void \| Promise<void>`                 | —                      | A valid, new address was invited. Svelte: `oninvite`. Vue: `@invite`. |
| `onShare`     | `(channel: string, link: string) => void \| Promise<void>` | —                      | A channel button was pressed. Svelte: `onshare`. Vue: `@share`.       |
| `onCopy`      | `(link: string) => void`                                   | —                      | The link reached the clipboard. Svelte: `oncopy`. Vue: `@copy`.       |
| `onRetry`     | `() => void`                                               | —                      | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.          |

### ShareInviteMember

| Field   | Type     | Description                                  |
| ------- | -------- | -------------------------------------------- |
| `id`    | `string` | A stable key.                                |
| `name`  | `string` | Shown in full; its initials fill the avatar. |
| `email` | `string` | Shown under the name.                        |
| `role`  | `string` | Shown in a badge: `Owner`, `Can edit`, …     |

### ShareInviteChannel

| Field   | Type     | Description                                  |
| ------- | -------- | -------------------------------------------- |
| `value` | `string` | Passed to `onShare`: `"slack"`, `"email"`, … |
| `label` | `string` | The button text, and the name in its toast.  |

### Feedback

| Action           | Toast on success  | Toast on failure                               |
| ---------------- | ----------------- | ---------------------------------------------- |
| Copy link        | "Link copied"     | "Could not copy the link"                      |
| A channel button | "Shared to Slack" | "Could not share to Slack" (`onShare` rejects) |
| Invite           | "Invite sent"     | "Invite not sent" (`onInvite` rejects)         |

An invalid address, or one already in `members`, shows an error under the field instead, and calls nothing.

### States

| State    | Prop           | What renders                                                       |
| -------- | -------------- | ------------------------------------------------------------------ |
| Default  | —              | The invite field, the people, the link and the channels.           |
| Sending  | —              | While `onInvite` runs: the field and button off, "Sending".        |
| Empty    | `members={[]}` | "Only you have access" in place of the people.                     |
| Loading  | `loading`      | Placeholders for the field, the people and the link.               |
| Error    | `error`        | An error alert with a "Try again" button in place of the settings. |
| Disabled | `disabled`     | Everything readable, every button and the invite field off.        |

Hover and focus-visible come from Button and Field.

### Sizing

| Container step           | What changes                                               |
| ------------------------ | ---------------------------------------------------------- |
| below `@sm`              | Everything stacks; the channels sit two in a row.          |
| `@sm` (`--container-sm`) | Each field sits beside its button; four channels in a row. |
| `@md` (`--container-md`) | The people split into two columns.                         |
| `@lg` (`--container-lg`) | The invite and the link become two panes, side by side.    |
