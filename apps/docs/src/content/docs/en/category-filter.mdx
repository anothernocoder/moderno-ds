## API Reference

### Props

| Prop              | Type                                 | Default             | Description                                                                    |
| ----------------- | ------------------------------------ | ------------------- | ------------------------------------------------------------------------------ |
| `heading`         | `string`                             | `"New arrivals"`    | The block's `h2`.                                                              |
| `description`     | `string`                             | a sample sentence   | The line under the heading. `""` hides it.                                     |
| `facets`          | `FilterFacet[]`                      | three sample facets | One Accordion item each, with a Checkbox per option.                           |
| `price`           | `PriceFilter \| null`                | `0` to `200` in EUR | The price range Slider. `null` leaves it out.                                  |
| `error`           | `string`                             | —                   | The filters failed to load; an error Alert takes their place.                  |
| `loading`         | `boolean`                            | `false`             | Placeholders take the place of the filters.                                    |
| `disabled`        | `boolean`                            | `false`             | Every control is off.                                                          |
| `children`        | products                             | —                   | Your products, beside the sidebar or under the heading. Vue: the default slot. |
| `onFiltersChange` | `(filters: CategoryFilters) => void` | —                   | The filters changed. Svelte: `onfilterschange`. Vue: `@filters-change`.        |
| `onRetry`         | `() => void`                         | —                   | "Try again" was pressed. Svelte: `onretry`. Vue: `@retry`.                     |

### FilterFacet

| Field     | Type                                                 | Description                                                   |
| --------- | ---------------------------------------------------- | ------------------------------------------------------------- |
| `id`      | `string`                                             | The key of this facet in `CategoryFilters.options`.           |
| `label`   | `string`                                             | The Accordion item's heading.                                 |
| `options` | `{ value: string; label: string; count?: number }[]` | One Checkbox each. `count` shows muted at the end of the row. |

### PriceFilter

| Field      | Type     | Description                                       |
| ---------- | -------- | ------------------------------------------------- |
| `min`      | `number` | The lowest price.                                 |
| `max`      | `number` | The highest price.                                |
| `step`     | `number` | How far one arrow key moves a thumb. Default `1`. |
| `currency` | `string` | An ISO currency code. Default `EUR`.              |

### CategoryFilters

| Field     | Type                       | Description                                        |
| --------- | -------------------------- | -------------------------------------------------- |
| `options` | `Record<string, string[]>` | The checked values, by facet `id`.                 |
| `price`   | `[number, number] \| null` | The chosen price range, or `null` with no `price`. |

### States

| State    | Prop                       | What renders                                                             |
| -------- | -------------------------- | ------------------------------------------------------------------------ |
| Default  | —                          | The filters, every facet open, nothing checked and the full price range. |
| Empty    | no `facets` and no `price` | "No filters for this category." in a dashed box.                         |
| Loading  | `loading`                  | Placeholders in a busy `status` region.                                  |
| Error    | `error`                    | An error Alert with "Try again".                                         |
| Disabled | `disabled`                 | Every checkbox, the price range and every button off.                    |

### Sizing

| Container step           | What changes                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------- |
| below `@sm`              | The filters are in a drawer; the Filters button fills its row under the heading.   |
| `@sm` (`--container-sm`) | The Filters button sits beside the heading.                                        |
| `@md` (`--container-md`) | The filters sit in a sidebar beside the products, and the heading steps up a size. |
| `@lg` (`--container-lg`) | The sidebar widens, with more room above and below.                                |
