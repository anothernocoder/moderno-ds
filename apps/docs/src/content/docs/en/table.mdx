## Usage

Use Table when people need to compare many records, sort them and act on several at once. Click a header to sort, tick rows to select them, and open a row's menu for its actions.

<ForFramework fw="react">

```tsx
import { Table } from "@/components/blocks/table";
```

```tsx
<Table invoices={invoices} onBatchAction={(action, ids) => run(action, ids)} />
```

</ForFramework>
<ForFramework fw="vue">

<script setup lang="ts">

```

<Table :invoices="invoices" @batch-action="run" />
```

</ForFramework>

Each invoice looks like `{ id: "inv-1042", number: "INV-1042", customer: "Acme Studio", email: "billing@acme.example", issued: "12 Jan 2026", amount: 2400, status: "Paid", statusVariant: "success" }`. Pass all of them: the block sorts and pages them itself.

## API Reference

### Props

| Prop                | Type                                      | Default                                                   | Description                                                                                                      |
| ------------------- | ----------------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `heading`           | `string`                                  | `"Invoices"`                                              | The section's heading, set in the serif face. It also names the table and its frame.                             |
| `description`       | `string`                                  | `"Every invoice you have sent, with what is still owed."` | The line under the heading. An empty string hides it.                                                            |
| `invoices`          | `TableInvoice[]`                          | twelve sample invoices                                    | Every invoice, in the order you pass them. `[]` shows the empty message.                                         |
| `pageSize`          | `number`                                  | `5`                                                       | Rows on a page. The page row shows only when there is more than one page.                                        |
| `rowActions`        | `TableAction[]`                           | View, Download PDF, Delete                                | The items in each row's actions menu.                                                                            |
| `batchActions`      | `TableAction[]`                           | Mark as paid, Download PDFs, Delete                       | The items in the "Bulk actions" menu.                                                                            |
| `formatAmount`      | `(amount: number) => string`              | euros, `en-GB`                                            | Turns each `amount` into the text in the Amount column.                                                          |
| `error`             | `string`                                  | —                                                         | Loading the invoices failed; an error Alert with a retry replaces the table.                                     |
| `loading`           | `boolean`                                 | `false`                                                   | Placeholder rows in a busy region replace the table.                                                             |
| `disabled`          | `boolean`                                 | `false`                                                   | The rows stay; the checkboxes, sort buttons, menus and page row are off.                                         |
| `onSelectionChange` | `(ids: string[]) => void`                 | —                                                         | The selection changed, with every selected `id`. Svelte: `onselectionchange`. Vue: `@selection-change`.          |
| `onRowAction`       | `(action: string, id: string) => void`    | —                                                         | An item in a row's menu, with its `value` and the row's `id`. Svelte: `onrowaction`. Vue: `@row-action`.         |
| `onBatchAction`     | `(action: string, ids: string[]) => void` | —                                                         | An item in "Bulk actions", with its `value` and the selected ids. Svelte: `onbatchaction`. Vue: `@batch-action`. |
| `onRetry`           | `() => void`                              | —                                                         | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                                                     |

### TableInvoice

| Field           | Type           | Description                                                        |
| --------------- | -------------- | ------------------------------------------------------------------ |
| `id`            | `string`       | A stable key, passed to the callbacks.                             |
| `number`        | `string`       | The invoice number people see, like `"INV-1042"`. Sortable.        |
| `customer`      | `string`       | Who the invoice is for. Sortable.                                  |
| `email`         | `string`       | The customer's email, shown under the name from `@lg`.             |
| `issued`        | `string`       | When it was sent, like `"12 Jan 2026"`. Shown from `@lg`.          |
| `amount`        | `number`       | What it is for, like `2400`. Sortable; shown by `formatAmount`.    |
| `status`        | `string`       | The badge's text, like `"Paid"`.                                   |
| `statusVariant` | `BadgeVariant` | Optional. The badge's colour, like `"success"`. Default `neutral`. |

### TableAction

| Field   | Type     | Description                                  |
| ------- | -------- | -------------------------------------------- |
| `value` | `string` | What the callback receives, like `"delete"`. |
| `label` | `string` | The menu item's text, like `"Delete"`.       |

### States

| State    | Prop            | What renders                                                               |
| -------- | --------------- | -------------------------------------------------------------------------- |
| Default  | —               | The heading, the toolbar, the first page of rows and the page row.         |
| Selected | tick a row      | "2 of 12 selected", "Clear selection" and "Bulk actions"; rows filled.     |
| Empty    | `invoices={[]}` | The heading and "You have not sent any invoices yet."                      |
| Loading  | `loading`       | The heading and placeholder rows.                                          |
| Error    | `error`         | The heading and an error Alert with "Try again".                           |
| Disabled | `disabled`      | The same rows, with every checkbox, sort button, menu and page button off. |

### Sizing

| Container step           | What changes                                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------------------------------- |
| below `@sm`              | The table scrolls sideways inside its frame. The page row is centred.                                           |
| `@sm` (`--container-sm`) | The page row moves to the end.                                                                                  |
| `@md` (`--container-md`) | The heading steps up.                                                                                           |
| `@lg` (`--container-lg`) | The Issued column appears, and each customer's email shows under the name. More room above and below the block. |

## Notes

- Keep status words short, so the Status column stays narrow.
- The block sorts and pages in the browser. For very large tables, edit your copy to sort and page on the server instead.
