## Usage

Use a callout for a note that belongs to the content: a tip, a caveat or a heads-up. It is quieter than an [Alert](/en/alert/), which reports what just happened.

<ForFramework fw="react">

```tsx
import { Callout } from "@moderno-ui/react";
```

```tsx
<Callout.Root variant="warning">
  <Callout.Content>
    <Callout.Title>Renaming breaks old links</Callout.Title>
    <Callout.Description>Share the new address with your team.</Callout.Description>
  </Callout.Content>
</Callout.Root>
```

</ForFramework>

## API Reference

### Callout.Root

`variant` defaults to `info`.

<PropsTable component="Callout" />

| Prop   | Type     | Default | Description                                           |
| ------ | -------- | ------- | ----------------------------------------------------- |
| `role` | `string` | `note`  | Overrides the note role, for example with a `region`. |

### Callout.Icon

A slot for your own glyph; the part colours it with the variant's hue through `currentColor`.

| Prop          | Type      | Default | Description                                     |
| ------------- | --------- | ------- | ----------------------------------------------- |
| `aria-hidden` | `boolean` | `true`  | Hides the decorative glyph from assistive tech. |

### Parts

Every part renders a `<div>` and accepts any div attribute.

| Part                  | `data-part`   | Description                                  |
| --------------------- | ------------- | -------------------------------------------- |
| `Callout.Root`        | `root`        | The note. Carries `data-variant`.            |
| `Callout.Icon`        | `icon`        | Optional glyph before the content.           |
| `Callout.Content`     | `content`     | Column that holds the title and description. |
| `Callout.Title`       | `title`       | Optional headline.                           |
| `Callout.Description` | `description` | The text of the note.                        |

### Variants

| `variant` | Colour slot     |
| --------- | --------------- |
| `info`    | `--info`        |
| `success` | `--success`     |
| `warning` | `--warning`     |
| `error`   | `--destructive` |

## Notes

- Callout is CSS-only: no Ark machine, just parts carrying `data-scope="callout"` and their `data-part`.
- A callout is not announced when it appears. If the message reports an event, use an Alert.
