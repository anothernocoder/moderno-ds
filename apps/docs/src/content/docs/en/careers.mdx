## API Reference

### Props

| Prop          | Type            | Default                | Description                                                              |
| ------------- | --------------- | ---------------------- | ------------------------------------------------------------------------ |
| `heading`     | `string`        | `"Come build with us"` | The section's heading. Set in the serif face.                            |
| `description` | `string`        | a sentence             | One sentence under the heading; `""` hides it.                           |
| `roles`       | `CareersRole[]` | five sample roles      | The open roles, in order. `[]` shows the empty message.                  |
| `error`       | `string`        | —                      | Loading the roles failed; an error Alert with a retry replaces the list. |
| `loading`     | `boolean`       | `false`                | Skeleton rows in a busy region replace the list.                         |
| `disabled`    | `boolean`       | `false`                | The roles stay; every apply link is inert and the retry button disabled. |
| `onRetry`     | `() => void`    | —                      | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.             |

### Role

| Field        | Type     | Description                                            |
| ------------ | -------- | ------------------------------------------------------ |
| `id`         | `string` | A stable key for the role.                             |
| `title`      | `string` | The job title. Rendered as an `h3`.                    |
| `department` | `string` | The team. Shown in an outline Badge.                   |
| `location`   | `string` | Where the role is based, like `"Remote"`.              |
| `type`       | `string` | How the role is held, like `"Full-time"`.              |
| `href`       | `string` | The role's application page. The apply link goes here. |

### States

| State    | Prop         | What renders                                                 |
| -------- | ------------ | ------------------------------------------------------------ |
| Default  | —            | Heading, introduction and every role with its apply link.    |
| Empty    | `roles={[]}` | Heading, introduction and "No open roles right now."         |
| Loading  | `loading`    | Heading, introduction and three placeholder rows.            |
| Error    | `error`      | Heading, introduction, then an error Alert with "Try again". |
| Disabled | `disabled`   | The same roles with every apply link inert.                  |

### Sizing

| Container step           | What changes                           |
| ------------------------ | -------------------------------------- |
| below `@sm`              | Each apply link sits under its role.   |
| `@sm` (`--container-sm`) | Each apply link sits beside its role.  |
| `@md` (`--container-md`) | The heading steps up a size.           |
| `@lg` (`--container-lg`) | More room above and below the section. |

- Order the roles the way candidates look for them, like by team.
