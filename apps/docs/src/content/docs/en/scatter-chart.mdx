## Usage

<ForFramework fw="react">

```tsx
import { ScatterChart } from "@moderno-ui/react";

const series = [
  {
    name: "Sessions",
    points: [
      { x: 0, y: 12 },
      { x: 1, y: 28 },
      { x: 2, y: 40 },
    ],
  },
```

## API Reference

### ScatterChart

<PropsTable component="ScatterChart" />

### Series

Each entry in `series` is one group of samples.

| Field    | Type                         | Description                    |
| -------- | ---------------------------- | ------------------------------ |
| `name`   | `string`                     | Optional label for the series. |
| `points` | `{ x: number; y: number }[]` | One marker per point.          |

### Defaults

| Prop               | Default                                                |
| ------------------ | ------------------------------------------------------ |
| `radius`           | `4`                                                    |
| `xDomain`          | The extent of every x value across all series.         |
| `yDomain`          | Every y value plus 0, rounded outward to nice numbers. |
| `xTicks`, `yTicks` | `5`                                                    |
| `margin`           | `{ top: 16, right: 16, bottom: 28, left: 36 }`         |
| `format`           | The number, rounded to 4 decimals                      |

### Data attributes

| Attribute     | On            | Values                                                                    |
| ------------- | ------------- | ------------------------------------------------------------------------- |
| `data-chart`  | Root `svg`    | `scatter`                                                                 |
| `data-part`   | Every element | `root`, `grid`, `grid-line`, `axis-line`, `tick-label`, `series`, `point` |
| `data-series` | Series `g`    | 0-based index, mapped to `--chart-1` through `--chart-5`                  |

## Notes

- Points are not connected; use a LineChart when the order between them matters.
- There is no colour prop: series paint from `--chart-1` to `--chart-5` by index.
- Grid, axes and tick labels use `--border` and `--muted-foreground`.
