## Usage

A Tooltip is a short label for a control. It shows while the pointer rests on the control, or while the control has keyboard focus, and hides on Escape. Use it to name an icon button or show a shortcut.

<ForFramework fw="react">

```tsx
import { Button, Portal, Tooltip } from "@moderno-ui/react";
```

```tsx
<Tooltip.Root>
  <Tooltip.Trigger asChild>
    <Button variant="outline">Save</Button>
  </Tooltip.Trigger>
  <Portal>
    <Tooltip.Positioner>
      <Tooltip.Content>
        <Tooltip.Arrow>
          <Tooltip.ArrowTip />
        </Tooltip.Arrow>
        Save your changes
      </Tooltip.Content>
    </Tooltip.Positioner>
  </Portal>
</Tooltip.Root>
```

</ForFramework>


```tsx
<Tooltip.Root>
  <Tooltip.Trigger
    asChild={(triggerProps) => (
      <Button {...triggerProps()} variant="outline">
        Save
      </Button>
    )}
  />
  <Portal>
    <Tooltip.Positioner>
      <Tooltip.Content>
        <Tooltip.Arrow>

      </Tooltip.Content>
    </Tooltip.Positioner>
  </Portal>
</Tooltip.Root>
```

</ForFramework>

`asChild` puts the trigger on your own button, so the tooltip describes it. `Portal` keeps the tooltip out of any parent that clips.

## API Reference

### Tooltip.Root

`size` is the Moderno addition; the content's padding, type and arrow follow it. The other props come from Ark's Tooltip.

<PropsTable component="Tooltip" />

| Prop            | Type                                   | Default                   | Description                                                    |
| --------------- | -------------------------------------- | ------------------------- | -------------------------------------------------------------- |
| `openDelay`     | `number`                               | `400`                     | Milliseconds the pointer rests on the trigger before it opens. |
| `closeDelay`    | `number`                               | `150`                     | Milliseconds before it closes once the pointer leaves.         |
| `positioning`   | `PositioningOptions`                   | `{ placement: "bottom" }` | Where it sits: `placement`, `gutter`, `offset`, …              |
| `open`          | `boolean`                              | —                         | Controlled open state.                                         |
| `defaultOpen`   | `boolean`                              | `false`                   | Open at first, when uncontrolled.                              |
| `onOpenChange`  | `(details: { open: boolean }) => void` | —                         | Called when it opens or closes.                                |
| `disabled`      | `boolean`                              | `false`                   | Never open.                                                    |
| `interactive`   | `boolean`                              | `false`                   | Let the pointer move onto the content without closing it.      |
| `closeOnClick`  | `boolean`                              | `true`                    | Close when the trigger is clicked.                             |
| `closeOnEscape` | `boolean`                              | `true`                    | Close on Escape.                                               |
| `aria-label`    | `string`                               | —                         | A label for screen readers when the content is not plain text. |

In Vue, bind the state with `v-model:open`, and listen with `@open-change`. In Svelte, use `bind:open`.

### Parts

| Part                 | Element    | Description                                                       |
| -------------------- | ---------- | ----------------------------------------------------------------- |
| `Tooltip.Root`       | —          | Holds the state. Renders no element; hands `size` to the content. |
| `Tooltip.Trigger`    | `<button>` | The control it describes. Use `asChild` to put it on your own.    |
| `Tooltip.Positioner` | `<div>`    | Places the content next to the trigger.                           |
| `Tooltip.Content`    | `<div>`    | The label, with the `tooltip` role. Carries `data-size`.          |
| `Tooltip.Arrow`      | `<div>`    | Optional. Points the content at the trigger.                      |
| `Tooltip.ArrowTip`   | `<div>`    | The tip you see, inside the arrow.                                |
| `Tooltip.Context`    | —          | Hands you the tooltip: `open`, `setOpen`, `reposition`.           |

### Data attributes

| Attribute      | Values                                                       |
| -------------- | ------------------------------------------------------------ |
| `data-state`   | On the trigger and content: `"open"` or `"closed"`           |
| `data-side`    | On the content: `"top"`, `"right"`, `"bottom"` or `"left"`   |
| `data-instant` | On the content, when it opened at once after another tooltip |
| `data-size`    | On the content: `"sm"`, `"md"` or `"lg"`                     |

## Notes

- `Tooltip.Root` and `Tooltip.Content` are wrapped to carry `size`; every other part is Ark's unchanged.
- Moving from one tooltip to the next opens it at once, without the fade. When the reader prefers reduced motion there is no fade at all.
- Touch screens have no hover. Keep what the tooltip says available some other way.
