## Usage

Use Store Nav once, at the top of every page of a store. It links home and to the categories, searches the catalogue and opens the cart.

<ForFramework fw="react">

```tsx
import { StoreNav } from "@/components/blocks/store-nav";
```

```tsx
<StoreNav
  brand="Northwind"
  categories={categories}
  suggestions={products}
  cartCount={cart.length}
  onSearch={(query) => navigate(`/search?q=${encodeURIComponent(query)}`)}
  onCart={openCart}
/>
```

</ForFramework>
<ForFramework fw="vue">

```vue

</script>
```

  :cart-count="cart.length"

A category looks like `{ id: "bags", label: "Bags", href: "/bags" }`, or `{ id: "workspace", label: "Workspace", links: [...] }` when it has sub-categories. A suggestion looks like `{ value: "canvas-tote", label: "Canvas tote", href: "/products/canvas-tote" }`.

## API Reference

### Props

| Prop          | Type                      | Default                                     | Description                                                                             |
| ------------- | ------------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------- |
| `brand`       | `string`                  | `"Northwind"`                               | The store's name, in the serif face. It links home, and titles the Drawer.              |
| `homeHref`    | `string`                  | `"/"`                                       | Where the brand links to.                                                               |
| `categories`  | `StoreNavCategory[]`      | two categories with sub-categories and Bags | The categories, in the bar and in the Drawer.                                           |
| `suggestions` | `StoreNavSuggestion[]`    | six sample products                         | What the search suggests, filtered by the typed text.                                   |
| `cartCount`   | `number`                  | `2`                                         | How many items the cart holds, shown in a Badge.                                        |
| `error`       | `string`                  | —                                           | Loading the categories failed; an error Alert with a retry shows under the bar.         |
| `loading`     | `boolean`                 | `false`                                     | Placeholders in a busy region replace the categories.                                   |
| `onSearch`    | `(query: string) => void` | —                                           | Enter in the search with no suggestion highlighted. Svelte: `onsearch`. Vue: `@search`. |
| `onCart`      | `() => void`              | —                                           | The cart button was pressed. Svelte: `oncart`. Vue: `@cart`.                            |
| `onRetry`     | `() => void`              | —                                           | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                            |

### StoreNavCategory

`StoreNavCategory` is a `StoreNavLink` or a `StoreNavMenu`.

A `StoreNavLink`:

| Field      | Type      | Description                                                                  |
| ---------- | --------- | ---------------------------------------------------------------------------- |
| `id`       | `string`  | A stable key for the link.                                                   |
| `label`    | `string`  | The link's text.                                                             |
| `href`     | `string`  | Where the link goes.                                                         |
| `current`  | `boolean` | Optional. The category the user is in: `aria-current="page"`, in foreground. |
| `disabled` | `boolean` | Optional. The link is dimmed, has no `href` and cannot be focused.           |

A `StoreNavMenu`:

| Field   | Type             | Description                                                                 |
| ------- | ---------------- | --------------------------------------------------------------------------- |
| `id`    | `string`         | A stable key for the category.                                              |
| `label` | `string`         | The Menu trigger's text in the bar, and the category's label in the Drawer. |
| `links` | `StoreNavLink[]` | The sub-categories: Menu items in the bar, a short list in the Drawer.      |

### StoreNavSuggestion

| Field   | Type     | Description                                   |
| ------- | -------- | --------------------------------------------- |
| `value` | `string` | A stable key for the suggestion.              |
| `label` | `string` | The text shown, and the text that is matched. |
| `href`  | `string` | Where choosing the suggestion goes.           |

### States

| State    | Prop                 | What renders                                                  |
| -------- | -------------------- | ------------------------------------------------------------- |
| Default  | `categories`         | The brand, the categories, the search and the cart.           |
| Empty    | `categories={[]}`    | The brand, the search and the cart. No "Menu" button.         |
| No match | a query              | The search list says "No suggestions. Press Enter to search." |
| Loading  | `loading`            | Three placeholders where the categories go.                   |
| Error    | `error`              | An error Alert with "Try again" under the bar. No categories. |
| Disabled | `disabled` on a link | That link dimmed, out of the tab order.                       |

### Sizing

| Container step           | What changes                                                          |
| ------------------------ | --------------------------------------------------------------------- |
| below `@sm`              | The brand and "Menu". The search and the cart share a row under them. |
| `@sm` (`--container-sm`) | More room at the ends of the bar.                                     |
| `@md` (`--container-md`) | The categories sit in the bar. The "Menu" button goes away.           |
| `@lg` (`--container-lg`) | The search and the cart join the bar, after the categories.           |

## Notes

- Keep the suggestions short: a handful of products or categories. For a full catalogue, fetch them as the user types and pass the result.
- Keep category labels to one word, so the bar stays on one line.
