## Usage

A radio group shows a short list of options, and the user picks exactly one. Use it when the options should be compared side by side; for a long list, use Select.

<ForFramework fw="react">

```tsx
import { RadioGroup } from "@moderno-ui/react";
```

```tsx
<RadioGroup.Root defaultValue="pro">
  <RadioGroup.Label>Plan</RadioGroup.Label>
  <RadioGroup.Item value="free">
    <RadioGroup.ItemControl />
    <RadioGroup.ItemText>Free</RadioGroup.ItemText>
    <RadioGroup.ItemHiddenInput />
  </RadioGroup.Item>
  <RadioGroup.Item value="pro">
    <RadioGroup.ItemControl />
    <RadioGroup.ItemText>Pro</RadioGroup.ItemText>
    <RadioGroup.ItemHiddenInput />
  </RadioGroup.Item>
</RadioGroup.Root>
```

</ForFramework>

## API Reference

### RadioGroup.Root

The first table lists Moderno's props: `variant` (default `"list"`), `size` (default `"md"`), and two for tiles, `columns` (unset: the cards fill the row) and `aspectRatio` (default `"16:9"`). The second lists the props that come from Ark's RadioGroup.

<PropsTable component="RadioGroup" />

| Prop            | Type                           | Default      | Description                                                                |
| --------------- | ------------------------------ | ------------ | -------------------------------------------------------------------------- |
| `value`         | `string \| null`               | —            | Controlled value. Pair with `onValueChange`.                               |
| `defaultValue`  | `string \| null`               | —            | Initial value when uncontrolled.                                           |
| `onValueChange` | `(details: { value }) => void` | —            | Called when the user picks an option.                                      |
| `orientation`   | `"vertical" \| "horizontal"`   | `"vertical"` | Stacks the options in a column or lines them up in a row.                  |
| `disabled`      | `boolean`                      | `false`      | Disables every option and dims the group.                                  |
| `invalid`       | `boolean`                      | `false`      | Sets `aria-invalid` and turns every circle, or tile edge, `--destructive`. |
| `readOnly`      | `boolean`                      | `false`      | Shows the choice but ignores clicks.                                       |
| `required`      | `boolean`                      | `false`      | Marks the radios as required.                                              |
| `name`          | `string`                       | —            | Form field name shared by every radio.                                     |

### RadioGroup.Item

| Prop       | Type      | Default | Description                                 |
| ---------- | --------- | ------- | ------------------------------------------- |
| `value`    | `string`  | —       | The value this option stands for. Required. |
| `disabled` | `boolean` | `false` | Disables this option only.                  |
| `invalid`  | `boolean` | `false` | Marks this option only as invalid.          |

### Parts

| Part                         | Element                | Description                                                                                       |
| ---------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------- |
| `RadioGroup.Root`            | `<div>`                | `role="radiogroup"`; carries `data-variant`, `data-size` and `data-orientation`.                  |
| `RadioGroup.Label`           | `<span>`               | The group's label; it names the radiogroup.                                                       |
| `RadioGroup.Item`            | `<label>`              | One option; clicking anywhere on it picks the option. In a tile, the whole card.                  |
| `RadioGroup.ItemMedia`       | `<span>`               | Moderno's slot for a tile's image or other content. Give an image `alt=""`.                       |
| `RadioGroup.ItemControl`     | `<div>`                | The radio circle. In a tile, the check badge in the card's corner.                                |
| `RadioGroup.ItemText`        | `<span>`               | The option's label; it names the radio.                                                           |
| `RadioGroup.ItemDescription` | `<span>`               | Moderno's hint under the label. Put it inside `ItemText`.                                         |
| `RadioGroup.ItemHiddenInput` | `<input type="radio">` | Visually hidden native radio; it carries focus, arrow keys, `name` and `value`. Always render it. |
| `RadioGroup.Indicator`       | `<div>`                | Ark's sliding highlight behind the checked item. Unstyled by default; use it for a custom look.   |

### Data attributes

| Attribute            | Values                                                     |
| -------------------- | ---------------------------------------------------------- |
| `data-state`         | `"checked"` or `"unchecked"`, on every part of an item     |
| `data-orientation`   | `"vertical"` or `"horizontal"`, on the root and every item |
| `data-disabled`      | Present on a disabled group or option                      |
| `data-invalid`       | Present while `invalid`                                    |
| `data-readonly`      | Present on the items while `readOnly`                      |
| `data-focus-visible` | On the item control whose radio has keyboard focus         |
| `data-variant`       | On the root: `"list"` or `"tile"`                          |
| `data-size`          | On the root: `"sm"`, `"md"` or `"lg"`                      |
| `data-columns`       | On a tile root with `columns`: `"1"` to `"6"`              |
| `data-aspect-ratio`  | On a tile root with `aspectRatio`, like `"4:3"`            |

### Tiles

Use `variant="tile"` to pick by picture, like a slide layout. Each option becomes a card; put the picture in `RadioGroup.ItemMedia`. It can be an `<img alt="">` or any content, like the SVG here. Set `columns` to fix the number of cards per row, and `aspectRatio` to change the picture's shape.

## Notes

- `RadioGroup.Root` is wrapped to add `variant`, `size`, `columns` and `aspectRatio`; `RadioGroup.ItemMedia` and `RadioGroup.ItemDescription` are Moderno's. Every other part is Ark's unchanged.
- Style state from `data-state` and the `data-*` flags.
- The arrow keys move the choice between options, as in a native radio group.
- RadioGroup replaces the predecessor's Radio.
