## Usage

Number Input is a text box for a number, with buttons that step it up and down. Use it for an exact number with limits, like a quantity. The arrow keys step it too.

<ForFramework fw="react">

```tsx
import { NumberInput } from "@moderno-ui/react";
```

```tsx
<NumberInput.Root value={quantity} onValueChange={(details) => setQuantity(details.value)}>
  <NumberInput.Label>Quantity</NumberInput.Label>
  <NumberInput.Control>
    <NumberInput.Input />
    <NumberInput.DecrementTrigger>−</NumberInput.DecrementTrigger>
    <NumberInput.IncrementTrigger>+</NumberInput.IncrementTrigger>
  </NumberInput.Control>
</NumberInput.Root>
```

</ForFramework>

<ForFramework fw="vue">

```ts

```


The value is a string, like `"3"`. `onValueChange` also gives `valueAsNumber`.

## API Reference

### NumberInput.Root

`size` is the Moderno addition; every part follows it. The other props come from Ark's NumberInput.

<PropsTable component="NumberInput" />

| Prop               | Type                                                          | Default   | Description                                                  |
| ------------------ | ------------------------------------------------------------- | --------- | ------------------------------------------------------------ |
| `value`            | `string`                                                      | —         | Controlled value.                                            |
| `defaultValue`     | `string`                                                      | —         | Value at first when uncontrolled.                            |
| `onValueChange`    | `(details: { value: string; valueAsNumber: number }) => void` | —         | Called when the value changes.                               |
| `onValueInvalid`   | `(details: { value: string; reason: string }) => void`        | —         | Called when the value goes under `min` or over `max`.        |
| `min`              | `number`                                                      | —         | The lowest value.                                            |
| `max`              | `number`                                                      | —         | The highest value.                                           |
| `step`             | `number`                                                      | `1`       | How far one step goes.                                       |
| `formatOptions`    | `Intl.NumberFormatOptions`                                    | —         | How to show the number: currency, percent, decimals.         |
| `locale`           | `string`                                                      | `"en-US"` | The locale used to format and read the number.               |
| `clampValueOnBlur` | `boolean`                                                     | `true`    | Snaps a typed value into `min`–`max` when the input blurs.   |
| `allowOverflow`    | `boolean`                                                     | `false`   | Lets a step go past `min` and `max`.                         |
| `allowMouseWheel`  | `boolean`                                                     | `false`   | Steps the value with the mouse wheel while focused.          |
| `spinOnPress`      | `boolean`                                                     | `true`    | Keeps stepping while a stepper is held down.                 |
| `disabled`         | `boolean`                                                     | `false`   | Dims the field and ignores input.                            |
| `readOnly`         | `boolean`                                                     | `false`   | Shows the value but ignores input.                           |
| `invalid`          | `boolean`                                                     | —         | Marks the value as wrong. Unset, it follows `min` and `max`. |
| `required`         | `boolean`                                                     | `false`   | Marks the field as required in a form.                       |
| `name`             | `string`                                                      | —         | The form field name of the input.                            |
| `translations`     | `{ incrementLabel?: string; decrementLabel?: string }`        | —         | What a screen reader says for each stepper.                  |

In Vue, bind the value with `:model-value` or `v-model`, and listen with `@value-change`.

### Parts

| Part                           | Element    | Description                                                   |
| ------------------------------ | ---------- | ------------------------------------------------------------- |
| `NumberInput.Root`             | `<div>`    | Carries `data-size`.                                          |
| `NumberInput.Label`            | `<label>`  | Optional. Names the field. Clicking it focuses the input.     |
| `NumberInput.Control`          | `<div>`    | The bordered box. Holds the input and the steppers.           |
| `NumberInput.Input`            | `<input>`  | The text box, with `role="spinbutton"`.                       |
| `NumberInput.DecrementTrigger` | `<button>` | Steps the value down. Off at `min`.                           |
| `NumberInput.IncrementTrigger` | `<button>` | Steps the value up. Off at `max`.                             |
| `NumberInput.Scrubber`         | `<div>`    | Optional. Drag it sideways to change the value.               |
| `NumberInput.ValueText`        | `<span>`   | Optional. The formatted value, for a readout outside the box. |

### Data attributes

| Attribute        | Values                                                    |
| ---------------- | --------------------------------------------------------- |
| `data-focus`     | While the input has focus, on the root, label and control |
| `data-invalid`   | When the value is invalid, on the root, control and input |
| `data-disabled`  | When `disabled`, on every part; on a stepper at its bound |
| `data-scrubbing` | While the scrubber is dragged, on the root and its parts  |
| `data-size`      | On the root: `"sm"`, `"md"` or `"lg"`                     |

## Notes

- `NumberInput.Root` is wrapped to add `size`; every other part is Ark's unchanged.
- The steppers are out of the tab order. The arrow keys do the same job from the input; Shift takes ten steps at a time.
- For a value the user picks by dragging along a track, use a Slider.
