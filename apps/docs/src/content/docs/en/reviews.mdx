## API Reference

### Props

| Prop            | Type            | Default                | Description                                                                  |
| --------------- | --------------- | ---------------------- | ---------------------------------------------------------------------------- |
| `heading`       | `string`        | `"Customer reviews"`   | The section's heading. Set in the serif face.                                |
| `reviews`       | `Review[]`      | three sample reviews   | The reviews to show, in order. `[]` shows the empty message.                 |
| `breakdown`     | `RatingCount[]` | counted from `reviews` | How many reviews gave each rating. The average and the total come from it.   |
| `error`         | `string`        | —                      | Loading the reviews failed; an error Alert with a retry replaces them.       |
| `loading`       | `boolean`       | `false`                | Placeholders replace the average, the bars and the reviews.                  |
| `disabled`      | `boolean`       | `false`                | The reviews stay; "Write a review" and the retry button are disabled.        |
| `onWriteReview` | `() => void`    | —                      | "Write a review" was pressed. Svelte: `onwritereview`. Vue: `@write-review`. |
| `onRetry`       | `() => void`    | —                      | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                 |

With both `reviews` and `breakdown` left out, the sample breakdown (132 reviews, 4.4 on average) goes with the sample reviews.

### Review

| Field       | Type      | Description                                                    |
| ----------- | --------- | -------------------------------------------------------------- |
| `id`        | `string`  | A stable key for the review.                                   |
| `author`    | `string`  | The author's name.                                             |
| `initials`  | `string`  | One or two letters. The avatar shows them until a photo loads. |
| `avatarUrl` | `string`  | Optional. The author's photo.                                  |
| `rating`    | `number`  | The stars the author gave, from 1 to 5.                        |
| `date`      | `string`  | When the review was written, formatted by you.                 |
| `content`   | `string`  | What the author wrote.                                         |
| `verified`  | `boolean` | Optional. Adds a "Verified purchase" Badge.                    |

### RatingCount

| Field    | Type     | Description                        |
| -------- | -------- | ---------------------------------- |
| `rating` | `number` | A star rating, from 1 to 5.        |
| `count`  | `number` | How many reviews gave that rating. |

### States

| State    | Prop           | What renders                                                              |
| -------- | -------------- | ------------------------------------------------------------------------- |
| Default  | —              | Heading, average, one bar per rating, "Write a review" and the reviews.   |
| Empty    | `reviews={[]}` | Heading, "Write a review" and "No reviews yet."                           |
| Loading  | `loading`      | Heading, "Write a review", then placeholders for the summary and reviews. |
| Error    | `error`        | Heading, "Write a review", then an error Alert with "Try again".          |
| Disabled | `disabled`     | The same reviews with "Write a review" disabled.                          |

### Sizing

| Container step           | What changes                                                        |
| ------------------------ | ------------------------------------------------------------------- |
| below `@sm`              | Everything in one column, the reviews at the small size.            |
| `@sm` (`--container-sm`) | The reviews read a size larger.                                     |
| `@md` (`--container-md`) | The average sits beside the bars, and the heading steps up.         |
| `@lg` (`--container-lg`) | The summary moves into a column beside the reviews, with more room. |
