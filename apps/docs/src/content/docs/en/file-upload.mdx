## Usage

Use a file upload when a form needs files from the user's computer, like a logo or font files. The user drops files on the zone or clicks it to pick them. The files show in a list under it.

<ForFramework fw="react">

```tsx
import { FileUpload } from "@moderno-ui/react";
```

```tsx
<FileUpload accept={["image/png"]} onFileChange={(details) => save(details.acceptedFiles)} />
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { FileUpload } from "@moderno-ui/vue";
```

```vue
<FileUpload v-model:accepted-files="files" :accept="['image/png']" />
```

</ForFramework>

<ForFramework fw="svelte">

```ts
import { FileUpload } from "@moderno-ui/svelte";
```

```svelte
<FileUpload bind:acceptedFiles={files} accept={["image/png"]} />
```

</ForFramework>

<ForFramework fw="solid">

```tsx
import { FileUpload } from "@moderno-ui/solid";
```

```tsx
<FileUpload accept={["image/png"]} onFileChange={(details) => save(details.acceptedFiles)} />
```

</ForFramework>

It only collects files. Send them to your server yourself.

## API Reference

### FileUpload

<PropsTable component="FileUpload" />

It also takes these props of Ark's FileUpload:

| Prop                   | Type                                               | Default | Description                                                        |
| ---------------------- | -------------------------------------------------- | ------- | ------------------------------------------------------------------ |
| `acceptedFiles`        | `File[]`                                           | —       | The accepted files, to control the list. Pair with `onFileChange`. |
| `defaultAcceptedFiles` | `File[]`                                           | `[]`    | The files it starts with when uncontrolled.                        |
| `minFileSize`          | `number`                                           | `0`     | The smallest file it takes, in bytes.                              |
| `validate`             | `(file, details) => string[] \| null`              | —       | Your own check. Return the reasons a file is turned away.          |
| `invalid`              | `boolean`                                          | `false` | Marks the upload as wrong: the zone's edge turns `--destructive`.  |
| `readOnly`             | `boolean`                                          | `false` | Shows the files but the user cannot change them.                   |
| `required`             | `boolean`                                          | `false` | A file is needed to submit the form.                               |
| `name`                 | `string`                                           | —       | Submits the files with a form under this name.                     |
| `locale`               | `string`                                           | `en-US` | The language of sizes and type lists ("SVG or PNG").               |
| `onFileAccept`         | `(details: { files }) => void`                     | —       | Called with the accepted files when they change.                   |
| `onFileReject`         | `(details: { files: { file, errors }[] }) => void` | —       | Called with the rejected files when they change.                   |

In Vue, bind the list with `v-model:accepted-files` and listen with `@file-change`. In Svelte, use `bind:acceptedFiles`.

A rejected file carries `errors`: `FILE_INVALID_TYPE`, `FILE_TOO_LARGE`, `FILE_TOO_SMALL`, `TOO_MANY_FILES` or `FILE_EXISTS`. A message returned by `validate` is shown as it is.

### Parts

| Part                  | Element    | Description                                                      |
| --------------------- | ---------- | ---------------------------------------------------------------- |
| `root`                | `<div>`    | Holds the zone and the lists. Carries `data-size`.               |
| `dropzone`            | `<div>`    | The zone, `role="button"`. `data-dragging` while files are over. |
| `dropzone-title`      | `<span>`   | The `label`, or "Drop files here or click to browse".            |
| `dropzone-hint`       | `<span>`   | What it takes: "SVG or PNG, up to 2 MB".                         |
| `item-group`          | `<ul>`     | One list. `data-type="accepted"` or `"rejected"`.                |
| `item`                | `<li>`     | One file.                                                        |
| `item-preview`        | `<div>`    | The thumbnail of an image, or a file icon.                       |
| `item-name`           | `<div>`    | The name, cut in the middle when it is long.                     |
| `item-size-text`      | `<div>`    | The size.                                                        |
| `item-error`          | `<span>`   | Why a file was not added.                                        |
| `item-delete-trigger` | `<button>` | Removes the file. Named "Remove logo.svg".                       |

### Keyboard

| Key               | Action                                         |
| ----------------- | ---------------------------------------------- |
| `Enter` / `Space` | On the zone, opens the file dialog.            |
| `Tab`             | Moves to the zone, then to each remove button. |
| `Enter`           | On a remove button, removes the file.          |

## Notes

- A file that breaks a rule shows in a second list, with the reason. The user removes it with its button.
- Screen readers hear each file added, removed or turned away.
- Rename the words with `translations`, for example `{ prompt: "Suelta archivos aquí" }`.
