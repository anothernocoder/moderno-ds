## Usage

Use Product List for a shop's catalogue or a category page. It shows one page of products and the pagination to reach the others.

<ForFramework fw="react">

```tsx
import { ProductList } from "@/components/blocks/product-list";
```

```tsx
<ProductList
  heading="Tableware"
  products={products}
  total={total}
  page={page}
  onPageChange={setPage}
/>
```

</ForFramework>
<ForFramework fw="vue">

```vue
<script setup lang="ts">
import ProductList from "@/components/blocks/ProductList.vue";
</script>
```

```vue
<ProductList
  heading="Tableware"
  :products="products"
  :total="total"
  :page="page"
  @page-change="page = $event"
/>
```

</ForFramework>
<ForFramework fw="svelte">


</ForFramework>
<ForFramework fw="solid">

```tsx
import { ProductList } from "@/components/blocks/product-list";
```

```tsx
<ProductList

  products={products()}
  total={total()}
  page={page()}
```

`products` holds the current page only. `total` counts every product, so the block knows how many pages there are.

## API Reference

### Props

| Prop           | Type                     | Default             | Description                                                                 |
| -------------- | ------------------------ | ------------------- | --------------------------------------------------------------------------- |
| `heading`      | `string`                 | `"The collection"`  | The section's heading. Set in the serif face.                               |
| `description`  | `string`                 | a sentence          | One sentence under the heading; `""` hides it.                              |
| `products`     | `ProductSummary[]`       | twelve sample items | The products on the current page. `[]` shows the empty message.             |
| `total`        | `number`                 | `products.length`   | How many products there are across every page. 48 with the sample products. |
| `pageSize`     | `number`                 | `12`                | How many products one page holds.                                           |
| `page`         | `number`                 | —                   | The current page, from 1. Leave it out and the block keeps its own page.    |
| `error`        | `string`                 | —                   | Loading the products failed; an error Alert with a retry replaces the grid. |
| `loading`      | `boolean`                | `false`             | Placeholder tiles in a busy region replace the grid.                        |
| `disabled`     | `boolean`                | `false`             | The products stay; every link is inert and every button disabled.           |
| `onPageChange` | `(page: number) => void` | —                   | A page was picked. Svelte: `onpagechange`. Vue: `@page-change`.             |
| `onRetry`      | `() => void`             | —                   | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                |

### ProductSummary

| Field            | Type           | Description                                                   |
| ---------------- | -------------- | ------------------------------------------------------------- |
| `id`             | `string`       | A stable key for the product.                                 |
| `name`           | `string`       | The product's name.                                           |
| `price`          | `string`       | The price as people read it, like `"€28"`.                    |
| `compareAtPrice` | `string`       | Optional. The old price, struck through after `price`.        |
| `badge`          | `string`       | Optional. One word on the image, like `"New"` or `"Sale"`.    |
| `href`           | `string`       | Optional. Turns the name into a link to the product's page.   |
| `image`          | `ProductImage` | Optional. The photo: `{ src, alt }`. Without it, a muted box. |

### States

| State    | Prop            | What renders                                                       |
| -------- | --------------- | ------------------------------------------------------------------ |
| Default  | —               | Heading, product count, one tile per product and the pagination.   |
| Empty    | `products={[]}` | Heading and "No products match yet." in a dashed box.              |
| Loading  | `loading`       | Heading, placeholder tiles and the pagination.                     |
| Error    | `error`         | Heading, then an error Alert with "Try again".                     |
| Disabled | `disabled`      | The same products with every link inert and every page button off. |

### Sizing

| Container step           | What changes                                           |
| ------------------------ | ------------------------------------------------------ |
| below `@sm`              | Two columns; the product count under the introduction. |
| `@sm` (`--container-sm`) | The product count moves beside the heading.            |
| `@md` (`--container-md`) | Three columns, and the heading steps up.               |
| `@lg` (`--container-lg`) | Four columns, with more room between and around.       |

## Notes

- Twelve products fill two, three or four columns evenly. Keep `pageSize` a multiple of 12 for the same effect.
- Use photos that still read when they are cropped to a square, and the same kind of photo for every product, so the rows look even.
- Scroll the page back to the heading after a page change, so people start reading at the top of the new page.
