## Usage

Progress shows how much of a task is done. Use it when the user waits on work you can measure, like an upload. It draws a bar, or a ring when you build it from `Progress.Circle`.

<ForFramework fw="react">

```tsx
import { Progress } from "@moderno-ui/react";
```

```tsx
<Progress.Root value={progress}>
  <Progress.Label>Uploading photos</Progress.Label>
  <Progress.ValueText />
  <Progress.Track>
    <Progress.Range />
  </Progress.Track>
</Progress.Root>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Progress } from "@moderno-ui/vue";
```

```vue
<Progress.Root :model-value="progress">
  <Progress.Label>Uploading photos</Progress.Label>
  <Progress.ValueText />
  <Progress.Track>
    <Progress.Range />
  </Progress.Track>
</Progress.Root>
```

</ForFramework>

<ForFramework fw="svelte">



`value` runs from 0 to 100 by default. Pass `null` when you don't know the amount yet.

## API Reference

### Progress.Root

`size` is the Moderno addition; every part follows it. The other props come from Ark's Progress.

<PropsTable component="Progress" />

| Prop            | Type                                           | Default                | Description                                      |
| --------------- | ---------------------------------------------- | ---------------------- | ------------------------------------------------ |
| `value`         | `number \| null`                               | —                      | Controlled value. `null` makes it indeterminate. |
| `defaultValue`  | `number \| null`                               | `50`                   | Value at first when uncontrolled.                |
| `onValueChange` | `(details: { value: number \| null }) => void` | —                      | Called when the value changes.                   |
| `min`           | `number`                                       | `0`                    | The value of an empty bar.                       |
| `max`           | `number`                                       | `100`                  | The value of a full bar.                         |
| `orientation`   | `"horizontal" \| "vertical"`                   | `"horizontal"`         | Lays a bar across or stands it up.               |
| `formatOptions` | `Intl.NumberFormatOptions`                     | `{ style: "percent" }` | How `Progress.ValueText` prints the value.       |
| `locale`        | `string`                                       | `"en-US"`              | The locale used to print the value.              |

In Vue, bind the value with `:model-value` or `v-model`, and listen with `@value-change`.

### Progress.View

| Prop    | Type                                         | Default | Description                                      |
| ------- | -------------------------------------------- | ------- | ------------------------------------------------ |
| `state` | `"loading" \| "complete" \| "indeterminate"` | —       | Required. Shows its children only in this state. |

### Parts

| Part                   | Element    | Description                                                    |
| ---------------------- | ---------- | -------------------------------------------------------------- |
| `Progress.Root`        | `<div>`    | Carries `data-size`.                                           |
| `Progress.Label`       | `<span>`   | Optional. Names what is in progress.                           |
| `Progress.ValueText`   | `<span>`   | Optional. The percentage, or your own text.                    |
| `Progress.Track`       | `<div>`    | The bar, with `role="progressbar"` and `aria-valuenow`.        |
| `Progress.Range`       | `<div>`    | The filled part of the bar. Ark sets its width from the value. |
| `Progress.Circle`      | `<svg>`    | The ring, with `role="progressbar"` and `aria-valuenow`.       |
| `Progress.CircleTrack` | `<circle>` | The full ring behind the range.                                |
| `Progress.CircleRange` | `<circle>` | The arc, drawn as far as the value.                            |
| `Progress.View`        | `<span>`   | Optional. Shows its children in one state only.                |

### Data attributes

| Attribute          | Values                                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| `data-state`       | `"loading"`, `"complete"` or `"indeterminate"`, on the root, the track and range, and the circle and its range |
| `data-orientation` | `"horizontal"` or `"vertical"`, on the root, label, track and range                                            |
| `data-size`        | On the root: `"sm"`, `"md"` or `"lg"`                                                                          |

## Notes

- `Progress.Root` is wrapped to add `size`; every other part is Ark's unchanged.
- The progressbar is named by its value (for example "60%"). To name it by the task, pass `aria-label` to `Progress.Track` or `Progress.Circle`.
- In Solid, start an indeterminate progress with `defaultValue={null}`. Ark's Solid binding treats `value={null}` as uncontrolled.
- Under reduced motion the value stops gliding, and the indeterminate bar and ring move slower instead of stopping.
- For a short wait with nothing to measure, use Spinner.
