## Usage

Use an avatar to show who someone is: next to a name, in a comment or in a menu. Put the initials in `Avatar.Fallback`; they show until the image loads, and stay if it fails.

<ForFramework fw="react">

```tsx
import { Avatar } from "@moderno-ui/react";
```

```tsx
<Avatar.Root>
  <Avatar.Fallback>AL</Avatar.Fallback>
  <Avatar.Image src="/ada.png" alt="Ada Lovelace" />
</Avatar.Root>
```

</ForFramework>

## API Reference

### Avatar.Root

<PropsTable component="Avatar" />

Behaviour props come from Ark. The one you may need:

| Prop             | Type                                                 | Default | Description                           |
| ---------------- | ---------------------------------------------------- | ------- | ------------------------------------- |
| `onStatusChange` | `(details: { status: "loaded" \| "error" }) => void` | —       | Called when the image loads or fails. |

### Parts

| Part              | Element  | Description                                                                 |
| ----------------- | -------- | --------------------------------------------------------------------------- |
| `Avatar.Root`     | `<div>`  | The box. Takes `size`, `shape` and the behaviour props.                     |
| `Avatar.Image`    | `<img>`  | The picture. Shown once it has loaded. Needs `src` and `alt`.               |
| `Avatar.Fallback` | `<span>` | The initials. Shown while the image loads, when it fails, or with no image. |

### Data attributes

| Attribute    | On              | Meaning                                                    |
| ------------ | --------------- | ---------------------------------------------------------- |
| `data-size`  | Root            | `sm`, `md` (default), `lg`                                 |
| `data-shape` | Root            | `circle` (default), `square`                               |
| `data-state` | Image, Fallback | `visible` or `hidden`. The hidden part also gets `hidden`. |

## Notes

- Only `Avatar.Root` is wrapped, to add `size` and `shape`. Every other part is Ark's.
- The image and the fallback never show together. Ark swaps them when the image loads.
