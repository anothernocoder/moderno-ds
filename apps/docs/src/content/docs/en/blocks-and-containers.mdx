## Container breakpoints

The same `Pricing` block in both tabs: it stacks under 36rem of container width and goes three-up above it.

| Slot             | Default | Variant | Width utilities    |
| ---------------- | ------- | ------- | ------------------ |
| `--container-sm` | `24rem` | `@sm:`  | `max-w-sm`, `w-sm` |
| `--container-md` | `36rem` | `@md:`  | `max-w-md`, `w-md` |
| `--container-lg` | `48rem` | `@lg:`  | `max-w-lg`, `w-lg` |

The variants come from the Tailwind preset. See [Token contract](/en/token-contract#tailwind-v4) for how it maps them.

## Build a responsive block

1. Declare `@container` on the block's root.
2. Lay it out with `@sm:`, `@md:` and `@lg:`.
3. Paint and size it from contract slots only.

```tsx
<section className="@container">
  <h2 className="text-lg font-semibold @md:text-xl">Pricing</h2>
  <ul className="mt-6 grid gap-4 @md:grid-cols-3">
    <li className="rounded-lg bg-card p-6 text-card-foreground shadow-sm">…</li>
  </ul>
</section>
```

## Rules

| Rule                          | Detail                                                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `@container`, not `@media`    | Viewport media queries are reserved for primitives that change shape on small screens. That allow-list is empty today. |
| Three steps only              | The preset replaces Tailwind's container scale: `@xl:` and wider don't exist.                                          |
| No literal colours or lengths | A hex or an arbitrary length like `w-[320px]` fails `moderno-lint`, which CI runs over every registry source file.     |
| Intrinsic layout is fine      | A `grid` with `auto-fit` columns needs no breakpoint. Use a container query when the layout changes shape.             |
