Use it in an editor that stacks objects on a canvas: select a layer, hide or lock it, drag it in front of or behind the others, and rename it in place. The block shows the layers; your app owns them.

Each callback names a layer by its `id`. `reorderLayers` puts `layers` in the order it receives, `updateLayer(id, change)` merges the change into that layer, and `deleteLayer` removes it once your app has confirmed.

## API Reference

### Props

| Prop          | Type                                        | Default            | Description                                                                                   |
| ------------- | ------------------------------------------- | ------------------ | --------------------------------------------------------------------------------------------- |
| `layers`      | `Layer[]`                                   | five sample layers | One row each, top row first. The top row is the front-most layer.                             |
| `selectedId`  | `string \| null`                            | `null`             | The selected layer's `id`.                                                                    |
| `onSelect`    | `(id: string) => void`                      | —                  | A row was clicked, or Enter was pressed on it. Svelte: `onselect`. Vue: `@select`.            |
| `onReorder`   | `(ids: string[]) => void`                   | —                  | A row was dropped in a new place: every `id`, top row first. Vue: `@reorder`.                 |
| `onChange`    | `(id: string, change: LayerChange) => void` | —                  | A layer was renamed, hidden, shown, locked or unlocked. Svelte: `onchange`. Vue: `@change`.   |
| `onDuplicate` | `(id: string) => void`                      | —                  | Duplicate was picked in the row's menu. Svelte: `onduplicate`. Vue: `@duplicate`.             |
| `onDelete`    | `(id: string) => void`                      | —                  | Delete was picked in the menu, or the Delete key pressed. Svelte: `ondelete`. Vue: `@delete`. |
| `onAdd`       | `() => void`                                | —                  | Add layer was pressed. Svelte: `onadd`. Vue: `@add`.                                          |

### Layer

| Field       | Type      | Description                                                                                               |
| ----------- | --------- | --------------------------------------------------------------------------------------------------------- |
| `id`        | `string`  | Names the layer in every callback.                                                                        |
| `name`      | `string`  | The row's name. Cut short with an ellipsis when long; the full name is its tooltip.                       |
| `visible`   | `boolean` | `false` dims the row and presses its visibility toggle.                                                   |
| `locked`    | `boolean` | `true` presses its lock toggle, which then shows a lock.                                                  |
| `thumbnail` | `string`  | Optional. An image URL, drawn small before the name.                                                      |
| `icon`      | `string`  | Optional. The layer kind, drawn when there is no thumbnail: `frame`, `group`, `text`, `image` or `shape`. |

### LayerChange

One of `{ name: string }`, `{ visible: boolean }` or `{ locked: boolean }`: the one field that changed.

### Parts

| Part              | What it is                                                                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------------- |
| Header            | The "Layers" heading and an Add layer Button.                                                                 |
| List              | A SortableList named "Layers", one item per layer.                                                            |
| Name button       | The row's SortableList trigger: the name, with the state in its accessible name. A Tooltip shows a long name. |
| Visibility toggle | A Toggle named "Hide Logo" or "Show Logo", pressed while the layer is hidden.                                 |
| Lock toggle       | A Toggle named "Lock Logo" or "Unlock Logo", pressed while the layer is locked.                               |
| Menu              | A ghost Button named "Actions for Logo" that opens a Menu: Duplicate, Rename, Delete.                         |
| Rename field      | An Editable input over the name while renaming.                                                               |
| Empty state       | "No layers yet" and an Add layer Button, when `layers` is empty.                                              |

### States

| State    | Prop             | What renders                                                                                 |
| -------- | ---------------- | -------------------------------------------------------------------------------------------- |
| Selected | `selectedId`     | The row has a tinted background and a bar at its start; its name button has `aria-current`.  |
| Hidden   | `visible: false` | The name is muted, the thumbnail dimmed, and the visibility toggle pressed and always shown. |
| Locked   | `locked: true`   | The lock toggle is pressed, shows a lock and is always shown.                                |
| Renaming | —                | An input over the name, its text selected.                                                   |
| Empty    | `layers` is `[]` | "No layers yet" and an Add layer button, in place of the list.                               |

### Keyboard

| Key            | Where            | Does                                                                  |
| -------------- | ---------------- | --------------------------------------------------------------------- |
| Tab            | The panel        | Enters the list on the selected row, then its toggles and menu.       |
| Up / Down      | A name button    | Moves to the row above or below.                                      |
| Home / End     | A name button    | Moves to the first or last row.                                       |
| Enter          | A name button    | Selects the layer.                                                    |
| F2             | A name button    | Renames the layer.                                                    |
| Delete         | A name button    | Asks to delete the layer. Backspace does too.                         |
| Space          | A name button    | Picks the row up; the arrows move it, Space drops it, Escape cancels. |
| Enter / Escape | The rename field | Saves / cancels the new name.                                         |

### Sizing

| Container step           | What changes                                  |
| ------------------------ | --------------------------------------------- |
| below `@sm`              | Small thumbnails; Add layer is an icon.       |
| `@sm` (`--container-sm`) | Bigger thumbnails; Add layer shows its label. |
