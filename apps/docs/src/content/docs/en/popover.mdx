Use a popover to show a little more next to a button: a short explanation, sharing options or a small form. The page stays usable while it is open, and a click outside or Escape closes it.

## Installation

<Install pkg="@moderno-ui/react" />

## Usage

<ForFramework fw="react">

```tsx
import { Popover, Portal } from "@moderno-ui/react";
```

```tsx
<Popover.Root>
  <Popover.Trigger>Share</Popover.Trigger>
  <Portal>
    <Popover.Positioner>
      <Popover.Content>
        <Popover.Title>Share this page</Popover.Title>
        <Popover.Description>Anyone with the link can view it.</Popover.Description>
      </Popover.Content>
    </Popover.Positioner>
  </Portal>
</Popover.Root>
```

</ForFramework>

## API Reference

### Popover.Root

`size` is the Moderno addition. The other props come from Ark's Popover. The Root renders no element of its own.

<PropsTable component="Popover" />

| Prop                     | Type                                   | Default                   | Description                                                                                     |
| ------------------------ | -------------------------------------- | ------------------------- | ----------------------------------------------------------------------------------------------- |
| `open`                   | `boolean`                              | —                         | Controlled open state. Pair with `onOpenChange` (`bind:open` in Svelte, `v-model:open` in Vue). |
| `defaultOpen`            | `boolean`                              | `false`                   | Open state at first when uncontrolled.                                                          |
| `onOpenChange`           | `(details: { open: boolean }) => void` | —                         | Called on every open or close, including Escape and clicks outside.                             |
| `positioning`            | `PositioningOptions`                   | `{ placement: "bottom" }` | Where the content goes: `placement`, `gutter`, `offset`, `flip`, `sameWidth`, …                 |
| `modal`                  | `boolean`                              | `false`                   | Traps focus and blocks the page, like a dialog.                                                 |
| `autoFocus`              | `boolean`                              | `true`                    | Moves focus into the content on open.                                                           |
| `initialFocusEl`         | `() => HTMLElement \| null`            | —                         | Element to focus on open. Defaults to the first focusable element in the content.               |
| `closeOnEscape`          | `boolean`                              | `true`                    | Closes on Escape.                                                                               |
| `closeOnInteractOutside` | `boolean`                              | `true`                    | Closes on a click outside.                                                                      |
| `lazyMount`              | `boolean`                              | `false`                   | Mount the content only on first open.                                                           |
| `unmountOnExit`          | `boolean`                              | `false`                   | Remove the content from the DOM when closed.                                                    |

### Portal

Renders its children at the end of `document.body`, so no parent's `overflow` or stacking clips the popover.

### Parts

Every part accepts its element's attributes; `Popover.Trigger` and `Popover.CloseTrigger` also take `asChild` to render your own `Button`.

| Part                   | Element    | Description                                                                   |
| ---------------------- | ---------- | ----------------------------------------------------------------------------- |
| `Popover.Trigger`      | `<button>` | Opens and closes the popover. The content is placed next to it.               |
| `Popover.Indicator`    | `<div>`    | Optional, inside the trigger. Turns over while the popover is open.           |
| `Popover.Anchor`       | `<div>`    | Optional. Places the content next to this element instead of the trigger.     |
| `Popover.Positioner`   | `<div>`    | Ark places it next to the trigger. Holds the content.                         |
| `Popover.Content`      | `<div>`    | The surface, with `role="dialog"`. Carries `data-size`. A column.             |
| `Popover.Arrow`        | `<div>`    | Optional, first inside the content. Ark points it at the trigger.             |
| `Popover.ArrowTip`     | `<div>`    | Inside the arrow: the point, filled like the surface and edged in `--border`. |
| `Popover.Title`        | `<div>`    | The accessible name, wired through `aria-labelledby`. An `<h2>` in Svelte.    |
| `Popover.Description`  | `<div>`    | Wired through `aria-describedby`, in `--muted-foreground`. A `<p>` in Svelte. |
| `Popover.CloseTrigger` | `<button>` | A small icon button in the top corner. Ark labels it `close`.                 |

### Data attributes

| Attribute        | Values                                                     |
| ---------------- | ---------------------------------------------------------- |
| `data-size`      | On the content: `"sm"`, `"md"` or `"lg"`                   |
| `data-state`     | `"open"` or `"closed"`, on the trigger, indicator, content |
| `data-placement` | On the trigger and content: where Ark placed the content   |

### Keyboard

| Key                 | Action                                                          |
| ------------------- | --------------------------------------------------------------- |
| `Enter` / `Space`   | On the trigger, opens or closes the popover.                    |
| `Esc`               | Closes the popover and returns focus to the trigger.            |
| `Tab` / `Shift+Tab` | Moves focus through the content; leaving it closes the popover. |

## Notes

- `Popover.Root` and `Popover.Content` are wrapped to add `size`; every other part is Ark's unchanged.
- Focus, placement and dismissal come from Ark; don't reimplement them.
- The popover is not modal by default: the page stays usable. Use a `Dialog` for a decision that must block the page.
