## API Reference

### Props

| Prop          | Type           | Default           | Description                                                               |
| ------------- | -------------- | ----------------- | ------------------------------------------------------------------------- |
| `heading`     | `string`       | `"Meet the team"` | The section's heading. Set in the serif face.                             |
| `description` | `string`       | a sentence        | One sentence under the heading; `""` hides it.                            |
| `members`     | `TeamMember[]` | six sample people | The people, in order. `[]` shows the empty message.                       |
| `error`       | `string`       | —                 | Loading the team failed; an error Alert with a retry replaces the grid.   |
| `loading`     | `boolean`      | `false`           | Placeholder members in a busy region replace the grid.                    |
| `disabled`    | `boolean`      | `false`           | The members stay; every name link is inert and the retry button disabled. |
| `onRetry`     | `() => void`   | —                 | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.              |

### TeamMember

| Field       | Type     | Description                                                    |
| ----------- | -------- | -------------------------------------------------------------- |
| `id`        | `string` | A stable key for the person.                                   |
| `name`      | `string` | The person's name.                                             |
| `role`      | `string` | Their job, like `"Head of Design"`.                            |
| `bio`       | `string` | One or two sentences about them.                               |
| `initials`  | `string` | One or two letters. The avatar shows them until a photo loads. |
| `avatarUrl` | `string` | Optional. Their photo.                                         |
| `href`      | `string` | Optional. Turns the name into a link to this page.             |

### States

| State    | Prop           | What renders                                                 |
| -------- | -------------- | ------------------------------------------------------------ |
| Default  | —              | Heading, introduction and one entry per person.              |
| Empty    | `members={[]}` | Heading, introduction and "No team members to show yet."     |
| Loading  | `loading`      | Heading, introduction and three placeholder members.         |
| Error    | `error`        | Heading, introduction, then an error Alert with "Try again". |
| Disabled | `disabled`     | The same people with every name link inert.                  |

### Sizing

| Container step           | What changes                                      |
| ------------------------ | ------------------------------------------------- |
| below `@sm`              | One column, each avatar above its name.           |
| `@sm` (`--container-sm`) | The avatar moves beside the name.                 |
| `@md` (`--container-md`) | Two columns, and the heading steps up.            |
| `@lg` (`--container-lg`) | Three columns, with more room between and around. |
