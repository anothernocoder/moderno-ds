## Usage

<ForFramework fw="react">

```tsx
import { Menu, Portal } from "@moderno-ui/react";
```

```tsx
<Menu.Root onSelect={(details) => console.log(details.value)}>
  <Menu.Trigger>Actions</Menu.Trigger>
  <Portal>
    <Menu.Positioner>
      <Menu.Content>
        <Menu.Item value="edit">Edit</Menu.Item>
        <Menu.Item value="delete">Delete</Menu.Item>
      </Menu.Content>
    </Menu.Positioner>
  </Portal>
</Menu.Root>
```

## API Reference

### Menu.Root

<PropsTable component="Menu" />

The other props come from Ark. The ones you will use most:

| Prop            | Type                                   | Default | Description                                                 |
| --------------- | -------------------------------------- | ------- | ----------------------------------------------------------- |
| `onSelect`      | `(details: { value: string }) => void` | —       | Called when the user chooses an item, with its `value`.     |
| `open`          | `boolean`                              | —       | Controlled open state. Update it from `onOpenChange`.       |
| `defaultOpen`   | `boolean`                              | `false` | Open at first, when uncontrolled.                           |
| `onOpenChange`  | `(details: { open: boolean }) => void` | —       | Called when the menu opens or closes.                       |
| `closeOnSelect` | `boolean`                              | `true`  | Close the menu after the user chooses an item.              |
| `positioning`   | `PositioningOptions`                   | —       | Where the menu opens, like `{ placement: "bottom-start" }`. |

In Vue, listen with `@select` and `@open-change`, and bind with `v-model:open`.

### Parts

| Part                  | Element    | Description                                                         |
| --------------------- | ---------- | ------------------------------------------------------------------- |
| `Menu.Root`           | —          | Holds the state. Takes `size` and Ark's props. Renders no element.  |
| `Menu.Trigger`        | `<button>` | Opens and closes the menu. Carries `data-size`.                     |
| `Menu.Indicator`      | `<div>`    | Optional. An arrow in the trigger that turns while open.            |
| `Menu.ContextTrigger` | `<button>` | Optional. An area that opens the menu on right-click or long-press. |
| `Menu.Positioner`     | `<div>`    | Places the menu. Wrap it in `Portal`.                               |
| `Menu.Content`        | `<div>`    | The menu surface. Carries `data-size`.                              |
| `Menu.Item`           | `<div>`    | One action. Takes a unique `value`, and `disabled`.                 |
| `Menu.ItemGroup`      | `<div>`    | Groups items under a label.                                         |
| `Menu.ItemGroupLabel` | `<div>`    | The group's name.                                                   |
| `Menu.Separator`      | `<hr>`     | A line between groups.                                              |
| `Menu.CheckboxItem`   | `<div>`    | An item that turns on and off. Takes `checked`.                     |
| `Menu.RadioItemGroup` | `<div>`    | Groups radio items. Takes `value`.                                  |
| `Menu.RadioItem`      | `<div>`    | One choice in a radio group.                                        |
| `Menu.ItemText`       | `<div>`    | The label of a checkbox or radio item.                              |
| `Menu.ItemIndicator`  | `<div>`    | Shown while a checkbox or radio item is checked.                    |
| `Menu.TriggerItem`    | `<div>`    | An item that opens a submenu.                                       |
| `Menu.Arrow`          | `<div>`    | Optional. Points at the trigger. Holds `Menu.ArrowTip`.             |

### Data attributes

| Attribute          | On                   | Values                                       |
| ------------------ | -------------------- | -------------------------------------------- |
| `data-size`        | Trigger, Content     | `sm`, `md` (default), `lg`                   |
| `data-state`       | Trigger, Content     | `open`, `closed`                             |
| `data-state`       | Checkbox, radio item | `checked`, `unchecked`                       |
| `data-highlighted` | Item                 | Present on the keyboard or pointer highlight |
| `data-disabled`    | Item                 | Present when the item is `disabled`          |

## Notes

- On a screen narrower than 40rem, the open menu is a bottom sheet: it slides to the foot of the screen over a dimmed page. A tap on the dimmed page closes it.
- `Menu.Root`, `Menu.Trigger` and `Menu.Content` are wrapped to add `size`. Every other part is Ark's.
- A submenu takes the size of its parent menu, unless you give it its own.
- Arrow keys move the highlight, typing jumps to an item, and Escape closes the menu.
