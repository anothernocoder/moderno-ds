## Usage

A toggle group is a row of buttons for related options. By default one button stays pressed at a time, like text alignment; with `multiple`, several can, like bold and italic.

<ForFramework fw="react">

```tsx
import { ToggleGroup } from "@moderno-ui/react";
```

```tsx
<ToggleGroup.Root defaultValue={["left"]} aria-label="Text alignment">
  <ToggleGroup.Item value="left">Left</ToggleGroup.Item>
  <ToggleGroup.Item value="center">Center</ToggleGroup.Item>
  <ToggleGroup.Item value="right">Right</ToggleGroup.Item>
</ToggleGroup.Root>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { ToggleGroup } from "@moderno-ui/vue";
```

```vue
<ToggleGroup.Root :default-value="['left']" aria-label="Text alignment">

  <ToggleGroup.Item value="center">Center</ToggleGroup.Item>
```

## API Reference

### ToggleGroup.Root

`variant` and `size` are the Moderno additions; every item follows them. The other props come from Ark's ToggleGroup.

<PropsTable component="ToggleGroup" />

| Prop            | Type                                     | Default        | Description                                                   |
| --------------- | ---------------------------------------- | -------------- | ------------------------------------------------------------- |
| `value`         | `string[]`                               | —              | Controlled pressed items. Pair with `onValueChange`.          |
| `defaultValue`  | `string[]`                               | `[]`           | Initial pressed items when uncontrolled.                      |
| `onValueChange` | `(details: { value: string[] }) => void` | —              | Called when an item is pressed or released.                   |
| `multiple`      | `boolean`                                | `false`        | Lets several items stay pressed.                              |
| `deselectable`  | `boolean`                                | `true`         | In single mode, lets the user release the pressed item.       |
| `orientation`   | `"horizontal" \| "vertical"`             | `"horizontal"` | Lays the items out in a row or a column; sets the arrow keys. |
| `disabled`      | `boolean`                                | `false`        | Disables every item.                                          |
| `loopFocus`     | `boolean`                                | `true`         | Arrow keys wrap from the last item to the first.              |
| `rovingFocus`   | `boolean`                                | `true`         | Tab stops once in the group; arrow keys move between items.   |

In Vue, listen with `@value-change` or bind the value with `v-model`.

### ToggleGroup.Item

| Prop       | Type      | Default | Description                 |
| ---------- | --------- | ------- | --------------------------- |
| `value`    | `string`  | —       | Required. The item's value. |
| `disabled` | `boolean` | `false` | Disables this item only.    |

### Parts

| Part               | Element    | Description                                                                                                         |
| ------------------ | ---------- | ------------------------------------------------------------------------------------------------------------------- |
| `ToggleGroup.Root` | `<div>`    | `role="radiogroup"`, or `role="group"` with `multiple`. Carries `data-variant`, `data-size` and `data-orientation`. |
| `ToggleGroup.Item` | `<button>` | One option. `role="radio"` with `aria-checked`, or `aria-pressed` with `multiple`.                                  |

### Data attributes

| Attribute          | Values                                                                 |
| ------------------ | ---------------------------------------------------------------------- |
| `data-state`       | On each item: `"on"` or `"off"`                                        |
| `data-disabled`    | Present on a disabled item, and on the root when the group is disabled |
| `data-orientation` | `"horizontal"` or `"vertical"`, on the root and items                  |
| `data-variant`     | On the root: `"ghost"` or `"outline"`                                  |
| `data-size`        | On the root: `"sm"`, `"md"` or `"lg"`                                  |

## Notes

- `ToggleGroup.Root` is wrapped to add `variant` and `size`; every other part is Ark's unchanged.
- Style state from `data-state` and the `data-*` flags on each item; `variant` and `size` are the only visual props.
- For one choice in a form, where each option needs its own label, use Radio Group.
