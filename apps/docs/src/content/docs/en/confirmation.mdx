## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`oncontinue`) in Svelte, and emits (`continue`, `retry`, `navigate`) in Vue.

| Prop          | Type                  | Default                      | Description                                                           |
| ------------- | --------------------- | ---------------------------- | --------------------------------------------------------------------- |
| `heading`     | `string`              | `"Thank you for your order"` | The page's `h1`.                                                      |
| `description` | `string`              | a line about the email       | The line under the heading; `""` hides it.                            |
| `orderNumber` | `string`              | `"#MD-10482"`                | The order's reference; `""` hides the row.                            |
| `delivery`    | `string`              | —                            | When the order should arrive, like `"Tue, 6 October"`.                |
| `email`       | `string`              | —                            | Where the receipt was sent.                                           |
| `items`       | `OrderItem[]`         | the block's samples          | The lines that were ordered. `[]` shows the empty message.            |
| `totals`      | `OrderTotal[]`        | the block's samples          | The rows above the total: `{ label, amount }`.                        |
| `total`       | `string`              | the block's sample           | The amount paid as people read it, like `"€168"`.                     |
| `loading`     | `boolean`             | `false`                      | The order is loading: placeholder lines replace the summary.          |
| `error`       | `string`              | —                            | The order failed to load: an alert with a retry replaces the summary. |
| `disabled`    | `boolean`             | `false`                      | Everything stays on screen; every control is inert.                   |
| `onContinue`  | `() => void`          | —                            | Continue shopping was pressed.                                        |
| `onRetry`     | `() => void`          | —                            | "Try again" after `error`.                                            |
| `onNavigate`  | `(to, event) => void` | —                            | A screen link was clicked: `home`, `orders`, `privacy` or `terms`.    |
| `homeHref`    | `string`              | `"#"`                        | Target of the wordmark.                                               |
| `ordersHref`  | `string`              | `"#"`                        | Target of "Your orders".                                              |
| `privacyHref` | `string`              | `"#"`                        | Target of the privacy link.                                           |
| `termsHref`   | `string`              | `"#"`                        | Target of the terms link.                                             |

### States

| State       | Props      | Renders                                                                |
| ----------- | ---------- | ---------------------------------------------------------------------- |
| Default     | —          | The thank-you and the order summary with its total.                    |
| Loading     | `loading`  | The thank-you, and placeholder lines in place of the summary.          |
| Order error | `error`    | The thank-you, and an alert with "Try again" for the summary.          |
| Empty       | `items=[]` | The thank-you, and "Your order is empty." for the summary.             |
| Disabled    | `disabled` | Everything shown; Continue shopping and every link in the recap inert. |

### Sizing

| Container step           | Change                                            |
| ------------------------ | ------------------------------------------------- |
| `@sm` (`--container-sm`) | The masthead moves onto one row.                  |
| `@md` (`--container-md`) | The heading grows; the footer moves onto one row. |
| `@lg` (`--container-lg`) | The order summary moves beside the thank-you.     |

### Composition

| Part                                | Role                                           |
| ----------------------------------- | ---------------------------------------------- |
| [Order Summary](/en/order-summary/) | The read-only lines and totals that were paid. |
| [Card](/en/card/)                   | The thank-you panel.                           |
| [Badge](/en/badge/)                 | "Order placed", with the `success` variant.    |
| [Button](/en/button/)               | Continue shopping.                             |

## Notes

- Presentational: nothing is fetched and no router is used. The page that mounts it does both.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The root is a `<div>`, not a `<main>`. Make it your `<main>` if the route has none.
- The screen imports its block from `@/components/blocks/…`; edit that line if your alias differs.
