## API Reference

### LineChart

<PropsTable component="LineChart" />

### Series

Each entry in `series` is one line.

| Field    | Type                         | Description                             |
| -------- | ---------------------------- | --------------------------------------- |
| `name`   | `string`                     | Optional label for the series.          |
| `points` | `{ x: number; y: number }[]` | The data points, joined in array order. |

### Defaults

| Prop               | Default                                                |
| ------------------ | ------------------------------------------------------ |
| `xDomain`          | The extent of every x value across all series.         |
| `yDomain`          | Every y value plus 0, rounded outward to nice numbers. |
| `xTicks`, `yTicks` | `5`                                                    |
| `margin`           | `{ top: 16, right: 16, bottom: 28, left: 36 }`         |
| `curve`            | Straight segments                                      |
| `format`           | The number, rounded to 4 decimals                      |

### Data attributes

| Attribute     | On            | Values                                                                   |
| ------------- | ------------- | ------------------------------------------------------------------------ |
| `data-chart`  | Root `svg`    | `line`                                                                   |
| `data-part`   | Every element | `root`, `grid`, `grid-line`, `axis-line`, `tick-label`, `series`, `line` |
| `data-series` | Series `g`    | 0-based index, mapped to `--chart-1` through `--chart-5`                 |

## Notes

- There is no colour prop: series paint from `--chart-1` to `--chart-5` by index.
- A sixth series and beyond fall back to `--chart-1`.
- Grid, axes and tick labels use `--border` and `--muted-foreground`.
- The geometry comes from `@moderno-ui/charts-core`, pure math with no DOM, so it renders on the server.
