## Usage

Vector Pad sets two numbers at once, x and y. Use it for a position, an offset or a light's direction. The user drags the handle on the square pad, or types each number in its field.

**y grows upward**, as on a graph: the top of the pad is the largest y.

<ForFramework fw="react">

```tsx
import { VectorPad } from "@moderno-ui/react";
```

```tsx
<VectorPad.Root value={offset} onValueChange={(details) => setOffset(details.value)}>
  <VectorPad.Label>Offset</VectorPad.Label>
  <VectorPad.Control>
    <VectorPad.Thumb />
  </VectorPad.Control>
  <VectorPad.Input axis="x" />
  <VectorPad.Input axis="y" />
</VectorPad.Root>
```

</ForFramework>

The value is `{ x, y }`. It runs from -100 to 100 on each axis and starts at the centre, `{ x: 0, y: 0 }`.

## API Reference

### VectorPad.Root

<PropsTable component="VectorPad" />

| Prop               | Type                                     | Default         | Description                                                                                                                                                       |
| ------------------ | ---------------------------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`            | `{ x: number; y: number }`               | —               | Controlled value.                                                                                                                                                 |
| `defaultValue`     | `{ x: number; y: number }`               | centre of range | Value at first when uncontrolled. Home and a double-click return here.                                                                                            |
| `onValueChange`    | `(details: { value: { x, y } }) => void` | —               | Called while the value changes.                                                                                                                                   |
| `onValueChangeEnd` | `(details: { value: { x, y } }) => void` | —               | Called once a change ends: the pointer lets go, a key on the handle sets the value, or a number field that changed it is committed (Enter, or leaving the field). |
| `min`              | `number \| { x: number; y: number }`     | `-100`          | Smallest value, for both axes or per axis.                                                                                                                        |
| `max`              | `number \| { x: number; y: number }`     | `100`           | Largest value, for both axes or per axis.                                                                                                                         |
| `step`             | `number \| { x: number; y: number }`     | `1`             | How far one move goes, for both axes or per axis.                                                                                                                 |
| `invertY`          | `boolean`                                | `false`         | Makes y grow downward, as on screen. The handle still follows the pointer.                                                                                        |
| `size`             | `"sm" \| "md" \| "lg"`                   | `"md"`          | The pad's size, matched to the Field sizes.                                                                                                                       |
| `disabled`         | `boolean`                                | `false`         | Dims the pad and the fields and ignores input.                                                                                                                    |
| `readOnly`         | `boolean`                                | `false`         | Shows the value but ignores input.                                                                                                                                |
| `invalid`          | `boolean`                                | `false`         | Marks the value as wrong.                                                                                                                                         |
| `getAriaValueText` | `(value: { x, y }) => string`            | `"X 20, Y -10"` | What a screen reader says for a value.                                                                                                                            |

In Vue, bind the value with `v-model` and listen with `@value-change`.

### VectorPad.Input

| Prop    | Type         | Default      | Description                             |
| ------- | ------------ | ------------ | --------------------------------------- |
| `axis`  | `"x" \| "y"` | —            | Required. The axis this field shows.    |
| `label` | `string`     | `"X"`, `"Y"` | The field's name, shown inside its box. |

### Parts

| Part                  | Element   | Description                                                   |
| --------------------- | --------- | ------------------------------------------------------------- |
| `VectorPad.Root`      | `<div>`   | A group named by the label. Carries `data-size`.              |
| `VectorPad.Label`     | `<label>` | Names the pad and the fields. Clicking it focuses the handle. |
| `VectorPad.Control`   | `<div>`   | The square pad you press or drag on.                          |
| `VectorPad.Grid`      | `<div>`   | Optional. Lines every quarter of the pad.                     |
| `VectorPad.Crosshair` | `<div>`   | Optional. Lines through the pad's centre.                     |
| `VectorPad.Thumb`     | `<div>`   | The handle, with `role="slider"`. It takes focus.             |
| `VectorPad.Input`     | `<div>`   | A number field for one axis.                                  |

### Keyboard

| Key                       | Action                                     |
| ------------------------- | ------------------------------------------ |
| `ArrowRight`, `ArrowLeft` | Moves the handle one `step` right or left. |
| `ArrowUp`, `ArrowDown`    | Moves the handle one `step` up or down.    |
| `Shift` + arrow           | Moves the handle ten steps.                |
| `Home`                    | Goes back to `defaultValue`.               |

### Data attributes

| Attribute       | Values                                     |
| --------------- | ------------------------------------------ |
| `data-dragging` | While the handle is dragged, on every part |
| `data-disabled` | When `disabled`, on every part             |
| `data-readonly` | When `readOnly`, on every part             |
| `data-invalid`  | When `invalid`, on every part              |
| `data-size`     | On the root: `"sm"`, `"md"` or `"lg"`      |

## Notes

- A screen reader says both values ("X 20, Y -10"). Pass `getAriaValueText` to say them in another language.
- The number fields are a full keyboard alternative: type a value, or step it with the arrow keys.
- What the user types moves the handle at once. The field shows the handle's value again when the user leaves it or presses Enter: `250` becomes `100`.
- A drag keeps going when the pointer leaves the pad; the handle stays at the edge.
