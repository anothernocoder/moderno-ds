Each service is `{ id, name, status, uptime, history }`. `history` has one day per entry, oldest first.

## API Reference

### Props

| Prop          | Type                        | Default                  | Description                                                   |
| ------------- | --------------------------- | ------------------------ | ------------------------------------------------------------- |
| `services`    | `StatusMonitoringService[]` | a sample set             | The services, in reading order. `[]` renders the empty state. |
| `heading`     | `string`                    | `"System status"`        | The heading over the services.                                |
| `description` | `string`                    | a sentence               | The line under the heading; `""` hides it.                    |
| `actionLabel` | `string`                    | `"Subscribe to updates"` | The header button's label; `""` hides the button.             |
| `error`       | `string`                    | —                        | The status failed to load; an alert with a retry replaces it. |
| `loading`     | `boolean`                   | `false`                  | Placeholder cards in a busy region replace the services.      |
| `disabled`    | `boolean`                   | `false`                  | The services stay readable and every button is disabled.      |
| `onAction`    | `() => void`                | —                        | The header button. Svelte: `onaction`. Vue: `@action`.        |
| `onRetry`     | `() => void`                | —                        | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.  |

### StatusMonitoringService

| Field     | Type                                                       | Description                                   |
| --------- | ---------------------------------------------------------- | --------------------------------------------- |
| `id`      | `string`                                                   | Stable identity.                              |
| `name`    | `string`                                                   | The service's name.                           |
| `status`  | `"operational" \| "degraded" \| "outage" \| "maintenance"` | How the service is doing now.                 |
| `uptime`  | `string`                                                   | The uptime over `history`, already formatted. |
| `history` | `UptimeDay[]`                                              | One entry per day, oldest first.              |

`UptimeDay` is a `status` value or `"no-data"`.

### States

| State    | Prop            | What renders                                                        |
| -------- | --------------- | ------------------------------------------------------------------- |
| Default  | —               | The overall status badge and one card per service.                  |
| Empty    | `services={[]}` | A "No services yet" card.                                           |
| Loading  | `loading`       | Four placeholder cards in a busy `status` region.                   |
| Error    | `error`         | One error alert with a "Try again" button in place of the services. |
| Disabled | `disabled`      | The services with every button disabled.                            |

### Sizing

| Container step           | What changes                                                                |
| ------------------------ | --------------------------------------------------------------------------- |
| below `@sm`              | Everything stacks: the button under the heading, the status under the name. |
| `@sm` (`--container-sm`) | The heading and the button share a row; so do each name and its status.     |
| `@md` (`--container-md`) | Taller bars and a larger heading.                                           |
| `@lg` (`--container-lg`) | Two services a row.                                                         |
