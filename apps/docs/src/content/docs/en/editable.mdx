## Usage

Editable shows a value as text. The user turns it into an input to rename it in place, like a layer in a layers panel or a file in a list. Use it when a dialog would be too much for one short name.

**Double click** the text to edit it, or press Enter or F2 when it has focus. The whole text is selected. Enter saves, Escape cancels, and a click away saves.

<ForFramework fw="react">

```tsx
import { Editable } from "@moderno-ui/react";
```

```tsx
<Editable.Root value={name} onValueChange={(details) => setName(details.value)}>
  <Editable.Label>Layer name</Editable.Label>
  <Editable.Area>
    <Editable.Input />
    <Editable.Preview />
  </Editable.Area>
</Editable.Root>
```

</ForFramework>

To act only on the saved name, listen to `onValueCommit`: it runs once, on Enter or a click away.

## API Reference

### Editable.Root

`size` is the Moderno addition, and `activationMode` starts on a double click. The other props come from Ark's Editable.

<PropsTable component="Editable" />

| Prop             | Type                                          | Default      | Description                                                                |
| ---------------- | --------------------------------------------- | ------------ | -------------------------------------------------------------------------- |
| `value`          | `string`                                      | —            | Controlled value. Update it in `onValueChange`.                            |
| `defaultValue`   | `string`                                      | `""`         | Value at first when uncontrolled.                                          |
| `onValueChange`  | `(details: { value: string }) => void`        | —            | Called on every change, and when Escape puts the value back.               |
| `onValueCommit`  | `(details: { value: string }) => void`        | —            | Called once when the value is saved.                                       |
| `onValueRevert`  | `(details: { value: string }) => void`        | —            | Called when an edit is cancelled, with the value put back.                 |
| `activationMode` | `"dblclick" \| "click" \| "focus" \| "none"`  | `"dblclick"` | What turns the text into an input. With `"none"`, only the Edit button.    |
| `submitMode`     | `"both" \| "enter" \| "blur" \| "none"`       | `"both"`     | What saves: Enter, a click away, both, or only the Save button.            |
| `selectOnFocus`  | `boolean`                                     | `true`       | Selects the whole text when an edit starts.                                |
| `placeholder`    | `string \| { edit: string; preview: string }` | —            | Shown when the value is empty.                                             |
| `maxLength`      | `number`                                      | —            | The most characters the input takes.                                       |
| `size`           | `"sm" \| "md" \| "lg"`                        | `"md"`       | Text and input height, matched to the Field sizes.                         |
| `disabled`       | `boolean`                                     | `false`      | Dims the text and ignores input.                                           |
| `readOnly`       | `boolean`                                     | `false`      | Shows the value but never turns into an input.                             |
| `invalid`        | `boolean`                                     | `false`      | Marks the value as wrong.                                                  |
| `name`           | `string`                                      | —            | The form field name of the input.                                          |
| `translations`   | `{ edit, submit, cancel, input: string }`     | English      | The buttons' names (`"Edit"`, `"Save"`, `"Cancel"`), for another language. |

In Vue, bind the value with `:model-value` or `v-model`, and listen with `@value-commit`.

### Parts

| Part                     | Element    | Description                                                                     |
| ------------------------ | ---------- | ------------------------------------------------------------------------------- |
| `Editable.Root`          | `<div>`    | Carries `data-size`.                                                            |
| `Editable.Label`         | `<label>`  | Optional. Names the text and the input.                                         |
| `Editable.Area`          | `<div>`    | Holds the text and the input, one in place of the other.                        |
| `Editable.Preview`       | `<span>`   | The value as text, a button in the tab order. Named by the label and the value. |
| `Editable.Input`         | `<input>`  | Replaces the text while the user edits. Named by the label.                     |
| `Editable.Control`       | `<div>`    | Optional. Holds the buttons, after the text.                                    |
| `Editable.EditTrigger`   | `<button>` | Starts an edit. Hidden while editing.                                           |
| `Editable.SubmitTrigger` | `<button>` | Saves. Shown while editing.                                                     |
| `Editable.CancelTrigger` | `<button>` | Cancels. Shown while editing.                                                   |

### Keyboard

| Key                    | Action                                            |
| ---------------------- | ------------------------------------------------- |
| `Enter`, `F2`, `Space` | On the focused text: starts an edit.              |
| `Enter`                | In the input: saves.                              |
| `Escape`               | In the input: cancels and puts the value back.    |
| `Tab`                  | Leaves the input, which saves (see `submitMode`). |

After a save or a cancel, focus goes back to the text.

### Data attributes

| Attribute                | Values                                               |
| ------------------------ | ---------------------------------------------------- |
| `data-focus`             | On the area, while editing                           |
| `data-placeholder-shown` | On the area and the text, when the value is empty    |
| `data-disabled`          | When `disabled`, on the area, the text and the input |
| `data-invalid`           | When `invalid`, on the text and the input            |
| `data-size`              | On the root: `"sm"`, `"md"` or `"lg"`                |

## Notes

- `Editable.Root`, `Editable.Preview` and `Editable.Input` are wrapped; every other part is Ark's unchanged.
- The text and the input are the same box, so nothing moves when an edit starts.
- Escape puts back the value from before the edit, even when it was empty.
- For a value the user always types, use a Field.
