    - case: A section of a working page that failed to load

    - case: A call to action between two sections of a working page

  gotchas:

## API Reference

### Props

| Prop                | Type             | Default             | Description                                                                            |
| ------------------- | ---------------- | ------------------- | -------------------------------------------------------------------------------------- |
| `code`              | `string`         | `"404"`             | The error code, in a badge above the title; `""` hides it.                             |
| `title`             | `string`         | `"Page not found"`  | What happened, in a few words. An `h1` in the serif face.                              |
| `description`       | `string`         | a sentence          | One line under the title; `""` hides it.                                               |
| `primaryAction`     | `string`         | `"Back to home"`    | The primary button's label; `""` hides it.                                             |
| `secondaryAction`   | `string`         | `"Contact support"` | The outline button's label; `""` hides it.                                             |
| `linksTitle`        | `string`         | `"Popular pages"`   | The heading over the popular pages, and the name of their `nav`.                       |
| `links`             | `NotFoundLink[]` | three sample pages  | `{ label, description?, href }` per page; `[]` hides the list.                         |
| `error`             | `string`         | —                   | The popular pages failed to load; an error Alert with a retry replaces them.           |
| `loading`           | `boolean`        | `false`             | Placeholders in a busy region replace the popular pages.                               |
| `disabled`          | `boolean`        | `false`             | The content stays and every button is disabled.                                        |
| `onPrimaryAction`   | `() => void`     | —                   | The primary button was pressed. Svelte: `onprimaryaction`. Vue: `@primary-action`.     |
| `onSecondaryAction` | `() => void`     | —                   | The outline button was pressed. Svelte: `onsecondaryaction`. Vue: `@secondary-action`. |
| `onRetry`           | `() => void`     | —                   | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.                           |

### States

| State    | Prop       | What renders                                                          |
| -------- | ---------- | --------------------------------------------------------------------- |
| Default  | —          | The code, title, description, both actions and the popular pages.     |
| Empty    | `links`    | The message and the actions alone, centred, when you pass `[]`.       |
| Loading  | `loading`  | The message and the actions, with placeholders for the popular pages. |
| Error    | `error`    | The message and the actions, with an error Alert and "Try again".     |
| Disabled | `disabled` | The same content with every button disabled.                          |

### Sizing

| Container step           | What changes                                                              |
| ------------------------ | ------------------------------------------------------------------------- |
| below `@sm`              | Everything is centred; the actions stack, each as wide as the message.    |
| `@sm` (`--container-sm`) | The actions sit side by side, centred, at their own width.                |
| `@md` (`--container-md`) | The title steps up a size.                                                |
| `@lg` (`--container-lg`) | The message moves to the start and the popular pages beside it, in a row. |

## Notes

- Say what happened and give one clear way out. Home is the safe default.
- Pick popular pages that answer why people land here: pricing, help, the latest changes.
- Send the 404 status from your server too. The block only paints the page.
