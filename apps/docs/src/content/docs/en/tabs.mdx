## Usage

Tabs show one panel at a time. Use them for sibling views of one subject, like the sections of a settings page. Each trigger selects the panel with the same `value`.

<ForFramework fw="react">

```tsx
import { Tabs } from "@moderno-ui/react";
```

```tsx
<Tabs.Root defaultValue="account">
  <Tabs.List aria-label="Settings">
    <Tabs.Trigger value="account">Account</Tabs.Trigger>
    <Tabs.Trigger value="password">Password</Tabs.Trigger>
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Content value="account">Change your name and email.</Tabs.Content>
  <Tabs.Content value="password">Change your password.</Tabs.Content>
</Tabs.Root>
```

</ForFramework>

## API Reference

### Tabs.Root

`variant` and `size` are the Moderno additions; the list, its triggers and the indicator follow them. The other props come from Ark's Tabs.

<PropsTable component="Tabs" />

| Prop             | Type                                   | Default        | Description                                                                      |
| ---------------- | -------------------------------------- | -------------- | -------------------------------------------------------------------------------- |
| `value`          | `string`                               | —              | Controlled selected tab. Pair with `onValueChange`.                              |
| `defaultValue`   | `string`                               | —              | Initial selected tab when uncontrolled.                                          |
| `onValueChange`  | `(details: { value: string }) => void` | —              | Called when a tab is selected.                                                   |
| `orientation`    | `"horizontal" \| "vertical"`           | `"horizontal"` | Lays the tabs out in a row or a column; sets the arrow keys.                     |
| `activationMode` | `"automatic" \| "manual"`              | `"automatic"`  | `automatic` selects a tab when it gets focus; `manual` waits for Enter or Space. |
| `loopFocus`      | `boolean`                              | `true`         | The arrow keys wrap from the last tab to the first.                              |
| `lazyMount`      | `boolean`                              | `false`        | Renders a panel only the first time its tab is selected.                         |
| `unmountOnExit`  | `boolean`                              | `false`        | Removes a panel when its tab is no longer selected.                              |

In Vue, listen with `@value-change` or bind the value with `v-model`.

### Tabs.Trigger

| Prop       | Type      | Default | Description                                          |
| ---------- | --------- | ------- | ---------------------------------------------------- |
| `value`    | `string`  | —       | Required. The tab's value; matches a `Tabs.Content`. |
| `disabled` | `boolean` | `false` | Disables this tab only.                              |

### Tabs.Content

| Prop    | Type     | Default | Description                                           |
| ------- | -------- | ------- | ----------------------------------------------------- |
| `value` | `string` | —       | Required. The value of the tab that shows this panel. |

### Parts

| Part             | Element    | Description                                                 |
| ---------------- | ---------- | ----------------------------------------------------------- |
| `Tabs.Root`      | `<div>`    | Carries `data-variant`, `data-size` and `data-orientation`. |
| `Tabs.List`      | `<div>`    | `role="tablist"`. Holds the triggers and the indicator.     |
| `Tabs.Trigger`   | `<button>` | `role="tab"` with `aria-selected`. Selects its panel.       |
| `Tabs.Indicator` | `<div>`    | Optional. The bar or pill that marks the selected tab.      |
| `Tabs.Content`   | `<div>`    | `role="tabpanel"`. Hidden unless its tab is selected.       |

### Data attributes

| Attribute          | Values                                        |
| ------------------ | --------------------------------------------- |
| `data-selected`    | Present on the selected trigger and its panel |
| `data-disabled`    | Present on a disabled trigger                 |
| `data-orientation` | `"horizontal"` or `"vertical"`, on every part |
| `data-variant`     | On the root: `"line"` or `"enclosed"`         |
| `data-size`        | On the root: `"sm"`, `"md"` or `"lg"`         |

## Notes

- `Tabs.Root` is wrapped to add `variant` and `size`; every other part is Ark's unchanged.
- Style state from `data-selected` and the `data-*` flags on each part; `variant` and `size` are the only visual props.
- For a choice the user submits, or a view mode like list or grid, use Toggle Group.
