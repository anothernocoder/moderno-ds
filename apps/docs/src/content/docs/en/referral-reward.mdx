Use it for the step of a referral program where a member sees what they have earned. It shows one KPI card per number; your page counts the rewards.

Each stat is one card:

```ts
const stats = [
  {
    id: "joined",
    label: "Friends joined",
    period: "All time",
    metric: {
      value: "5",
      delta: "+2",
      tone: "positive",
      caption: "this month",
      trend: [1, 2, 3, 5],
    },
  },
];
```

## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`onretry`) in Svelte, and emits (`retry`, `navigate`) in Vue.

| Prop          | Type                   | Default                          | Description                                                       |
| ------------- | ---------------------- | -------------------------------- | ----------------------------------------------------------------- |
| `reward`      | `string`               | `"a free month"`                 | What the reader gets for each friend who joins.                   |
| `stats`       | `ReferralRewardStat[]` | Invited, joined, earned (sample) | One card each: `id`, `label`, `period?`, `metric`.                |
| `error`       | `string`               | —                                | The rewards could not load: every card shows the alert and retry. |
| `loading`     | `boolean`              | `false`                          | The rewards are loading: placeholders in every card.              |
| `disabled`    | `boolean`              | `false`                          | Every control is shown but inert.                                 |
| `onRetry`     | `() => void`           | —                                | "Try again" was pressed.                                          |
| `onNavigate`  | `(to, event) => void`  | —                                | A screen link was clicked: `home`, `share`, `privacy` or `terms`. |
| `homeHref`    | `string`               | `"#"`                            | Target of the wordmark.                                           |
| `shareHref`   | `string`               | `"#"`                            | Target of "Invite more friends".                                  |
| `privacyHref` | `string`               | `"#"`                            | Target of the privacy link.                                       |
| `termsHref`   | `string`               | `"#"`                            | Target of the terms link.                                         |

`metric` is the [KpiCard](/en/kpi-card/)'s: `{ value, delta?, tone?, caption?, trend? }`, or `null`.

### States

| State    | Props                  | Renders                                          |
| -------- | ---------------------- | ------------------------------------------------ |
| Default  | `stats`                | Each number with its change and its sparkline.   |
| Empty    | `metric: null` in stat | "No data yet" in that card.                      |
| Loading  | `loading`              | Placeholders in every card, `aria-busy` on each. |
| Error    | `error`                | An alert with "Try again" in every card.         |
| Disabled | `disabled`             | The screen is shown but can't be used.           |

### Sizing

| Container step           | Change                                |
| ------------------------ | ------------------------------------- |
| `@sm` (`--container-sm`) | The masthead moves onto one row.      |
| `@md` (`--container-md`) | The title grows, the footer lines up. |
| `@lg` (`--container-lg`) | The cards sit side by side.           |

### Composition

| Part                     | Role                                            |
| ------------------------ | ----------------------------------------------- |
| [KpiCard](/en/kpi-card/) | One number, its change and its trend, per stat. |

## Notes

- Presentational: no request, no router. The page that mounts it counts the rewards.
- `tone` is what the change means: more friends joined is `positive`.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The screen imports the KpiCard block from `@/components/blocks/…`; edit that line if your alias differs.
