## Usage

Pagination is a row of page buttons with previous and next. Use it when a list is too long for one screen and you show it a page at a time. Far pages hide behind an ellipsis, so the row stays short.

<ForFramework fw="react">

```tsx
import { Pagination } from "@moderno-ui/react";
```

```tsx
<Pagination.Root
  count={120}
  pageSize={10}
  page={page}
  onPageChange={(details) => setPage(details.page)}
>
  <Pagination.PrevTrigger>‹</Pagination.PrevTrigger>
  <Pagination.Context>
    {(pagination) =>
      pagination.pages.map((page, index) =>
        page.type === "page" ? (
          <Pagination.Item key={index} {...page}>
            {page.value}
          </Pagination.Item>
        ) : (
          <Pagination.Ellipsis key={index} index={index}>
            …
          </Pagination.Ellipsis>
        ),
      )
    }
  </Pagination.Context>
  <Pagination.NextTrigger>›</Pagination.NextTrigger>
</Pagination.Root>
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { Pagination } from "@moderno-ui/vue";
```

```vue
<Pagination.Root v-model:page="page" :count="120" :page-size="10">
  <Pagination.PrevTrigger>‹</Pagination.PrevTrigger>
  <Pagination.Context v-slot="{ pages }">
    <template v-for="(page, index) in pages" :key="index">
      <Pagination.Item v-if="page.type === 'page'" v-bind="page">{{ page.value }}</Pagination.Item>
      <Pagination.Ellipsis v-else :index="index">…</Pagination.Ellipsis>
    </template>
  </Pagination.Context>
  <Pagination.NextTrigger>›</Pagination.NextTrigger>
</Pagination.Root>
```

</ForFramework>

```tsx
</Pagination.Root>
```

</ForFramework>

`count` is the number of items, not pages. With 120 items and 10 per page, there are 12 pages. Pages start at 1.

## API Reference

### Pagination.Root

`size` is the Moderno addition; every button follows it. The other props come from Ark's Pagination.

<PropsTable component="Pagination" />

| Prop               | Type                                                      | Default    | Description                                                   |
| ------------------ | --------------------------------------------------------- | ---------- | ------------------------------------------------------------- |
| `count`            | `number`                                                  | `1`        | How many items there are in all.                              |
| `pageSize`         | `number`                                                  | —          | Controlled number of items on one page.                       |
| `defaultPageSize`  | `number`                                                  | `10`       | Items on one page at first, when uncontrolled.                |
| `page`             | `number`                                                  | —          | Controlled current page, from 1.                              |
| `defaultPage`      | `number`                                                  | `1`        | Page at first, when uncontrolled.                             |
| `onPageChange`     | `(details: { page: number; pageSize: number }) => void`   | —          | Called when the page changes.                                 |
| `onPageSizeChange` | `(details: { pageSize: number }) => void`                 | —          | Called when the page size changes.                            |
| `siblingCount`     | `number`                                                  | `1`        | How many pages to show on each side of the current one.       |
| `boundaryCount`    | `number`                                                  | `1`        | How many pages to show at each end. Not in Vue.               |
| `type`             | `"button" \| "link"`                                      | `"button"` | `"link"` gives each button an `href` from `getPageUrl`.       |
| `getPageUrl`       | `(details: { page: number; pageSize: number }) => string` | —          | Builds the `href` of a page, when `type` is `"link"`.         |
| `translations`     | `IntlTranslations`                                        | —          | What a screen reader says for the row, each page and trigger. |

In Vue, bind the page with `v-model:page`, and listen with `@page-change`.

### Parts

| Part                      | Element    | Description                                                    |
| ------------------------- | ---------- | -------------------------------------------------------------- |
| `Pagination.Root`         | `<nav>`    | The landmark. Carries `data-size`.                             |
| `Pagination.Context`      | —          | Hands you `pages`, the list to render, and the current `page`. |
| `Pagination.Item`         | `<button>` | One page. Takes `type="page"` and `value`; spread the page.    |
| `Pagination.Ellipsis`     | `<div>`    | Stands for the pages skipped. Takes its `index` in `pages`.    |
| `Pagination.PrevTrigger`  | `<button>` | Goes one page back. Off on the first page.                     |
| `Pagination.NextTrigger`  | `<button>` | Goes one page on. Off on the last page.                        |
| `Pagination.FirstTrigger` | `<button>` | Optional. Goes to the first page.                              |
| `Pagination.LastTrigger`  | `<button>` | Optional. Goes to the last page.                               |

### Data attributes

| Attribute       | Values                                                 |
| --------------- | ------------------------------------------------------ |
| `data-selected` | On the current page's item, with `aria-current="page"` |
| `data-index`    | On each item: its page number                          |
| `data-disabled` | On a trigger with nowhere to go                        |
| `data-size`     | On the root: `"sm"`, `"md"` or `"lg"`                  |

## Notes

- `Pagination.Root` is wrapped to add `size`; every other part is Ark's unchanged.
- The row keeps the same length as the page changes: near an end, Ark fills in more pages instead of an ellipsis.
- In a right-to-left page the row runs from the right. Pass the mirrored glyphs, `›` for previous and `‹` for next.
- To pick one exact number, use a NumberInput.
