Use it for the onboarding step where someone invites their team. It shows an email field and the invites nobody has accepted yet; your page sends the invites and loads the list.

## API Reference

### Props

Callbacks are `on…` props in React and Solid, lowercase (`onremoveinvite`) in Svelte, and emits (`submit`, `removeInvite`, `navigate`) in Vue.

| Prop             | Type                  | Default | Description                                                      |
| ---------------- | --------------------- | ------- | ---------------------------------------------------------------- |
| `invites`        | `ListItem[]`          | samples | The invites nobody has accepted yet. `[]` is the empty state.    |
| `invitesLoading` | `boolean`             | `false` | The pending invites are loading: placeholder rows.               |
| `invitesError`   | `string`              | —       | Loading the invites failed: an alert with "Try again".           |
| `sendError`      | `string`              | —       | Sending failed: an alert over the email field.                   |
| `emailsError`    | `string`              | —       | What is wrong with the addresses. Marks the field invalid.       |
| `sending`        | `boolean`             | `false` | Invites on their way: the field is inert, the send button busy.  |
| `disabled`       | `boolean`             | `false` | Nothing on the screen can be used right now.                     |
| `onSubmit`       | `(event) => void`     | —       | Native form submit.                                              |
| `onEditInvite`   | `(id) => void`        | —       | An invite's Edit button was pressed.                             |
| `onRemoveInvite` | `(id) => void`        | —       | An invite's Remove button was pressed.                           |
| `onRetry`        | `() => void`          | —       | "Try again" after `invitesError`.                                |
| `onContinue`     | `() => void`          | —       | The Continue button was pressed.                                 |
| `onNavigate`     | `(to, event) => void` | —       | A screen link was clicked: `home`, `skip`, `privacy` or `terms`. |
| `homeHref`       | `string`              | `"#"`   | Target of the wordmark.                                          |
| `skipHref`       | `string`              | `"#"`   | Target of "Skip for now".                                        |
| `privacyHref`    | `string`              | `"#"`   | Target of the privacy link.                                      |
| `termsHref`      | `string`              | `"#"`   | Target of the terms link.                                        |

`ListItem` is the [List](/en/list/) block's row: `id`, `title`, `subtitle`, `initials`, `avatarUrl`, `status`, `statusVariant` and `meta`.

### States

| State          | Props            | Renders                                              |
| -------------- | ---------------- | ---------------------------------------------------- |
| Default        | `invites`        | The email field and one row per pending invite.      |
| Invalid emails | `emailsError`    | The field marked invalid, with the message under it. |
| Send error     | `sendError`      | An alert over the email field.                       |
| Sending        | `sending`        | The field inert, the send button `aria-busy`.        |
| Loading        | `invitesLoading` | Placeholder rows in a busy region.                   |
| List error     | `invitesError`   | An alert with "Try again" in place of the rows.      |
| Empty          | `invites={[]}`   | "No members yet" in place of the rows.               |
| Disabled       | `disabled`       | The screen is shown but can't be used.               |

### Form fields

| Name     | Control                  | Posted            |
| -------- | ------------------------ | ----------------- |
| `emails` | Email, several addresses | Always, as typed. |

### Sizing

| Container step           | Change                                                                |
| ------------------------ | --------------------------------------------------------------------- |
| `@sm` (`--container-sm`) | The masthead, the send button and the Continue row move onto one row. |
| `@md` (`--container-md`) | The title grows and the footer moves onto one row.                    |

### Composition

| Part                | Role                                                               |
| ------------------- | ------------------------------------------------------------------ |
| [Field](/en/field/) | The email field.                                                   |
| [List](/en/list/)   | The pending invites. Its "Invite member" button focuses the field. |

## Notes

- Presentational: no request, no router. The page that mounts it sends the invites and loads the list.
- The field does not check the addresses. Split `emails` on commas, check each one, and pass `emailsError` when one is wrong.
- `onNavigate` passes the click event: skip `metaKey`/`ctrlKey` clicks, then `preventDefault()` to route.
- The screen imports the List block from `@/components/blocks/…`; edit that line if your alias differs.
