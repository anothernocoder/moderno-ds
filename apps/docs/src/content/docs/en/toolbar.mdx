## Usage

A toolbar groups the controls of an editor in one bar: undo, redo, text style, zoom. Keyboard users reach the whole bar with one Tab and move between its items with the arrow keys.

<ForFramework fw="react">

```tsx
import { Toolbar } from "@moderno-ui/react";
```

```tsx
<Toolbar.Root aria-label="Canvas tools">
  <Toolbar.Button label="Undo" shortcut="⌘Z" onClick={undo}>
    <UndoIcon />
  </Toolbar.Button>
  <Toolbar.Separator />
  <Toolbar.Toggle label="Bold" pressed={bold} onPressedChange={setBold}>
    <BoldIcon />
  </Toolbar.Toggle>
</Toolbar.Root>
```

</ForFramework>

## API Reference

### Toolbar.Root

<PropsTable component="Toolbar" />

| Prop          | Type                         | Default        | Description                                                            |
| ------------- | ---------------------------- | -------------- | ---------------------------------------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Lays the items out in a row or a column, and picks the arrow keys.     |
| `size`        | `"sm" \| "md" \| "lg"`       | `"md"`         | Height of every item: Button's sizes.                                  |
| `dir`         | `"ltr" \| "rtl"`             | `"ltr"`        | Text direction. In `rtl` the Left and Right arrows swap.               |
| `aria-label`  | `string`                     | —              | Names the toolbar for screen readers, like `"Canvas tools"`. Required. |

### Toolbar.Button

| Prop       | Type      | Default | Description                                                                                          |
| ---------- | --------- | ------- | ---------------------------------------------------------------------------------------------------- |
| `label`    | `string`  | —       | Names an icon-only button. It is the `aria-label` and the text of the tooltip.                       |
| `shortcut` | `string`  | —       | A keyboard shortcut the tooltip shows in parentheses after the label.                                |
| `disabled` | `boolean` | `false` | The button stays in the arrow-key order and is announced as disabled, but pressing it has no effect. |

Every other prop, like `onClick`, goes to the `<button>`.

### Toolbar.Toggle

Takes `label`, `shortcut` and `disabled` like `Toolbar.Button`, plus:

| Prop              | Type                         | Default | Description                                            |
| ----------------- | ---------------------------- | ------- | ------------------------------------------------------ |
| `pressed`         | `boolean`                    | —       | Controlled pressed state. Pair with `onPressedChange`. |
| `defaultPressed`  | `boolean`                    | `false` | Initial pressed state when uncontrolled.               |
| `onPressedChange` | `(pressed: boolean) => void` | —       | Called with the new state when it is pressed.          |

In Vue, bind it with `v-model:pressed` or listen with `@pressed-change`. In Svelte, `bind:pressed` works.

### Toolbar.Group and Toolbar.Separator

`Toolbar.Group` holds related items. Give it an `aria-label`, like `"Text style"`. `Toolbar.Separator` draws a line between groups. Neither takes props of its own.

### Parts

| Part                | Element    | Description                                                                 |
| ------------------- | ---------- | --------------------------------------------------------------------------- |
| `Toolbar.Root`      | `<div>`    | `role="toolbar"` with `aria-orientation`. Carries `data-size`.              |
| `Toolbar.Button`    | `<button>` | One action. With a `label`, it shows a tooltip on hover and keyboard focus. |
| `Toolbar.Toggle`    | `<button>` | A button that stays pressed, with `aria-pressed`.                           |
| `Toolbar.Group`     | `<div>`    | `role="group"`: related items.                                              |
| `Toolbar.Separator` | `<div>`    | `role="separator"`, across the toolbar: upright in a row, flat in a column. |

Any other element inside the root, like a zoom readout, sits on the same line as the items.

### Keyboard

| Key                        | Action                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| `Tab`                      | Moves into the toolbar, to the item used last (the first at the start), and out again.   |
| `ArrowRight` / `ArrowLeft` | Next / previous item in a row. Wraps at the ends.                                        |
| `ArrowDown` / `ArrowUp`    | Next / previous item in a column. Wraps at the ends. In a row, `ArrowDown` opens a menu. |
| `Home` / `End`             | First / last item.                                                                       |
| `Enter`, `Space`           | Activates the focused item: runs a button, presses a toggle, opens a menu.               |

### Data attributes

| Attribute          | Values                                                                                       |
| ------------------ | -------------------------------------------------------------------------------------------- |
| `data-size`        | On the root: `"sm"`, `"md"` or `"lg"`                                                        |
| `data-orientation` | `"horizontal"` or `"vertical"`, on the root, items and groups; a separator's is its own axis |
| `data-state`       | On a toggle: `"on"` or `"off"`                                                               |
| `data-disabled`    | Present on a disabled item                                                                   |

### Menu

A `Toolbar.Button` inside `Menu.Trigger` opens a menu. It is still one of the toolbar's items, so the arrow keys move past it. `Enter` or `Space` opens the menu. In a row, `ArrowDown` opens it too; in a column, `ArrowDown` goes to the next item.
