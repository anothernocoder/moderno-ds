## Usage

A Carousel shows slides one page at a time. Use it when a few pictures, cards or quotes share one spot on the page. Previous and next buttons move a page, and each dot jumps to its page.

<ForFramework fw="react">

```tsx
import { Carousel } from "@moderno-ui/react";
```

```tsx
<Carousel.Root slideCount={slides.length}>
  <Carousel.ItemGroup>
    {slides.map((slide, index) => (
      <Carousel.Item key={slide.id} index={index}>
        <img src={slide.src} alt={slide.alt} />
      </Carousel.Item>
    ))}
  </Carousel.ItemGroup>
  <Carousel.Control>
    <Carousel.PrevTrigger>‹</Carousel.PrevTrigger>
    <Carousel.IndicatorGroup>
      {slides.map((slide, index) => (
        <Carousel.Indicator key={slide.id} index={index} />
      ))}
    </Carousel.IndicatorGroup>
    <Carousel.NextTrigger>›</Carousel.NextTrigger>
  </Carousel.Control>
</Carousel.Root>
```

</ForFramework>

`slideCount` is how many slides you render. Give each `Carousel.Item` its `index`, from 0. Pages start at 0 too.

## API Reference

### Carousel.Root

`size` is the Moderno addition; the triggers, dots and progress text follow it. The other props come from Ark's Carousel.

<PropsTable component="Carousel" />

| Prop             | Type                                                         | Default        | Description                                                              |
| ---------------- | ------------------------------------------------------------ | -------------- | ------------------------------------------------------------------------ |
| `slideCount`     | `number`                                                     | —              | Required. How many slides there are.                                     |
| `slidesPerPage`  | `number`                                                     | `1`            | How many slides show at once.                                            |
| `slidesPerMove`  | `number \| "auto"`                                           | `"auto"`       | How many slides one step moves. `"auto"` moves a whole page.             |
| `spacing`        | `string`                                                     | `"0px"`        | The gap between slides, as a CSS length.                                 |
| `padding`        | `string`                                                     | —              | Space at each end, so the next slide peeks in.                           |
| `page`           | `number`                                                     | —              | Controlled current page, from 0.                                         |
| `defaultPage`    | `number`                                                     | `0`            | Page at first, when uncontrolled.                                        |
| `onPageChange`   | `(details: { page: number; pageSnapPoint: number }) => void` | —              | Called when the page changes.                                            |
| `loop`           | `boolean`                                                    | `false`        | Go from the last page back to the first. On by default with `autoplay`.  |
| `autoplay`       | `boolean \| { delay: number }`                               | `false`        | Move on every 4 seconds, or every `delay` ms. Held under reduced motion. |
| `allowMouseDrag` | `boolean`                                                    | `false`        | Let a mouse drag the slides, not only a touch.                           |
| `orientation`    | `"horizontal" \| "vertical"`                                 | `"horizontal"` | Which way the slides scroll.                                             |
| `translations`   | `IntlTranslations`                                           | —              | What a screen reader says for each slide, dot and trigger.               |

In Vue, bind the page with `v-model:page`, and listen with `@page-change`.

### Parts

| Part                         | Element    | Description                                                        |
| ---------------------------- | ---------- | ------------------------------------------------------------------ |
| `Carousel.Root`              | `<div>`    | The region a screen reader calls a carousel. Carries `data-size`.  |
| `Carousel.ItemGroup`         | `<div>`    | Scrolls the slides and snaps to each page.                         |
| `Carousel.Item`              | `<div>`    | One slide. Takes its `index`, from 0.                              |
| `Carousel.Control`           | `<div>`    | Holds the triggers and the dots in a centred row.                  |
| `Carousel.PrevTrigger`       | `<button>` | Goes one page back. Off on the first page, unless it loops.        |
| `Carousel.NextTrigger`       | `<button>` | Goes one page on. Off on the last page, unless it loops.           |
| `Carousel.IndicatorGroup`    | `<div>`    | Holds the dots. Arrow keys move between pages here.                |
| `Carousel.Indicator`         | `<button>` | One dot per page. Takes its page `index`.                          |
| `Carousel.AutoplayTrigger`   | `<button>` | Optional. Starts and stops autoplay.                               |
| `Carousel.AutoplayIndicator` | `<span>`   | Optional. Shows its content while playing, `fallback` when paused. |
| `Carousel.ProgressText`      | `<span>`   | Optional. The page as text, like "2 / 5".                          |
| `Carousel.Context`           | —          | Hands you the carousel: `page`, `pageSnapPoints`, `isPlaying`.     |

### Data attributes

| Attribute      | Values                                 |
| -------------- | -------------------------------------- |
| `data-current` | On the current page's dot              |
| `data-inview`  | On each slide in view                  |
| `data-pressed` | On the autoplay trigger while it plays |
| `data-index`   | On each slide and dot: its index       |
| `data-size`    | On the root: `"sm"`, `"md"` or `"lg"`  |

## Notes

- `Carousel.Root` is wrapped to add `size` and to respect reduced motion; every other part is Ark's unchanged.
- When the reader prefers reduced motion, `autoplay` does not start, and the buttons and dots do not animate. The reader can still start autoplay with `Carousel.AutoplayTrigger`.
- A carousel takes the width of its container. Give a vertical one a height.
- In a right-to-left page the slides run from the right. Pass the mirrored glyphs, `›` for previous and `‹` for next.
