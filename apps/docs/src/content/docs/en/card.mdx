## API Reference

### Card.Root

<PropsTable component="Card" />

### Parts

The parts other than `Card.Root` take only native attributes.

| Part               | Element | Description                                                      |
| ------------------ | ------- | ---------------------------------------------------------------- |
| `Card.Root`        | `div`   | The surface. Takes `variant` and `size`.                         |
| `Card.Header`      | `div`   | Holds the title and description.                                 |
| `Card.Title`       | `h3`    | The card's heading. Pass `role`/`aria-level` to change its rank. |
| `Card.Description` | `p`     | The muted line under the title.                                  |
| `Card.Content`     | `div`   | The body. The only part that grows, so footers in a row line up. |
| `Card.Footer`      | `div`   | The actions row.                                                 |

### Data attributes

| Attribute      | On         | Values                                                        |
| -------------- | ---------- | ------------------------------------------------------------- |
| `data-scope`   | Every part | `card`                                                        |
| `data-part`    | Every part | `root`, `header`, `title`, `description`, `content`, `footer` |
| `data-variant` | Root       | `outline` (default), `muted`, `ghost`                         |
| `data-size`    | Root       | `sm`, `md` (default), `lg`                                    |

## Notes

- Adjacent parts share one padding step instead of stacking two.
- The root fills its container; the grid or flex row belongs to the page.
- Depth is a surface step and a border, never a shadow.
- The corner is `--radius`, so a theme that pins it to 0 gives square cards.
