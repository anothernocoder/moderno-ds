## API Reference

### Props

| Prop        | Type                   | Default       | Description                                                           |
| ----------- | ---------------------- | ------------- | --------------------------------------------------------------------- |
| `banners`   | `AppBannerItem[]`      | a sample list | The banners, top to bottom. `[]` renders nothing.                     |
| `error`     | `string`               | —             | The banners failed to load; an alert with a retry replaces them.      |
| `loading`   | `boolean`              | `false`       | One skeleton banner in a busy region replaces them.                   |
| `disabled`  | `boolean`              | `false`       | The banners stay readable and every button is disabled.               |
| `onAction`  | `(id: string) => void` | —             | A banner's action was pressed. Svelte: `onaction`. Vue: `@action`.    |
| `onDismiss` | `(id: string) => void` | —             | A banner's dismiss was pressed. Svelte: `ondismiss`. Vue: `@dismiss`. |
| `onRetry`   | `() => void`           | —             | "Try again" after `error`. Svelte: `onretry`. Vue: `@retry`.          |

### AppBannerItem

| Field         | Type                                       | Description                                               |
| ------------- | ------------------------------------------ | --------------------------------------------------------- |
| `id`          | `string`                                   | Stable identity, reported by `onAction` and `onDismiss`.  |
| `kind`        | `"impersonation" \| "trial" \| "incident"` | The tint and the icon: warning, info or error.            |
| `title`       | `string`                                   | The banner's message, like "12 days left in your trial".  |
| `description` | `string`                                   | Optional. One line more, like what happens when it ends.  |
| `actionLabel` | `string`                                   | Optional. The action button's label, like "Upgrade".      |
| `dismissible` | `boolean`                                  | Optional. Adds a dismiss button labelled with the banner. |

### States

| State    | Prop           | What renders                                                   |
| -------- | -------------- | -------------------------------------------------------------- |
| Default  | —              | One tinted banner per item, each with its action and dismiss.  |
| Empty    | `banners={[]}` | Nothing: the block takes no space.                             |
| Loading  | `loading`      | One skeleton banner in a busy `status` region.                 |
| Error    | `error`        | One error alert with a "Try again" button in place of banners. |
| Disabled | `disabled`     | The banners with every button disabled.                        |

### Sizing

| Container step           | What changes                                                 |
| ------------------------ | ------------------------------------------------------------ |
| below `@sm`              | The action and dismiss buttons sit under the message.        |
| `@sm` (`--container-sm`) | The buttons move beside the message.                         |
| `@md` (`--container-md`) | The title and description share one line.                    |
| `@lg` (`--container-lg`) | Each dismiss button shows its "Dismiss" label next to the ×. |

## Notes

- Presentational: it changes nothing itself. Remove a banner in `onDismiss`.
- Put it once, above the page content, so every page shows the same banners.
