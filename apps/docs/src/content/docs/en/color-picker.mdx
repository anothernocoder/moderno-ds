<Install pkg="@moderno-ui/react" />

## Usage

Use a color picker when the user chooses a colour, like a brand colour. The button shows the colour and its hex. It opens a panel with an area, sliders and a hex box.

<ForFramework fw="react">

```tsx
import { ColorPicker } from "@moderno-ui/react";
```

```tsx
<ColorPicker defaultValue="#1E90FF" onValueChange={(details) => save(details.value)} />
```

</ForFramework>

<ForFramework fw="vue">

```ts
import { ColorPicker } from "@moderno-ui/vue";
```

```vue
<ColorPicker v-model="color" />
```

</ForFramework>

<ForFramework fw="svelte">

```ts
import { ColorPicker } from "@moderno-ui/svelte";
```

```svelte
<ColorPicker bind:value={color} />
```

</ForFramework>

<ForFramework fw="solid">

```tsx
import { ColorPicker } from "@moderno-ui/solid";
```

```tsx
<ColorPicker defaultValue="#1E90FF" onValueChange={(details) => save(details.value)} />
```

</ForFramework>

The value is a hex string: `#RRGGBB`, or `#RRGGBBAA` when the colour is see-through.

## API Reference

### ColorPicker

<PropsTable component="ColorPicker" />

It also takes these props of Ark's ColorPicker:

| Prop            | Type                          | Default | Description                                                                 |
| --------------- | ----------------------------- | ------- | --------------------------------------------------------------------------- |
| `open`          | `boolean`                     | —       | Controlled open state. Pair with `onOpenChange`.                            |
| `defaultOpen`   | `boolean`                     | `false` | Open state at first when uncontrolled.                                      |
| `onOpenChange`  | `(details: { open }) => void` | —       | Called when the popover opens or closes.                                    |
| `closeOnSelect` | `boolean`                     | `false` | Closes the popover when a swatch is picked.                                 |
| `disabled`      | `boolean`                     | `false` | Turns the picker off.                                                       |
| `readOnly`      | `boolean`                     | `false` | Shows the colour but the user cannot change it.                             |
| `invalid`       | `boolean`                     | `false` | Marks the value as wrong: the trigger's border turns `--destructive`.       |
| `positioning`   | `PositioningOptions`          | —       | Where the popover goes: `placement` (`"bottom-start"`), `gutter`, `flip`, … |

In Vue, bind the value with `v-model` and listen with `@value-change`. In Svelte, use `bind:value`.

### Parts

| Part                   | Element    | Description                                                 |
| ---------------------- | ---------- | ----------------------------------------------------------- |
| `root`                 | `<div>`    | Holds the trigger and the popover. Carries `data-size`.     |
| `trigger`              | `<button>` | Opens the popover. Shows the swatch and the hex.            |
| `swatch`               | `<div>`    | A colour chip, over a checkerboard when see-through.        |
| `value-text`           | `<span>`   | The hex, in the trigger.                                    |
| `content`              | `<div>`    | The popover, `role="dialog"`.                               |
| `area`                 | `<div>`    | Saturation (across) and brightness (up).                    |
| `area-thumb`           | `<div>`    | The area's 2D slider, named "Saturation and brightness".    |
| `channel-slider`       | `<div>`    | A slider. `data-channel="hue"`, or `"alpha"` with `alpha`.  |
| `channel-slider-thumb` | `<div>`    | The slider's thumb, named "Hue" or "Alpha".                 |
| `hex-input`            | `<input>`  | The hex box.                                                |
| `eye-dropper-trigger`  | `<button>` | Picks a colour from the screen. Only where the browser can. |
| `swatch-group`         | `<div>`    | The preset swatches.                                        |
| `swatch-trigger`       | `<button>` | One preset. `data-state="checked"` when it is the value.    |

### Keyboard

| Key                     | Action                                                            |
| ----------------------- | ----------------------------------------------------------------- |
| `Enter` / `Space`       | On the trigger, opens the popover.                                |
| `Arrow keys`            | In the area, change saturation and brightness. On a slider, move. |
| `Page Up` / `Page Down` | Move by a larger step.                                            |
| `Home` / `End`          | On a slider, go to the start or the end.                          |
| `Enter`                 | In the hex box, takes the typed hex.                              |
| `Esc`                   | Closes the popover and moves focus to the trigger.                |

## Notes

- The hex box takes `#RGB`, `#RRGGBB` or `#RRGGBBAA`, with or without `#`. A hex that is not valid is dropped when the box loses focus.
- The eyedropper appears only in browsers with the EyeDropper API.
- Rename the parts for a screen reader with `translations`, for example `{ hue: "Tono" }`.
