Only `Checkbox.Root` is wrapped, to inject the `size` recipe's `data-size`;
every other part is Ark's verbatim. The root is a `<label>` bound to a visually
hidden native `<input type="checkbox">`, so forms, `name`/`value` and screen
readers work with no extra wiring, and `components.css` paints the control from
Ark's `data-state="checked|unchecked|indeterminate"` plus
`data-disabled`/`data-invalid`.
