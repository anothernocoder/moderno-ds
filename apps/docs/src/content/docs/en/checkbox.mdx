## API Reference

### Checkbox.Root

`size` is the Moderno addition and defaults to `md`; the other props come from Ark's Checkbox.

<PropsTable component="Checkbox" />

| Prop              | Type                             | Default | Description                                                         |
| ----------------- | -------------------------------- | ------- | ------------------------------------------------------------------- |
| `checked`         | `boolean \| "indeterminate"`     | —       | Controlled state. Pair with `onCheckedChange`.                      |
| `defaultChecked`  | `boolean \| "indeterminate"`     | `false` | Initial state when uncontrolled.                                    |
| `onCheckedChange` | `(details: { checked }) => void` | —       | Called when the state changes.                                      |
| `disabled`        | `boolean`                        | `false` | Disables the hidden input and dims every part.                      |
| `invalid`         | `boolean`                        | `false` | Sets `aria-invalid` and re-colours the border from `--destructive`. |
| `required`        | `boolean`                        | `false` | Marks the input as required.                                        |
| `name`            | `string`                         | —       | Form field name.                                                    |
| `value`           | `string`                         | `"on"`  | Value submitted with the form when checked.                         |

### Checkbox.Indicator

| Prop            | Type      | Default | Description                                                          |
| --------------- | --------- | ------- | -------------------------------------------------------------------- |
| `indeterminate` | `boolean` | `false` | Show this indicator in the mixed state instead of the checked state. |

### Parts

| Part                   | Element                   | Description                                                                            |
| ---------------------- | ------------------------- | -------------------------------------------------------------------------------------- |
| `Checkbox.Root`        | `<label>`                 | Carries `data-size`; clicking anywhere on it toggles the box.                          |
| `Checkbox.Control`     | `<div>`                   | The visible box.                                                                       |
| `Checkbox.Indicator`   | `<div>`                   | The glyph; shown only in its state.                                                    |
| `Checkbox.Label`       | `<span>`                  | The text beside the box.                                                               |
| `Checkbox.HiddenInput` | `<input type="checkbox">` | Visually hidden native input that carries focus, `name` and `value`. Always render it. |

### Data attributes

| Attribute       | Values                                                         |
| --------------- | -------------------------------------------------------------- |
| `data-state`    | `"checked"`, `"unchecked"` or `"indeterminate"`, on every part |
| `data-disabled` | Present while `disabled`                                       |
| `data-invalid`  | Present while `invalid`                                        |
| `data-size`     | On the root: `"sm"`, `"md"` or `"lg"`                          |

## Notes

- Only `Checkbox.Root` is wrapped, to add `size`; every other part is Ark's unchanged.
- Style state from `data-state` and the `data-*` flags; `size` is the only visual prop.
- The filled box uses `--primary` with the glyph on `--primary-foreground`; the resting border is `--input`.
